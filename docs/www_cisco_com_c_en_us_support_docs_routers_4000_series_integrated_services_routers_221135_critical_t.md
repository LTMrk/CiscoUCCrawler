## **Critical temperature condition is observed**
### **ICSeverity**
1 - Alert
### **Impact**
Rising temperature could cause device shutdown.
### **Description**
This message indicates that there is an environmental condition on the device. This could be the temperature readings at various sensors, power supply voltage readings, or RPMs on the various fans. Inside the message text, it can report which sensor or location has seen a condition, and the criticality of the reading.
### **SyslogMessage**

```
ENVIRONMENTAL-1-ALERT
```

### **MessageSample**

```
Oct  8 15:27:38 <> %ENVIRONMENTAL-1-ALERT: Temp: Inlet x Location: Rx State: Critical Reading: xx Celsius
```

### **ProductFamily**
  * Cisco 4000 Series Integrated Services Routers
  * Cisco cBR Series Converged Broadband Routers


### **Regex**
N/A
### **Recommendation**
Verify the cards, fans, and chassis status with show environment, show platform or show module, and show logging commands. You need to dispatch a local technician to verify the ambient temperature, airflow, and filter status on the device. Please engage with the support engineer if the issue persists.
### **Commands**
**`#show version`**
**`#show logging`**
**`#show module`**
**`#show environment all`**
**`#show platform`**
**`#show clock`**
**`#show inventory`**
