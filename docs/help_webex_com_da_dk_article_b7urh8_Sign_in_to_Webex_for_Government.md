# Log ind på Webex for forvaltninger
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
Du kan logge ind på Webex-appen via den version, der leveres af din administrator. Du kan også omdirigere den kommercielle Webex-app for at starte Webex for myndighederne. 
![Webex til offentlige desktop- og mobile log ind-skærme](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/460001-470000/468001-469000/468924.jpg)**_Webex til offentlige log ind-skærme_**
  * [Log ind på Webex for forvaltninger](https://help.webex.com/da-dk/article/b7urh8/Log-ind-p%C3%A5-Webex-for-forvaltninger#Cisco_Task.dita_d0324c16-0bb5-4191-afc9-ea8b5c379056)
  * [Skift fra kommerciel Webex-app](https://help.webex.com/da-dk/article/b7urh8/Log-ind-p%C3%A5-Webex-for-forvaltninger#Cisco_Task.dita_f8b28eb6-fe00-420f-87f4-406adb003ce9)


Din administrator kan levere en brugertilpasset installation af Webex-appen , der er forudkonfigureret for Webex, til forvaltninger.  
| 1  |  Start Webex-appen.  Login-skærmen viser FedRamp-logoet og Webex for forvaltninger, som er forhåndsvalgt.  |  
| --- | --- |  
| 2  |  Klik på Log ind, og angiv dine legitimationsoplysninger.  |  
Du kan skifte fra den kommercielle Webex-app til Webex for forvaltninger i Webex-appen.  
| 1  |  Start Webex-appen.  Login-skærmen viser Webex-logoet og Den valgte Webex .  |  
| --- | --- |  
| 2  |  Klik på pilen nedad ved siden af Webex, og vælg Webex som forvaltninger på listen. Webex-appen genstarter for at tage dig til FedRAMP-loginsiden.   |  
| 3  |  Indtast din e-mailadresse, og markér Jeg accepterer vilkår og betingelser, og klik derefter på Næste for at logge ind. Første gang du logger ind, skal du opsætte en adgangskode.  |
