## Background
"Power on hours" is an important metric for SSD lifespan determination. In order to identify the affected Solid State Drives(SSD), you will need to download 3rdparty utilities that will allow you to see the Power-On Hours(PoH)and in some cases the model#for the affected SSD. Below you will find the instructions on where to get the utilities and how to use them.
## Where to get the utilities
There are4different utilities to choose from depending on your OS and needs. Please review the below table.   
| **Tool**  | **Applicable OS's**  | **Tool Source**  |  
| --- | --- | --- |  
| SmartMon Tools  | Linux, Windows, VMware  | [https://sourceforge.net/projects/smartmontools/files/smartmontools/](https://sourceforge.net/projects/smartmontools/files/smartmontools/)  |  
| sg3_utils  | Linux, Windows  | [http://sg.danny.cz/sg/sg3_utils.html](http://sg.danny.cz/sg/sg3_utils.html)  |  
| SanDisk Tool  | Linux, Windows  | [https://kb.sandisk.com/app/answers/detail/a_id/18565/~/lightning-gen.-ii-ssd-drive-firmware](https://kb.sandisk.com/app/answers/detail/a_id/18565/~/lightning-gen.-ii-ssd-drive-firmware)  |  
| Storcli Utility  | All OS's  | <https://docs.broadcom.com/docs/007.1410.0000.0000_Unified_StorCLI.zip>  |  
## Steps on how to use each utility.
Each utility requires some knowledge on installing software in Linux, VMware and Windows. Be sure to read any readme files before installing.
### SmartMonTools for Windows - JBOD mode
**Note:** If you are using a RAID controller, you cannot collect this data through Windows
  1. **Installation:**
    1. Go the download link posted in the table above and download and install the smartmontools utility
    2. Get the smartctl Windows setup file through above link.
    3. Execute the setup file:  

```
smartmontools-7.1-1.win32-setup.exe 
```

    4. Open the command prompt
    5. Go to folder:  

```
C:\Program Files\smartmontools\bin
```

  2. **Check Drive Firmware Version:**
    1. Run below command to get the device name of target drive.  

```
smartctl –scan 
```
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-00.png "Related image, diagram or screenshot.")  
[jbod windows smartmon fw 1]
    2. Read drive firmware version as below:  

```
smartctl -i /dev/sdc 
```
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-01.png "Related image, diagram or screenshot.")  
[jbod windows smartmon fw 2]
  3. Check Power On Hours: 
    1. Once installed, you will be using the ‘smartctl’ utility within the smartmontools package.
    2. Open up CMD, go to the smartmontools directory and find the list of SSDs by typing:  

```
smartctl.exe --scan 
```

    3. Once you identify which SSD you want to check, you can then type the following two commands in order to get the output needed (where X is the drive letter you wish to check😞  

```
smartctl -t short /dev/sdX – Wait 10 seconds before running the second command 
smartctl -l selftest /dev/sdX
```

    4. Look for the “Lifetime” hours from the 1st line. That will be the latest record of PoH.  
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-02.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-02.jpeg "Related image, diagram or screenshot.")  
[jbod windows smartmon]

### SmartMonTools for Linux - RAID mode
  1. Installation 
    1. You will need to install both smartmontools and storcli utility to collect the data.
    2. Go the download link posted in the table above and download and install the smartmontools utility 
    3. Get the smartctl installation file Linux version through above link.
    4. Untar the installation file.  

```
tar -zxvf smartmontools-7.1.tar.gz 
```

    5. Go to folder:  

```
smartmontools-7.1
```

    6. Run below commands in order.  

```
./configure 
make 
make install 
```

    7. Now go to the download link posted in the table above and download and install the storcli utility.
    8. To identify the drive you want to check, go to the storcli directory and type the command:  

```
storcli /c0/eall/sall show 
```

    9. Look for the Device ID(DID). The Device ID will be needed in the future steps.  
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-17.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-17.png "Related image, diagram or screenshot.")  
[raid linux smartmon fw 1]
  2. Check Drive Firmware Version
    1. ‘148’ in below command is the device ID (DID) of target drive. And ‘sdc’ is its device name.  

```
smartctl -d megaraid,148 -i /dev/sdc 
```
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-18.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-18.png "Related image, diagram or screenshot.")  
[raid linux smartmon fw 2]
  3. Check Power On Hours
    1. Once you identify which SSD you want to check, you can then type the following two commands in order to get the output needed (where X is the Device ID you got from step 4😞  
Note: In order for this to work, you need to make sure and use the ‘**megaraid** ’switch in the command when using a RAID set. Otherwise it won’t work.  

```
smartctl -d megaraid,N -t short /dev/sdX – Wait 10 seconds before running the second command 
smartctl -d megaraid,N -l selftest /dev/sdX 
```

    2. Look for the “Lifetime” hours from the 1st line. That will be the latest record of PoH.  
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-19.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/215834-identifying-power-on-hours-for-ssd-drive-19.jpeg "Related image, diagram or screenshot.")  
[raid linux smartmon]
