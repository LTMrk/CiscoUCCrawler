# Centrul de date Singapore pentru Webex Calling
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Centrul de date Webex Calling Singapore Media Pop oferă servicii edge, servicii media și interconexiuni cu parteneri precum Cloud-Connected PSTN (CCPP) către locații ale clienților din țările din Asia de Sud-Est. 
## Specificatii
  * Centrul de date din Singapore are scopul de a oferi o calitate media optimă tuturor clienților cu locații din țările din Asia de Sud-Est, indiferent de locul în care se află. 
  * Găzduirea pentru clienții Webex Calling nu este furnizată. Acești clienți pot fi găzduiți în orice alt centru de date Webex Calling și pot profita în continuare de calitatea media oferită de Singapore Media POP. 
  * Clienții cu locații în țările din Asia de Sud-Est se vor conecta automat la Singapore Media POP ca cea mai apropiată margine de rețeaua Webex. 
Acești clienți ar trebui să ia în considerare furnizarea de servicii PSTN de la CCPP interconectate în Singapore Media POP pentru a asigura cea mai bună performanță. 
  * Serviciile media furnizate de Singapore Media POP sunt redundante. Failover pentru Singapore Media POP este furnizat prin intermediul centrelor de date Webex Calling din Japonia pentru a asigura redundanța completă. În timpul failover, latența media poate crește temporar, deși acest lucru apare rar și este scurt.
