## Introduction
This document describes the installation guide for Cisco ISR-WAAS on Cisco Integrated Services Router (ISR). It is the implementation of virtual Wide Area Application Services (vWAAS) on a Cisco ISR.
ISR-WAAS is deployed inside an IOS-XE container. A container in this context, refers to the hypervisor that runs virtualized applications on a Cisco ISR 4000 Series router.
## ISR-WAAS Installation Prerequisites
Each WAAS software version can have different resource requirements (Memory, CPU, and Solid State Drives (SSD) ), if you do not meet the requirements, it can lead to performance issues or even errors during installation.
Please review the configuration guide at this link:
[https://www.cisco.com/c/en/us/support/routers/virtual-wide-area-application-services-vwaas/products-installation-and-configuration-guides-list.html ](https://www.cisco.com/c/en/us/support/routers/virtual-wide-area-application-services-vwaas/products-installation-and-configuration-guides-list.html)
This table summarizes the resource requirements and supported ISR platforms for each ISR model.

## Difference between NIM-SSD and ISR-SSD
### NIM-SSD
NIM-SSD is the one that is located outside of ISR and is hot swappable.
[![213851-isr-waas-installation-guide-on-isr-4000-01.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-01.png "213851-isr-waas-installation-guide-on-isr-4000-01.png")
This is a module that gets installed in one of the available Network Interface Modules (NIM) of ISR Routers.
These are Product Identifiers (PIDs) for the NIM-SSD and SSD that can be used to raise RMA:

```
NIM-SSD(=)NIM Carrier Card for SSD drives
SSD-SATA-200G(=)200 GB, SATA Solid State Disk for NIM-SSD
```

In order to remove the NIM-SSD or NIM-HDD from the Router, follow these steps:
Step 1. Use a Phillips screwdriver to loosen the captive screws on either side, as shown in this image:
[![213851-isr-waas-installation-guide-on-isr-4000-02.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-02.png "213851-isr-waas-installation-guide-on-isr-4000-02.png")
Step 2. Remove the NIM-SSD or NIM-HDD from the route, as shown in this image:
[![213851-isr-waas-installation-guide-on-isr-4000-03.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-03.png "213851-isr-waas-installation-guide-on-isr-4000-03.png")
### ISR-SSD
ISR-SSD on the other hand is installed inside the router chassis, you need to power down the router, open its cover to locate the ISR-SSD.
The ISR-SSD is not hot swappable.
This is PID for the ISR-SSD on ISR 4300 series that can be used to raise RMA:

```
SSD-MSATA-200G(=)200 GB, mSATA Solid State Disk 
```

This image shows Flash Memory Card and SSD mSATA Storage Device Locations :
[![213851-isr-waas-installation-guide-on-isr-4000-04.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-04.png "213851-isr-waas-installation-guide-on-isr-4000-04.png")
## ISR-WAAS Installation
Once you meet all the requirements for the installation of ISR-WAAS, the next step is to download an Open Virtualization Appliance (OVA) file of the ISR-WAAS version you intend to deploy. You can download software from this link:
<https://software.cisco.com/download/home/280484571/type/280836712>
Once you have downloaded the software, you need to transfer the file to the bootflash of the router :
[![213851-isr-waas-installation-guide-on-isr-4000-05.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-05.png "213851-isr-waas-installation-guide-on-isr-4000-05.png")
On the router CLI, please follow these steps to deploy ISR-WAAS use the EZConfig program:
  1. Run the Service WAAS enable command.
  2. Select the previously transferred .ova image for the WAAS version you wish to deploy.
  3. Select the WAAS profile you want to deploy.
  4. Configure the ISR-WAAS IP address.
  5. Configure the WAAS central manager IP address.


[![213851-isr-waas-installation-guide-on-isr-4000-06.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-06.png "213851-isr-waas-installation-guide-on-isr-4000-06.png")
  1. Select the Wide Area Network (WAN) interface on the router where you would like to enable WAAS interception.
  2. Save the configuration after you have finished. This is the image from successful installation.


[![213851-isr-waas-installation-guide-on-isr-4000-07.png](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-07.png)](https://www.cisco.com/c/dam/en/us/support/docs/routers/4000-series-integrated-services-routers/213851-isr-waas-installation-guide-on-isr-4000-07.png "213851-isr-waas-installation-guide-on-isr-4000-07.png")

### SSD Failure Scenario
In some cases if the SSD is faulty, while you run commands related to hard disk and file system, you see these errors.

```
 “request platform hardware filesystem harddisk: destroy”
  %This operation can take some time, please be patient
   %Harddisk not present. Destroy filesystem aborted.

 
```

To resolve it, you can try these steps:
Step 1. Try to reseat the SSD.
Step 2. Reboot the router.
Step 3. If those steps failed, just RMA the SSD.
