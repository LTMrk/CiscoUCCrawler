Migrar do Ferramentas de Produtividade para o add-In do Agendador Webex
![list-menu](https://help.webex.com/images/feedback.svg)Comentários?
Recomendamos que os clientes que desejam agendar reuniões de equipe Webex a partir do Outlook comece a usar o add-in Webex Scheduler, que substituirá Ferramentas de Produtividade futuramente. Siga estes passos para uma migração tranquila Ferramentas de Produtividade para o novo complemento do Agendador Webex. 
## Migrar para o complemento do Agendador Webex
  1. [Instale o Agendador Webex para Microsoft 365 ou Exchange local](https://help.webex.com/pt-br/ngjh53x/).
  2. [Implante e configure o Agendador Webex para Microsoft 365 ou Exchange local](https://help.webex.com/pt-br/pzti9s/).


## Desinstalar o Ferramentas de Produtividade
  1. Para administradores de IT, _consulte a seção Configurar e remover o aplicativo de desktop Webex e Ferramentas de Produtividade no Mac_ [do guia do administrador de IT para implantação em massa da área de trabalho Webex Meetings e do Ferramentas de Produtividade](https://www.cisco.com/c/dam/en/us/td/docs/collaboration/webex_centers/esp/cisco_webex_meetings_it_administrator_mass_deployment_guide.pdf).
  2. [Desinstalar as Ferramentas de Produtividade do Webex para os usuários](https://help.webex.com/pt-br/1akczh/).


## O que fazer em seguida:
  * [Agende e participe de reuniões com o Webex Scheduler para Microsoft Office 365](https://help.webex.com/pt-br/nttajz6/).
  * [Comparação de recursos do Webex Scheduler para Microsoft Office](https://help.webex.com/pt-br/0v1jpm/).
  * [Problemas conhecidos e limitações do Agendador Webex para Microsoft Office](https://help.webex.com/pt-br/n194fs/)


Se você for um cliente TMS-XE que está usando o Ferramentas de Produtividade para agendar e receber o One Button to Push (OBTP) para dispositivos de vídeo gerenciados no local, deverá mudar para uma nova solução OBTP. TMS-XE não é suportado com o complemento do Agendador Webex. Para obter mais informações, consulte o [TelePresence Management Suite Extension para Microsoft Exchange 5.13 notas de versão](https://www.cisco.com/c/dam/en/us/td/docs/telepresence/infrastructure/tmsxe/release_note/Cisco-TMSXE-Release-Notes-5-13.pdf).
