Abonner
Fejl: "Kørselsfejl for Microsoft Visual C++ Runtime Library", når du deltager i et møde
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
**PROBLEM**  
Brugere støder på "Microsoft Visual C++ Runtime Library Runtime Error" ved forsøg på at starte eller deltage i et møde.  
  
**LØSNING**  
**Opdater det visuelle C++ Runtime-bibliotek**
  1. Download og installer den nyeste visuelle version [C++ runtime-bibliotek fra Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170).


Hvis du ikke har rettighederne til at installere software, skal du kontakte din IT-afdeling for at få hjælp.
  1. Genstart din computer efter installationen og forsøg at deltage i Webex-mødet igen.


Hvis fejlen fortsætter, skal du gå videre til den næste løsning.  
  
**Installer de seneste opdateringer til Windows** s
  1. Sørg for, at dit Windows-operativsystem er opdateret med de seneste programrettelser og opdateringer.
  2. Genstart din computer efter installation af opdateringer.
  3. Prøv at deltage i mødet en gang til.


Yderligere oplysninger og mulige løsninger findes i Microsoft Knowledge Base-artiklen på [<http://support.microsoft.com/kb/822521>]. Hvis problemet fortsætter efter disse trin, kan yderligere undersøgelse være nødvendig for at isolere årsagen og finde en passende løsning.
**ÅRSAG**  
Du modtager muligvis en runtime-fejl, når du starter eller deltager i et møde, hvis Microsoft Visual C++ Runtime-biblioteker mangler eller er beskadiget. Fejlen vil angive "Dette program har anmodet om, at Runtime afsluttes på en usædvanlig måde".
