Overview
EOL15634 - Amended
Cisco announces the end-of-sale and end-of-life dates for the Cisco Meeting Server 1000 M6. The last day to order the affected product(s) is September 15, 2025. Customers with active service contracts will continue to receive support from the Cisco Technical Assistance Center (TAC) as shown in Table 1 of the EoL bulletin. Table 1 describes the end-of-life milestones, definitions, and dates for the affected product(s). Table 2 lists the product part numbers affected by this announcement. For customers with active and paid service and support contracts, support will be available under the terms and conditions of customers' service contract. 
The Cisco Meeting Server 1000 M6 was based upon Intel chipsets that have been superseded. Therefore, the Cisco Meeting Server 1000 M6 is being superseded by the Cisco Meeting Server Small M7 (CMS-S-M7-K9). Cisco Meeting Server 1000 M6 is only affected by this notice. The Cisco Meeting Server conferencing application is not part of this notice.
