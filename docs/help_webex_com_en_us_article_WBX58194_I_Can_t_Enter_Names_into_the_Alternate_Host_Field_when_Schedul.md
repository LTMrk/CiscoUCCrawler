I Can't Enter Names into the Alternate Host Field when Scheduling a Meeting using Webex Desktop App
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
You must enter email addresses into the To: field in the Outlook appointment before you can select an Alternate host. 
## I can't enter names into the Alternate host field when scheduling a meeting using Webex Desktop App.
## I am unable to enter an alternate host when scheduling a meeting using in Outlook.
## The Alternate host button is grayed out when scheduling a meeting using Webex Desktop App.
  
**Solution:**
You must enter email addresses into the To: field in the Outlook appointment before you can select an Alternate host.
**To resolve the issue:**
  1. In the _Webex Settings_ window, click the **OK** button.
  2. In the Outlook appointment window, enter the alternate host's email address in the _To:_ field. 
  3. Click the **Change Settings** button.  
  
The 'Webex Settings' window appears.  

  4. Go to the **Resources** tab.
  5. In the _Alternate host:_ section, check the box beside the person you would like to make an alternate host.
  6. Click the **OK** button.
