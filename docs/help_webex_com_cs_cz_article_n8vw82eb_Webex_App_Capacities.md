# Kapacity aplikací | Webex
![list-menu](https://help.webex.com/images/feedback.svg)Zpětná vazba?
Chcete vědět, jak daleko můžete posouvat věci v Aplikaci Webex? Ne všechny vaše možnosti jsou nekonečné (i když některé jsou). Podívejte se na kapacity a pokyny pro prostory, zprávy, soubory nebo schůzky v Aplikaci Webex. 
## Týmy  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Týmy na organizaci  |  Bez omezení  |  
|  Členové týmu  |  5000  |  
## Prostory  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Prostory na organizaci  |  Bez omezení  |  
|  Prostory na tým  |  Bez omezení  |  
|  Vesmírný obrázek  |  Velikost souboru: 10 MB nebo méně. Typy souborů: .jpg, .png, .gif nebo .bmp  |  
|  Vesmírní účastníci  |  5000  |  
|  Počet zpráv na mezeru  |  Bez omezení  |  
## Soubory a tabule  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Tabule na mezeru   |  Bez omezení  |  
|  Počet souborů na prostor  |  Bez omezení  |  
|  Náhled souborů v prostoru  |  Velikost souboru: 100 MB nebo méně Soubor má méně než 50 stránek Typ souboru: .doc, .docx, .gif, .jpeg, .pdf, .png, .ppt, .pptx, .xls a .xlsx  |  
## Filtry  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Oblíbené prostory  |  Bez omezení  |  
|  Uvedené zmínky  |  50  |  
|  Zprávy označené příznakem  |  200  |  
|  Koncepty zpráv  |  Bez omezení  |  
## Zpráva  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Velikost zprávy na příspěvek   |  5400 znaků  |  
|  Počet souborů, které můžete přidat do jedné zprávy.  |  10 souborů ve Windows, Mac, iOS a na webu. 5 souborů v systému Android.  |  
|  Velikost souboru  |  2GB  |  
|  Automatické přehrávání GIF  |  2MB  |  
## Profilový obrázek  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Velikost souboru  |  10 MB nebo méně  Aplikace Webex změní velikost profilového obrázku tak, aby se v aplikaci Webex používal v různých oblastech. V ideálním případě by měl být váš profilový obrázek čtvercový v rozmezí 200x200 až 1000x1 000 pixelů.  |  
|  Typ souboru  |  .jpg, .png, .gif nebo .bmp  |  
## Schůzky  
|  Funkce  |  Maximální limit  |  
| --- | --- |  
|  Schůzky – bezplatné účty aplikace Webex nebo účty aplikace Webex pouze pro zasílání zpráv  |  100  |  
|  Schůzky – Placené volání Webex nebo účet aplikace Webex  |  150  |  
|  Schůzky – hostitelský účet webex Meetings nebo licence aplikace Webex pro základní schůzky (M2)   |  200  |
