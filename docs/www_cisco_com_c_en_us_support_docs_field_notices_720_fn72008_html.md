### Problem Description
Cisco Unity Connection releases listed in the Products Affected section require Adobe Flash and some functionality will no longer work as of 2021-01-01.
### Background
In accordance with [Adobe’s End-of-Life announcement](https://www.adobe.com/products/flashplayer/end-of-life.html), Adobe might block Flash-based content and will no longer distribute or support Flash software after 2020-12-31. In addition, third-party software updates from operating system vendors and/or browser vendors might also block Flash-based content after 2020-12-31.
Even if Flash-based content works normally after 2020-12-31, the lack of Flash maintenance updates from Adobe introduces various levels of risk that administrators should evaluate.
Cisco has migrated from Flash to alternate technologies. Refer to the Workaround/Solution section for specific details on this product.
### Problem Symptom
After 2020-12-31, if Adobe Flash-based content is blocked or if Flash cannot be downloaded or installed, affected products might lose full functionality.
If Adobe Flash-based content is enabled on a system with Flash already installed, affected products might or might not continue to operate normally after 2020-12-31, depending on the organization’s operating system and browser environments.
Cisco Unity Connection Web Inbox users will not be able to record their voice messages.
### Workaround/Solution
Upgrade Cisco Unity Connection software to either [Release 11.5(1)SU8](https://software.cisco.com/download/home/286286362/type/282074295/release/11.5\(1\)SU8 "Unity Connection Version 11.x Software Download") or [Release 12.5(1)SU3](https://software.cisco.com/download/home/286313379/type/286319533/release/12.5\(1\)SU3 "Unity Connection Version 12.x Software Download") as soon as possible in order to avoid disruption after December 2020.
