# 在安排培训课程时添加测验
![list-menu](https://help.webex.com/images/feedback.svg)反馈？
在安排培训课程时，添加测试可评估与会者的知识。 
在培训课程安排过程中，您只能添加已创建并保存在“测验题库”中的测验。   
| 1  |  选择测验 > 添加测验。   |  
| --- | --- |  
| 2  |  选择一个测验作为新测验的模板，然后选择下一步。   |  
| 3  |  输入新测验的名称，选择测验提供方式选项，然后选择保存。  有关详细信息，请参阅为“已安排的培训课程指定测验提供方式”。  |  
| 4  |  重复上述步骤，向培训课程中添加多个测验。   |  
| 5  |  选择安排或更新。   |
