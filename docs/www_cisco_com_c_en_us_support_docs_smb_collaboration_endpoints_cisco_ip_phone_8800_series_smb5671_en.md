Enable Auto Answer Page on a Cisco IP Phone 8800 Series Multiplatform Phone
## Introduction
Enabling Auto Answer Page on the Cisco IP Phone allows it to automatically answer any incoming call or page without you having to accept the page. This feature is designed to work using the speakerphone or a headset.
To automatically answer calls when Auto Answer Page is enabled, take note of the following:
**When using a headset**
  * Make sure that your headset is properly connected to the phone.
  * Make sure that the headset [![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-1.png "Related image, diagram or screenshot.") button is lit up. This indicates that you are on headset mode.
  * Do not use the headset [![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-2.png "Related image, diagram or screenshot.") button to start or end calls. Pressing this button turns off the headset mode. Use the buttons and softkeys instead.
  * If you wish to switch to speakerphone mode, simply press the speakerphone button. This automatically turns off the headset mode and use the speakerphone.
  * If you wish to switch to handset mode, simply lift the handset. This automatically turns off the headset mode and use the handset.


**When using the speakerphone**
  * Make sure that the headset [![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-3.png "Related image, diagram or screenshot.") button is not lit up.
  * Leave the handset in the cradle.
  * If you wish to switch to headset mode, simply press the headset [![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-4.png "Related image, diagram or screenshot.") button. This automatically turns off the speakerphone mode and use the headset.
  * If you wish to switch to handset mode, simply lift the handset. This automatically turns off the speakerphone mode and use the handset.

This article aims to show you how to enable Auto Answer Page on your Cisco IP Phone 8800 Series.

  * 8800 Series


## Software Version
  * 11.0.1


## Enable Auto Answer Page
### Through the Web-based Utility
Step 1. Access the web-based utility of your IP Phone then click **Admin Login > a****dvanced**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step1.png "Related image, diagram or screenshot.")
Step 2. Click **Voice**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step2.png "Related image, diagram or screenshot.")
Step 3. Click **User**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step3.png "Related image, diagram or screenshot.")
Step 4. In the Supplementary Services area, click on the drop-down menu for Auto Answer Page and choose **Yes**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step4.png "Related image, diagram or screenshot.")
Step 5. Click **Submit All Changes**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step5.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-07282017-autoanswer-step5.png "Related image, diagram or screenshot.")
You should now have enabled Auto Answer Page through the web-based utility of the phone.
