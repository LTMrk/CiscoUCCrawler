# Вибір способу локалізації відомостей про нараду службою гібридного календаря
![list-menu](https://help.webex.com/images/feedback.svg)Надіслати відгук?
Глобальна настройка Центру керування може використовуватися для визначення мови, яку служба гібридного календаря використовує для всіх відомостей про приєднання, доданих до нарад в організації. Цей параметр корисний, якщо у вас є законодавча вимога щодо подання інформації однією певною мовою та потрібно змінити мову, яку планувальники встановили для власного календаря, поштової скриньки або запрошення. 
Якщо ви **не зміните мову за замовчуванням** на певну мову для організації, Гібридний календар визначатиме, яку мову використовувати по-різному, залежно від типу інтеграції календаря:  
|  Тип інтеграції календаря  |  За замовчуванням, якщо не вибрано конкретної мови  |  
| --- | --- |  
|  Office 365 (за допомогою API Microsoft Graph через хмарну службу)  |  "language":{"locale"} налаштування з налаштувань поштової скриньки планувальника  |  
|  Календар Google G Suite  |  налаштування локалі з налаштувань календаря планувальника  |  
|  Microsoft Exchange або Office 365 (за допомогою EWS через з'єднувач календаря на основі Expressway)  |  властивість item.Culture із запрошення на зустріч  |  
| 1  |  Увійдіть у Центр [https://admin.webex.com ](https://admin.webex.com/)керування та перейдіть до  розділу Служби > гібридні.  |  
| --- | --- |  
| 2  |  На картці гібридного календаря для середовища календаря натисніть кнопку Редагувати настройки. Якщо службу гібридного календаря настроєно для кількох середовищ календаря, доступ до параметра Мова за промовчанням можна отримати з кількох місць у Центрі керування. Установлення параметра в одному розташуванні скасовує значення в будь-якому іншому розташуванні та змінює мову відомостей про об'єднання для всіх нарад, які обробляє гібридний календар .  |  
| 3  |  У розділі Запрошення на нараду виберіть мову з розкривного списку Мова за промовчанням і натисніть кнопку Зберегти. Після збереження змін гібридний календар використовує вибрану мову щоразу, коли додає приєднання до відомостей про нараду. Це не змінює мову для наявних відомостей про приєднання.  |
