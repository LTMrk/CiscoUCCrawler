# Installera mobilappen Webex Meetings
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
Om du vill hålla och delta i möten, händelser och utbildningsmöten från din mobila enhet kan du hämta och installera Meetings-appen. 
Om dina möten körs på [Webex Suite-mötesplattformen](https://help.webex.com/sv-se/m61d8eb/)[installerar du Webex App-mobilappen](https://help.webex.com/sv-se/krgc3ab/).
  * [iOS](https://help.webex.com/sv-se/article/njd6v2l/Installera-mobilappen-Webex-Meetings#id_124452)
  * [Android](https://help.webex.com/sv-se/article/njd6v2l/Installera-mobilappen-Webex-Meetings#id_124453)


Du kan hämta appen genom att:
  * Söker efter `Cisco Webex Meetings` i **App Store**
  * Delta i ett möte för första gången i din enhets webbläsare och acceptera erbjudandet att installera appen på din enhet
  * Skanna den här koden:
![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/440001-441000/440217.jpg)


När du har öppnat Meetings accepterar du villkoren för att användaappen.
