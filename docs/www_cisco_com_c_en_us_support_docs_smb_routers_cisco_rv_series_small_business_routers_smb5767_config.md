Configure Static IP WAN Settings on the RV34x Router
## Introduction
A Wide Area Network (WAN) is a network that covers a broad area. A user or network of users can connect to the Internet through an Internet Service Provider (ISP) who offers various methods to set up a client with an Internet connection. These methods can be automatic Dynamic Host Configuration Protocol (DHCP), Static Internet Protocol (IP), Point-to-Point Protocol over Ethernet (PPPoE), Point-to-Point Tunneling Protocol (PPTP), Layer 2 Tunneling Protocol (L2TP), Bridge, and Stateless Address Auto-configuration (SLAAC) for IPv6.
Configuring the right WAN settings on the router is necessary in order to properly set up Internet connection based on your network requirements and setup. Some WAN settings to be used on your router such as Usernames, Passwords, IP addresses, and DNS servers should be provided to you by your ISP.
In this scenario, the setup from the ISP requires the router to use Static IP settings in order to connect to the Internet. This connection type allows you to specifically assign a preferred IP address to a device for a period of time. Static IP is mainly used for device services that do not change IP addresses on the Internet.
## Objective
This article aims to show you how to configure the Static IP WAN settings on the RV34x Router.
## Applicable Devices
  * RV340
  * RV340W
  * RV345
  * RV345P


## Software Version
  * 1.0.01.17


## Configure Static IP WAN Settings
**Note:** The ISP provides the static IP address and other specific addresses for your connection.
Step 1. Access the router web-based utility and choose **WAN > ****WAN****Settings**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step1.png "Related image, diagram or screenshot.")
Step 2. In the WAN Table, click the **Add** button.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step2.png "Related image, diagram or screenshot.")
Step 3. In the Add/Edit WAN Sub-interface window that appears, click on the WAN interface that you want to configure.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step3.png "Related image, diagram or screenshot.")
**Note:** In this example, WAN1 is chosen. This is the default setting.
Step 4. Enter the VLAN ID in the field provided. In this example, 1 is used.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step4.png "Related image, diagram or screenshot.")
**Note:** The Sub-Interface Name area automatically updates based on the WAN and VLAN ID entered. In this example, WAN1.1 is displayed indicating WAN 1 and VLAN 1.
Step 5. Click the tab of the connection that you are using.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step5.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step5.png "Related image, diagram or screenshot.")
**Note:** In this example, IPv4 is chosen. This is the default setting. If you are using IPv6, skip to [IPv6](https://www.cisco.com/c/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/smb5767-configure-static-ip-wan-settings-on-the-rv34x-router.html#IPv6).
**IPv4**
Step 6. Click on the Static IP radio button to choose the Connection Type.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step6.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step6.png "Related image, diagram or screenshot.")
Step 7. Under Static IP Settings, enter the static IP address that the router will use in the _IP Address_ field.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step7.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step7.png "Related image, diagram or screenshot.")
**Note:** In this example, 192.168.2.2 is used.
Step 8. Enter the Netmask in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step8.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step8.png "Related image, diagram or screenshot.")
**Note:** In this example, 255.255.255.0 is used.
Step 9. Enter the Default Gateway in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step9.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step9.png "Related image, diagram or screenshot.")
**Note:** In this example, 192.168.2.0 is used.
Step 10. Enter the Static DNS 1 in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step10.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step10.png "Related image, diagram or screenshot.")
**Note:** In this example, 192.168.2.0 is used.
Step 11. (Optional) Enter the Static DNS 2 in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step11.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step11.png "Related image, diagram or screenshot.")
Step 12. Click **Apply**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step12.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstatic-step12.png "Related image, diagram or screenshot.")
**IPv6**
Step 1. Click the **IPv6** tab.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step1.png "Related image, diagram or screenshot.")
Step 2. Click on the **Static IP** radio button to choose the Connection Type.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step2.png "Related image, diagram or screenshot.")
Step 3. Under Static IP Settings, enter the IPv6 IP Address in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step3.png "Related image, diagram or screenshot.")
**Note:** In this example, 2001:DB8:0:CD30::123:4567 is used.
Step 4. Enter the Prefix Length in the field provided. This determines the number of bits in the address.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step4.png "Related image, diagram or screenshot.")
**Note:** In this example, 64 is used.
Step 5. Enter the IPv6 Default Gateway in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step5.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step5.png "Related image, diagram or screenshot.")
**Note:** In this example, 2001:DB8:0:CD30::123:4566 is used.
Step 6. Enter the Static DNS 1 address in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step6.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step6.png "Related image, diagram or screenshot.")
**Note:** In this example, 2001:DB8:0:CD30::123:4566 is used.
Step 7. (Optional) Enter the Static DNS 2 address in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step7.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step7.png "Related image, diagram or screenshot.")
**Note:** In this example, 2001:DB8:0:CD30::123:4555 is used.
Step 8. (Optional) Check the **DHCP-PD** checkbox if you are using DHCPv6 prefix delegation.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step8.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step8.png "Related image, diagram or screenshot.")
Step 9. (Optional) Enter the prefix name in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step9.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step9.png "Related image, diagram or screenshot.")
**Note:** In this example, DHCPv6 is used.
Step 10. Click **Apply**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step10.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-01102018-configstaticipv6-step10.png "Related image, diagram or screenshot.")
You now have successfully set your RV34x Router WAN settings to Static IP.
