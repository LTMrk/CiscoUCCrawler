# 임원진 및 임원진 지원자 기능 액세스 코드
![list-menu](https://help.webex.com/images/feedback.svg)피드백이 있습니까?
임원진 지원자 서비스가 활성화되면 사용자는 전화 키패드를 사용하여 기능 액세스 코드(FAC)를 입력하고 특정 서비스를 제어할 수 있습니다. 해당하는 FAC는 사용자에게 지정된 기본 IP 전화에서 작동합니다.   
|  기능 액세스 코드 이름  |  기본값  |  연계된 서비스  |  
| --- | --- | --- |  
|  |  
|  임원진 통화 필터링 활성화  |  #61  |  임원진  |  
|  임원진 통화 필터링 비활성화  |  #62  |  임원진  |  
|  임원진-지원자 통화 푸시*  |  #63  |  임원진 지원자  |  
|  임원진-지원자 통화 시작*  |  #64  |  임원진 지원자  |  
|  임원진 지원자 선택*  |  #65  |  임원진 지원자  |  
|  임원진 지원자 선택 취소*  |  #66  |  임원진 지원자  |  
*다이얼할 때 추가 숫자가 필요합니다.
## 추가 숫자를 요구하는 기능 액세스 코드
임원진-지원자 FAC를 사용하기 위한 다이얼링 순서 옵션의 예제는 다음과 같습니다.
**선택 기능 액세스 코드 예제:**
임원진의 전화 번호나 내선 번호에 FAC가 제공되지 않은 경우, 지원자는 임원진의 전화 번호나 내선 번호를 입력하도록 안내받습니다.
  * #65 - 그 후 임원진의 전화 번호나 내선 번호를 입력하도록 안내받습니다.
  * #65 + 전화 번호 또는 내선 번호.
