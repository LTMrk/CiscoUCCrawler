### Problem Description
Cisco IP Phones that only contain and utilize the Manufacturer Installed Certificate (MIC) for secure network deployment will fail to operate when the certificate expires. In the event of certificate expiration, an administrator must install a Locally Significant Certificate (LSC) in order to ensure secure device communication and operation.
See [Configure LSC on Cisco IP Phone with CUCM](https://www.cisco.com/c/en/us/support/docs/content-networking/certificates/213295-how-to-install-an-lsc-on-a-cisco-ip-phon.html) for more information.
### Background
Phones manufactured prior to 2018 might contain a MIC with a 10-year expiration date that could impact phone functionality in certain secure deployment scenarios. In non-secure deployments, phones that contain expired MICs will continue to operate as normal. Customers that previously configured phones in a secure deployment reported to the Technical Assistance Center (TAC) that phones older than 10 years no longer work. Cisco TAC has analyzed the conditions and provided a resolution.
### Problem Symptom
Phone failure symptoms vary from the inability to register to Unified Communications Manager (Unified CM) to not completing call media path setup for a placed call.
The known scenarios in which a phone will not work properly with an expired MIC are:
  * 802.1x authentication at a switching level (RADIUS, Identity Services Engine, and so on)
  * VPN connection that utilizes certificate-based authentication (Adaptive Security Appliance or Cisco IOS®)
  * Secure device registration with Unified CM
  * Restricted access to the phone's webpage via any current browser
  * Secure Survivable Remote Site Telephony (SRST) registration on a voice gateway in the case of a Unified CM failure


**Problem Impact**
The impact to the customer’s network includes loss of voice communications, intermittent call interruptions, or non-deterministic endpoint behavior. Phones previously deployed and configured in a secure manner that use the supported LSC method and also contain an expired MIC will continue to operate normally.
### Workaround/Solution
Cisco IP Phones do not support field replacement of the MIC. No hardware replacement is necessary as the LSC method is tested, supported, and adds additional security to the phone and the Unified Communications deployment.
If a customer encounters issues related to secure deployment or features on the phones, then the administrator should follow the procedure in [Configure LSC on Cisco IP Phone with CUCM](https://www.cisco.com/c/en/us/support/docs/content-networking/certificates/213295-how-to-install-an-lsc-on-a-cisco-ip-phon.html) in order to install LSCs for secure communication.
