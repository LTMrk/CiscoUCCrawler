# Rejoindre un événement Webex (Classique)
![list-menu](https://help.webex.com/images/list-menu.svg)Dans cet article
![list-menu](https://help.webex.com/images/feedback.svg)Un commentaire ?
Vous pouvez rejoindre un événement Cisco Webex à partir de votre courrier électronique d'invitation, votre site Webex ou votre périphérique mobile. Si vous ne pouvez toujours pas le rejoindre, vous pouvez tenter de résoudre les problèmes que vous rencontrez. 
## Rejoindre un événement
Il y a plusieurs façons de rejoindre un événement. Si vous rencontrez des difficultés pour rejoindre un événement, vous pouvez résoudre les problèmes que vous rencontrez. Pour plus d’informations, voir [Dépannage de Cisco Webex](https://collaborationhelp.cisco.com/article/WBX000029055).
[ Rejoindre une réunion à partir d'un courrier électronique d'invitation](https://help.webex.com/fr-fr/article/kwmj5eb/Rejoindre-un-%C3%A9v%C3%A9nement-Webex-\(Classique\)#id_17236)
Avant de commencer
Si l’organisateur demande un identifiant d’inscription pour l’événement, assurez-vous de conserver le courrier électronique de confirmation d’inscription. Vous devez saisir l'identifiant lorsque vous rejoignez l’événement.  
| 1  |  Sélectionnez le lien pour rejoindre la réunion contenu dans votre courrier électronique d'invitation. ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/423001-424000/423856.jpg)  |  
| --- | --- |  
| 2  |  Sur la page Informations sur l'événement, saisissez votre nom, votre adresse électronique, ainsi que le mot de passe de l'événement. Cliquez sur Rejoindre maintenant.  |  
[Rejoindre à partir d’un site Webex](https://help.webex.com/fr-fr/article/kwmj5eb/Rejoindre-un-%C3%A9v%C3%A9nement-Webex-\(Classique\)#task_967150A4B81C346545ADAFF4E87BAA25)  
|  À partir de la page d’Accueil du site Webex sur lequel l’événement est organisé, saisissez le numéro de l’événement à 9 chiffres dans la zone de texte, saisissez le mot de passe fourni dans le courrier électronique d’invitation et sélectionnez Rejoindre maintenant. ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/426001-427000/426369.jpg) Si l'événement n'a pas encore démarré, le bouton Rejoindre maintenant est grisé. Vous trouverez le numéro d'événement à 9 chiffres dans votre courrier électronique d'invitation.  |  
| --- |  
[Rejoindre un événement à partir de votre périphérique mobile](https://help.webex.com/fr-fr/article/kwmj5eb/Rejoindre-un-%C3%A9v%C3%A9nement-Webex-\(Classique\)#id_17240)
Avant de commencer
Avant de vous connecter à un événement à partir de votre appareil mobile, vous devez installer Webex Meetings. Si vous avez déjà installé le Application Webex Meetings sur votre appareil mobile, il se lance automatiquement. Sinon, vous êtes dirigé(e) vers la page d'installation.  
| 1  |  Tapez sur Rejoindre dans votre courrier électronique d’invitation lorsqu’il est l’heure de rejoindre la réunion. ![Appuyez sur Rejoindre](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/438001-439000/438122.jpg)  |  
| --- | --- |  
| 2  |  Tapez sur Télécharger pour installer l Cisco Webex Meetings appl application et rejoindre la visioconférence. Pour rejoindre la réunion par téléphone uniquement, appuyez sur le numéro affiché à l’écran.  |  
| 3  |  Tapez sur Ouvrir lorsque l’application est installée et acceptez les Conditions d’utilisation et la Déclaration de confidentialité.  |  
| 4  |  Tapez sur Rejoindre la réunion , saisissez l’numéro de réunion réunion—elle est dans le courrier électroniqued’invitation—et tapez sur Rejoindre.  |  
| 5  |  Saisissez le mot de passe de la réunion—il est dans le courrier électronique d’invitation—et tapez sur OK. Lorsque l Application Webex Meetings vidéo s’ouvre, l’aperçu de votre vidéo vous permet de voir comment vous allez voir les autres personnes avant de rejoindre la réunion.![Utiliser Internet pour l’audio](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/438001-439000/438123.jpg)  |  
| 6  |  [Changez vos paramètres audio et vidéo](https://help.webex.com/fr-fr/nt2ig0y/) avant de rejoindre votre réunion.  |  
| 7  |  Cliquez [sur Se connecter à un périphérique pour rejoindre la réunion à partir](https://help.webex.com/fr-fr/by1t1x/) d’un périphérique vidéo compatible.   |  
| 8  |  Tapez sur Rejoindre. ![Tapez sur Rejoindre](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/438001-439000/438127.jpg)  |  
[Rejoindre via les systèmes vidéo](https://help.webex.com/fr-fr/article/kwmj5eb/Rejoindre-un-%C3%A9v%C3%A9nement-Webex-\(Classique\)#id_128919)
Les panélistes d’Events (classiques) peuvent rejoindre les événements en utilisant leurs systèmes vidéo. Les invités ne peuvent pas rejoindre la réunion via un système vidéo. Les invités de l’événement doivent être promus panéliste pour partager une vidéo. Les Organisateur de l’événement / organisateur d’événements et les panélistes peuvent toujours partager leur vidéo au cours d’un événement. Jusqu’à 200 panélistes peuvent partager leur vidéo au cours d’un événement.  
| 1  |  Cliquez sur Utiliser un système vidéo pour rejoindre la réunion à partir![Système vidéo](https://help.webex.com/en/us/td/i/400001-500000/420001-430000/426001-427000/426834.JPG) d’un périphérique compatible. L’application recherche les systèmes vidéo à proximité. ![Se connecter à un périphérique vidéo](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/438001-439000/438325.jpg)  |  
| --- | --- |  
| 2  |  Si l’application détecte les systèmes vidéo à proximité, vous voyez une liste de ces périphériques. Sélectionnez dans la liste le système vidéo que vous souhaitez utiliser. ![Sélectionnez le périphérique](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/440001-441000/440142.jpg)  |  
| 3  |  Si votre système vidéo n’est pas détecté, demander à l’application d’appeler votre périphérique. Saisissez l’adresse du système vidéo et sélectionnez le périphérique lorsqu’il s’affiche dans la liste. ![Saisissez l'adresse vidéo](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/440001-441000/440143.jpg)  |  
L’application se connectera automatiquement à votre système vidéo ou elle appellera votre périphérique lorsque vous sélectionnerez Rejoindre laréunion.
![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/440001-441000/440144.jpg)
## Se connecter à l’audio et à la vidéo Webex
Vous pouvez vous connecter à votre audio et à votre vidéo lorsque vous démarrez ou rejoignez une réunion ou un événement pour que les autres invités peuvent vous entendre et vous voir.
Events (classique) offre la flexibilité de se connecter à l’audio de plusieurs façons. Pour en savoir plus, voir [Conseils et astuces pour utiliser l’audio avec Cisco Webex](https://collaborationhelp.cisco.com/article/0izy25)
