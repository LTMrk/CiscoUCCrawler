## 생산성 도구 또는 Webex 스케줄러는 언제 사용해야 할까요?
Microsoft 365를 사용하는 경우 Outlook에서 Webex Scheduler를 사용하여 Webex 회의를 예약하세요.
온프레미스 Exchange를 사용하고 위임 일정을 필요로 하는 경우 생산성 도구 버전 **45.2.0.63 이상** 을 계속 사용하십시오. Webex Scheduler는 웹 추가 기능이며, Microsoft는 온프레미스 Exchange에서 대리인 일정을 예약하는 데 필요한 웹 추가 기능 기능을 지원하지 않습니다. 생산성 도구 버전 45.2.0.63 이상은 해당 고객에게 계속 제공됩니다.
생산성 도구는 Windows에서만 지원됩니다. Mac에서 Outlook을 사용하는 사용자는 Webex Scheduler를 사용해야 합니다. 
## 필수 버전
Webex 사이트에 자동 업데이트가 활성화된 경우, 생산성 도구는 Microsoft Outlook이 열려 있는 동안 업데이트를 확인합니다. 버전을 확인하려면 다음을 참조하세요.
  1. Microsoft Outlook에서 회의 예약으로 이동합니다. > 더 > 업데이트 확인.
  2. 업데이트가 있는 경우 업데이트를 선택하십시오.
  3. 메시지가 표시되면 Microsoft Outlook을 다시 시작하십시오.
  4. 회의 일정을 선택하세요 > 에 대한 정보를 입력하여 설치된 버전이 45.2.0.63 이상인지 확인하십시오.


고객은 설치된 버전을 다운로드 횟수와 비교할 수도 있습니다. > Webex 사이트에서 버전 정보를 확인할 수 있습니다.
자동 업데이트가 비활성화된 경우 IT 관리자는 지원되는 패키지를 정기적으로 배포해야 합니다.
## 지원 정책 지침
  * 45.2.0.63 이전 버전은 지원되지 않으며 Webex 서비스와 호환되지 않을 수 있습니다.
  * 이후 보안 또는 호환성 강화 조치가 시행되면 새로운 최소 지원 버전이 적용됩니다.
  * 문제 해결을 계속하기 전에 Cisco 지원팀에서 업그레이드를 요청할 수 있습니다.


## 배포 권장 사항
새로운 배포 및 마이그레이션에는 Webex 스케줄러를 사용하십시오. 생산성 도구를 계속 사용해야 하는 고객은 Webex 사이트의 다운로드 페이지에서 제공되는 최신 지원 패키지를 사용하십시오. 또한 자동 업데이트를 활성화하거나 지원되는 패키지를 정기적으로 대량 배포해야 합니다.
## Webex 사이트 버전과 생산성 도구의 호환성
  * 고객에게 사용 가능한 최신 버전으로 생산 도구를 업데이트할 것을 강력히 권장합니다.
  * 생산 도구는 이전 버전과의 제한적인 호환성을 이어받습니다.
