## 無法存取 Webex 網站。
## 錯誤：「無法顯示頁面」
## 錯誤：「找不到伺服器」，主持人和出席者無法存取 Webex 網站來連接至會議。
## 主持人和出席者無法存取網站；收到「無法顯示頁面。」
  
**解決方案：**  
**完成下面的每個疑難排解步驟之後，測試您是否可以存取您的 Webex 網站：**
  1. 清除您的 臨時網際網路檔案和 Cookie，請參閱： 
     * [WBX38898 - 如何在 Mozilla Firefox 中清除我的快取和 Cookie？](https://help.webex.com/article/WBX38898)
     * [WBX38899 - 如何在 Google Chrome 中清除我的快取和 Cookie？](https://help.webex.com/article/WBX38899)
  2. 退出您的 Web 瀏覽器的所有實例並啟動新副本。
  3. 如果可能，請重新啟動網際網路連線。
  4. 排清 DNS 快取，請參閱： 
     * [WBX18967 - 如何從 DOS 命令提示字元執行 DNS 排清動作？](https://help.webex.com/article/WBX18967)

如果您仍然無法存取網站，請聯絡技術支援。 有關說明，請參閱：[WBX162 - 如何聯絡 Webex 客戶服務或技術支援？](https://help.webex.com/article/WBX162)  
  
**驗證您的IP 位址是否不在 Bright Cloud 或 Talos 錯誤IP清單中（應該同時勾選 BrightCloud 和 Talos）**  
附註：您可以透過訪問找到您的公用 IP位址<https://www.whatismyip.com/>  
  
**明亮的雲端：**
  1. 導覽至 <https://www.brightcloud.com/tools/url-ip-lookup.php#>
  2. 在 _查找 URL 或 IP_ 欄位中，輸入您的 IP 位址。
  3. **檢查** _我不是機器人_ 方塊，然後按一下 **向上查找** 按鈕。

**Talos：**
  1. 導覽至： <https://talosintelligence.com> 。 
  2. 在 _聲譽查找_ 欄位中，輸入您的 IP 位址，然後按 **Enter** 鍵。
