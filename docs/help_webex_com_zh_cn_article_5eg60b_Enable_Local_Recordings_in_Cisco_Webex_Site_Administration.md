# 在 Cisco Webex 站点管理中启用本地录制
![list-menu](https://help.webex.com/images/feedback.svg)反馈？
作为站点管理员，您可以在 Windows 桌面设备上为会议、活动及课程启用本地录制。会议和活动以 MP4 格式录制，而培训录制文件则保存为 WRF 格式。允许本地录制可节省组织存储空间并让您的用户即时访问录制文件。 
主持人必须通过网络语音加入，才能录制音频。  
| 1  |  登录站点管理并转至 > 站点设置  > 。   |  
| --- | --- |  
| 2  |  在“站点选项”区域中，选中 Webex会议、活动、培训课程和Webex Teams会议的本地录制 允许用户将录制文件直接保存到其计算机上。   |  
| 3  |  用户必须接受免责声明，才能开始录制会议。 要在本地录制会议为MP4文件之前显示免责声明，请选择 显示本地录制的免责声明（仅限MP4），然后在文本字段中输入指向组织隐私指导原则的URL链接。   |  
| 4  |  本地 MP4 录制文件不具有以下网络录制文件功能：
  * 转录。
  * 记录聊天、参加者列表或在会议期间共享的文件。

选择更新。   |
