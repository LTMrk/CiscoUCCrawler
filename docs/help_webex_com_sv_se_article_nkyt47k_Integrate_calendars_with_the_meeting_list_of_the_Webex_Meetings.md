# Integrera kalendrar med möteslistan i Webex Meetings appen
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
Hittar du inte dina möten i möteslistan? Du kan välja vad som visas i möteslistan i Webex Meetings mobilappen. Gör den matcha vad som är listat på din Webex-webbplats, mobila enhet, Microsoft Office 365-kalender eller någon kombination du vill.   
| 1  |  Öppna appen Webex Meetings och tryck på Inställningar ![Inställningsknappen representerad av en kugghjulsikon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/438001-439000/438264.jpg) för att visa huvudmenyn för inställningar.  |  
| --- | --- |  
| 2  |  Tryck på Möteslista för att öppna kalenderintegreringsval.  |  
| 3  |  Välj från följande alternativ:
  * Välj Webex-kalender för att integrera schemalagda Webex-möten och möten i personliga rum från din Webex-webbplats och se dessa kommande möten i mötesappen.
  * Välj Enhetskalender för att integrera möten som är schemalagda på din mobila enhet och se dessa kommande möten i Mötes-appen.
  * Välj Office 365 Kalender för att integrera möten från Outlook och se dessa kommande möten i Mötes-appen.

![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/444001-445000/444708.jpg) Om det finns ett möte i Webex-kalendern, Microsoft Office 365-kalendern och enhetskalendern samtidigt visas inte dubbla poster i Webex-kalendern. Prioritetsnivån för kalendern är följande: Webex-> för Office 365-> enhetskalender. Endast Webex-möten visas i möteslistan. Om du inte kan se schemalagda möten i personliga rum och använder iOS 12.2. eller senare begränsar din organisations policy för hantering av mobila enheter tredjepartsappar från fullständig åtkomst till dina företagskonton. För att lösa detta måste din webbplatsadministratör distribuera Webex Meetings-applikationen från [Webex Management Program](https://help.webex.com/sv-se/n4b78j9/). Kontakta din webbplatsadministratör för mer information.[](https://help.webex.com/sv-se/WBX15/)  |
