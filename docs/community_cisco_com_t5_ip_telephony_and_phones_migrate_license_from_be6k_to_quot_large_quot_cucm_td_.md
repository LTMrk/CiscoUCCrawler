It is still not supported to run BE6K on a third party HW platform since it is a bundle that comes pre installed with a certain set of UC applications on a specific Cisco UCS hardware. However, you can always run UC applications on a third party server (in case you do not want to order BE6K) as long as it meet the requirements mentioned in below document:
http://docwiki.cisco.com/wiki/UC_Virtualization_Supported_Hardware#.22Can_I_use_this_server.3F.22
For migrating the licenses, reach out to Cisco Licensing Team at licensing@cisco.com and they will help you with the same once you provide them Sales Order (SO) Number, Purchase Order (PO) etc.
