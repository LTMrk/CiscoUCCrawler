# Kit de acessórios USB-C para fone de ouvido Cisco
![list-menu](https://help.webex.com/images/feedback.svg)Comentários?
O kit de acessórios USB-C do fone de ouvido Cisco contém um cabo USB-C e um adaptador USB-A para USB-C. 
O kit de acessórios USB-C do fone de ouvido Cisco contém os seguintes acessórios:
  * Adaptador USB-A para USB-C — conecta a dispositivos com uma porta USB-C.
![Adaptador USB-A a USB-C](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/454001-455000/454030.jpg)
  * Cabo USB-C — conecta o fone de ouvido sem fio Cisco a qualquer porta USB-C.
![Cabo USB-C](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/454001-455000/454032.jpg)


Para solicitar informações, consulte <https://www.cisco.com/c/en/us/support/collaboration-endpoints/headset-700-series/series.html>.
