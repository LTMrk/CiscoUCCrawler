## Introduction
This document describes how to configure the browser, computer, and application settings to prevent agents from being logged out unexpectedly.
## Prerequisites
### Requirements
Cisco recommends that you have knowledge of these topics:
  * [Webex Contact Center Portal](https://admin.webex.com/)
  * [Webex Contact Center Agent Desktop (cisco.com)](https://desktop.wxcc-us1.cisco.com/)
  * WxCC 2.0  
  



### Components Used
The information in this document is based on this software versions:
  * WxCC 2.0


The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.  

## Configure
### Configure Browsers
When a browser has an active setup for the sleeping tab feature, it puts inactive tabs (that you have not accessed for minutes/hours) to sleep mode or suspends those tabs. That is helpful so tabs cannot occupy system resources or memory unnecessarily. However, the Agent Desktop application could lose connection if the browser tab goes into sleep mode. Cisco recommends disabling the sleeping tab configuration on the browsers that agents use for the Webex Contact Center Agent Desktop.
#### Google Chrome (chrome://settings/performance)
In your Google Chrome browser, navigate to **Settings** >**Performance**
Add your WxCC dedicated location desktop URL: https://desktop.wxcc-(DC).cisco.com: (for example, <https://desktop.wxcc-us1.cisco.com>).
[![WxCC Desktop URL](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-00.png "WxCC Desktop URL")
Disable Memory Saver mode

Disable Energy Saver mode
[![Disable Energy Saver Mode](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-02.png "Disable Energy Saver Mode")

### Configure the Sleep Setting on your Windows Personal Computer (PC) or MAC
When your PC or MAC goes to sleep, it can cause the Agent Desktop application to lose connectivity with the Cloud and log out of the agent. Cisco recommends adjusting the sleep configuration to prevent the Agent Desktop application from logging out. 
#### Windows PC
On your PC, find the **Power & Sleep Settings**
[![Windows PC Settings](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-08.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-08.png "Windows PC Settings")
Adjust the sleep settings to the time you want the agent to be inactive and stay logged in.
[![Adjust Sleep Settings](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-09.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-09.png "Adjust Sleep Settings")
#### MAC
On your MAC, find the **Energy Saver** configurations and make sure you have a check for **Prevent your Mac from automatically sleeping when the display is off**.
[![MAC Settings](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-10.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-10.png "MAC Settings")
### Configure Desktop Inactivity Timeout
If the tenant is configured with Desktop Inactivity Timeout, inactive agents are automatically logged out after the specified time in the configurations. 
If the desktop-inactivity-timeout is on, you can enable or disable the Feature Flag in the Webex Contact Center Admin portal and adjust the time per your business requirements.
[![Configure Desktop Inactivity Timeout](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-11.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-11.png "Configure Desktop Inactivity Timeout")
Be aware that the Agent Timeout configurations in the Desktop Profile overwrite the tenant timeout configurations. For example, if the tenant timeout is configured with 30 minutes but the Desktop Profile has the Desktop Timeout configured with 20 minutes, the inactive agent logs out after 20 minutes in this scenario. 
[![Set Desktop Timeout](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-12.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d-12.png "Set Desktop Timeout")
