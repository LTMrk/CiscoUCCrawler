## Разрешить пользователям добавлять сведения о сеансах в календари
Эта процедура предназначена только для Webex Meetings, Webex Training и Webex Events. Данный параметр используется для включения функций iCalendar на веб-сайте, а также отображения кнопки Добавить в мой календарь на странице информации о сеансе Webex. iCalendar представляет собой стандартный формат календаря. С помощью iCalendar пользователи могут предоставлять совместный доступ к информации календаря и автоматически обновлять свои расписания.   
| 1  |  Войдите в службу администрирования веб-сайта Webex и перейдите к меню Конфигурация > Общие настройки веб-сайта > Параметры.   |  
| --- | --- |  
| 2  |  В разделе Параметры сайта установите флажок iCalendar (Показать, что нужно добавить в мой календарь для встреч, тренингов и мероприятий).   |  
| 3  |  Нажмите Обновить.  |  
## Разрешить пользователям Cisco Unified MeetingPlace присоединяться к внешним совещаниям WBS30
Эта процедура предусмотрена только для веб-сайтов Meeting Center и выпуска WBS30. Настройте работу веб-сайта по умолчанию в планировщиках совещаний и инструментов повышения производительности, разрешив обычным интернет-пользователям присоединяться к совещаниям. Чтобы разрешить сторонним посетителям присоединиться к какому-либо совещанию, следует включить соответствующий параметр для организатора этого совещания. Если этот параметр выключен в планировщике, к совещанию могут присоединиться только посетители из внутренней сети. 
Прежде чем начать
Этот параметр доступен только в том веб-сайт Webex , где для вашей компании предусмотрены следующие следующую опцию. 
  * Параметр интеграции с Cisco Unified MeetingPlace. 
  * Параметр Webex Node для MCS 

  
| 1  |  Войдите в службу администрирования веб-сайта Webex и перейдите к меню Пользователи > Добавить пользователя. 
  * Чтобы обновить существующую учетную запись пользователя, выберите Пользователи > Редактировать пользователя, затем выберите пользователя. 

 |  
| --- | --- |  
| 2  |  В разделе Привилегии рядом с Центром собранийвыберите Разрешить внешних участников.   |  
| 3  |  Чтобы сохранить изменения, нажмите Добавить или Обновить.   |  
| 4  |  Открыв расположенную слева панель навигации, выберите Конфигурация > Общие настройки веб-сайта.   |  
| 5  |  Прокрутите страницу вниз до раздела Настройки интеграции Cisco Unified MeetingPlace.   |  
| 6  |  Чтобы разрешить участие внешних участников, установите флажок По умолчанию для внешних участников MP в поле.   |  
| 7  |  Нажмите Обновить.   |

## Разрешить пользователям планировать совещания и сеансы обучения от других пользователей
Эта процедура предназначена только для Webex Meetings и Webex Training.
Прежде чем начать
Пользователи, планирующие совещания, должны иметь учетную запись организатора Webex.  
| 1  |  Войдите в службу администрирования веб-сайта Webex и перейдите к меню Конфигурация > Общие настройки веб-сайта > Параметры.   |  
| --- | --- |  
| 2  |  В разделе Параметры планирования встреч установите флажок Пользователи могут разрешать другим пользователям планировать встречи от их имени.   |  
| 3  |  Нажмите Обновить.   |  
## Разрешить пользователям печатать или сохранять файл в совместном доступе
Эта процедура предназначена только для Webex Meetings, Webex Events и Webex Training.   
| 1  |  Войдите в службу администрирования веб-сайта Webex и перейдите к меню Конфигурация > Общие настройки веб-сайта > Параметры.   |  
| --- | --- |  
| 2  |  В разделе Параметры сайта установите флажок  Разрешить Print/Save в поле «Совместное использование документов » . Снимите флажок, чтобы запретить участникам распечатывать или скачивать файл во время демонстрации.  |  
| 3  |  Нажмите Обновить.   |
