在 Board 和 Desk 系列裝置上啟用 Web 應用程式管理
![list-menu](https://help.webex.com/images/feedback.svg)意見回饋？
開啟 Web App 管理，直接從設備添加、編輯和刪除 Web 應用。 
您可自裝置的本地 Web 介面啟用下列的組態。 請參閱[裝置組態](https://help.webex.com/en-us/n5pqqcm/Advanced-Settings-for-Room-and-Desk-Devices)一文，取得如何存取 Web 介面的更多資訊。
打開設備的 Web 介面後，選擇  設置  選項卡下的設置  ，然後選擇  配置 
  * 配置  > Web 引擎  > 模式 ：選擇「  打開  」以啟用 Web 引擎。
  * Configuration  > WebEngine  > Features  > LocalWebAppManagement ：如果您希望使用者從裝置上的設定功能表中添加、編輯和刪除 Web 應用程式，請選擇  允許  的。 設置為  「不允許  」時，可以在設置功能表中訪問 Web 應用清單，但無法添加、編輯或刪除它們。 設置為「關閉  」 時，Web 應用不在 設備的設置功能表中。
