# Playwright Validation

## Commands

```bash
# list projects/tests
yarn playwright test --config=playwright.config.ts --list

# run target suite
yarn test:e2e playwright/suites/<suite-file>.spec.ts

# run target set
yarn test:e2e --project=SET_1
```
