EOL12691 - Amended
Cisco announces the end-of-sale dates for the Cisco Meeting Server Migration Program. The last day to order the affected product(s) is November 5, 2018. Table 1 describes the end-of-life milestones, definitions, and dates for the affected product(s). Table 2 lists the product part numbers affected by this announcement. For customers with active and paid service and support contracts, support will be available under the terms and conditions of customers' service contract.
Cisco announces the end-of-sale dates for the Cisco TelePresence Server or Cisco MCU to Cisco Meeting Server migration. The last day to order the affected product(s) is November 5, 2018. Cisco Meeting Server is not end-of-sale or support with this notice. This notice is only for end-of-sale of the migration pricing program. Customers who purchased Cisco Meeting Server using this migration program will continue to renew services and access support per existing support contracts.
