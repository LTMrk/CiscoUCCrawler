Schůzky Webex jsou podporovány v konkrétních verzích Windows, Mac, iPhone, iPad, Android a Web. 
## Systémové požadavky sady Webex Meetings Suite 
Pokud vaše schůzky probíhají na [platformě pro schůzky Webex Suite](https://help.webex.com/cs-cz/m61d8eb/), podívejte se na [systémové požadavky pro služby Webex](https://help.webex.com/cs-cz/fz1e4b/).
### Podpora operačního systému a prohlížeče pro sadu Webex Meetings Suite
#### Podporované operační systémy
**Windows**
  * Windows Server 2008 (64bitová verze)
  * Windows Server 2008 R2 (64bitová verze)
  * Windows 10
  * Windows 10 Enterprise LTSB
  * Windows 11


**Poznámky:**
  * Podpora operačního systému Windows v počítači Microsoft Surface Pro je poskytována.
  * Každá měsíční verze aplikace Webex Meetings je testována a certifikována za použití aktuální verze Preview měsíčních souhrnných aktualizací a všech půlročních vydání systému Windows 10.
  * Aplikace Webex Meetings podporuje systémy Windows Server 2012 R2 a 2016 s tím omezením, že pokud uživatel nemá oprávnění správce pro schůzky Webex, nástroje produktivity a počítačovou aplikaci, správce musí nainstalovat aplikace Webex Meetings a nástroje produktivity.


**Mac OS X**
  * 10.15
  * 11.0 (Big Sur)
  * 12.0 (Monterey) 


  * Weby Webex Meetings kompatibilní s programem FedRAMP vyžadují systém MacOS 10.13 nebo novější.
  * Společnost Apple od verze Mac OS X 10.7 již nenabízí software Java jako součást operačního systému Mac. Vzhledem k tomu, že aplikace Webex Meetings dříve využívala modul plugin Java pro prohlížeče ke stažení aplikace Meetings pro uživatele, kteří tuto aplikaci ještě nepoužívali, uživatelé bez nainstalovaného softwaru Java měli potíže s připojením ke schůzce. Závislost na softwaru Java byla odstraněna. Místo toho je uživatel vyzván k instalaci malého modulu plugin, který po instalaci zpracovává zbývající část instalace aplikace Meetings a poté aplikaci spustí.
  * Při prvním spouštění nebo připojování k události pomocí aplikace Events (klasické zobrazení) v aplikaci Safari 6.x a Safari 7 dojde k chybě. Aplikace Safari vyžaduje po instalaci aplikace Webex, abyste pro modul plugin nastavili důvěryhodný vztah pro web, ze kterého se pokoušíte připojit nebo spustit událost. Stránka se poté obnoví, ale k události se nepřipojíte. Chcete-li se připojit, vraťte se na původně vybraný odkaz a budete se moci úspěšně připojit.
  * K dispozici jsou následující služby Webex:
    * Webex Meetings 
    * Webex Webinars 
Režim webového vysílání pro účastníky nepodporuje 64bitový systém Windows Server 2008, 64bitový systém Windows Server 2008 R2, systém Mac OS 10.13 a Mac OS 10.14.
    * Events (klasická verze) 
    * Webex Training
  * Podpora Webex Support již není poskytována v systému Mac OS, protože využíval klienta Java, který byl 1. dubna 2021 vyřazen z nabídky.


**Linux (webová aplikace) (32bitová a 64bitová verze)**
  * Ubuntu 14.x nebo novější
  * OpenSuSE 13.x nebo novější
  * Fedora 18 nebo novější
  * Red Hat 6 nebo novější
  * Debian 8.x nebo novější


Následující služby Webex jsou k dispozici pro systém Linux ve webové aplikaci:
  * Schůzky 
  * Webex Webinars 
Režim webového vysílání pro účastníky nepodporuje tyto systémy: OpenSuSE 13.x nebo novější, Fedora 18 nebo novější, Red Hat 6 nebo novější a Debian 8.x nebo novější.
  * Events (klasická verze) (účastníci)
  * Webex Training (účastníci)


Známé problémy a omezení pro systém Linux ve webové aplikaci Webex Meetings:
  * V některých verzích systému Linux musí uživatelé nejprve nainstalovat a aktivovat plugin „OpenH264 Video Codec provided by Cisco Systems, Inc.“, jinak video, volání počítače uživatele a sdílení obsahu nebudou v prohlížeči Firefox fungovat.
  * Sdílení obsahu nefunguje ve verzích systému Linux, které používají Wayland jako systém pro správu zobrazení (například Fedora 25 a novější). Je to způsobeno problémem s rozhraním API pro sdílení obrazovky WebRTC.
  * Odesílání a příjem videa nefunguje v systému Fedora 28 kvůli problému s kodekem H.264. 
  * Klienti se systémem Linux nejsou podporováni pro šifrování typu end-to-end.


**Podpora OS Chrome**
Podpora pro systém Google Chrome je v současné době k dispozici prostřednictvím webové aplikace Webex Meetings (podpora klienta pro webové schůzky) a aplikace Webex Meetings pro systém Android (podpora klienta pro schůzky ke stažení). 
Mobilní aplikace Webex Meetings (verze 11.0 nebo novější) je podporována ve všech zařízeních Chrome, která oficiálně podporují aplikace pro Android prostřednictvím služby Google Play.

**Mac OS X**
  * Prohlížeč Firefox 52 a novější je plně podporován v systému Mac OS X. Firefox 51 a starší verze podporovány nejsou. Uživatelé obdrží zprávu oznamující tuto skutečnost, když se pokusí připojit nebo zahájit schůzku za použití těchto verzí prohlížeče.
  * Safari 11 a novější
  * Nejnovější verze 32bitové/64bitové aplikace Chrome

  * Linux (32bitový/64bitový)
  * Firefox 48 nebo novější
  * Chrome 65 nebo novější
  * Chromium

    * Webex Meetings 
    * Webex Webinars 
    * Events (klasická verze) 
    * Webex Training
    * Remote Support


**Windows**
  * Dvoujádrový procesor Intel 2.XX GHz nebo procesor AMD (doporučeny 2 GB paměti RAM)
  * V prohlížeči musí být povolen jazyk JavaScript a soubory cookie.
  * Software Java není vyžadován pro uživatele prohlížečů Mozilla Firefox a Google Chrome.

    * Events (klasická verze) 
    * Webex Training
    * Access Anywhere
    * Remote Access
    * Praktické cvičení

###  Software virtuální plochy služby Meetings
Aplikace Meetings poskytuje vylepšené prostředí infrastruktury virtuálních počítačů (VDI). ## Známé problémy a omezení pro různé platformy 
Tato část obsahuje známé problémy a omezení týkající se prohlížečů a operačních systémů podporovaných webexovými schůzkami. Informace o dalších známých problémech najdete v jednotlivých poznámkách k verzi pro každou službu.
**Sdílení souborů z osobních složek My Webex**
Uživatelé již nemohou sdílet soubory ze svých osobních  složek My Webex  , i když všichni uživatelé mohou během schůzky nahrávat a sdílet soubory.
**Podpora systému Microsoft Office 2007**
  * Microsoft Office 2007 může zobrazit výstrahu zabezpečení oznamující, že digitální podpis webex Meetings je neplatný.
  * Uživatelé nemusí být schopni sdílet soubory aplikace Microsoft PowerPoint. Alternativním řešením je sdílení obrazovky zařízení nebo sdílení aplikace PowerPoint.


**Podpora systému Microsoft Office 2010**
  * UCF Toolkit není podporována v systému Microsoft Office 2010 64-bit. 
  * Nové animace, přechody a 3D grafika zavedené v systému Microsoft Office 2010 nejsou podporovány. 
  * Import adresáře společnosti do kontaktů Webex Meetings není podporován v 64bitové verzi aplikace Microsoft Outlook 2010. 


**Podpora Microsoft Office 2013**
  * Pokud je nainstalovaný Microsoft Office 2013, nejsou při sdílení souborů Microsoft PowerPointu 2013 podporované následující funkce: 
    * Animace a přechody 
    * Vložené video nebo zvukové soubory 
    * UCF Toolkit 
  * Některé vlastní prvky nemusí být na přizpůsobených  kartách Informací  podporovány. Doporučujeme, aby ji uživatelé ověřili, aby se během schůzek zobrazovala správně.
  * V několika případech může dojít k následujícím problémům:
    * Barvy textu a výplně se mohou mírně lišit od skutečných barev na snímku.
    * Některé grafické prvky mohou na snímku chybět.
    * Písma mohou být na snímku rozmazaná nebo se mohou lišit od originálu.
    * Velikost obrazců se může lišit od originálu. 
  * Pokud se objekt v prezentaci aplikace Microsoft PowerPoint nezobrazuje správně v režimu úprav, je automaticky odebrán v zobrazení prezentace. Objekt se však může nadále zobrazovat, když je soubor sdílen ve schůzce. 
  * Uživatelé nemohou sdílet soubory Aplikace Microsoft PowerPoint 2013 chráněné heslem pomocí funkce sdílení souborů. Místo toho použijte funkce sdílení aplikací nebo sdílení plochy. 
  * Uživatelé nemohou sdílet soubory aplikace Microsoft Excel 2013 ve Windows 8 a 8.1 pomocí funkce sdílení souborů. Místo toho použijte funkce sdílení aplikací nebo sdílení plochy. 
  * Uživatelé nemohou sdílet dokumenty Wordu 2013 (64bitová verze) ve Windows 8 a 8.1 (64bitová verze) pomocí funkce sdílení souborů. Místo toho použijte funkce sdílení aplikací nebo sdílení plochy. 


**Podpora Microsoft Office 2016**
Microsoft Office 2016 je podporován v aplikaci Webex Meetings pro Windows nebo Mac. Sdílení souborů prezentací aplikace Microsoft PowerPoint však někdy způsobuje chybu. Sdílení více prezentací aplikace Microsoft PowerPoint najednou může také způsobit, že aplikace přestane reagovat. 
**Windows 2000**
Systém Windows 2000 již není od této verze podporován. Uživatelé systému Windows 2000 se mohou stále moci připojit ke schůzkám, ale výkon není zaručen.

  * Uživatelé Mac PowerPC se již nemohou připojit ke schůzkám.
  * Přehrávač síťových záznamů schůzek Webex nepodporuje převod nahrávek do formátu MP4 v systému Mac.
  * Podpora více monitorů ještě není ve webex Meeting for Mac k dispozici.


**Podpora 64bitových systémů Linux**
  * 64bitový Linux je podporován prostřednictvím [ webové aplikace Cisco Webex Meetings Web App ](https://help.webex.com/cs-cz/article/n1pxgbz)a je podporován na Ubutuntu 14.x nebo novějších, OpenSuSE 13.x nebo novějších, Fedora 18 nebo novějších, Red Hat 6 nebo novějších a Debian 8.x nebo novějších


**Známé problémy a omezení:**
  * V některých verzích Linuxu musí uživatelé proaktivně nainstalovat a aktivovat plugin "OpenH264 Video Codec provided by Cisco Systems, Inc.", aby video, volání do počítače a funkce sdílení obsahu fungovaly ve Firefoxu.
  * Sdílení obsahu nefunguje ve verzích systému Linux, které používají Wayland jako systém pro správu zobrazení (například Fedora 25 a novější). Je to způsobeno problémem s rozhraním API pro sdílení obrazovky WebRTC.
  * Odesílání a příjem videa nefunguje v systému Fedora 28 kvůli problému s kodekem H.264.


**Mozilla Firefox 43 nebo novější**
Doplněk Webex Meetings Productivity Tools pro Mozilla Firefox není v současné době podporován pro Mozilla Firefox verze 43 nebo novější. Doporučujeme, aby uživatelé místo toho používali aplikaci Internet Explorer.
**Citrix XenDesktop a XenApp**
Pro dosažení nejlepších výsledků doporučuje společnost Cisco nejnovější verzi přijímače Citrix pro systémy Windows i Mac.
  * XenApp není podporován podporou Webexu .
  * Vzhledem k architektonickému omezení prostředí virtuální plochy nemusí odesílání videa ve schůzkách Webex fungovat hladce. Kromě toho může být při odesílání videa ve schůzce snímková frekvence nízká. Výsledkem je méně než optimální uživatelské prostředí při odesílání videa.
  * Některé formáty videosouborů (WMV, AVI a MP4) nelze sdílet v prostředí virtuální plochy v aplikaci Webex Meetings kvůli omezením XenApp.
  * Vzdálený přístup a přístup odkudkoli nejsou podporovány, protože tyto agenty po restartování operačního systému automaticky odebere základní platforma Citrix.
  * Praktická cvičení nejsou podporována.
  * Při použití [ webové aplikace Cisco Webex Meetings v aplikaci ](https://help.webex.com/cs-cz/article/n1pxgbz) XenApp nebo XenDesktop můžete přijímat video, ale ne odesílat. Důvodem je, že webové prohlížeče nemohou detekovat zařízení virtuálních kamer v prostředí VDI.
  * Při použití [ webové aplikace Cisco Webex Meetings v aplikaci ](https://help.webex.com/cs-cz/article/n1pxgbz) XenApp nebo XenDesktop mohou uživatelé při použití volání  pomocí počítače zaznamenat problémy s kvalitou zvuku . Při použití webové aplikace v prostředí VDI doporučujeme použít  Call me  , Call in nebo  Call using video system  .

**Mac OS X 10.8 Mountain Lion**
Při zahájení nebo připojení ke schůzce pomocí proxy PAC v systému Mac OS X 10.8 Mountain Lion dojde k chybě aplikace schůzky. Jedná se o chybu operačního systému, která byla nahlášena společnosti Apple (hlášení o chybě Apple # 11844696). Problém byl vyřešen v sestavení Mac OS X 10.8.2. 
**Internet Explorer 10 a 11**
Rozšířený chráněný režim v Internet Exploreru 10 a 11 na ploše není podporovaný. Vzhledem k tomu, že tento režim nabízí procházení bez zásuvných modulů, jsou doplňky Webex Meetings zakázány a lze použít metody stahování ActiveX nebo Java. Uživatelé mohou stále používat řešení dočasné složky pro připojení ke schůzce. Případně se uživatelé mohou rozhodnout vypnout rozšířený chráněný režim, aby se mohli normálně připojit ke schůzce. 
Zapnutí kompatibilního zobrazení v aplikaci Internet Explorer na ploše může způsobit nesprávné vykreslení některých stránek schůzek Webex. Správcům doporučujeme, aby pro svůj web kompatibilní zobrazení vypnuli. 
**Prohlížeč Google Chrome**
  * Někteří uživatelé prohlížeče Google Chrome nemají přístup k Internetovému obchodu Chrome. V tomto případě se soubor rozšíření Webex Meetings automaticky nenainstaluje, když se uživatelé připojí ke schůzce. Tito uživatelé jsou přesměrováni na stránku nápovědy s pokyny k ručnímu stažení a instalaci souboru rozšíření.
  * Doplněk rozšíření Webex Meetings se nemusí nainstalovat a místo toho vrátí chybovou zprávu. Důvodem může být, že in-line instalaci nelze spustit z vyskakovacího okna v prohlížeči Google Chrome. Integraci může být nutné změnit tak, aby místo vyskakovacího okna používala okno nejvyšší úrovně.
