# Активировать устройство серии Board, настольного или комнатного устройства
![list-menu](https://help.webex.com/images/feedback.svg)Отправить обратную связь?
Узнайте, как активировать и настроить устройство серии Board, настольный или комнатный ряд для бесшовной интеграции с Cisco Webex. 
Перед началом настройки
Регистрируя в Cisco Webex устройство серии Board, desk или room, вы можете легко управлять им с помощью control Hub. Дополнительные сведения о концентраторе управления см. в разделе [ Начало работы с Cisco Webex Control Hub ](https://help.webex.com/ru-ru/nkhozs6/). 
Прежде чем приступить к настройке устройства, необходимо создать рабочее пространство и 16-значный код активации на control Hub. Читайте здесь, как добавить [ общие устройства и службы в рабочее пространство ](https://help.webex.com/ru-ru/1mqb9cb/) и [ сформировать код активации для устройства ](https://help.webex.com/ru-ru/ndb7w0db/).
Если вы хотите добавить Cisco Webex Calling и другие сервисы, см. раздел [ «Добавление сервисов к существующему рабочему месту с помощью устройств ](https://help.webex.com/ru-ru/zgjezbb/) для досок, настольных и комнат». Обратите внимание, что добавить Cisco Webex Calling в Room USB невозможно.
Устройство поставляется с предустановленным программным обеспечением, и обновления устанавливаются автоматически. Если при первой регистрации нового устройства доступно обновление программного обеспечения, мы рекомендуем выполнить его обновление. Дополнительные сведения об обновлениях программного обеспечения см. в разделе [ « Обновления ](https://help.webex.com/ru-ru/idba5c/) программного обеспечения RoomOS».  
| 1  |  Установите и подсоедините необходимые кабели в соответствии с инструкциями по установке, инструкциями по установке. При подключении устройство автоматически запускается и проверяет сетевое соединение. Если сетевое соединение работает, устройство проверяет наличие обновлений RoomOS и устанавливает все новые версии, которые оно находит. При возникновении неполадок с подключением появляется сообщение об ошибке, предполагающее, что ее причина может быть обнаружена.   |  
| --- | --- |  
| 2  |  После обновления программного обеспечения запускается мастер настройки. Следуйте экранным инструкциям по настройке сетевых настроек, введите код активации и проверьте экран, камеру и звук.  Параметры языка можно изменить до начала работы с мастером настройки или после этого с  помощью меню настроек  устройства. Формат времени соответствует настройке часового пояса в сети и не может быть настроен отдельно.  |
