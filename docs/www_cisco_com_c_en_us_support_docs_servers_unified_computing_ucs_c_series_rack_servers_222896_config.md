## Introduction
This document describes the procedure to convert a UCS-C series integrated in Intersight Managed Mode to standalone mode.
## Prerequisites
Ensure that you have these requirements before you attempt this configuration.
  * Computer to connect to C-Series Server
  * Monitor
  * KVM cable
  * Keyboard
  * 1G cable to connect to the management port


### Requirements
Cisco recommends that you have knowledge of these topics:
  * Basic understanding on Unified Computing Systems servers (UCS)
  * Basic understanding of Intersight Managed Mode (IMM)
  * Basic understanding of Cisco Integrated Management Controller (CIMC)
  * Basic understanding of Networking


### Components Used
  * Intersight Managed Mode (IMM)
  * Firmware version 4.3(3.240007)
  * 6536 Fabric Interconnect
  * UCSC-C220-M5SX


The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Background Information
This process is required in situations where Network Adapter requires replacement and part arrives with a lower firmware not allowing server to complete discovery.
## Configure
### Put The Server In Standalone Mode
[![warning-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/warn.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/warn.gif "warning-icon")
**Warning** : Ensure the server is powered off before you start this procedure.
#### **Step 1. Decommission The Server**
Navigate to your **IMM web interface** , then navigate to**Fabric Interconnects tab > Connections > Servers** and select the **desired server**.
Then, click in the **3 dots** and **decommission** it: 
[![Decommission the Server](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-00.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-00.jpeg "Decommission the Server")
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : You can verify the decommissioning progress in the requests tab.
#### **Step 2. Unconfigure The Server Ports**
Navigate to **Fabric Interconnects tab > UCS Domain Profile** and select **Port policy** :
[![Locate the Domain Profile](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-01.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-01.jpeg "Locate the Domain Profile")
[![Location for the Port Profile](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-02.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-02.jpeg "Location for the Port Profile")
In **Port Roles** tab, select the **current ports** that are configured as **Server port**. Click **Configure** and select the role as **Unconfigured**. Save **changes** and re-deploy the **domain profile**. Repeat the same procedure on Fabric Interconnect B.
[![Configuration Ports](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-03.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-03.jpeg "Configuration Ports")
[![Port Role](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-04.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-04.jpeg "Port Role")
#### **Step 3. Change CIMC To Default Settings  
**
Power off the **server** and remove **power cords**.
Wait for 2 minutes and connect the **power cords** again.
Connect a **KVM cable** to the console port of the server with a monitor and keyboard.
Monitor the server boot process until you reach the Cisco menu and press**F8** to enter Cisco IMC Configuration Utility.
[![Boot Process](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-05.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-05.jpeg "Boot Process")
[![CIMC Configuration Utility](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-06.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-06.jpeg "CIMC Configuration Utility")
Press **F1** and enable **Factory Default**.
[![Factory Defaults](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-07.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-07.jpeg "Factory Defaults")
Press **F10** to save changes and **reboot** the server.
#### **Step 4. Configure CIMC To Standalone Mode  
**
Monitor the server boot process until you reach the Cisco menu and press**F8** to enter to Cisco IMC Configuration Utility again.
Apply the next configuration:
  * NIC mode selected to Dedicated
  * IP to IPV4
  * CIMC IP with an IP in the same subnet as your computer.
  * NIC redundancy to none
  * No VLAN


[![Good Factory Defaults](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-08.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-08.jpeg "Good Factory Defaults")
Press **F10** to save changes and **reboot** the server.
Connect your computer to the physical **Management Port** on the server and open a **web browser**.
Use the IP you configured https://x.x.x.x 
[![CIMC GUI Interface](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-09.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-09.jpeg "CIMC GUI Interface")
CIMC Prompt view and current CIMC version:
[![CIMC Dashboard](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-10.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-10.jpeg "CIMC Dashboard")
### Reimage Firmware Version
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")

#### **Step 1. Download Host Upgrade Utility (HUU) ISO  
**
You can download HUU ISO at software.cisco.com. 
#### **Step 2. Launch KVM And Map HUU ISO  
**
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : If you prefer, you can expand the KVM tab, navigate to **Actions > System** and click **Launch KVM**.
**[![KVM Location](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-11.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-11.jpeg "KVM Location")**

Map HUU on Map CD/DVD:
[![Map Virtual Media](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-13.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-13.jpeg "Map Virtual Media")
#### **Step 3. Boot Using HUU ISO  
**
Reboot the server and monitor the boot process until you reach the Cisco menu and press**F6** to enter to Boot Menu.
[![Boot Menu](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-14.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-14.jpeg "Boot Menu")
Select **vKVM-Mapped vDVD** option to boot HUU ISO mapped:
[![Boot Devices](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-15.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-15.jpeg "Boot Devices")
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : Loading HUU ISO can take several minutes.
#### **Step 4. Reimage Current Version  
**
Wait until HUU ISO loads and accepts the Cisco Software License Agreement.
[![HUU](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-16.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-16.jpeg "HUU")
Switch to **Advanced Mode** and select **all the components** , then click **Update & Activate**.
Wait until it finishes the reimage and the server reboots.
### Integrate Server to Cisco Intersight
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : Before integrating the server to Intersight, it is important to Reset**CIMC** and **VIC adapter** into factory Default settings so that they can be properly configured.
#### **Step 1. Set BMC And VIC To Factory Default**
Navigate to **Administration > Utilities > Actions > Admin Utilities > Reset to Factory Defaults**:**  
**
[![Reset to Factory Default](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-17.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-17.jpeg "Reset to Factory Default")
[![Adapter CIMC Factory Default](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-18.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-18.jpeg "Adapter CIMC Factory Default")
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : It is not required to reset to default Storage devices. If selected, it erases the Virtual Drives and the data written to the Disks.
#### **Step 2. Reconfigured Ports As Server Ports  
**
Navigate to **Fabric Interconnects tab > UCS Domain Profile** and select **Port policy**.
In **Port Roles** tab. Select the **previous ports** that were configured as **Unconfigured** state. Click **Configure** and select the port role as **Server port**. Save the changes and re-deploy the **domain profile** , repeat the same procedure on Fabric Interconnect B.
[![Port Reconfiguration](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-19.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-19.jpeg "Port Reconfiguration")
Connect the required ports from the Network Adapter to the Fabric Interconnects ports.
#### **Step 3. Recommission The Server  
**
Navigate to **Fabric Interconnects** tab. Select the **Fabric Interconnect** connected to the server. Click **Connections** tab and in **Decommissioned** area select **Servers**. Select the **server** and **recommission** it.
[![Server Recommission](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-20.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-20.jpeg "Server Recommission")
You can monitor the server discovery process in the **Requests** tab.
[![Discovery Process](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-21.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/222896-configure-integrated-ucs-c-series-to-sta-21.jpeg "Discovery Process")
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : Discovery can take several minutes to start.
