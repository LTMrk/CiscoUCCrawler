## Privilegii utilizator  
|  Privilegiu   |  Descriere   |  
| --- | --- |  
|  Serviciu  |  Servicii Webex, cum ar fi WebexMeetings, Webex Training și așa mai departe.   |  
|  Tip sesiune admis  |  Un pachet predefinit de caracteristici și opțiuni.  |  
|  Securitate  |  Setați condițiile pentru resetarea parolei și blocarea contului.   |  
|  Editor înregistrare  |  Selectați această opțiune pentru a permite utilizatorilor să editeze înregistrările sesiunii Webex.   |  
|  Videoclip de înaltă calitate  |  Activați setările video. Videoclipurile de înaltă calitate trebuie să fie activate pentru a activa videoclipuri de înaltă definiție.   |  
|  Transcrierile înregistrărilor  |  Activați înregistrarea transcrierilor pentru toate înregistrările MP4 ale acestui utilizator.  |  
|  Integrare Facebook Live  |  Permiteți acestui utilizator să redea în flux întâlniri cu Facebook Live.  |  
|  Cameră personală _(doar pentru Webex Meetings)_  |  Activați Camera personală, atunci când este disponibilă pe site.  |  
|  Sală de ședințe de colaborare  _(doar pentru Webex Meetings)_  |  Permiteți acestui utilizator să se alăture întâlnirilor Webex de pe dispozitive video, atunci când este disponibil pe site.  |  
|  Webex Training  |  Dacă ați activat Webex Training pentru acest utilizator și opțiunile Laborator practic sunt activate pentru site-ul dvs., selectați Administrator laborator practic pentru a face din acest utilizator administrator de laborator.   |  
|  Webex Events  |  Dacă ați activat Webex Events pentru acest utilizator, selectați Optimizare lățime de bandă... pentru a optimiza lățimea de bandă pentru participanții din aceeași rețea.   |  
|  Privilegiul telefoniei  |  Selectați tipurile de opțiuni de teleconferință pe care doriți ca utilizatorul să le poată selecta atunci când programează sesiuni, inclusiv teleconferința de apel și de apel invers și VoIP integrat.   |  
|  Transmisie web  |  Selectați tipul de webcast pe care doriți să îl activați, privilegiul De bază și De administrator de site.   |  
|  Webex Meetings  |  Dacă ați activat Webex Meetings pentru acest utilizator, selectați dacă permiteți acestui utilizator să se alăture părții audio a întâlnirilor Conferință personală înainte de gazdă.  |  
|  My Webex  |  Selectați fiecare tip de pagină My Webex pe care doriți să o activați pentru acest utilizator. De asemenea, introduceți cantitatea de stocare a fișierelor și a înregistrărilor și computerele suplimentare pe care doriți să le alocați acestui utilizator.   |  
|  Webex Support  |  Dacă ați activat Asistența Webex pentru acest utilizator, indicați: 
  * Vizualizarea și culorile implicite pentru consola acestui utilizator. 
  * Dacă doriți ca sesiunea utilizatorului să se înregistreze automat. Alegeți din înregistrarea bazată pe rețea (BNR) sau Salvați înregistrarea pe computerul local și specificați o locație. 
  * Dacă doriți ca clientul implicit pentru acest utilizator să fie Sesiune multiplă sau Sesiune unică.

 |  
|  Remote Access  |  Dacă ați activat Acces la distanță pentru acest utilizator, indicați: 
  * Computerele care sunt atribuite utilizatorului. 
  * Vizualizarea și culorile implicite pentru consola acestui utilizator. 
  * Dacă doriți ca sesiunea utilizatorului să se înregistreze automat. Alegeți din înregistrarea bazată pe rețea (BNR) sau Salvați înregistrarea pe computerul local și specificați o locație. 

 |  
|  System Management  |  Activați Gestionarea sistemului, vizualizați și editați profiluri.   |  
|  Birou de asistență  |  Activați Service Desk, vizualizați și editați roluri.   |  
|  Limită de participanți  |  Precizează numărul maxim de participanți care sunt per serviciu.  |  
|  Preferințe WebACD  |  Dacă ați activat WebACD pentru acest utilizator, indicați dacă utilizatorul este un agent, manager sau ambele. Pentru a folosi o coadă de așteptare Call-Me-Back, acest utilizator trebuie să aibă privilegii de telefonie. Pentru a selecta cozile de atribuit utilizatorului, selectați Selectare cozi. 
  * Un agent și numărul de sesiuni simultane pe care agentul le poate gestiona. 
  * Un agent și dacă agentul poate accepta solicitările de intrare webex Support. 
  * Un agent și dacă agentul poate atribui automat toate cozile de asistență Webex sau specificate. 
  * Un manager și ce agenți și cozi poate monitoriza managerul. 
  * Un manager și dacă managerul poate atribui automat toate cozile de asistență Webex sau specificate. 
  * Un manager și dacă managerul poate atribui automat toți agenții Webex Support.

## Setarea privilegiilor contului de utilizator
Administratorii site-ului pot seta atribuirile de privilegii pentru un cont de utilizator în orice moment, specificând următoarele: 
  * Tipurile de întâlniri pe care un utilizator le poate găzdui pe un site de servicii Webex. Tipurile de întâlniri determină caracteristicile pe care un utilizator le poate utiliza pe site-ul dvs. 
  * Dacă un utilizator poate utiliza caracteristicile My Webex Standard sau My Webex Pro. 
  * Serviciile de teleconferință pe care un utilizator le poate utiliza în timpul unei întâlniri sau al unei sesiuni de instruire. 


Administratorii site-ului pot modifica privilegiile fie pentru toate conturile de utilizator simultan, fie doar pentru anumite conturi de utilizator. 
## Setarea privilegiilor pentru conturile individuale  
| 1  |  Pe bara de navigare, selectați  Utilizatori > Adăugare utilizator sau Editare utilizator.   |  
| --- | --- |  
| 2  |  Găsiți contul de utilizator și selectați linkul corespunzător.   |  
| 3  |  Pe pagina Adăugare utilizator sau Editare utilizator, în secțiunea Privilegii, selectați privilegiile pe care doriți să le activați pentru utilizator.   |  
| 4  |  Selectați Adăugare sau actualizare .   |
