## Introduction
This document describes how to get the PRT log from an MPP Phone that is currently registered on Webex Calling.
## Prerequisites
### Requirements
Cisco recommends that you have knowledge of these topics:
  * Webex Calling
  * Control Hub
  * Multi-Platform Phones (MPP)


### Components Used
The information in this document is based only on Multi-Platform Phones.
The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Background Information
When you try to get the Problem Report Tool (PRT) logs from Control Hub and it fails, you must know how to download the PRT logs manually from an MPP device.
## Enable Web Access for the MPP Phone
By default, in Webex Calling, when a device is onboarded in Control Hub, it has the web access disabled. In order to enable it, navigate to **`Control Hub > Devices`**and choose the device that you want to enable Web Access.
Once the device is chosen, click **`Device Settings`**:
[![Device Settings 1](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-00.png "Device Settings 1")Device settings 1
By default, the device uses the location settings. First, you must change the device settings to use custom settings:
[![Device Settings 2](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-01.png "Device Settings 2")Device settings 2
Once chosen, custom settings are now available.
Scroll down the page, find the option **`MPP Web Access (User)`**, enable the toggle, and click**`Save`**:
[![MPP Web Access \(User\)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-02.png "MPP Web Access \(User\)")MPP Web Access (User)
The device must be rebooted in order to take the new configuration.
## Generate the PRT from the Device
Step 1.On the device, click the **`Applications`**button[![Applications Button](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-03.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-03.jpeg "Applications Button") Applications button .
Step 2. Navigate to**`Status > Report Problem`**.
Step 3.Enter the Date and Time of the problem.
Step 4. Choose a Description from the list.
Step 5.Click**`Submit`**.
## Get the PRT Log from the Web GUI
Step 1. Log in to **`https://IP_ADDRESS_PHONE/`**.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : If the IP Address is unknown, it can be obtained from **`Settings > Status > Network Status > IPv4 Status`**.
Step 2. The first time the page shows a warning message, choose **`Advanced`**.
[![Warning Message 1](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-04.png "Warning Message 1")Warning message 1
And then click, **`Proceed to 10.152.212.70 (unsafe)`**.
[![Warning Message 2](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-05.png "Warning Message 2")Warning message 2
Step 3. Navigate to **`Info > Debug Info`**. Download the PRT Log. Right-click on the link and choose**`Save link as...`** in order to download the logs.
[![Web GUI](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/221052-generate-prt-manually-for-mpp-phones-reg-06.png "Web GUI")Web GUI
The PRT log is now downloaded to your PC.
