# Tack för din feedback.
![](https://help.webex.com/images/thumbs-up.svg)Ja tack!![](https://help.webex.com/images/thumbs-down.svg)Inte riktigt
09 april 2025 | 287 visning(ar) | 0 personer tyckte att detta var till hjälp

Prenumerera
Fel: ”Begäran misslyckades med statuskod 400” vid start Slido i ett möte
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
PROBLEMWebex-värdar får felmeddelandet ”Begäran misslyckades med statuskod 400” när de försöker starta en händelse (omröstning/frågor och svar) i Cisco Webex Meetings.  
Slido Det här felet stör de interaktiva funktionerna i möten, t.ex. live-omröstningar och frågor och svar-sessioner, som är nödvändiga för att engagera mötesdeltagare.  
  
![Bild tillagd av användare](https://help.webex.com/sv-se/article/WBX9000034465/Fel:-%E2%80%9DBeg%C3%A4ran-misslyckades-med-statuskod-400%E2%80%9D-vid-start-Slido-i-ett-m%C3%B6te)  
  
  
**UPPLÖSNING**  
Följ dessa steg för att åtgärda felet ”Begäran misslyckades med statuskod 400”: 
  1. Skicka en [problemrapport](https://help.webex.com/article/WBX000021930) till Webex med information om problemet.
  2. Öppna ett [supportärende](https://www.slido.com/contact#support) med Slido och ange problemrapport-ID från Webex som referens.
  3. Skapa en ny Slido händelse direkt på Slido webbplatsen ([http://slido.com](http://slido.com/)) som en tillfällig lösning.
  4. När den nya Slido händelsen har skapats väljer du den i Cisco Webex Meetings-apparnaSlido för att fortsätta dina mötesaktiviteter.

Läs mer Begränsningar för omröstningar och frågor och svar i ORSAKFelet ”Begäran misslyckades med statuskod 400” indikerar vanligtvis att en felaktig begäran skickades till servern.|[Slido](https://help.webex.com/en-us/article/o8hygt/Limitations-for-polls-and-Q&A-in-Slido)  
  
  
Detta kan inträffa av olika orsaker, till exempel felaktig begärandeformatering, saknade parametrar eller konfigurationsproblem inom Slido integreringen i Webex Meetings. Felet tyder på att begäran från värden om att starta en Slido händelse inte uppfyller serverns förväntningar eller begränsningarna för den aktuella Slido integreringen.
