## Introduction
This document describes the solution for an issue observed in Webex Calling where a 488 "Not Acceptable Here" is received by registered Fax devices.
## Prerequisites
### Requirements
Admin access in Control Hub.
### Components Used
The information in this document is based on these software and hardware versions:
  * Webex Calling
  * Control Hub


The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Problem
Fax calls do not work because the T.38 protocol is not being negotiated between the Fax device and the Webex Cloud. In this scenario, there is a 488 "Not Acceptable Here" generated by Webex Calling in response to the Re-Invite for the Switchover to negotiate the T.38 mode.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : This document assumes that T.38 mode is already configured in Control Hub on the device.
[![Call Message Flow](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-00.png "Call Message Flow")Call Message Flow
## Solution
**Step 1.** In [Control Hub](https://admin.webex.com/login "Control Hub") go to **Management.**
**Step 2.** Select the **Workspace** tab or the **User** tab. This depends upon which of those options you have assigned the Fax device to.
**Step 3.** Choose the **Workspace** or **User** that has assigned the Fax device.
**Step 4.** Select the **Calling** tab.
[![Select the Calling Tab](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-01.png "Select the Calling Tab")Select the Calling Tab
**Step 5.** Scroll down and select **Call Experience**.
[![Call Experience Option](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-02.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-02.jpeg "Call Experience Option")Call Experience Option
**Step 6.** In the **Compression options** , select **Normal compression**.
[![Normal Compression Setting](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-03.jpeg)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222133-fix-488-sip-error-for-fax-t-38-reinvite-03.jpeg "Normal Compression Setting")Normal Compression Setting
**Step 7.** Restart the Fax device and the Fax machine to ensure that changes are being updated in the configuration files for the Fax device registered to the Webex Cloud.
