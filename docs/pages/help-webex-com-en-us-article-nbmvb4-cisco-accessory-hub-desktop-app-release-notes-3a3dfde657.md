## January 2026

Version: 4.2.0.410

This release delivers the following features:

New MSI installation package

A Microsoft software installer (MSI) package is now available for the Cisco Accessory Hub desktop app. An IT administrator can efficiently automate the deployment, configuration, and
        maintenance of the application across multiple user workstations within an organization,
        reducing manual effort and ensuring consistent installations.

See the following link for more details:

- Download
              and install the Cisco Accessory Hub desktop app

New notification configuration settings

On Cisco Headset 950, you are now able to hear a gentle, in-ear notification when a Webex
        meeting is starting on your desktop. You can configure the Meeting Join notification
        settings in the Cisco Accessory Hub desktop app.

See the following link for more details:

- Customize
            your Cisco headset with the Cisco Accessory Hub desktop app

The Meeting Join notification is only supported on Cisco Headset 950 with firmware 5.2.7
          and later. For more information, see Cisco Headset 950 release notes .

## July, 2025

Version: 4.0.0.395

To avoid potential upgrade issues when using Cisco headsets or Cisco Desk Camera devices
          with Cisco Jabber, it is inadvisable to run the Cisco Accessory Hub desktop app.

This release delivers the following feature:

Secure Cisco Desk Camera 1080p

As an IT administrator, you can use the Cisco Accessory Hub desktop app to secure the access to a Cisco Desk Camera 1080p for a camera user who is working with Microsoft Windows 10 or Windows 11. When the
        secured camera is connected to the user's computer for the first time, this camera is
        assigned to this computer and works with this computer exclusively. This app also allows you
        to reset a secured camera so that this camera can operate on another user's computer.

## January, 2025

Version: 3.0.0.314

It is not recommended to run the Cisco Accessory Hub desktop app and the Webex app at the same time.

This release delivers the following features:

Support for Cisco Headset USB-C Adapter

You can use the Cisco Accessory Hub desktop app to pair the Cisco Headset USB-C Adapter to your Cisco Bluetooth ® headset. With the Cisco Accessory Hub desktop app, you can also manage your paired headsets for the Cisco Headset USB-C Adapter. This includes viewing the history of headsets previously paired with your USB-C Adapter,
        connecting to them, or removing them from the history list. In addition, you can update the
        firmware of the Cisco Headset USB-C Adapter by using the Cisco Accessory Hub desktop app.

See the following links for more details:

- Pair your Cisco Headset USB-C Adapter in the Cisco Accessory Hub desktop app

- Upgrade your USB adapter in the Cisco Accessory Hub desktop app

Mute Reminder notification customization

When you start to speak while the earbud mics are muted during an active call or meeting,
        you will receive a gentle in-ear reminder that you are muted. You can enable or disable the
        mute reminder under the Audible Notification settings in the Cisco Accessory Hub Desktop
        app.

New notification configuration settings

You are now able to hear new voice prompts for the Surroundings settings. For example, when
        you are changing the Surroundings settings between Noise Cancellation, Neutral, and
        Transparency (Own Voice) modes, you will hear "Noise Cancellation On", "Neutral", and
        "Transparency On" ("Own Voice On"). You can configure the voice prompts notification
        settings in the Cisco Accessory Hub Desktop app.

See the following link for more details:

- Customize your Cisco headset with the Cisco Accessory Hub
            desktop app

The Mute Reminder feature and new notification configuration settings are only supported
          with the Bang & Olufsen Cisco 950 earbud firmware 5.2.1 and later. For more
          information, see the Bang & Olufsen Cisco 950 release notes .

Webex Control Hub headset management

- After you log in the Cisco Accessory Hub desktop app with your Webex account, the connected Cisco headset registers to your account in Webex
          Control Hub. Webex system administrators can then configure settings of the headset in
          Control Hub. These configurations are pushed to the Accessory Hub desktop app and you can
          view the configuration updates as well.

- A new Firmware toggle status is now available in the Headset info or the Camera info panel in the Cisco Accessory Hub desktop app. Control Hub Administrators can switch the firmware channel in Control Hub for a
          device, and you are now able to receive the latest firmware updates for the specified
          channel while logged into Control Hub through the Cisco Accessory Hub desktop app.

Cisco Accessory Hub desktop app UI improvement

When installed on macOS platforms, the Cisco Accessory Hub desktop app now displays 3D animations for the connected Headsets, Desk Cameras, and Cisco Headset
        USB Adapters in the Accessories panel.

## August, 2024

Version: 2.2.0.162

This release delivers the following features:

Support for Bang & Olufsen Cisco 900 Series

You can use the Cisco Accessory Hub desktop app to configure the settings and upgrade the firmware on the Bang & Olufsen Cisco 980
        headset and 950 earbuds.

See the following links for more details:

- Customize your Cisco headset with the Cisco Accessory Hub desktop app

- Upgrade your headset in the Cisco Accessory Hub desktop app

Webex Control Hub device registration and inventory management

The Cisco Accessory Hub desktop app allows users to log in with their Webex account. After signing in, the connected Cisco
        headset or camera registers to the user in Control Hub, where administrators can then manage
        the device inventory.

For more information about this feature, see Sign in to Cisco Accessory Hub desktop app .
