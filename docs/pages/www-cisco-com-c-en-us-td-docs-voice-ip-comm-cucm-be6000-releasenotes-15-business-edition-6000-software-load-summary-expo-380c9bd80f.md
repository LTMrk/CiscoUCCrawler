## Introduction to Software Load Summary

The document identifies the software that is preloaded on the appliance model of this product for your convenience.

We attempt to keep the software versions in this build as up-to-date as possible; however, newer code may have been released
                              after this product was manufactured.

Before using this software, ensure that you have the latest maintenance updates, available either from Cisco Software Center (CSC), or using Cisco Electronic Software Delivery (ESD). We provide details on how to use Electronic Software Delivery in an email to you when you order licenses for your

## Types of Factory—Loaded Software

Business Edition 6000/7000 appliance hardware is loaded with the latest supported BIOS, firmware, and drivers from Cisco’s UCS Hardware and Software Compatibility Tool at the time of factory build. At the time of installation, consult this tool to see if any items must be refreshed.

VMware vSphere ESXi software is required but not included or factory-preloaded. Must be customer-provided and manually installed/licensed.

Collaboration applications are not factory-preloaded currently. Check Cisco.com, Cisco Software Center, Cisco Electronic Software
                              Delivery, and Cisco License Central for access to images for installation and latest maintenance updates. See the Check the Business Edition 6000/7000 or 14 or 15 Installation Guide for more details.

## Preloaded Virtualization and Application Software—Business Edition 6000 and 7000

The appliance models that are described in this document are primarily intended for Collaboration System Release 14 and 15
                              Unified Communications (UC) applications. These applications include Cisco Unified Communications Manager, Cisco Unified IM
                              and Presence Service, and Cisco Unity Connection. For release sets of compatible application versions, see Cisco Collaboration
                              Systems Release documents at https://www.cisco.com/c/en/us/support/unified-communications/unified-communications-system/tsd-products-support-series-home.html .

Refer to the Business Edition 6000/7000 or 14 or 15 Installation Guide and the installation guide for each application for
                              instructions.
