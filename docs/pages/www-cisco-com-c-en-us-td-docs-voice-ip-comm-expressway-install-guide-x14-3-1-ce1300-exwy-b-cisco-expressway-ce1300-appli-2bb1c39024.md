## Locating Serial Numbers

The Cisco Expressway appliance displays two serial numbers:

UCS serial number in format WZPxxxxxxxx . Displayed on the hardware pullout tab, and in the Cisco Integrated Management Controller ( Connecting Using CIMC Serial Over LAN ) web interface.

Software serial number in format 52E5NNNN . Displayed in the Cisco Expressway web interface or through SSH.
