## Getting Started

In order to begin development using the CTIOS toolkit you need to install the CTIOS desktop and select the Toolkit features you want to install. The CTIOS toolkit is NOT available for download from the Solution Partner Program website. You must order the CTIOS media.

Customers and partners should order CTIOS by ordering the NFR Media kit CCEH-MEDIA80-K9 through their sales team.

Note that all customers and partners wishing to deploy custom CTI integrations using CTIOS are required to have a valid Developer Services contract.  You should have a lab system from a Advanced Technology Partner in order to develop and test your CTIOS Toolkit based Application.
