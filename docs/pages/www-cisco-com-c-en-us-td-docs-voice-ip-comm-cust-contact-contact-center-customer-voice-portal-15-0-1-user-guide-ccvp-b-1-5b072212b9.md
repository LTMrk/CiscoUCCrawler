## About this
                        	 Guide

This document describes the various components that can exist on Cisco
                           		Unified CVP VXML Server, administering the VXML Server, and VXML Server
                           		logging.

## Audience

This design guide is intended for the system architects, designers,
                           		engineers, and Cisco channel partners who want to apply best design practices
                           		for the Cisco Unified Customer Voice Portal (CVP).

This document assumes that you are already familiar with basic contact center terms and concepts.
