Cisco BroadWorks Documentation Guide Release 26

# Cisco BroadWorks Documentation Guide Release 26

Updated: July 22, 2025

Chapter: Reference

## Chapter: Reference

# Reference

## Technical References

Document Title

Description

Cisco BroadWorks Feature Overview (All Releases)

Use this document to view the description of all Cisco BroadWorks features. This document provides links to the individual
                                       feature description documents.

Cisco BroadWorks Feature Overview (Release 25 and Later Only)

Use this document to view the description of the features added to Cisco BroadWorks in Release 26. This document provides
                                       links to the individual feature description documents.

Cisco BroadWorks Functional Summary

Use this document to view the capabilities, features, and services added to Cisco BroadWorks in the current release including
                                       the interface changes introduced by these capabilities.

Cisco BroadWorks Interface Impact Summary

Use this document as a quick reference to see how each feature in the Cisco BroadWorks release affects each of the external
                                       interfaces.

Cisco BroadWorks Server Security Guide

Use this document as an overview of the required protocols for Cisco BroadWorks, the ports that they use, and the Server Access
                                       Control Lists (ACLs) and firewalls used to restrict access to servers so that they can only access required ports.

Cisco BroadWorks System Performance Monitoring Guide

Use this document as a guide as to which measurements that should be gathered to monitor the performance of a Cisco BroadWorks
                                       system.

Cisco BroadWorks Redundancy Guide

Use this document to view the configuration requirements for deploying a redundancy solution for Cisco BroadWorks.

Cisco BroadWorks Service Guide

Use this document as an overview of all the services provided by Cisco BroadWorks.

Cisco BroadWorks Service Interaction Guide

Use this document to view the interactions between the different user services provided by Cisco BroadWorks.

Cisco BroadWorks Network Function Manager Virtualized Network Function Lifecycle Management Guide

Use this document to view how some of the VNF Manager functions are implemented by the Cisco BroadWorks Network Function Manager
                                       (NFM) and how they can be used to perform VNF lifecycle management.

## Interworking

Document Title

Description

Cisco BroadWorks VoiceXML and CCXML Developer's Guide

Use this document as a reference for writing VoiceXML or CCXML scripts that run on a Cisco BroadWorks Media Server.

Cisco BroadWorks Announcement Guide

Use this guide to configure languages and tones for Cisco BroadWorks announcements.

Cisco BroadWorks Application Server Identity Guide

Use this document to learn about the identity-related configuration and handling on the Cisco BroadWorks Application Server.

Cisco BroadWorks Application Server VTR Administration Guide

Use this document to execute call-processing simulations to better understand and test various configurations using the Verify
                                       Translation and Routing (VTR) diagnostic tool.

Cisco BroadWorks Call Recording Guide

Use this document to learn about and configure the Cisco BroadWorks Call Recording Interface.

Cisco BroadWorks Call Recording on XS-TAS Guide

Use this document to learn about and configure the Cisco BroadWorks Call Recording Interface in an Execution Server Telephony
                                       Application Server (XS-TAS) deployment.

.

Cisco BroadWorks External Emergency Number SOAP Query Interface Specification Guide

Use this document to learn how to use the External Emergency Number Simple Object Access Protocol (SOAP) Query Interface to
                                       make the Cisco BroadWorks Application Server query a third-party server to translate an emergency number, such as 911, into
                                       a routable number.

Cisco BroadWorks MGCP Access Interface Interworking Guide

Use this document to learn how to use the Media Gateway Control Protocol (MGCP) interface to communicate between Cisco BroadWorks
                                       Application Servers and partner MGCP access devices.

Cisco BroadWorks SIP Access Interface Interworking Guide

Use this document to learn how to use the Cisco BroadWorks Application Server access interface to communicate between the
                                       Cisco BroadWorks Application Server and partner access devices including SIP phones, SIP access gateways, SIP trunking gateways,
                                       and so on.

Cisco BroadWorks SIP External Voice Mail Support Interworking Guide

Use this document to view end-to-end call flow examples for typical voice messaging scenarios. This document is a supplement
                                       to the Cisco BroadWorks SIP Access Interworking Guide for partners and operators who want to interface external voice mail/messaging platforms with Cisco BroadWorks.

Cisco BroadWorks SIP Network Interface Interworking Guide

Use this document to learn how to use the SIP interface to communicate between Cisco BroadWorks servers and partner network
                                       elements, including Application Servers, softswitches, Network Servers, SIP proxies, and so on.

Cisco BroadWorks Treatment Guide

Use this document to learn about the system-default treatments used by Cisco BroadWorks and how to configure the system to
                                       modify certain aspects of these treatments to provide better feedback to callers, to enhance interoperability with other vendor
                                       equipment, or to obtain more specific information in call detail records.

Cisco BroadWorks Network Function Manager Network Monitoring Guide

Use this document to learn how the Network Monitoring application integrates in the Cisco BroadWorks Network Function Manager
                                       (NFM) and how it bridges the rest of the Network Function Manager functions with the Network Monitoring Console.

## Compatibility

Document Title

Description

Cisco BroadWorks Device Management Interoperability Test Plan

Use this document to integrate SIP access devices with the Cisco BroadWorks Device Management feature.

Cisco BroadWorks IMS ISC Interoperability Test Plan

Use this document to validate the functional interoperability between the Cisco BroadWorks Application Server and a Serving
                                       Call Session Control Function (S-CSCF) over the IP Multimedia Subsystem (IMS) Service Control (ISC) interface by exercising
                                       a comprehensive cross section of Cisco BroadWorks features in an IMS configuration.

Cisco BroadWorks Ro Interface Interoperability Test Plan

Use this document to validate basic interoperability between Cisco BroadWorks and an Online Charging System (OCS) using the
                                       Diameter interface, known in IMS as the Ro reference point.

Cisco BroadWorks SIP Access Device Interoperability Test Plan

Use this document to validate SIP interoperability between Cisco BroadWorks and SIP access devices such as access gateways,
                                       IADs, SIP MTAs, ATAs, and so on.

Cisco BroadWorks SIP Phone Interoperability Test Plan

Use this document to validate SIP interoperability between Cisco BroadWorks and SIP phones or soft clients. Completion of
                                       the test plan validates the SIP interface with Cisco BroadWorks and meets a prerequisite for Cisco BroadCloud integration.

Cisco BroadWorks VoLTE UE Interoperability Test Plan

Use this document to validate SIP interoperability between Cisco BroadWorks and Voice over Long Term Evolution User Equipment
                                       (VoLTE UE) via IP Multimedia Subsystem Core Network (IMS CN). This includes service invocation occurring on the IMS Service
                                       Control (ISC) interface and the Gm interface.

## Platform Quick Reference Guides

Document Title

Description

Cisco BroadWorks Auto Attendant Basic Quick Reference Guide

Use this document to learn how to plan, define, and test your automated receptionist, using the Cisco BroadWorks Auto Attendant
                                       - Basic service.

Cisco BroadWorks Auto Attendant Standard Quick Reference Guide

Use this document to learn how to plan, define, and test your automated receptionist, using the Cisco BroadWorks Auto Attendant
                                       - Standard service.

Cisco BroadWorks Anywhere Quick Reference Guide

Use this document to learn how to use the BroadWorks Anywhere service once it is set up by the office administrator. Follow
                                       the provided procedures to use the different BroadWorks Anywhere functions.

Cisco BroadWorks Group Voice Portal Quick Reference Guide

Use this document to get a quick overview of the Cisco BroadWorks group voice portal and learn how to set up the voice portal
                                       for your organization. Follow the step-by-step procedures to configure the greetings, set passcode rules, and customize voice
                                       portal menus.

Cisco BroadWorks Login Functions Quick Reference Guide

Use this document to learn how to set-up your access to Cisco BroadWorks, such as logging in and out, adding Cisco BroadWorks
                                       to your "Favorites", or auto-starting Cisco BroadWorks web portal.

Cisco BroadWorks Meet-Me Conferencing Quick Reference Guide

Use this document to learn how to use the Cisco BroadWorks Meet-Me Conferencing service to organize, configure, moderate,
                                       and record conferences, as well as participate in conferences organized by others.

Cisco BroadWorks Paging Quick Reference Guide

Use this document to learn how to set up a paging system for your organization in Cisco BroadWorks.

Cisco BroadWorks Personal Voice Portal Quick Reference Guide

Use this document to learn how to use your personal voice portal to listen to your messages, leave messages to others, and
                                       record personalized greetings.

Cisco BroadWorks Special Calling Features Quick Reference Guide

Use this document to view all the Cisco BroadWorks features available using feature access codes (FAC). Follow the step-by-step
                                       procedures to use the features.
