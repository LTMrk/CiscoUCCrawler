# Set Up Your Applications

Perform the following tasks to set up your applications.

Deploy virtual machine OVAs for each application that you want to install.

## Deploy Virtual Machine OVAs

Each application that you want to run, requires its virtual machine base OVA file from software.cisco.com.

Depending on the preloaded application, the OVA contains any of the following applications:

Fully installed ready to run application

VM configuration alone for an empty virtual machine

For more details, see the Physical Appliance Installation and Upgrade Guides .
