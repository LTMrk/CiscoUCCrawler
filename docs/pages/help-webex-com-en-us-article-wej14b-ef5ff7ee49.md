Use these steps to check the region (Europe or North America) to which a particular country maps.

Download CountryCodeGEOMapping.xlsx .

Open the file in Microsoft Excel.

Choose from one of the following actions:

- On the User page tab, select a country from the drop-down
            list in cell B3. The associated region is displayed in cell B4.

- Use the Country Code GEO mapping tab to browse the country
            list.
