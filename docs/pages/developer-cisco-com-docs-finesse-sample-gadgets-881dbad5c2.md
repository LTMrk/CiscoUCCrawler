# Sample Gadgets

The following gadget are sample gadgets to demonstrate the usage of the Finesse JavaScript Library and REST APIs. These gadgets are only a sample and is NOT guaranteed to be bug free and production quality.

Call History Gadget

Displays an agent's call activity for the last 24 hours and provides a simple way to call a number back without manually switching to a not ready state.

Call Recording Gadget

Enables a Start Recording button when a call is in progress.

Click To Call Sample Gadget

Demonstrates how to place a call from an agent to another extension.

CSS3 Animation Sample Gadget

Demonstrates how to use CSS3 animations in a gadget.

CUIC Sample Gadget

Demonstrates how to create a gadget that displays a CUIC permalink in an iframe.

Digital Channel Sample Gadget

Demonstrates how to use the digital channel APIs from the Finesse JavaScript library.

Edit Call Variables Task Management Sample Gadget

Demonstrates how to display, edit, and save the Task Management Call Variable Layout in a gadget.

Embedded WebApp Sample Gadget

Demonstrates how to display a webpage in a gadget.

External REST API Sample Gadget

Demonstrates how to call an external REST API using gadgets.io.makeRequest() in a gadget.

Google Maps Screen Pop Sample Gadget

Provides a screen pop of Google Maps using the address that is stored in a call variable.

Hub Topic Sample Gadget

Demonstrates how to communicate data between two or more gadgets in the Finesse desktop. It is intended to serve as an example of using the gadgets.hub.publish and gadgets.hub.subscribe, which are part of the OpenSocial Specification.

Learning Sample Gadget

Demonstrates how to use the User and Dialog objects as well as perform operations such as change User state, place a call, and using a Dialog's CallVariable for a screen pop in an iframe.

Non Gadget Python Sample

A simple python script that utilizes the Finesse REST APIs to sign in/out, change the agent state, and do a GET on the user. There is also logic to connect to the Finesse Notification Service using a XMPP library to receive Finesse notifications.

Non Gadget Sample

Presents a web page allowing the ability to sign in/out, query for and change agent state, and perform basic call control operations.

Non Gadget Sample With Strophe And WebSocket

Presents a web page allowing the ability to sign in/out, query for and change agent state, and perform basic call control operations.

Notification Service Client Sample

A simple Java program that uses the Smack library to connect to the Finesse Notification Service.

Phone Book Sample Gadget

Demonstrates how to access the User's phone books collection and display it on the gadget.

Reload From Other URL Sample Gadget

Demonstrates loading a different gadget at the click of a button.

Screenpop Sample Gadget

Demonstrates how to create a screen pop into a webpage from data in a CallVariable associated with an inbound call.

Silent Monitor Sample Gadget

Gives a visible notification when the user is being silent monitored.

Task Activity Notification Sample Gadget

Demonstrates how to use the Finesse APIs for notifying and receiving updates about digital task activity status.

Task Management Sample Gadget

Demonstrates how to use the Finesse Task Routing APIs.

Thick Client Sample Gadget

Demonstrates to integrate a JavaApplet to allow a Windows command line to be invoked from a workflow action event.

UCCX Facebook Messenger Chat Connector

Adds Facebook Messenger as a supported chat client for customers to communicate with agents.

Update Call Variable Data Sample Gadget

Demonstrates how to use the Update Call Variable Data REST API in a gadget.

Webex Team Announcements Sample Gadget

Demonstrates how to integrate Cisco Webex API’s in a gadget.

Web Service Sample Gadget

Demonstrates how to retrieve xml from a 3rd party server.

Workflow Screen Pop Sample Gadget

Displays a tab in the gadget when a workflow action is triggered with type "Browser Pop" that is handled by "Other".
