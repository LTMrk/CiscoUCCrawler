## Chapter: Applications

# Applications

## Available Applications

Cisco phones don't include these applications by default. But your company might have added applications such as the weather,
                           stock information, company news, to-do lists, or similar information and services.

## View Active Applications

You can easily see what applications you already have open.

Step 1

Press Applications .

Step 2

Select Running applications .

Step 3

Press Exit .

## Switch to Active Applications

Step 1

Press Applications .

Step 2

Select Running applications .

Step 3

Select a running application and press Switch to to open and use the selectedapplication.

Step 4

Press Exit .

## Close Active Applications

Step 1

Press Applications .

Step 2

Select Running applications .

Step 3

Select a running application and press Close app to close the application.

Step 4

Press Close , then press Exit .
