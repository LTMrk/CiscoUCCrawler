# Internal REST API Endpoints

Following authenticated REST API endpoints are exposed for internal invocation from within the solution. These REST API endpoints
                        are listed for information purposes only, and not intended for external consumption currently. If you have a valid use case
                        to know more, please get in touch with the product team.

```
https://<VVB_HOSTNAME_OR_IP>/adminapi/application
https://<VVB_HOSTNAME_OR_IP>/adminapi/asrServer
https://<VVB_HOSTNAME_OR_IP>/adminapi/ttsServer
https://<VVB_HOSTNAME_OR_IP>/adminapi/sipTrigger
https://<VVB_HOSTNAME_OR_IP>/adminapi/callControlGroup
https://<VVB_HOSTNAME_OR_IP>/adminapi/dialogGroup
https://<VVB_HOSTNAME_OR_IP>/adminapi/systemParam
https://<VVB_HOSTNAME_OR_IP>/adminapi/speechconfig/rest/config
https://<VVB_HOSTNAME_OR_IP>/adminapi/cloudConnect
```
