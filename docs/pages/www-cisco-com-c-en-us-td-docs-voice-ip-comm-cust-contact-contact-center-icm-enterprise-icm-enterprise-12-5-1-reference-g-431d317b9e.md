## About This Guide

This manual describes the Customer Telephony Integration (CTI)
                              Server message interface between Unified Contact Center Enterprise (Unified
                              CCE) and application programs.

## Audience

This manual is for system integrators and programmers who want to integrate CTI client applications with Unified CCE.
