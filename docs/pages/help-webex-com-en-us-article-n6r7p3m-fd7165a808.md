## BroadWorks Software Requirements

See Lifecycle Management - BroadSoft
                                        Servers .

We expect the Service Provider to be "patch current" with the latest
                                BroadWorks patches and Release Independent (RI) apps. The following
                                list of patches is the minimum requirement for integrating with
                                Webex.

Make sure to review the patch notes for these software patches. Some patches may have additional CLI requirements.
