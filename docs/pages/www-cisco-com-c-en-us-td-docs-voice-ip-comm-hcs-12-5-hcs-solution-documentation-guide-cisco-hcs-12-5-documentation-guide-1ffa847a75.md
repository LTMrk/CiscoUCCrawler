# Documentation Changes

## HCS Release Numbering

The current release number for Cisco Hosted Collaboration Solution is 12.5, and the latest release is called HCS 12.5 Add-on
                           1; future solution releases will be named by increasing the "add-on" number.

Cisco HCS releases are numbered so components of the solution (eg., Cisco Hosted Collaboration Mediation Fulfillment) are
                           given a tertiary release number that descends from the solution release number. For example, HCM-F 12.5(1) is the initial
                           release for that component; subsequent releases are numbered 12.5(2), 12.5 (3), and so on until the next solution release.

## Retired Documents

The following documents were retired for the Cisco Hosted Collaboration Solution 12.5 release.

Document Title

Notes

Cisco Hosted Collaboration Solution Dial Plan Management Guide for Cisco Unified Communications Domain Manager

Retired due to the end-of-life of CUCDM 8.x. Note also that there is no corresponding Dial Plan Management Guide for CUCDM
                                       10.x/11.5 under HCS 12.5. For advice on Dial Plan Management using those versions of CUCDM, consult the guide for HCS 11.5.

Cisco Hosted Collaboration Solution Integration with Cisco Collaboration Client Applications

Cisco Hosted Collaboration Solution End-User Provisioning

These guides primarily discussed configuration in CUCDM, which is not a component of HCS 12.5. If you are using an earlier
                                       version of CUCDM with HCS 12.5, consult the 11.5 version of the guide.

Most of the content of the deprecated SIP/CTI support guide had been duplicated or superseded by the Solution Reference Network Design Guide , so any information that was still relevant has been absorbed into that guide.

Cisco Hosted Collaboration Solution  Multitenant Expressway Configuration Guide

This was a temporary guide - its contents are now distributed through several of the solution documents related to design
                                       and configuration.

Cisco Hosted Collaboration Solution Flexibility Guide

This was also a temporary guide, introducing the flexibility in solution design that is now a core characterstic of HCS 12.5.

Cisco HCS Large Enterprise Reference Guide

This guide was relevant to a previous HCS offering that is positioned differently for HCS 12.5.
