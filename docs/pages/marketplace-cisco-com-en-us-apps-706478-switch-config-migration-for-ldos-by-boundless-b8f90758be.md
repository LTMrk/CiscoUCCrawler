# Switch Config Migration for LDOS by BOUNDLESS

by Boundless

Automate Catalyst switch migrations to cloud-managed networking. Upload CLI configs, get cloud-ready templates in minutes—not weeks.

## Overview

### Accelerate your Catalyst modernization.

Upload your Catalyst config. Deploy to cloud-managed switches with confidence—automatically.

### Key benefits

- Accelerate Catalyst modernization Move faster from legacy configs to a cloud-managed model. Config Bridge turns existing Catalyst configurations into a structured, cloud-ready blueprint—cutting weeks of manual rebuild work into a repeatable workflow.

- Reduce risk with a reviewable translation See what will change before you deploy. The app extracts and translates key configuration elements into a clear, reviewable output so teams can validate intent, catch gaps, and avoid surprises during cutover.

- Standardize at scale Replace one-off site builds with consistent rollouts. Config Bridge helps normalize configurations across sites (naming, patterns, and structure), making it easier to enforce standards and maintain consistency across large estates.

- Improve efficiency for teams and partners Save engineering time and deliver more projects. By automating the ingestion and translation steps, Config Bridge reduces repetitive CLI analysis and accelerates delivery—especially valuable for MSPs and partners running multi-site migrations.

- Config Ingest Import Catalyst configuration files (single or batch) to kick off a project in minutes—no manual copy/paste or spreadsheet prep.

- Deep Config Parsing Automatically extracts key objects from the configuration (e.g., VLANs, interfaces, port modes, and more) and presents them in a clean, readable format for engineering review.

- Translation Engine Converts recognized Catalyst settings into a target-ready model, mapping source constructs into cloud-manageable equivalents to accelerate modernization and reduce rework.

- Security Assessment Automatically highlights security-relevant configuration elements and potential gaps (e.g., inconsistent controls, legacy patterns, or missing protections) so teams can remediate during the migration—not after.

- Target Switch Recommendations Uses observed configuration and port requirements to recommend an appropriate target switch approach—helping teams avoid over/under-sizing and aligning design choices with real site needs.

- Pre-Deployment Readiness Checks Runs checks that help confirm the config is “migration-ready” (coverage, exceptions, conflicts, required inputs) so you can confidently move from translation to execution.

- Deployment Mode Options Supports different deployment paths (e.g., staged rollout vs. one-shot cutover) so you can match the execution model to site constraints, timelines, and risk tolerance.
