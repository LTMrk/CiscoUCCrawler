## Introduction

This document describes how to stop mass Resend Invitations emails in Control Hub.

## Problem: Send Invitations Accidentally Initiated for all Organization Users

An administrator accidentally initiated Send Invitations to all of the users in the organization.

## Solution: Stop the Resend Invitations Task

To stop the Resend Invitations task, complete these steps:

1. Sign in to Control Hub, then select Overview .

Overview Tab in Control Hub Menu

2. Navigate to Quick links .

Quick Links Card in Control Hub

3. Under Admin capabilities , select View organization tasks .

View Organization Tasks Option

4. Select the Resend Invitations task, then click the X located on the right-side of the process bar under Resend Status.

Resend Invitations Task

5. Select Stop Resend Invitations to stop the task.

Stop Resend Invitations Option

6. Resend Status shows Stopped .

Resend Status Stopped
