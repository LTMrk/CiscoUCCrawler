# New and Changed Information

## Cisco Prime License Manager 10.x New Distribution Model

Cisco Prime License Manager, formally Enterprise License Manger, has a
		  new distribution model for co-resident and standalone deployments.

Unified Communications  deployment (co-resident Cisco Prime License Manager):

- Application + Cisco Prime License Manager deployment

- Distribution under
			 top-level product SKU with Cisco Unified Communications Manager, Cisco Unity Connection, and Business Edition 6000

Standalone deployment:

- Ordered under top-level
			 product SKU

- Cisco Prime Standalone =
			 (Cisco Prime License Manager + Unified Communications Operating System)

New features in this release include:

- E-Migration

- Welcome Screen

## Electronic Migration

Electronic Migration supports the migration of licenses to Cisco Prime License Manager without requiring human interaction with the Cisco Licensing Operations or the Cisco Customer Portal. The license migration request is submitted electronically to the Cisco Licensing Operations and the new migrations are automatically installed on Cisco Prime License Manager. The availability of this feature depends on the product type as well as the types of licenses being migrated.

## Welcome Screen

A welcome screen has been added to Cisco Prime License Manager to provide direction to new users who may want to add product instances or install licenses. The welcome screen can be disabled when it is no longer needed.
