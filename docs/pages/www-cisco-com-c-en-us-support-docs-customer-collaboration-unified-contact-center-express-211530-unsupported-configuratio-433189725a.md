## Contents

## Introduction

This document describes unsupported configurations and scenarios for Unified Contact Center Express (UCCX) Non-Voice Integration with SocialMiner.

## Prerequisites

### Requirements

It is recommended to have knowledge on these products for the Non-Voice integration

- UCCX

- SocialMiner

- Microsoft Exchange Server

### Components Used

The information in this document is based on these software and hardware versions:

- UCCX 11.5

- SocialMiner 11.5

- Microsoft Exchange Server 2013

The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, make sure that you understand the potential impact of any command or changes.

Note : Possible symptoms highlighted in the document are seen in the lab environment. There is a potential for other side-effects due to the unsupported configurations.

## Background

UCCX Non-Voice Integration with SocialMiner is applicable for Chat and Email features. This provides the capability for agents to receive Chat and Emails as a contact from UCCX and service their customers through Finesse in addition to voice.
