# Cisco IP Phone 8800 Series Compatibility

The Cisco IP Phone 8800 Series has several supported VIDs. Each VID has a specific minimum firmware release. You can't load
                  an older firmware version on a phone that requires a newer firmware version.

The following table lists the minimum firmware load for each VID. In the table, X means "not applicable" . The phones with VID V07 or previous can run any firmware load.
