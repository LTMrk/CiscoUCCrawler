Customer Voice Portal

Customer Voice Portal (CVP) combines open-standards support for speech with intelligent application development and call control to deliver personalized self-service to callers. It allows developers to extend the already customizable voice-portal/IVR applications and add VoiceXML browser services.

Learn more

Customer Voice Portal APIs

Custom Elements for Call Studio

Allows developers to create custom interfaces to other systems or take control of the dynamic VoiceXML created by the software while retaining multi-platform compatibility.

Customer Voice Portal REST APIs

Allows developers to programmatically control CVP application script deployment, related media resource management and CVP server configurations.

Virtualized Voice Browser REST APIs

Provides VoiceXML browser services when used in conjunction with a VoiceXML server, such as the Cisco Unified CVP.

Test your code in a Customer Voice Portal Sandbox

The Customer Voice Portal Sandbox is the Cisco cloud service provided to help customers, partners, and developers quickly integrate their solutions with a number of Cisco technologies. The Sandbox provides a developer with an environment to design, develop and test using the APIs that are available in the Customer Voice Portal solution. View all

PCCE 12.6 (with CVP) Sandbox

Use the PCCE Sandbox, that includes Customer Voice portal, to try out various Customer Voice Portal integrations and customizations such as the Customer Voice Portal REST APIs.
