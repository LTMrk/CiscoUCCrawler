# Jabber Guest for Android SDK Release - 11.2.0

Introduction

Cisco Jabber Guest enables organizations using Cisco Unified Communications Manager (UCM) and Cisco Expressway to
                connect with remote visitors (guests) through their website or mobile application using instant-on, real-time
                voice and video. Guests simply click a URL, website link, or mobile application to start the interaction. Build
                these capabilities into your website or mobile application with the included SDKs, or use the Jabber Guest client
                experiences.

New and Changed Functionality

- Support 64-bit architectures to meet Google Play requirement. Refer to
                    https://developer.android.com/distribute/best-practices/develop/64-bit

API updates(Refer to API Guide documentation for more details)

- Update targetAPI to 28 to meet Google Play restriction. Refer to
                    https://developer.android.com/distribute/best-practices/develop/target-sdk
