# Cisco Wireless Phone 840 and 860 Release Notes for Firmware Release 1.10(4)

These release notes support the Cisco Wireless Phone 840 and 860 software release 1.10(4). These wireless smartphones require:

Call Control

Cisco Unified Communications Manager

Minimum: 11.5(1)

Recommended: 12.5(1), 14.0(1), or higher)

Webex Calling

Wireless LAN Controller and Access Points

See the Cisco Wireless Phone 840 and 860 Deployment Guide for supported solutions.

## What’s New in This Release?

The following sections describe the features that are new or have changed in this release.

Support Date/Time Group

When Auto Time Zone is disabled trhough Device Settings application, phone aligns with Time Group settings and changes accordingly.

Pickup Group alert

Pickup Group does not play Audio. To enable this feature, you need to set the Call Pickup Group Notification Policy to Visual Alert . Default value is Audio and Visual Alert . Shared line notification is now part of Silent Call Features.

Visual Notification Only

Phones no more play audible notifications (only visual notification is supported) if shared line is picked up by another phone.

This feautre is supported by phones registered to both CUCM and Webex calling.

Allow Custom Settings Application

Barcode (840s and 860s models only) = com.cisco.barcode.service

- Battery Life = com.cisco.batterylife

- PTT = com.cisco.ptt

- Web API = com.cisco.webapi
