Use QR Code on Android Phone to Join Webex Meeting

# Use QR Code on Android Phone to Join Webex Meeting

### Download Options

Updated: April 3, 2024

Document ID: 221842

Contents

## Contents

## Introduction

This document describes how to join a Webex Meeting from a QR code on Android phones.

## Prerequisites

### Requirements

- Android phone with a camera.

### Components Used

The information in this document is based on Android version 11; Webex Meeting Version 44.2.0

The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.

## Configure

- Open camera and hold QR code image in front of camera.

- Select the yellow QR code icon that appears.

- A URL link appears at the bottom of the phone screen; Click the URL .

- A web page with the Webex Meeting details opens.

- Select Download Webex Meetings link.  - If you already have Webex Meeting installed; skip to step 8.

- You are then redirected to the Google Play Store Webex Meeting Application.

- Select Install . Once the install complete, there are two options: Uninstall and Open.

- Go back to the Webex Meeting web page and select Join Meeting link.

- A Webex Meeting notification pops up. Select Allow and Accept .

- A Join the Meeting window appears.  Fill out your name , and email address .

- Click Join as Guest .

- You are now entered into the meeting.
