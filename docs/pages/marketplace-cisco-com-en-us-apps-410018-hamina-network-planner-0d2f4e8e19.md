# Hamina Network Planner

by Hamina Wireless

Hamina Network Planner is a fast and easy, 100% cloud-based wireless network planning tool. Whether you're running Cisco Meraki or Cisco Catalyst Center, Hamina connects directly to your infrastructure so you can plan smarter, deploy faster, and see exactly what's happening on your network right now. Hamina is scientific yet easy to use for creating high-performance wireless networks.

## Overview

### AI-Powered Wireless Network Planner for Designing High-Performance Cisco Networks

Design wireless and wired networks, including cabling and switching! Hamina Wireless Network Planner is a web-based tool for rapidly designing high-performance networks. This scientific yet easy-to use AI-powered planning tool supports Wi-Fi (including Wi-Fi 7), UWB (Ultra-Wideband), Private 4G/5G, and IoT technologies such as BLE (Bluetooth Low Energy), Zigbee, and Enocean.

Hamina fully integrates with Cisco Wireless; Cisco APs and antennas are fully modeled in Hamina Network Planner. When the network design is complete, one button click exports the design from Hamina to Meraki or Cisco Catalyst, and existing networks can be imported to Hamina for RF analysis. 

The Hamina Live View allows you to see your entire network, live, using Hamina Wireless Network Planner Plus. Coverage, redundancy, roaming, interference, channel utilization, non-Wi-Fi interference - you name it. Hamina shows it.

- AI-powered, faster wireless network design Design wireless, quickly, accurately, and in 3D! Hamina's AI-powered design features automatically model walls and align floors to create a full building model in seconds. Hamina also sets the scale and scope zone for your network plan. - Design switching, cabling, PoE needs Hamina doesn't stop at wireless: it also accounts for switches, IDFs, MDFs, cabling, and PoE consumption, even factoring in security cameras, desk phones, and other PoE clients!
