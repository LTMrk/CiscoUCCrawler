# Cisco Agentic Workflows

by Cisco

Cisco Agentic Workflows is Cisco’s AI-powered network automation solution for simplifying and scaling network operations. Built into Cisco Cloud Control and the Cisco Meraki dashboard, it helps teams create, deploy, and manage automations across Cisco and third-party environments using prebuilt, customizable, or fully custom workflows. ## Overview

### Cisco Agentic Workflows

Cisco Agentic Workflows is Cisco’s AI-powered network automation solution for simplifying and scaling network operations. Built into Cisco Cloud Control and the Meraki dashboard, it helps teams create, deploy, and manage automations across Cisco and third-party environments using prebuilt, customizable, or fully custom workflows. With an intuitive low code/no code drag-and-drop editor, validated actions, and natural-language automation through Cisco AI Assistant, Agentic Workflows turns complex, repetitive network tasks into fast, consistent outcomes.

### Key benefits

- Automate faster with low/no-code Build automations with an intuitive drag-and-drop editor, no specialized coding skills required. Start with a prebuilt workflow, customize one for your needs, or create your own from scratch.

- Connect and orchestrate your ecosystem Automate processes across Cisco products, third-party applications, cloud and on-premises environments, and existing tools such as Ansible, Terraform, and Python, all through a unified orchestration layer.

- Turn intent into action with AI Use natural language with Cisco AI Assistant to find, run, and even build the right workflow. Combine AI-powered guidance with deterministic automation for predictable, repeatable outcomes.

- Improve operational visibility Monitor workflow status, review inputs and activity, incorporate approval steps, and maintain detailed audit logs. Give teams the oversight needed to automate operations with greater confidence and accountability.

- Visualize and troubleshoot workflow runs The Workflow Run View makes troubleshooting workflows effortless. Easily follow the visual logic path taken during each workflow run. Inspect the inputs and outputs of every activity, and quickly identify where issues occurred.

- Automation rules Trigger workflows automatically based on time, events, or incoming information. Automation Rules can launch workflows on a defined schedule, through webhooks from external systems, or in response to email messages. This flexibility helps teams automate recurring tasks, respond quickly to operational events, and connect workflows to existing tools and processes without requiring manual initiation.

## Features

### Workflows Exchange

Workflows features an exchange of premade automations that solve common use cases. They are created by Cisco, our partners, and the broader community, and each one is reviewed before it’s published. These automations can be run as-is or easily customized in the drag-and-drop workflow editor. This helps teams accelerate time to value without having to build every automation from the beginning. Check for frequent updates.

### Drag and drop visual editor

Turn automation ideas into working processes with an intuitive low-code/no-code editor. Drag activities onto the canvas, connect steps, add decision logic, and incorporate existing workflows. Teams can build sophisticated automations without requiring every user to learn a programming language or specialized automation syntax.

### Adapter-based integrations

Connect Cisco products, third-party applications, and existing automation tools through a growing library of adapters. Each adapter includes prebuilt activities, along with a Generic activity that can access additional APIs for the supported system while Workflows handles authentication. Generic HTTP activities can also be used to automate virtually any REST API, even when a dedicated adapter isn’t available.

### Manage and view workflows in one place

Centralize workflows across networking domains in a single workspace. Detailed run records and audit history simplify troubleshooting, validation, and governance. GitHub integration and JSON import/export also make it easier to back up, share, and version control workflow definitions.

### Visualize and troubleshoot workflow runs

The Workflow Run View makes troubleshooting workflows effortless. Easily follow the visual logic path taken during each workflow run. Inspect the inputs and outputs of every activity, and quickly identify where issues occurred.

### Automation rules

Trigger workflows automatically based on time, events, or incoming information. Automation Rules can launch workflows on a defined schedule, through webhooks from external systems, or in response to email messages. This flexibility helps teams automate recurring tasks, respond quickly to operational events, and connect workflows to existing tools and processes without requiring manual initiation.

### Natural language workflow execution

Tell the Cisco AI Assistant the outcome you want instead of searching through tools or building every process manually. The assistant can review available workflows, including those published in the Workflows Exchange, and recommend one that fits your goal. It can then summarize what the workflow will do, collect the required information, and initiate execution, providing a conversational path from operational intent to action.

### AI-assisted workflow creation

Accelerate automation development with the Cisco AI Assistant. Teams can describe their intent in natural language, and the assistant will propose a workflow plan for review. Users can then work with the assistant to add, remove, or update steps before approving the plan. Once approved, the assistant generates a deterministic, auditable workflow, making advanced automation more accessible while keeping users in control.

### Human-in-the-loop controls

Automation does not have to mean giving up human oversight. Add approval steps and interactive prompts that pause a workflow when review or input is required. Teams can automate time-consuming processes while retaining control over sensitive changes and maintaining a clear, accountable decision trail.

### AI Agents for AgenticOps

Move beyond AI-generated responses with an agent that can reason and take action. The AI Agent activity interprets network events or requests, selects the appropriate production-ready workflow, determines the required inputs, and executes them as tools. Deterministic workflows provide predictable automation, while the agent handles dynamic decision-making and returns both the final result and a detailed audit trail of the workflows it executed.

### FAQ

Frequently Asked Questions

#### How do I access Cisco Agentic Workflows?

- Cisco Agentic Workflows is available in Cisco Cloud Control and from the Automation tab in the Cisco Meraki dashboard. You do not need Meraki devices or a Meraki license to get started. You can create a Meraki account at:
https://account.meraki.com/login/new_account

#### Do I need coding experience to use Cisco Agentic Workflows?

- No. The visual drag-and-drop editor supports low-code and no-code workflow creation. Programming skills are not required, although experienced users can incorporate APIs, Python, JavaScript, and other advanced capabilities.

#### What products and systems can Cisco Agentic Workflows automate?

- Workflows can automate processes across Cisco products, third-party applications, and cloud and on-premises environments. Available integrations are updated regularly, so users should check the adapter and activity palette in the Workflow Editor for the latest supported systems.

#### How will role-based access control help organizations govern workflow access?

- Role-based access control will allow administrators to grant users permission to run approved workflows without giving them the ability to create or edit workflow logic. This will enable broader access to automation while helping organizations maintain appropriate operational controls.

#### How can Cisco Agentic Workflows connect to on-premises devices and systems?

- Workflows uses Automation Remote to securely communicate with controllers, devices, and other resources inside your network that are not directly accessible from the internet. The new Docker Remote provides a lightweight, container-based option for bridging on-premises resources with cloud-hosted workflows. This allows organizations to incorporate on-premises systems into their automations without exposing those systems publicly.
