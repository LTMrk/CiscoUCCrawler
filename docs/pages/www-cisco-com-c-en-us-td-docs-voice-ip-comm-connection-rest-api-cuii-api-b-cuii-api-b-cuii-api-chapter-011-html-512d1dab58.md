                     	 Connection Imaging Interface (CUII) API -- Using CUII to View the Current MWI
                     	 Status

Links to Other API pages: Cisco Unity Connection APIs

```
GET https://<connection-server>/vmrest/mailbox/folders/inbox/<user_alias>/mwistatusimage
```

The above request returns the image with respect to current MWI status
                        		of the mailbox. The MWI status can be ON or OFF.
