October 27, 2021

RedSky or Intrado E911 Service Integration with Emergency Responder

RedSky Integration is supported when Emergency Responder system is enabled in FIPS mode.

Configure Emergency Responder and National E911 Service Provider

October 27, 2021

Secure Phone Alert for Onsite Security Users

Emergency Responder supports enabling Secure Real-Time Transport Protocol (SRTP) on audio alert to Onsite Security User when
                                          an Emergency Call is placed

Cisco Unified Communications Manager Clusters

October 27, 2021

Permanent License Reservation

Emergency Responder provides support for Permanent License Reservation that allows administrator to reserve an entitled Permanent
                                          License Tag from the Smart Account and Virtual Account against a Product instance

Compliance to New Federal Regulations

E911 support is provided  for remote teleworker and off-premises users registered over Virtual Private Network (VPN) or Mobile
                                          and Remote Access

Support for configuration APIs

                                          Manager settings

Cisco Emergency Responder API Documentation

Support for Switch Refresh Utility

Configure Switch Refresh Utility

Version Independent Licensing

Smart Licensing Registration through Authentication based Proxy

Swtich Support

                                          Series Switches, and Cisco Meraki Switches MS120, MS125, and MS355
