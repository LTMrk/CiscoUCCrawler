# SplashAuth

by Splash Access

SplashAuth delivers enterprise WiFi via seamless 802.1X authentication—integrating with Azure, Google, or Duo for secure, captiveportal free BYOD onboarding. Live on the Apple Store and Android Play

## Overview

### SpalshAuth a BRAND NEW Authentication Solution

SplashAuth is a NEW secure, frictionless BYOD Wi-Fi onboarding solution that uses 802.1X authentication integrated with leading identity providers — Azure AD, Google Workspace, and Duo .  
  A NEW way of thinking about BYOD authentication, SplashAuth bridges enterprise identity with secure wireless access , eliminating the need for captive portals or manual certificate provisioning.

Enterprises, educational institutions, and public sector organizations that use Cisco wireless infrastructure and want a simple, scalable, and secure way to connect employee, student, and guest devices without IT-heavy onboarding.

### Zero sensitive credential exposure

Azure, Google, and Duo logins are verified directly with their providers; passwords never pass through SplashAuth servers.

### Instant onboarding

Users connect in seconds with one-tap authentication instead of lengthy setup guides or insecure portals.

### Cross-platform support

Works seamlessly with Windows , iOS, macOS Chrome Books and seamlessly delivered on Cisco networks, delivering the same user experience across environments.

### Reduced IT load

Automates lifecycle management, minimizing helpdesk tickets and administrative overhead.

### Why Now ?

With the rapid shift to hybrid work, SplashAuth’s brand-NEW BYOD solution provides an easy, ready-to-deploy, Cisco-compatible platform that meets today’s needs — accelerating secure onboarding without compromising user experience. A brand new way at looking at the problem of BYOD devices and how to onboard them and tie back to an Identity Provider (IDP)

### Key benefits

- Frictionless BYOD Onboarding Employees, students, and Staff connect in seconds with one-tap 802.1X authentication—no captive portals, no lengthy setup guides, no IT intervention.

- Seamless Cross-Platform Experience SplashAuth delivers consistent, secure Wi-Fi access across all devices and available on Cisco-compatible devices—ensuring every user has the same effortless experience.

- Built for Cisco Wireless Infrastructures Designed specifically for all Cisco networks, SplashAuth integrates natively with enterprise-grade Wi-Fi environments to ensure compatibility, performance, and scalability.

- Future-Ready Security & Compliance Support today’s flexible workplace by enabling secure Wi-Fi access for employee-owned and remote devices—without extra configuration or IT bottlenecks.

- Rapid, Scalable Deployment SplashAuth can be rolled out enterprise-wide in hours, not months, with cloud-native management that scales effortlessly across campuses, branch offices, or entire organizations.

- Identity-Driven Access Control Tie Wi-Fi policies directly to enterprise identities. Assign network access based on user role, group membership, or department to strengthen security posture.
