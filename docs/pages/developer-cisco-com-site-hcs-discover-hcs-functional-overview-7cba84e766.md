# HCS Functional Overview

## HCS Functional Overview

The following diagram illustrates a high-level view of the Cisco HCS components.

- The device layer contains the devices that deliver voice, video, messaging, presence and other services to the customers and end users. Developers can use collaboration application and device related APIs to create 3rd party applications that extend the collaboration services.

- The domain layer contains the domain managers. Domain managers perform management, provisioning, fault management and performance management of the devices and services.

- Hosted Collaboration Mediation (HCM) performs centralized management for the entire Cisco HCS solution, and interacts with all of the domain managers.

- HCM provides the Fulfillment APIs (HCM-F APIs) and the Assurance APIs (PC4HCS APIs) to help developers integrate Service Provider systems with HCS.
