# HCS Assurance APIs

The HCS Assurance APIs provide a single, normalized fault management interface from the multi-component HCS assurance system.

## Two Types of HCS Assurance interfaces

SNMP Trap Notifications

Prime Central for HCS supports SNMP Trap Notifications.
NBI listeners are added/updated/removed by WebServices API.

Prime Central for HCS Web Service

The Prime Central for HCS Web Service provides APIs to subscribe/unsubscribe and query for event related information.
