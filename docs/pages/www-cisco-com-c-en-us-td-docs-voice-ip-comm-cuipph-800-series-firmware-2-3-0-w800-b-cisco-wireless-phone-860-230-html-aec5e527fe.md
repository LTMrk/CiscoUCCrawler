# Cisco Wireless Phone 860 Release Notes for Firmware Release 2.3(0)

These release notes support the Cisco Wireless Phone 860 software release 2.3(0). These wireless smartphone require:

Call Control

Cisco Unified Communications Manager

Minimum: 11.5(1)

Recommended: 12.5(1), 14.0(1), or higher

Webex Calling

Wireless LAN Controller and Access Points

See the Cisco Wireless Phone 840 and 860 Deployment Guide for supported solutions.

## What’s New in This Release?

The following sections describe the features that are new or have changed in this release.

### WPA2 SHA256 CCMP128 (AES) Support

With this release, for the Cisco Wireless Phone 860 phones, support for WPA2 SHA256 CCMP128 (AES) is added.

Personal phones have the following support:

- WPA2-PSK-SHA256 + CCMP128 (AES)

Enterprise phones have the following support:

- WPA2-802.1x-SHA256 + CCMP128 (AES)

### WPA3 CCMP128 (AES) Support

With the release, for the Cisco Wireless Phone 860 phones, support for WPA3 CCMP128 (AES) is added.

Personal phones have the following support:

- WPA3-SAE + CCMP128 (AES)

- WPA3-FT SAE + CCMP128 (AES)

Enterprise phones have the following support:

- WPA3-802.1x-SHA256 + CCMP128 (AES)

- WPA3-FT 802.1x + CCMP128 (AES)

### Control through CTI using Jabber/Webex app for CUCM Platform

With this release, the Cisco Wireless Phone 860 on the CUCM platform, can now be controlled through CTI using the Jabber or Webex app.

### Updated Incoming Call Ringing Duration

If an incoming call is not answered by the user, the phone will ring for up to 3.5 minutes instead of 60 seconds.
