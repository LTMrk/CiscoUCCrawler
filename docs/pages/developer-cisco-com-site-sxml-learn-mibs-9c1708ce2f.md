# Use the MIB Navigator

Developers can use the MIB Navigator to download the latest MIBs for the Unified CM Serviceability SNMP functionality.

## UC Serviceability MIBs

You will need to download the following MIBs and their dependencies for Unified CM Serviceability.

- CISCO-CCM-CAPABILITY

- CISCO-CCM-MIB

- CISCO-CDP-MIB

- CISCO-CDP-CAPABILITY

- SYSAPPL-MIB

## Using the MIB Navigator

- Go to https://snmp.cloudapps.cisco.com/Support/SNMP/do/BrowseOID.do?local=en in your browser.

- Search for the MIBs listed above (CISCO-CCM-CAPABILITY, CISCO-CCM-MIB, CISCO-CDP-MIB, CISCO-CDP-CAPABILITY, SYSAPPL-MIB).

- Follow the links to download the MIB and its dependencies.
