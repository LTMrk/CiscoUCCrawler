# Configuration Backup & Recovery by BOUNDLESS

by Boundless

Safeguard by Boundless backs up Cisco Meraki configs in near-real time, lets you diff versions and roll-back instantly—cutting network downtime and compliance risk.

## Overview

### Instantly roll-back any Cisco Meraki misconfiguration

When an accidental change, cyber-attack, or firmware glitch takes your network offline, every minute costs money and reputation. Safeguard keeps a live, encrypted snapshot of every Meraki organization, network and template—capturing changes automatically through change log detection. With one click you can compare versions, restore specific settings or entire networks, and even schedule automated roll-backs after late-night maintenance windows. 

A central cloud portal means nothing to install. Safeguard provides coverage for MX, MR, MS, MV & MT devices, as well as network, template and organization-level configurations exposed via an API endpoint. Stay compliant, slash MTTR, and sleep better.

### Key benefits

- Near-real-time backups Captures every config change in 1–5 minute intervals after it happens, so you always have an up-to-date rollback point.

- One-click restore & granular roll-back Recover an entire network or just a single security rule within minutes—reducing mean-time-to-repair and simplifying troubleshooting.

- Snapshot diff & change explorer Side-by-side view pinpoints exactly who changed what and when, accelerating audits and root-cause analysis.

- Automated compliance alerts Get email notifications if critical settings are modified or users run unauthorized changes.

### FAQ

Frequently asked questions for Safeguard.

#### How often are backups taken?

- The system runs change log detection every 1–5 minutes by default; if a change to a network is detected, a backup will automatically be triggered.

#### Does Safeguard consume Meraki API rate-limits?

- No—our scheduler staggers calls and uses smart queuing to stay below limits.

#### Which devices are supported?

- All Cisco Meraki product families with required API endpoints exposed: MX, MR, MS, MV, MT.

#### Which configuration settings are supported?

- All configuration settings for organizations, networks, devices, and templates that are exposed via Meraki API endpoints are supported.

#### Can I restore a single SSID or firewall rule?

- Yes—choose object-level granularity or full-network restore.

#### What happens after the 14-day trial?

- Your snapshots remain available; simply add a licence key to keep protection active.

#### Does it track who made a change?

- Yes—change logs include the Meraki admin email and timestamp for each event.

#### Is any on-prem software required?

- None. Safeguard is 100 % cloud delivered.

#### How do Meraki organizations connect to the Boundless platform?

- Meraki organizations connect via individual OAuth 2.0 authentication.

#### How can I purchase a license?

- You can purchase a license by contacting us directly or through your preferred reseller partner. Our solutions are also listed on Cisco’s Global Price List (GPL), streamlining the procurement process for Cisco customers and ensuring smooth integration with their existing infrastructure.

#### Is a trial version available?

- Yes, a 14-day free trial is available—no credit card required.
