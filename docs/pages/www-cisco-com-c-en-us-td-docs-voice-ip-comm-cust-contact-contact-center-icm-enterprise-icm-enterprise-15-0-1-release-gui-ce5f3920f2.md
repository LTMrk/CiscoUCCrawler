# Introduction

## About This Guide

These release notes describe new and updated features and other changes for Release 15.0(1) of the following contact center
                              solutions and their components:

Cisco Unified Contact Center Enterprise

Cisco Packaged Contact Center Enterprise

Information in this document applies to the contact center solutions listed above, except where otherwise noted.

### Engineering Special (ES) Patch Releases

CCE periodically releases Engineering Special (ES) patches between quarterly releases. Each ES patch can include many new
                              and updated features in addition to defect fixes. To ensure your deployment includes the latest features and updates, we recommend
                              that you obtain the most recent ES patch for this release.

For the latest ES patch release notes, see https://www.cisco.com/c/en/us/support/customer-collaboration/unified-contact-center-enterprise/products-release-notes-list.html .

For instructions on how to install or uninstall ES patches for all CCE components, see the Cisco Unified Contact Center Enterprise Engineering Specials Installation Guide, Release 15.0(1) at https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/cust_contact/contact_center/icm_enterprise/icm_enterprise_15_0_1/installation/guide/rcct-b-cce-es-installation-guide--release-15_01_es.html
