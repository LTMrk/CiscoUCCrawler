Note: The Cisco TSP is not tested/supported with Remote Desktop or Remote TSP scenarios.

*1 - Cisco TSP 7.x support for Windows 2008 will be
            available for ARC only.

*2 - Requires Unified Communications Manager release 8.5(1)
            Service Update 1 (or later)
