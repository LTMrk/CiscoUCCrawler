                                       					 same volume. |

                                       					 same speed. |

                                       					 same speed. |

                                       					 same volume. |

                                       					 same volume. |

                                       					 same volume. |

                                       					 the message starts playing from the beginning. |
| Fast Forward | Starts playing the after message menu as soon as you select this
                                       					 option. |
| Play Message Attachments | Plays only audio part of the message attachment. |
| Forward Message | Forwards only the audio part of the video message to the
                                       					 recipient. |
| Forward Original Message | Forwards only the audio part of the video message as attachment
                                       					 to the recipient. |
| Reply | Allows you to reply to a video message in audio format only. |
| Reply to all | Allows you to reply to a video message to all the recipients in
                                       					 audio format only. |
