# Build a Development Lab

To begin working with Extension Mobility APIs, you will need to create a lab that has Cisco Unified Communications Manager (CUCM) installed on a server that is accessible from your application server. You will also need a phone, such as a softphone, registered with CUCM.

Solution Partner Program members can obtain development licenses for Unified CM through the Cisco Unified Communications Not-for-Resale program. This program allows partners to acquire the core components of Cisco Unified Communications System for use in non-revenue generating activities such as labs, demos, and internal course development and training.

For more information about the "Not For Resale" Program, visit the Developer Discount Purchase section .

Solution Partner Program members can also register to use the DevNet Sandbox for development purposes.

Visit the Extension Mobility API Developer Forums to ask questions and interact with other developers.
