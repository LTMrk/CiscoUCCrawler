- Review the Cisco Unified IP Phone Services section of the CUCM System Guide, which is an in-depth description of IP Phone Services programming.

- Review the IPPS Application Developer Notes for the desired Unified CM release. Schema information can be found in the Cisco IP Phone Services XML Schema (XSD).

- Subscribe to the IP Phone Services blog to receive updates from the interface Product Manager.

A. You must have a Cisco.com account with partner level access to purchase this product.  If you do not have an account, please register for one at https://tools.cisco.com/RPF/register/register.do .  If you have an account, but have forgotten your password, you can reset it at http://tools.cisco.com/RPF/passwordreset.do .

B. Contact the Solution Partner Program Help Desk to confirm if you have partner level access associated with your Cisco.com account.  If you do not, it may take 3 – 5 days to apply this level of access to your account.

C. Once you have received confirmation from the Solution Partner Program Program office, you can order this product online by following these instructions: To purchase the latest Unified Communications NFR Software bundle - Navigate to Cisco Marketplace - Login using your Cisco.com UserID - Click on Unified Communications NFR Software (display box) - Select Unified Communications Not-For-Resale Products link (small link at top of page) - Select Cisco Unified Communications System Release NFR Program (drop down menu on right) - Select Technology Developer Partner - Click Add to cart

Membership and program information can be found at Solution Partner .

Program members are also eligible to purchase Cisco hardware at a discount.  Program details can be found by clicking here .  (Partner Login Required).

- Include Cisco IP Phones and/or Softphones to compare and validate IP phone services.

- Click here to access Cisco Unified CM documentation on Cisco.com. See also the UCM Technical Readiness site for additional documents, training, ordering guides and more.

- After CUCM installation and phone registration has completed, download the IPPS SDK from the documentation page to start testing sample apps.

- If you have any questions or need help post on the IPPS forum.
