# GreyMatter

by ReliaQuest

ReliaQuest GreyMatter integrates seamlessly with Cisco products, including ASA, Duo Security, ISE pxGrid, Meraki, Secure Endpoint, Secure Firewall Management Center, and Umbrella, to deliver comprehensive security operations across cloud and hybrid environments.

## Overview

### ReliaQuest GreyMatter Makes Security Possible

ReliaQuest GreyMatter is a security operations platform built on an Open XDR architecture. We designed GreyMatter to help security teams increase visibility, reduce complexity, and manage risk across their security tools, regardless of environment—including on-premises, clouds, networks, and endpoints.

GreyMatter integrates seamlessly with Cisco products, including ASA, Duo Security, ISE, Meraki, Secure Endpoint, Secure Firewall Management Center, and Umbrella, to deliver comprehensive security operations across cloud and hybrid environments. These integrations empower organizations to strengthen security, streamline incident response, and address emerging threats effectively.

### Key benefits

- Cisco Meraki Integration Cisco Meraki offers a cloud-based integration with support for response and hunting capabilities. It includes playbooks for containment and remediation, enabling actions like blocking/unblocking IPs, domains, and URLs, isolating/unisolating hosts by MAC address, and managing URL access permissions. This integration is particularly suited for proactive threat hunting while enabling swift and effective responses to incidents.

- Cisco Secure Endpoint Integration Cisco Secure Endpoint integrates as a cloud-based Endpoint Detection and Response (EDR) solution, focusing on response and detection capabilities. It supports containment and remediation playbooks for isolating/unisolating hosts and banning/unbanning file hashes. Enrichment playbooks provide host-related context, while GreyMatter Detect enhances detection at both the vendor source and RQ-authored storage levels. This integration is ideal for organizations requiring advanced detection and response capabilities.

- Cisco Firewall Management Center Integration The Cisco Secure Firewall Management Center integration is cloud-based and focused entirely on response capabilities. It supports containment and remediation playbooks for blocking/unblocking IPs, domains, and URLs. This integration is designed to streamline incident response workflows, enabling organizations to mitigate network threats quickly and efficiently.

- Cisco Umbrella Integration Cisco Umbrella integrates through a cloud-based Direct Source connection, offering robust response capabilities. It supports containment and remediation playbooks for managing domain and URL access, including blocking/unblocking, adding/removing items from lists, and enforcing domain or URL restrictions. This integration enhances response efficiency by centralizing domain and URL management, ensuring rapid mitigation of web-based threats.

- Cisco Duo Security Integration Cisco Duo Security integrates through a cloud-based Direct Source connection, offering a wide range of capabilities, including investigation, response, and hunting. It supports enrichment playbooks to provide detailed user context and includes containment and remediation actions, such as enrolling MFA, enabling/disabling MFA, and managing user accounts. Its proactive hunting and investigative capabilities make it ideal for tackling complex threats while responding effectively to incidents.

- Cisco Identity Services Engine (ISE) pxGrid Integration The Cisco ISE pxGrid integration is cloud-based and focused on response capabilities. It supports enrichment playbooks to enhance policy-related data and provides containment and remediation playbooks for isolating or unisolating hosts by IP or MAC address. This integration helps organizations respond efficiently to network-based threats while enriching policy-related insights to improve decision-making.

- Cisco Adaptive Security Appliance (ASA) The Cisco ASA integration supports on-premises and cloud environments via a Direct Source connection, offering capabilities for both investigation and response. It allows organizations to implement containment and remediation playbooks for actions such as blocking or unblocking IPs and domains, ensuring swift responses to threats. The primary use case for this integration is focused on responding to security incidents.

## Features

### Enable Communications Across Security Tools

Security-relevant telemetry lives across many tools and in many formats. Manually normalizing data, learning query languages for each tool, and keeping up with newer tools is slowing your team. The Universal Translator, a patented technology, is a data-normalization engine that helps security operations teams get better visibility across your toolset.

Convert diverse data types from tools in your technology stack into a normalized format to facilitate search and enrichment.
Run queries at scale across your diverse portfolio of security tools and log sources.
The Universal Translator gives you the optionality to use the best security tools while eliminating the need for your team to develop and maintain expertise in many individual security tools.

### Detect Threats Across Your Attack Surface

Security teams struggle to keep threat detections up to date across a diverse attack surface. GreyMatter Detect, a cloud-based threat detection library, manages and translates detections across tools including one or multiple SIEMs, EDRs, clouds, and other technologies.

Deploy detections using a centrally managed library across your existing security tool portfolio in minutes.
Run high-fidelity “detection as code” consistently across multiple technologies and tune it to individual environments.
GreyMatter Detect helps you locate threats faster, more consistently, and more accurately across your diverse attack surface without the pain of building detections for individual tools.

### Automatically Enrich Investigations with Threat Intel and Context

Threat investigations require data from both your portfolio of security tools and external threat feeds. Manual collection of incident artifacts and threat intelligence is time-consuming and can result in inconsistent and incomplete investigations. Data-stitching capabilities within GreyMatter streamline investigations by removing the high-time, low-brain processes of security operations.

Extract context from security telemetry and relevant threat intelligence without ingesting data in a central location.
Apply a consistent and comprehensive cyber analysis methodology to prevent investigative gaps and accelerate investigations.
Reduce mean time to resolve (MTTR) for incidents and free your team to work on higher-priority projects.

### Automate Response Actions Across Tools at Scale

Running response actions manually through a broad set of tools hinders rapid response. GreyMatter provides bi-directional API integrations to facilitate response actions across tools.

Integrate with a fast-growing number of technologies including SIEMs, EDRs, firewalls, identity, email security, and cloud platforms.
Deploy configurable remediation playbooks that automate response actions through existing security technologies.
Accelerate threat response while sparing your analysts from the pain of executing individual response actions in individual tools.
