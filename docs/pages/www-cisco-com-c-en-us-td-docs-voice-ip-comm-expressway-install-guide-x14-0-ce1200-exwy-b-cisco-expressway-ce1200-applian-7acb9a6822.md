### Power Cables

Power cables are available to order from Cisco.

If you opt not to order power cables from Cisco, you must use cables of the
                                          				designated type, - see https://www.cisco.com/c/dam/en/us/products/collateral/servers-unified-computing/ucs-c-series-rack-servers/c220m5-lff-specsheet.pdf

### KVM Adaptors

KVM adaptors are available to order from Cisco.

### Field-Replaceable Components

These components are field replaceable:

Hard disks

Power supply units (PSUs)

Fan module

SFP network connection modules (1 Gb and 10 Gb)

To avoid compatibility issues use only the supplied SFPs, and follow the
                                                						other requirements for SFPs in Task 2: Insert the SFP
                                                   							Network Connection Modules

### Returns or Replacements

If you need to begin a Return Material Authorization (RMA) for any reason, go to http://www.cisco.com/web/ordering/cs_info/or3/o32/Return_a_Product/WebReturns/product_Online_web_returns.html .
