# GET /organization/{orgid}/v2/contact-number

**API:** Webex Contact Center
**Área:** Contact Number
**operationId:** `getAllConfigWithMetaData_19`

## Resumen

## Descripción
Retrieve a list of Contact Number(s) in a given organization.
