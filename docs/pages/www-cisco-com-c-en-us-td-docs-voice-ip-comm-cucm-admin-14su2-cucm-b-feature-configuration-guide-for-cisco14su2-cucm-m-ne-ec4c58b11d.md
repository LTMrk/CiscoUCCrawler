# New and Changed Information

## New and Changed Information

The following table provides an overview of the significant changes to the features in this guide up to this current release.
                              The table does not provide an exhaustive list of all changes made to the guide or of the new features up to this release.

Feature or Change

Description

See

Date

Call Control Discovery via Service Advertisement Framework

Removed support for Call Control Discovery via Service Advertisement Framework in Unified Communications Manager

Deprecation of Call Control Discovery via Service Advertisement Framework in Cisco Unified Communications Manager

July 31, 2025

Enable SIP OAuth for 78xx and 88xx Phones

SIP OAuth provides end to end secure signaling and media encryption without CAPF on-premises as well as over MRA and by default,
                                          TFTP is secure for SIP phones when SIP OAuth is enabled.

SIP OAuth Mode Configuration Task Flow

Enable OAuth Access Token for Devices

March 31, 2021

Headset and Accessories Inventory Download

This feature enables an administrator to download a detailed report of Headsets and Accessories in the deployment into a CSV
                                          file from the Unified Communications Manager user interface.

Headset and Accessories Inventory

March 31, 2021

MRA Failover with Lightweight Keepalives

The MRA High-Availability for endpoint registration feature allows Cisco Webex and Cisco Jabber clients to quickly detect
                                          any failure of network elements like Cisco Expressway-E, Cisco Expressway-C, or Unified Communications Manager in the path
                                          and take corrective action to re-register using a new path.

MRA Failover with Lightweight Keepalives

March 31, 2021

Native Phone Migration using IVR and Phone Services

Using this feature, an end user or an administrator can easily migrate all the settings from an old phone to a new phone with
                                          a simple user interface.

Native Phone Migration using IVR and Phone Services Overview

March 31, 2021

Oracle JRE Removal from Manager Assistant

The Oracle Java Runtime Environment (JRE) is no longer included in the Cisco Unified Communications Manager Assistant plug-in.

Manager Assistant Prerequisites

March 31, 2021

Support for Meraki Access Points

Unified Communications Manager supports Location Awareness for wireless endpoints connecting through Meraki Access Points.

Location Awareness Overview

October 27, 2021

TFTP Proxy Support for OAuth

Unified Communications Manager supports TFTP Proxy in SIP OAuth deployments.

Enable SIP OAuth Mode

October 27, 2021

Wi-Fi to LTE Call Handoff

Unified Communications Manager provides flexibility for Cisco Webex users to switch between Wi-Fi and LTE networks without
                                          disconnecting any active calls that the user may be while switching network.

Wi-Fi to LTE Call Handoff

October 27, 2021

RedSky E911 Location Services Support

The RedSky solutions integrated with Unified Communications Manager allow the clients to have an active location URI for 9-1-1
                                          emergency calling coverage for their entire workforce, whether on campus or remote, and send the calls to emergency responders.

Emergency Call Handling with RedSky

June 16, 2022

Secure Call Support for Parking Lot

Unified Communications Manager handles the originating SRTP-only call as a secure call throughout, irrespective of the SRTP
                                          fallback option status.

Secure Call Queuing

June 16, 2022
