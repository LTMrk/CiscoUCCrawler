# Introduction

## Introduction

This document provides instructions to perform authorized conversion of Cisco IP Phone 8800 series and Cisco IP Phone 7800
                              series Multiplatform Phones to on-premises firmware that is able to interoperate with Cisco Call Control systems.

If you are a Cisco Unified Communications Manager administrator and plan to migrate any Cisco IP Phones 7800 series Multiplatform
                              phones or Cisco IP Phone 8800 series Multiplatform phones to on-premises firmware, you can refer this document. This document
                              assumes that you are familiar with phone administration on Cisco Unified Communications Manager and on the third-party call
                              control system.

## Scope

This document provides information on the migration of Cisco IP multiplatform phone firmware to Cisco on-premises phone firmware.

This document doesn't contain information on configuring the phones.

Before you start the migration, you will need to have at least one of the same model with on-premises firmware installed on
                              your system.
