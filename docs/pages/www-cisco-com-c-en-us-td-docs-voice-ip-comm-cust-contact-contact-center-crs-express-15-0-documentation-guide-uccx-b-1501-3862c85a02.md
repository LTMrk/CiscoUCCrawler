# Documentation Guide

## Overview

This documentation guide provides details of all the documents for this release of Unified Contact Center Express (Unified
                           CCX), Release 15.0 and contains links to the documents.

For the latest version of all of the documents of Unified CCX, see:

https://www.cisco.com/c/en/us/support/customer-collaboration/unified-contact-center-express/tsd-products-support-series-home.html .

### Document Changes

The following tables identify the documents that changed for this release.

New Solution Documents in This Release

There are no new solution documents in this release.

New Documents in This Release

There are no new Unified CCX documents in this release.

Documents Updated in This Release

The following table lists the documents that are updated in this release:

Document

Notes

Cisco Unified Contact Center Express Administration and Operations Guide

Updates to this document are as follows:

Removed Cloud Connect content.

Removed Cisco Webex Experience Management.

Added Trigger OVA migration command topic.

Removed the Change Licensing Packages topic.

Removed Upload Licensing topic.

Updated the Specific License Reservation Commands examples for 15.0.

Removed the content related to Perpetual License.

Removed content relatated to License Management and Classic License Management.

Removed NFR, Perpetual Enhanced, and Perpetual Premium.

Removed the topic Classic License Management .

Removed content related Perpetual License.

Removed the utils uccx delete license licenseName topic.

Removed the utils uccx list license topic.

Removed the show uccx license topic.

Added information about switch back from Unifed CCX 15.0 to previous releases.

Added the topic Cipher Management .

Added the following CLIs

utils system tls_ciphers config list

utils system tls_ciphers config export

utils system tls_ciphers config import

utils system tls_ciphers config reset

utils uccx database reindex tablename

utils uccx informix_ssl status

utils uccx informix_ssl cert generate

uccx informix_ssl cert info

utils uccx informix_ssl enable

utils uccx informix_ssl disable

Updated the connection method to Cisco SSM.

Added a new field Secure Connection in Datasource Configuration Web Page.

The ODBC connections to Unified CCX now supports encryption.

Cisco Unified Contact Center Express Features Guide

Removed the Cisco Webex Experience Management content.

Updated Premium License as Flex Premium License.

Removed content related to Perpetual Premium and Perpetual Enhanced.

Solution Design Guide for Cisco Unified Contact Center Express

Removed the Cisco Webex Experience Management content.

Updated the list of supported ciphers.

Removed the content related to Perpetual Licensing and updated the content to reflect Flex Standard and Flex Premium.

Cisco Finesse Agent and Supervisor Desktop User Guide for Cisco Unified Contact Center Express

Updated that the User IDs are not case-sensitive.

Added keyboard shortcuts.

Cisco Unified Contact Center Express Install and Upgrade Guide

Added pre-upgrade COP for FIPS.

Updated the RTMT tool download option.

Updated the RAM for 400 agents profile.

Suppressed information about Prime Collaboration Deployment.

Removed the information about case sensitivity of the User ID.

Removed information related to WFO.

Removed information related to Classic Licensing.

Added information about switch back from Unified CCX 15.0 to previous releases.

Cisco Unified Contact Center Express Reporting User Guide

Removed information related to Perpetual license.

Removed Classic Chat.

Port Utilization Guide for Cisco Unified Contact Center Express Solution

Added TCP 9089

Removed CherryPoint.

#### Cisco Unified CCX Administration and Operations Guide

This document provides instructions for using the Unified CCX Administration web interface to provision the subsystems of
                                 the Unified CCX package and to configure Unified CCX applications. This document also describes all the operations that are
                                 related to Unified CCX:

Using the Unified CCX Serviceability interface to configure, monitor, and troubleshoot Unified CCX services and components.

Using Real-Time Monitoring Tool (RTMT) to monitor system performance and troubleshoot system problems.

Backing up and restoring.

Using CLI commands to configure, administer and troubleshoot Unified CCX.

Using the TCP and UCP ports.

The latest guide is located at:

https://www.cisco.com/c/en/us/support/customer-collaboration/unified-contact-center-express/products-maintenance-guides-list.html .
