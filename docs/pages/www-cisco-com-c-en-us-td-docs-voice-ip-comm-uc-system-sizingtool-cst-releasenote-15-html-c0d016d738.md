## Other Changes in this Release

1. The Cisco Expressway Sizing Tool is a standalone tool (a hyperlink to download the Expressway tool is provided on the top pane) in the Collaboration Sizing, Configuration & Quote ( https://cucst.cloudapps.cisco.com/ ).

b. Collaboration Management.

c. The field “VMWare ESXi 5.5+ Latency Sensitivity Option Set to High” in Voice Messaging.

d. The process type selection is removed from the Unified CM Web Interface page.

3. IM & Presence VM is categorized into Extra-small, Small, Medium, and Large.

4. CER 15 does not support 20000 users with Hosted Collaboration Solution (HCS).

5. A 12000 user profile is removed from CER 15 VM specifications as both 12000 and 20000 users have the same specifications.

6. Gateway platforms: The following gateway platforms are added, supporting until the XE 17.13 IOS release:

· Catalyst 8000V Edge-S

· Catalyst 8000V Edge-M

· vCube on AWS/Azure

· Catalyst 8000V Edge-L

· Cisco 8300 Catalyst Edge Series-1N1S-6T

· Cisco 8300 Catalyst Edge Series-2N2S-6T

· Cisco 8300 Catalyst Edge Series-1N1S-4T2X

· Cisco 8300 Catalyst Edge Series-2N2S-4T2X

· Cisco 8200 Catalyst Edge-1N-4T

· Cisco 8200L Catalyst Edge Series-1N-4T

7. Previously, the Cisco 4300 Series and Cisco 4400 Series gateway platforms were supported till XE 17.3. Now it is extended to support the XE 17.12 IOS release.

8. The following are updated as per the recommendation:

a. Memory and disk space of Unified CM 15.

b. The memory of IM & Presence 15.

c. Memory and CPU of CER 15.

9. CMS/Telepresence will support the version from Cisco Meeting Server 3.0 to CMS 3.8.

10. IceLake and SapphireRapids are added to process generation.

11. The Release Note tab is included on the Menu bar in the Application.

## Limitations and Restrictions

The following is the limitation and restriction that may affect this release.

The tool will take time to evaluate the macros and formulae depending on the system CPU configuration.

### Minimum System Requirements

■ Windows 10 (running on a PC or VM on a MAC).

■ MS Office 2021.

■ If using Windows 10, you may receive an error suggesting the sizing tool installer is unsafe. If this happens, click More info and then click Run anyway to install the app.

#### Manually Install the Sizing Tool

##### Before You Begin

To manually install and run the sizing tool, you must have administrative or equivalent privileges on the machine, or some tool features may be impaired.

1. Download the installer file (CiscoSizingTool.exe) from https://www.cisco.com/go/cst .

2. Launch the installer with the administrator privilege (right-click and select Run as Administrator ).

3. Select the Excel 2021 compatible package on the Choose Components page of the running installer.

4. Once the installation is successful, open the Sizing Tool.

Note: If the tool does not open correctly, try to launch it using administrator privilege.

### MS Windows Region and Language Setting

The sizing tool follows your MS OS configuration. To avoid potential problems when using the sizing tool, we recommend keeping the default Region and Language settings for your MS Windows and Office versions.

If you manually change the Region and Language settings, you may encounter issues with the sizing tool. For example, if you have a US-English-based MS Windows 10 with MS Office 2021 installation and change the Region Format to Turkish , the Decimal symbol and Digit grouping symbol change. This change causes errors in the sizing tool.

### Decimal Separator

In some regions, commas (instead of decimal points) are used to separate a number's integer and fractional parts (for example, 1,25 instead of 1.25). Using commas can lead to errors or issues when loading solution information from XML (if values written to the XML use commas instead of decimal points). For this reason, we recommended that periods "." be used as the decimal separator in solution values rather than commas.

To specify the preferred decimal separator settings:

1. On the Excel file menu, click the Excel Options button.

2. In the Excel Options window, click Advanced in the panel on the left.

3. For the Use system separators option, specify a period (full stop) as the Decimal Separator and a comma as the Thousands separator .

4. Click OK in the Excel Options dialog.

### Tool Download Problems

■ To download the installer file, use the following browsers with the latest versions, MS Edge or Google Chrome, or you may receive a download error that indicates a false positive virus detection.

■ If you use the Download Now button on the sizing tool start page, Cisco SSO authentication to the tool download website may fail. If you experience any issues with direct download or are not running the latest version:

1. Go to the following link directly from your browser: https://www.cisco.com/go/cst

2. Download the latest Collaboration Sizing Tool

3. Install it. No uninstall is necessary.

### PG Sizing

The sizing tool oversubscribes IVR resources to Agent PGs when the incoming port requirements for talking agents, queuing, and self-service are greater than 1000. For systems requiring more than 1000 ports for an Agent PG, regardless of the number of Agents, we recommend sizing your solution with VRU PGs for all incoming traffic.

### Media Streaming and Recording

Beginning from release 12.0(1), the Media Streaming and Recording component is no longer available in the Collaboration Sizing Tool solution.

### Display PDFs

You need a PDF viewer application to open and display the exported Solution Summary Report.

## Upgrades

Release 15 of Cisco Unified Communications Manager, Cisco IM and Presence Service, Cisco Emergency Responder, and Cisco Prime Collaboration Deployment, all of which are supported with the Cisco Collaboration Sizing Tool, Release 15.

Before you upgrade, we recommend you work with your channel partner or account team to use the Cisco Collaboration Sizing Tool to compare your current deployment to an upgraded one. If required, change VM resources to ensure that your upgraded deployment provides the best performance.
