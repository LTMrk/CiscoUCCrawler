## Contents

## Introduction

This document describes common procedures for Cisco TelePresence Management Suite (TMS), Cisco TelePresence Management Suite Extension for Microsoft Exchange (TMSXE) and Cisco TelePresence Management Suite Provisioning Extension (TMSPE) with the use of video links.

## Prerequisites

### Requirements

There are no specific requirements for this document.

### Components Used

The information in this document is based on these software versions:

- Cisco TelePresence Management Suite (TMS) 13.x, 14.x, and 15.x

- Cisco TelePresence Management Suite Extension for Microsoft Exchange(TMSXE) 2.x, 3.x, 4.x, and 5.x

- Cisco TelePresence Management Suite Provisioning Extension (TMSPE) 1.x

- TMS log collection Utility

- Structured Query Language (SQL) Management Studio

The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.

## Video Links

There are public videos that describe each procedure and can be found at https://video.cisco.com .

1. This video explains how to collect logs for TMS and TMSXE with the use of the TMS web interface and the TMS log collection utility.

- English Version: How to Collect TMS and TMSXE Logs

2. This video demonstrates how to use SQL Management Studio to backup the databases for Cisco TMS and TMSPE.

- English Version: Backup of TMS/TMSPE Databases

- Spanish Version: TMS/TMSPE Copia de Seguridad

3. This video demonstrates the process of generation of a Certificate Signing Request (CSR) and how to import a newly signed certificate for Cisco TMS server.

- English Version: How to Renew a TMS Web Certificate

- Spanish Version: Renovar certificado de TMS

4. This video explains how to download conference event logs from TMS.

- English Version: How to Collect Conference Event Logs from TMS

5. This video demonstrates how to install licenses on TMS.

- English Version: Install TMS Licenses
