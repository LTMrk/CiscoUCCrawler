# Cisco Wireless Phone 840 and 860 Release Notes for Firmware Release 1.9(0)SR1

## What's new in this release

The following sections describe the features that are new or have changed in this release.

Enhancement to allow toggling Managed Home Screen mode for WebAPI App to enable direct url opening

When the phone is managed by an Enterprise Mobility Management (EMM) application, it allows you to perform the following functions:

Short tap the Web API application icon to open the first configured URL.

Long tap the Web API application icon to open the configuration menu for the Web API application.
