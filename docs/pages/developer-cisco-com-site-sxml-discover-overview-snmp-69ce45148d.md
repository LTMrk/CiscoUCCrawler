# SNMP Overview

The Simple Network Management Protocol (SNMP) interface allows external applications to query and report
                various Cisco Unified Communications Manager (Unified CM) entities. It provides information on the
                connectivity of the Unified CM to other devices in the network, including syslog information. The
                management information base (MIB) supported by Unified CM include:

- Cisco-CCM-MIB, CISCO-CDP-MIB, Cisco-syslog-MIB

- Standard MIBs like MIB II, SYSAPPL-MIB, HOST RESOURCES-MIB

- Vendor MIBs

To learn how to download the SNMP MIBs, use the MIB Navigator .

For general information on SNMP, see Simple
                Network Management Protocol .
