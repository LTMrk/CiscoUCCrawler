## About this
                        	 Guide

This document provides specifications for the Say It Smart plug-ins
                           		included with Cisco Unified CVP VoiceXML Server.

## Audience

This document is intended for voice application developers using Cisco
                           		Unified CVP VXML Server and Cisco Unified Call Studio.

The grammer logic supplied with the out-of-the-box plug-in follows
                                       		  English grammer logic only. To achieve logic for other languages, you must
                                       		  develop your own plug-in.
