## Overview

### Overview

The Cisco Meraki integration allows you to easily provide Wi-Fi network access to your visitors. It securely provisions network access, so you no longer need to worry about unsafe or unstable guest networks or manually providing network credentials.

After they sign-in, visitors will receive an email or text message with the Wi-Fi network name, password, and access instructions. When they open their browser, a custom splash page will prompt them to enter the password they received.

### FAQs

#### What is the difference between V1 and V2 of Meraki?

- V2 has more functionality to blocklist by visitor type from receiving credentials, and connects directly to the Meraki API, therefore when visitors sign out, their session ends automatically. The update also lets your Security team easily cross-reference internet activity to specific visitors.

#### Is the default session timeout for passwords changeable in Meraki?

- the default session timeout for passwords is 24 hours, which is not changeable in Meraki. We expire the user when the visitor is signed out either manually or at the defined time using the setting to sign out all visitors.
