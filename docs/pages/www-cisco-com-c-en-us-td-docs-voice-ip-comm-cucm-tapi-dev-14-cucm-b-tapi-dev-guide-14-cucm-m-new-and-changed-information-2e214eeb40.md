### Cisco Unified Communications Manager Release 7.0(1)

This section describes new and changed features supported in Unified Communications Manager Release 7.0(1) and contains the
                              following:

For the features, Join Across Lines, Do Not Disturb-Reject, and Calling Party Normalization, each TAPI application must be
                                          upgraded to a version that is compatible with these features. Additionally, if you are upgrading from Release 5.1 and you
                                          use Join Across Lines, the Conference Chaining feature must not be enabled or used until all applications are either upgraded
                                          to a version compatible with the new CUCM version. Also, you should verify that the applications are not impacted by the Conference
                                          Chaining feature.
