Important

If you are installing/uninstalling any ES prior to ES55 (mandatory OpenJDK ES and mandatory Smart Licensing ES) on a Fresh installed/Technology Refreshed 12.5(1a) system, you might encounter the following issues:

JRE upgrade error - An error message stating “An error was encountered while trying to launch Java 8 Update 1.8.0_221 installer” will be reported at the end of ES installation.

You can safely ignore this message. This is because the installer was trying to install the non-existing Oracle JRE.

Multiple errors seen in the installation log file relating to zip files being extracted – The installer tries to extract the following zip files using Oracle Java that is not present in the system: wsscli.zip, unifiedconfig-realm-assembly.zip, shindig-cache-assembly.zip, and adminclient.zip.

You can safely ignore this message.

CCE Admin and Web Setup may not work after ES installation – This is due to Tomcat service being down as it tries to load the Oracle JVM instead of the OpenJDK JVM.

Help files do not launch for CCE tools – This is due to the failure to extract the cce_help.zip file. Some of the tools impacted are Configuration Manager, Service Account Manager, and so on.

Administration Client Setup may not launch on Administration Client machines – This is due to the failure to extract the adminclient.zip file.

To fix the above issues, download the 12.5(1) ES Install Utility and run 12.5.1-ES-Install-Utility.bat by following the instructions provided in the readme file.
