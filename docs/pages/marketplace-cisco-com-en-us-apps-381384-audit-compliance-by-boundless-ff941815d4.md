# Audit & Compliance by BOUNDLESS

by Boundless

Audit Meraki security and configuration compliance in seconds with Audit and Compliance by Boundless—continuous rule-set checks and drift alerts keep every network audit-ready.

## Overview

### Overview

Audit and Compliance by Boundless eliminates manual Cisco Meraki configuration checks by continuously scanning network, template and device settings against your gold-standard security and configuration rule-sets. Using the Meraki Dashboard API, it flags drifts that break compliance, so engineers fix issues before audits fail. Meraki users can now get faster audit cycles, slashing exposure windows from days to minutes.

### Key benefits

- Security rule audits Automatically verifies firewall, content-filter and traffic-shaping policies across every site, removing manual line-item checks.

- Config compliance sets Build multi-layer templates (network, switch, wireless, SD-WAN) and run 24/7 drift detection.

- Tag audit & update Central dashboard spots typos or similar tags and lets you bulk-edit devices, ports or networks, driving tag-data accuracy for cleaner network management and automations.

- Continuous notifications Dynamic rule-sets don’t stop after the first pass—any new drift triggers instant notifications so nothing slips through change windows.
