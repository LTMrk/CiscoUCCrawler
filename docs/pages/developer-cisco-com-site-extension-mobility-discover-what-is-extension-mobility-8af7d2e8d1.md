# What is Extension Mobility API?

The Extension Mobility API is an XML-based HTTP interface that allows applications to remotely invoke the extension mobility feature on behalf of a user.

The Extension Mobility API is a simple tool to empower developer applications. Applications can login and logout users to an enabled IP phone, and then temporarily update the phone's settings specified for that user. The phone is reset to a default behavior once the user is no longer logged into the phone.

Examples of applications which can be developed using the Extension Mobility API include:

- "Hot desk seating" for visiting employees in the office

- Providing personalized phone services to patients' rooms in a hospital or clinic

- Hotel/hospitality solutions, which can automate customized phone settings for guest rooms

- Scheduling conference calls for specific rooms/phones via an automated reservation system
