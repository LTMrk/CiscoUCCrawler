# Cisco Wireless Phone 840 and 860 Release Notes for Firmware Release 1.10(3)

These release notes support the Cisco Wireless Phone 840 and 860 software release 1.10(3). These wireless smartphones require:

Call Control

Cisco Unified Communications Manager

Minimum: 11.5(1)

Recommended: 12.5(1), 14.0(1), or higher)

Webex Calling

Wireless LAN Controller and Access Points

See the Cisco Wireless Phone 840 and 860 Deployment Guide for supported solutions.

## What’s New in This Release?

The following sections describe the features that are new or have changed in this release.

Answer and end calls using the hardware buttons

You can answer and disconnect the calls by pressing the hardware buttons instead of using the on-screen controls.

By default, this feature doesn’t come enabled. So, you have to turn it on manually using the Buttons application.

Turn ON and OFF flaslight using the hardware buttons

You can turn ON and OFF the flashlight by pressing the hardware buttons.
