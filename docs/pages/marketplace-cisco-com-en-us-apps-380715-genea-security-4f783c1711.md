# Genea Security

by Genea

Genea Security provides a single pane of glass cloud-based access control platform allowing companies to automate physical access credentialing across locations globally. View Genea access events and unlock door directly from the Meraki Vision portal.

## Overview

### Overview

Many of Genea’s largest customers rely on Cisco Meraki cameras to secure their facilities and accelerate incident response. To deliver deeper visibility and faster verification, Genea offers a native integration that brings Meraki’s industry-leading video intelligence directly into Genea’s cloud-native access control platform. Together, the two systems provide a unified, real-time view of who accessed a space and what happened at the moment of entry—without added infrastructure or complexity.

By pairing Genea’s identity-rich access logs with Meraki’s high-quality video, teams can quickly validate events, reduce false alarms, and simplify investigations and audits. Built on a secure, cloud-native architecture, Genea eliminates on-prem maintenance while enabling automatic updates, remote administration, and effortless scaling across locations. Secure, encrypted APIs and granular role-based permissions ensure the integration strengthens security posture while supporting compliance requirements.

With Genea, organizations can also:

- Use a single secure credential across all locations

- Automate user provisioning and deprovisioning

- Migrate cost-effectively using existing access control hardware

- Enable mobile credentials for added convenience and security

- Simplify audits with centralized logs and synchronized video

- Scale globally with zero on-prem infrastructure
