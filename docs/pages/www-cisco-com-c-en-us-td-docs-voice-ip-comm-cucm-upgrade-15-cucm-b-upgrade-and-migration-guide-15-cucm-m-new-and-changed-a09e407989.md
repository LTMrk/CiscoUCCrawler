December 18, 2023

Unified Communications Manager and IM and Presence Service and all applications have moved to a 64-bit architecture.

Some of the affected areas are:

Unified Communications Manager and IM and Presence Service 15 requires a minimum ESXi version of 7.0 U3 or 8.0 U1.

Release 15 of Unified Communications Manager supports only virtual disks of minimum 110 GB at install-time. Virtual disks
                                                of 80GB at install-time are not supported.

Direct Refresh Upgrades from Pre-12.5.x source to Release 15 is not supported.

Pre-upgrade Readiness COP File has new checks added for Unified Communications Manager and IM and Presence Service.

Unified Communications Manager and IM and Presence Service 15 supports only Open VM Tools.

IPSec policy with 3DES Algorithm is not supported in FIPS mode for Release 15.

December 18, 2023

You can upgrade Cisco Unified Real-Time Monitoring Tool (Unified RTMT) on workstations running on both Windows or Linux operating
                                          systems using a single 'CiscoRTMTPlugin.zip' plug-in.
