# Cisco Unified Presence Server Administration Guide, Release 1.0(2)

Updated: August 28, 2006

Chapter: AXL Configuration

## Chapter: AXL Configuration

- Configuring AXL Settings

## AXL Configuration

Use AXL configuration settings to configure the username and password for AXL Application Programming Interface (API) access. You can use the AXL Configuration window to change the AXL username and password that you entered during installation.

## Configuring AXL Settings

This section describes how to configure the AXL username and password.

Step 1 Choose Cisco Unified Presence Server > Security > AXL Configuration .

The AXL Configuration window displays.

Step 2 Enter the AXL username and password.

Step 3 Confirm the AXL password.

Step 4 To save your settings, click the Save icon that displays in the tool bar in the upper, left corner of the window (or click the Save button that displays at the bottom of the window).
