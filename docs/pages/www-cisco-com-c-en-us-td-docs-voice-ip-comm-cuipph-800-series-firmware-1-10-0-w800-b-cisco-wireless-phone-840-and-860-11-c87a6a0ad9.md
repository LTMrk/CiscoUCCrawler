# Cisco Wireless Phone 840 and 860 Release Notes for Firmware Release 1.10(0)

These release notes support the Cisco Wireless Phone 840 and 860 software release 1.10(0). These wireless smartphones require:

Call Control

Cisco Unified Communications Manager

Minimum: 11.5(1)

Recommended: 12.5(1), 14.0(1), or higher)

Webex Calling

Wireless LAN Controller and Access Points

See the Cisco Wireless Phone 840 and 860 Deployment Guide for supported solutions.

## What’s New in This Release?

The following sections describe the features that are new or have changed in this release.

Hoteling Guest Login for Webex Calling

Cisco Wireless Phones 840 and 860 now support device-based Hoteling guest login.

Japanese Locale Support

Japanese locale support for Cisco Wireless Phone 840 and 860 applications.

Updated Ringtone Per Line Management for Cisco Unified Communications Manager

You can set the ringtone type to "None" for any line on your phone. By which the phone doesn't ring, but displays the incoming
                  calls.

Limited CTI Support

Limited Computer Telephony Integration (CTI) support added for Informacast interoperatbility only. CTI Control from Jabber
                  or Webex App is not supported.

XML Support for Informacast

Cisco Wireless Phone 840 or 860 can now use the Informacast solution for emergency notifications.

Enhancement to Incoming Call UI Screen and Heads-Up Notification

The incoming call UI screen and heads-up notification now display the calling party number.

### Important Notes

Third Party Application Conflicts

Third party application interference can be eliminated by factory reset and reregistration of a problematic phone.
