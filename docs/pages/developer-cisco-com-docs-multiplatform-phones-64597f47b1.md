# Cisco IP Multiplatform Phones

The Cisco® IP Phone Series with Multiplatform Phone (MPP) Firmware is a high-fidelity voice and video communications portfolio designed to improve your organization’s person-to-person communications while reducing your operating costs on approved Unified-Communications-as-a-Service (UCaas) platforms.

# Why Remote SDK Feature on Multiplatform Phones

This API, available on Cisco Multiplatform 11.3.1 or later phones, will enable service providers or Cisco partners to quickly test and certify IPPhone Firmware loads in their labs. The MPP Remote SDK utilizes a WebSocket connection, initiated by the MPP phone, to allow the controlling WebSocket server to send commands, receive command results, and receive event notifications from the MPP phone.
