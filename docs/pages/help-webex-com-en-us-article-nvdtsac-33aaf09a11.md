A status contains the current state of the device, such as connected calls, connected inputs, and output sources.

You can also select 6 statuses to be exposed on the device’s details page. These favorites are connected to the Control Hub user, and the same statuses are exposed for all devices in the organization.

Statuses are available on Control Hub for the following devices:

Devices running RoomOS 10.12.1.4 and later or RoomOS 9.15.11.7 and
                            later

To find description for the statuses, go to roomos.cisco.com .

Cisco IP phones running PhoneOS 4.0.1 and later

To find description for the statuses, go to phoneos.cisco.com .

## View statuses

From the customer view on https://admin.webex.com , go to Devices and select a device.

Under Statuses Overview, click View all statuses to open the status page for the device.

On this page, you can browse or search for the statuses you’re interested in.

## Add statuses to device details page

To add or edit statuses that appear on the device’s details page, go to Devices and select a device. Go to Statuses Overview and click the cogwheel icon.

Browse or search for the statuses you’re interested in. Click +Add to add them to the list of favorites.
