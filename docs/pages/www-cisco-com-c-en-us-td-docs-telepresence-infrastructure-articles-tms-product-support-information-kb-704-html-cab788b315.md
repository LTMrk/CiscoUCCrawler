# Cisco TelePresence Management Suite (TMS)

## Finding information about systems supported by Cisco TMS

### Finding information about systems supported by Cisco TMS

Cisco TMS supports a wide range of telepresence endpoints and infrastructure systems for management and scheduling.

To find updated product support information:

- An overview of supported system types and management modes, as well as guidance for adding the different types of systems, can be found in the Cisco TMS web help or Administrator Guide for your version of Cisco TMS.

- Tested system series and models can be found in the Cisco TelePresence Interoperability database .

For some earlier releases of Cisco TMS, a "Product Support" document was available, detailing feature sets supported for selected systems, as well as some information on adding and managing the systems in Cisco TMS.

The product support document has been discontinued and will not be updated for current or future versions of Cisco TMS.
