## Voice Message
                        	 Identification

If you have a voice
                           		message, the Call button on the DCU is red and the phone screen displays the
                           		New Voicemail status message. You can also configure an audible message
                           		indicator using Cisco Unified Communications Manager Self Care Portal. If you
                           		have configured an audible message indicator, listen for a stutter tone when
                           		you try to place a call.
