## Getting Started With Cisco JTAPI

- Review the JTAPI section of the Introducion to Unified CM Interface slide deck.

- Review the JTAPI Developer Guide for the desired Cisco Unified CM release.

- Subscribe to the Cisco JTAPI blog to receive updates from the interface Product Manager.

- You will need access to a Cisco Unified CM system, and a couple of Cisco phone devices (either software or hardware).  See this link for info on building a lab or accessing the DevNet Sandbox lab .
