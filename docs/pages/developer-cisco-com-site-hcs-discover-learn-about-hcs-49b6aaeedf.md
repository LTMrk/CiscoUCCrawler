# Learn about HCS

Cisco Hosted Collaboration Solution (HCS) delivers applications within a highly secure, cloud-ready, virtualized platform under a centralized management system.

This solution helps partners differentiate themselves and promote value in the collaboration market.

## HCS is built on best of breed data center platform

- Optimized for a multi-customer environment

- Application performance and optimal hardware utilization

- Built in security, redundancy

- Flexible and global delivery across different customer sizes

- Extensive on and off network integration capabilities
