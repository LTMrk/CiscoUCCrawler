## About Webex Calling

Webex Calling is a feature of our Webex Collaboration Service.  Webex Calling is optimized for midsize business needs and is based on the Cisco BroadWorks carrier-grade unified communication software platform.

## Webex Calling Xsi Interface

With this open API, Webex Developers can use Webex Calling Xsi to develop distinct applications or middleware services to communication-enable existing CRM, HRM, or service desk applications. The Xsi Interface enables third party applications to develop calling and analytics applications using the familiar BroadWorks eXtended Services Interface (Xsi).

Webex Calling Xsi is very scalable and designed to be used securely by different types of applications. The Xsi interface allows resources to be addressed over HTTP using simple XML and informs external applications when Webex Calling related subscriber activity occurs.

## Webex Calling Developer Interface

Xsi (eXtended services interface) – XSI is a family of BroadWorks APIs that allow resources to be addressed over HTTP using simple XML.  Xsi can be used to develop distinct applications or middleware services to communication enable existing CRM, HRM, or service desk applications.

Xsi is very scalable and designed to be used securely over multiple protocols by different types of applications.  The Xsi interface informs external applications when BroadWorks subscriber activity occurs.

### Types of events include:

• Call Events – Provides notification of real-time call information on active calls.

• Service Events – Provides notification when service configuration has been changed.

## In summary

The Xsi application interface features of Webex will allow Application Developers to create value-added user and operational applications which Webex Calling users can consume.

For additional information, visit Webex Calling on cisco.com.
