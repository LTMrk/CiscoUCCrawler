# Reverse Proxy

## New Features

None.

## Updated Features

### VPN-less Finesse Enhancements

VPN-less Finesse now includes the following enhancements:

Multi-instance support – Support for multiple podman instances per VM

OS upgrade – Reverse proxy is now deployed on RHEL 9.4 instead of the existing CentOS

Automatic upgrade – Automatically upgrade the installer and env properties from 12.6(2) to 15.0(1)

Web socket authentication – User authentication support for secure WebSocket connection.

Security enhancements – IPTable rules and SeLinux rules are automatically applied.

For more information, see the VPN-less Access to Finesse Desktop and Reverse Proxy Automated Installer chapters in Cisco Unified Contact Center Enterprise Features Guide .
