## Getting Started With Cisco TAPI

- Review the TAPI section of the Introducion to Unified CM Interface slide deck.

- Review the TAPI Developer
                        Guide for the desired Cisco Unified CM release.

- Subscribe
                        to the Cisco TAPI blog to receive updates from the interface Product Manager.

- You will need access to a Cisco Unified CM system, and a couple of Cisco phone devices (either
                        software or hardware).
