## About this
                        	 Guide

This document describes how to use the programming APIs provided by
                           		Cisco Unified CVP VXML Server (VXML Server). Topics covered include building
                           		custom elements and the Cisco Unified Customer Voice Portal (Unified CVP)
                           		VoiceXML Java and XML APIs

## Audience

This document is intended for developers writing system and voice
                           		applications/components using Cisco Unified CVP VoiceXML.
