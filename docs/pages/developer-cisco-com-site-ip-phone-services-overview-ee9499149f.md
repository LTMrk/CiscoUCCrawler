## Technical Overview of Cisco IPPS

Not sure Cisco IPPS is right for you and your organization? The technical overview describes the basics: how to use Cisco IPPS , where it fits in the architecture, and some requirements.

Cisco IP Phone Services bring the power of the World Wide Web to Cisco IP Phones. An integral part of a Cisco
          AVVID (Architecture for Voice, Video and Integrated Data) solution, IP Phone Services provide access to intelligent
          network applications and dynamic and interactive communication tools.
