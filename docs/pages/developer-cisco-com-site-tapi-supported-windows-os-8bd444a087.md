# Supported Windows OS for Cisco TAPI

- For older Windows OS versions, see Supported Windows OS (EOL releases) for Cisco TAPI

TAPI 2.1 is supported by CiscoTSP on the following platforms.

Note: The Cisco TSP is not tested/supported with Remote Desktop or Remote TSP scenarios.

*1 - Cisco TSP legacy wave driver is not supported under
            VMWare

*2 - Requires Unified Communications Manager release 8.5(1)SR1+.  CiscoTSP does not support Itanium platforms

*3 - CiscoTSP supports Windows 10 from the following versions:

- 10.5.2.8  (for v10.5)

- 11.0.1.4  (for v11.0)

*4 - Cisco TSP 64 bit plugin support tested for (with Persistent and Dedicated configured on below platforms) :

- •	Citrix Virtual Desktops (Standard, Advanced, and Premium) version 7.19

- •	VMware Horizon (Standard, Advanced, and Enterprise)

*5 - Cisco TSP 32 bit plugin support is deprecated starting with Cisco Unified Communications Manager Release 14SU5 and in all subsequent ES and SU releases in this train, and Release 15SU4 and in all subsequent ES and SU releases in this train.
