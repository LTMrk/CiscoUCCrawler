## License Unit Report

Use license unit report to display the total license capacity and the number of licenses in use. This tool generates a report that lists the total number of available licenses.

## Generating a License Unit Report

Use the following procedure to generate a report for the number of licenses that are available.

Step 1 Choose System > Licensing > License Unit Report .

Step 2 The License Unit Report window displays. This window displays the number of node licenses that are available by

• Units Available

• Units Used

• Units Remaining
