# VAULT

by RoamingiQ

VAULT automatically onboards users to your network, configures network policies such as user bandwidth, and allows users to manage their Wi-Fi account and password. VAULT is an innovative SaaS solution that migrates a user’s Wi-Fi password (PSK) off the local hardware and to the cloud. This enables a user’s Wi-Fi password to work securely on any VAULT-enabled Wi-Fi network in the world. VAULT works for multi-family/MDU, hospitality, public/private space, and more.

## Overview

### Global Wi-Fi Roaming and Network Onboarding

VAULT automatically onboards users to your network, configures network policies such as user bandwidth, and allows users to manage their Wi-Fi account and password. Using VAULT's patented Global Roaming Passphrase (GRP) technology, users can roam between VAULT-enabled-networks, and automatically connect using their unique Wi-Fi password.

### Key benefits

- Simple, One-time Authentication Understanding MAC addresses is a thing of the past and replaced with manufacturer’s instructions to add IoT devices.

- Users Access a Pre-shared Key Via Email There is no need for an appointment with the property manager or hours on the phone with support. The Internet is always on, and the apartment is move-in ready.

- Security that Follows the User Automatically encrypts data without user intervention for a fully secure environment, property-wide

- Automatic Dynamic Policy Provisioning VAULT communicates with on-site network equipment to provision dynamic policies. When a resident purchases a 1gbps plan, or a diamond loyalty member checks in, VAULT will provision those service policies to the local network equipment.

- Payment Processing VAULT collects payments via Stripe to automatically enable customer access without intervention from the property or the network operator.

- Network Administrator Management The Network Administrator Dashboard is the central hub for Network Administrators to manage their network operator environment, venues, and subscribers.

## Features

### Global Wi-Fi Roaming

VAULT is an innovative SaaS solution that migrates a user’s Wi-Fi password (PSK) off the local hardware and to the cloud. This enables a user’s Wi-Fi password to work securely on any VAULT-enabled Wi-Fi network in the world.

### Network Administrator Management

Network Operators can create Venues, manage subscribers, customize the look and feel of customer communications, define VAULT's user policies, and much more.

### Venue Administrator Management

The Venue Administrator Dashboard is the central hub for venue management to add and remove users and view a summary of support status. With VAULT's comprehensive capabilities, venue managers gain insights, enhance security, and elevate subscriber satisfaction. VAULT empowers the staff to manage subscriber and guest access, monitor performance, optimize connectivity, and much more.

### Subscriber Management

The Subscriber Console is the central hub for subscribers, or end-users of your internet service, to manage their accounts. The subscriber console allows subscribers to view and edit their Wi-Fi passwords, view messages sent by network administrators and venue administrators, view their devices, and more. Subscribers, or users, can also upgrade/downgrade services and manage their payment information.

### Subscriber Sign Up

VAULT has multiple ways to add subscribers. Network Administrators or Venue Administrators can add subscribers, or subscribers can sign up via the shopping cart. No matter how a subscriber is added to VAULT, the quick and easy onboarding process remains the same.

### Automatic Policy Provisioning

VAULT communicates with on-site network equipment to provision dynamic policies. When a resident purchases a 1gbps plan, or a diamond loyalty member checks in, VAULT will provision those service policies to the local network equipment.

### Optional Captive Portal

With VAULT, a portal page is not required for authentication. WPA2 confirms user identity and privileges. The user can be redirected to a welcome or advertisement page once connected to Wi-Fi. That's the beauty of VAULT...flexibility!

### Wi-Fi Security

All Wi-Fi traffic from the consumer device to the access point is secured and encrypted. All devices using the same password will be placed on an isolated dynamic VLAN.

### Cloud Authentication Server

With VAULT, no additional equipment is needed. VAULT eliminates the need for complicated gateways with high support and licensing costs. Regardless of the Wi-Fi vendor and actual user location in the world, VAULT allows users to roam from one location to another. One unique SSID can service billions of users.

### User Location Identification

VAULT replaces outdated technologies for subscriber tracking based on device MAC Address with unique, individual WPA2 credentials. VAULT triggers different types of policies that are user and location-based. VAULT understands when the user is “home” or roaming and applies different types of network policies and given allowances. For example, bandwidth limitations, content filtering, and assigned VLAN.

### Data Privacy Protection

Complies with data privacy regulations such as NDB, PDPA, GDPR, CCPA and LGPD.

### IoT Friendly

VAULT makes it easy to onboard IoT devices to Wi-Fi simply by using the manufacturer's guidelines. This is not possible on open or SSL-based Wi-Fi networks.

### Advanced API Integration

Integrates with any Subscriber Management Software that is being used by the MSO/MSP and enables full control over VAULT. Simple API based on XML and/or software widgets.

### Mobile Offload

Offload data traffic from LTE / 5G networks to any VAULT enabled Wi-Fi network.
