# New and Changed Information

## Log Level Configuration

You can now set the log level for core services and product instances using either of the following CLI commands: license management set log level core_services and license management set log level product_instances . There are four different levels to choose from: error, warning, info, and debug.

If you're unsure what your current log level is, enter license management show log level core_services or license management show log level product_instances .

For more information about any of these commands, see the Cisco Prime License  Manager User Guide at http:/​/​www.cisco.com/​c/​en/​us/​support/​cloud-systems-management/​prime-license-manager/​products-user-guide-list.html .

## User Credential Configuration Update

Administrators can now track the IP address of the user who last signed in to Cisco Prime License Manager successfully or unsuccessfully. The IP address of the most recent failed and successful login attempts are displayed in the User Credential Configuration window.
