                              				Communications Manager .

                           		following table provides a high-level overview of calling features and their

                           		to the Cisco Unified IP Phone 6901 and 6911 User Guide for Cisco Unified IP Phone 6901 and 6911 (SCCP and SIP) .

The guide is
                           		available at this URL:

http://www.cisco.com/en/US/products/ps10326/tsd_products_support_series_home.html
