## About This Guide

This manual describes the ICM-to-ICM Gateway feature that is part of Cisco Unified Contact Center  Enterprise (Unified CCE).
                           It discusses ICM-to-ICM Gateway functionality, architecture, and call flows and provides step-by-step instructions for configuring
                           ICM systems for ICM-to-ICM Gateway user.

## Audience

This manual is intended primarily for system administrators who are responsible for configuring ICM systems for ICM-to-ICM
                           Gateway use.
