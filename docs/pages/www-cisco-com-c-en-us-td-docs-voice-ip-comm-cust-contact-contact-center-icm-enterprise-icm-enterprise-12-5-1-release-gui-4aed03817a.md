# Cisco Unified Contact Center Management Portal

## Legacy Resource Manager Deprecated

Legacy Resource Manager, the traditional three-pane view to manage and maintain resources, is deprecated in Unified CCE 12.5
                           release. It is recommended that you use the Resource Manager gadgets for all resource management related tasks.
