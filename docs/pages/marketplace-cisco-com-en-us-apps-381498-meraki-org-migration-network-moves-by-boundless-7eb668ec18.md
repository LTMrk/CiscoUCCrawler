# Meraki Org Migration & Network Moves by BOUNDLESS

by Boundless

Migration by Boundless delivers Cisco Meraki splits, merges and moves, halving timelines and minimizing downtime via API automation.

## Overview

### Automate network and device migrations in Meraki

Migration by Boundless is a fully managed service that moves Cisco Meraki networks, devices and configurations between organizations. Combining Meraki APIs with purpose-built automation, the service removes error-prone manual rebuilds, stores configuration settings with API-level backups and finishes projects in a fraction of the usual window. Typical moves that once demanded days of planning and long manual processes now complete within a few hours, trimming project schedules by half and minimizing the risk of outages devices normally suffer during hand-offs.

### Key benefits

- Network cloning The cloning engine duplicates every network and template parameter into the target org, creating like-for-like sites in seconds — 100 % of API-exposed settings replicated automatically.

- Automated device moves Meraki-API scripts unclaim, transfer and reprovision each appliance, switch or AP automatically.

- Rollback safety nets A pre-flight backup captures the configuration state via the Meraki Dashboard API, while restore files are auto-generated. If anything drifts, engineers can roll back every settings, protecting captured configs.

- Expert-led planning Boundless specialists with 8 years of Meraki-API experience guide assessments, staging and execution to de-risk complex splits and mergers.

### FAQ

Frequently asked questions for Migration by Boundless.

#### Who actually performs the migration?

- A senior Boundless employee plans and executes every step; you stay in control of change windows and approvals.

#### What API permissions are needed?

- We require Meraki Dashboard API keys with write scope for the source and target organizations; keys can be revoked immediately after cut-over.

#### How is downtime minimized?

- Automation moves devices and pushes configs in bulk, so each device experiences only a brief reprovisioning cycle instead of 1–3 hours of manual re-entry.

#### Is there a backup if something goes wrong?

- An API-based backup and restore files are generated before any destructive action, enabling an instant rollback.

#### Is a free assessment available?

- Yes—Boundless provides a no-cost discovery call.
