## Introduction

This document describes the process to license a Cisco Unified Attendant Console (CUAC) Advanced Server and, the installation types that is covered are the upgrades and the new installations.

## CUAC-Advanced License Process

CUAC-Advanced License is completely different than any other Cisco product, and this often causes trepidation on how the license process works. Here are the steps on how to activate and install a CUAC-Advanced Server license.

Information needed before you attempt to activate a CUAC-Advanced License:

- CUAC-Advanced should be installed on a Windows Server.

- This can be found when you navigate to Help > Licensing.

- If you install a purchased license, the License Activation Code (LAC).

- If you install an Upgrade license, the upgrade LAC and the previously registered Registration Code or LAC.

### Activate a Demo/Evaluation License for CUAC-Advanced

When you install the application for the first time, CUAC-Advanced allows the application to fully function for ten days. After this ten day period, you have the option to install a demo/evaluation license or permanent license. The demo/evaluation license is valid for sixty days. Once the sixty day mark is reached the console must be permanently licensed. This cannot be extended. In order to create a sixty day demo/evaluation license for CUAC Advanced, do this:

Step 1. Browse to www.cisco.com/go/ac

Step 2. Login to this site (the site is not attached to your Cisco Connection Online (CCO) account, so if registration is needed, select Register Your Details ).

Step 3. Once logged in, select ACTIVATE EVALUATION SOFTWARE .

Step 4. Select a Reseller (if your reseller is not present, select Add a Reseller and enter the details).

Step 5. Select a Customer (if your reseller is not present, select Add a Customer and enter the details).

Step 6. Select a Site (if your reseller is not present, select Add a Site and enter the details).

Step 7. Select the product version 10.X or version 11.X .

Step 8. Select CUAC Advanced .

Step 9. Enter the Registration Code found on the CUAC-Advanced website.

Step 10. Click Submit .

You are then emailed the 60 day evaluation license to install on the CUAC-Advanced server.

### Activate a Purchased License for CUAC-Advanced

Step 1. Browse to www.cisco.com/go/ac

Step 2. Login to this site (the site is not attached to your CCO Account, so if registration is needed, select Register Your Details ).

Step 3. Once logged in, select ACTIVATE PURCHASED SOFTWARE

Step 4. Select a Reseller (if your reseller is not present, select Add a Reseller and enter the details).

Step 5. Select a Customer (if your reseller is not present, select Add a Customer and enter the details).

Step 6. Select a Site (if your reseller is not present, select Add a Site and enter the details).

Step 7. Select the product version 10.X or version 11.X .

Step 8. Select CUCA Advanced .

Step 9. Enter the Registration Code found on the CUAC Advanced server in the left most text box.

Step 10. Enter the 27 character LAC that you were provided with the purchase of the software.

Step 11. Click Next .

Step 12. Click Submit .

You are then emailed the permanent license to install on the CUAC Advanced server.

### Activate an Upgrade License for CUAC-Advanced

Step 1. Browse to www.cisco.com/go/ac

Step 2. Login to this site (the site is not attached to your CCO Account, so if registration is needed, select Register Your Details ).

Step 3. Once logged in, select ACTIVATE PURCHASED SOFTWARE

Step 4. Select a Reseller (if your reseller is not present, Add a Reseller and enter the details).

Step 5. Select a Customer (if your reseller is not present, select Add a Customer and enter the details).

Step 6. Select a Site (if your reseller is not present, select Add a Site and enter the details).

Step 7. Select the product version 10.X or version 11.X .

Step 8. Select CUAC Advanced .

Step 9. Enter the Registration/Machine Code found on the CUAC Advanced server website in the left most text box.

Step 10. Enter the 27 character LAC that you were provided with the purchase of the software.

Step 11. Click Next .

Step 12. In the event, that the LAC are of type Unified Communications Software Subscription (UCSS), you are prompted that this is an upgrade license. Click OK .

Step 13. Enter either the Registration Code or LAC of the previously registered CUAC server. This information must be provided in order to complete the license process.

Step 14. Click Submit .

You are then emailed the permanent license to install on the CUAC-Advanced server.

### Procedure to Install a License on the CUAC-Advanced Server

Once the license is generated, a Redundancy Group Facility (RGF) file for installation is emailed to you on the CUAC-Advanced server.

In order to install the license, follow these steps:

Step 1. In the CUAC Advanced website, navigate to Help > Licensing .

Step 2. Select the Registration File Radio Button .

Step 3. Browse to the RGF File and select RGF File and then click Open .

Step 4. Click Save .

Once the license is validated, the CUAC server operates normally and is permanently licensed.
