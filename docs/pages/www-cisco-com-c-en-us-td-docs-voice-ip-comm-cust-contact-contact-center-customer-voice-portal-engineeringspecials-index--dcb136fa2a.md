To ensure compatibility, VVB 12.5(1)_SU ES02 must be installed only when migrating from CVP 12.5(1) to 12.6(2). If this is
                                       installed along with CVP 12.5(1), UI compatibility issues will occur.

Note: This ES must be installed using CLI only. A system reboot is mandatory after applying the patch.

This ES addresses a critical issue in 12.5(1) SU.

Note : This ES is to be installed using CLI only . Reboot of system is mandatory after applying the patch.

Important

Custom values are set on the VVB servers by the VoiceBrowser.properties and SIPSubsystem.properties properties files. The following commands may reset the custom values to their default values:

```
show vvb cache *
show vvb call *
show vvb mrcp *
show vvb http client response timeout
```
