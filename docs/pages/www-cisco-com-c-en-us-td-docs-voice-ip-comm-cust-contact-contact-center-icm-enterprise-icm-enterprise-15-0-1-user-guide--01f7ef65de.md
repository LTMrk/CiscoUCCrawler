## About This
                        	 Guide

This manual describes how to use the Script Editor tool for Cisco Unified Contact Center Enterprise (Unified CCE) to create
                              and maintain routing and administrative scripts.

## Audience

This document is intended for system managers. A system manager must have a general understanding of contact center operations
                              and management, and specific information about the contact centers and carrier networks connected to a Unified CCE system.
