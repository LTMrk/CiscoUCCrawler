# CLOSE_CONF

Unified CCX confirms the termination of the communication
		  session with the CLOSE_CONF message, defined in the following table.

Fixed part

Field name

Value

Data type

Byte size

InvokeID

Set to the same value as the InvokeID from the
					 corresponding CLOSE_REQ message.

UINT

4

| Fixed part Field name | Value | Data type | Byte size |
|---|---|---|---|
| InvokeID | Set to the same value as the InvokeID from the
					 corresponding CLOSE_REQ message. | UINT | 4 |
