# Preface

## About This
                        	 Document

This document
                           		provides the details of the Engineering Specials for the Cisco Unified Contact
                           		Center Express.

Unified CCX
                                       		  Engineering Specials are cumulative, unless specified otherwise. Therefore, you
                                       		  must install the latest Engineering Special available at the time for the
                                       		  Unified CCX version. However, it is not mandatory but beneficial to stay on the
                                       		  latest Engineering Special so that the defect fixes are applied proactively on
                                       		  the system.

Send your feedback
                           		to ask-ccx@cisco.com.
