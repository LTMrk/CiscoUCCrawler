This chapter explains the following:

## Power Cables

Power cables are available to order from Cisco.

Warning

If you opt not to order power cables from Cisco, you must use cables of the designated type, see Cisco UCS C220 M6 SFF Rack Server Spec Sheet .

## KVM Adaptors

KVM adaptors are available to order from Cisco.

## Field-Replaceable Components

These components are field replaceable:

Hard disks

Power supply units (PSUs)

Fan module

SFP network connection modules (1 Gb and 10 Gb)

Caution

To avoid compatibility issues, use only the supplied SFPs, and follow the other requirements for SFPs in Task 2: Insert the SFP Network Connection Modules .

## Returns or Replacements

If you need to begin a Return Material Authorization (RMA) for any reason, go to Cisco Returns Portal .
