# Cisco Wireless Phone 840 and 860 Release Notes for Firmware Release 1.9(1)

There are no updates for Cisco Wireless Phone 860.

These release notes support the Cisco Wireless Phone 840 software release 1.9(1) only. This wireless smartphone requires:

Call Control

Cisco Unified Communications Manager

Minimum: 11.5(1)

Recommended: 12.5(1), 14.0(1), or higher

Webex Calling

Wireless LAN Controller and Access Points

See the Cisco Wireless Phone 840 and 860 Wireless LAN Deployment Guide for supported solutions.

## What’s new in this release

The following sections describe the features that are new or have changed in this release.

Cisco Wireless Phone 840 roaming recovery enhancements when a roam failure occurs

Added an enhancement to send an association to candidate Access Point after a reassociation time-out occurs without disconnecting
                     the TCP socket to the Cisco Unified Communications Manager.
