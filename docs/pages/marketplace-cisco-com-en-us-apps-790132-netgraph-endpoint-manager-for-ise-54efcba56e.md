# Netgraph Endpoint Manager for ISE

by Netgraph

Netgraph Endpoint Manager extends Cisco ISE with real-time endpoint lifecycle orchestration, delegated administration, and operational visibility. Operating natively via Cisco ISE ERS and Monitoring APIs, the platform reads and writes directly to the ISE database — ensuring Cisco ISE remains the authoritative source of truth at all times.

Endpoint metadata, including group-based and device-specific custom attributes such as Serial Number, Owner, and Asset ID, is stored directly within Cisco ISE to eliminate synchronization conflicts. The solution also provides scoped visibility into active sessions, IP addresses, and connected switch/port/access point information without exposing full ISE administrative access.

Designed for enterprise IT teams and managed service providers requiring secure, scalable endpoint governance.

## Overview

### Delegated Endpoint Management for Cisco ISE Environments

Netgraph Endpoint Manager extends Cisco ISE with real-time endpoint lifecycle orchestration, metadata governance, and distributed operational visibility. Using Cisco ISE ERS and Monitoring APIs, it reads and writes directly to the ISE database — ensuring ISE remains the authoritative source of truth. Custom attributes and endpoint metadata are stored natively in ISE, eliminating sync conflicts.
The platform enables delegated administration and scoped session visibility (IP address, active session, switch/port/AP) without exposing full ISE configuration access. Built for enterprise and MSP environments requiring secure, scalable endpoint operations.

### FAQ

Frequently Asked Question

#### Q: Does Netgraph Endpoint Manager replace Cisco ISE?

- No. Netgraph Endpoint Manager extends Cisco ISE but does not replace it. Cisco ISE remains the authoritative source of truth for endpoint data, authentication, and authorization policies. The platform operates as a live orchestration and visibility layer via Cisco ISE APIs.

#### Q: Does the solution create a separate endpoint database?

- No. All endpoint records and metadata are stored directly within Cisco ISE. Netgraph Endpoint Manager reads and writes via ERS and Monitoring APIs, eliminating synchronization conflicts or dual data ownership scenarios.

#### Q:What types of environments is this designed for?

- Netgraph Endpoint Manager is ideal for:

- IoT-heavy environments

- Healthcare networks

- Campus and university deployments

- Industrial and OT networks

- Managed service provider deployments

#### Q: How are custom attributes handled?

- The platform writes both group-based and device-specific custom attributes directly into Cisco ISE endpoint records.

Group-based attributes are automatically applied when endpoints are assigned to specific ISE endpoint groups. Device-specific attributes such as Serial Number, Owner, or Asset ID are stored natively within ISE custom fields.

#### Q: Is the solution suitable for multi-tenant or MSP environments?

- Yes. The platform supports delegated administration and segmented visibility models, allowing enterprises and managed service providers to distribute endpoint management without exposing full ISE configuration access.

#### Q: Does it support large-scale endpoint environments?

- Yes. The architecture is designed for enterprise-scale environments managing thousands of endpoints with group-based governance and distributed operational visibility.
