## Technical Overview of Cisco JTAPI

Not sure is right for you and your organization? The technical overview describes the basics: how to use , where it fits in the architecture, and some requirements.

Cisco CallManager exposes sophisticated control of the integrated telephony platform via its Computer/Telephony Integration (CTI) APIs. These APIs allow custom applications to register interest in CallManager device call events, and take full control of those devices to make, take, transfer, end calls, etc. Applications may monitor or control Cisco IP Phones, create and register 'soft' phone ports (CTI Ports) which provide media streaming capabilities, and manage CTI Route Points to queue and distribute high-volume incoming calls..
