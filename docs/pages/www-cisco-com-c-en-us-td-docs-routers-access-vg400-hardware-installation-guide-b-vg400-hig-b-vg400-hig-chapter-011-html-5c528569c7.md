# Troubleshooting

This section describes possible mechanical problems and corrective actions.

Warning

Only trained and qualified personnel should be allowed to install, replace, or service this equipment. Statement 1030

Warning

No user-serviceable parts inside. Do not open. Statement 1073

If there appears to be a malfunction, first check all cables and connections. If these are in order, see the Troubleshooting section for specific troubles and solutions.

For problems with the configuration, refer to Cisco vg400 Voice Gateway Software Configuration Guide. .
