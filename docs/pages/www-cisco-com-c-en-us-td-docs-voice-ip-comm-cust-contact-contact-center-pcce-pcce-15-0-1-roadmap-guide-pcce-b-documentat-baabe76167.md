### Documents Updated in This Release

The following documents are updated in this release:

Cisco Packaged Contact Center Enterprise Installation and Upgrade Guide

This document includes updates for the following features:

Upgrade to Visual Studio 2022

Updated Microsoft Windows Server to 2022

Updated Microsoft SQL Server to 2022

Updated the OpenLogic-OpenJDK JRE details

Usage of maintenance mode command to bring down the Unified CCE services on server, and leverage the capabilities of graceful
                                                shutdown.

Added Cisco Reverse Proxy upgrade as Stage 1 in the upgrade flow.

Removed IOS VXML Gateway instances as it is not supported in 15.0(1)

See the document’s Change History for more details.

To view the guide, see Cisco Packaged Contact Center Enterprise Installation and Upgrade Guide, Release 15.0(1) .

Cisco Packaged Contact Center Enterprise Administration and Configuration Guide

This document includes updates for the following features:

Smart Transport: Transport mode for Smart Licensing

Modify Logger

Switching to Unified CCE Deployment Type

Supported TLS Ciphers are added for FIPS mode and non-FIPS mode

Manage Reason Code Conflicts During Upgrade

Product Version Reporting to Cisco SSM

Session Inactivity Timer

Support for Third Party Gateway

See the document’s Change History for more details.

To view the guide, see Cisco Packaged Contact Center Enterprise Administration and Configuration Guide, Release 15.0(1) .

Cisco Packaged Contact Center Enterprise Features Guide

This document includes updates for the following features:

Add MR PIM for Outbound 4000 and 12000 Agent Deployment

Support for Facebook, Whatsapp, and Apple Messages for Business Digital Channels

Webex Connect Digital Channels and ECE Coexistence in a Single CCE Deployment

See the document’s Change History for more details.

To view the guide, see Cisco Packaged Contact Center Enterprise Features Guide, Release 15.0(1) .

Cisco Packaged Contact Center Enterprise Developer Reference Guide

This document includes updates for the following features:

New API: General Setting API

Updated "Agent API"

To view the guide, see Cisco Packaged Contact Center Enterprise Developer Reference Guide .

Solution Design Guide for Cisco Packaged Contact Center Enterprise

This document includes updates for the following features:

Extended agent events and scale up to 36000 Agents

VM specifications values have been updated in all Reference Designs

See the document’s Change History for more details.

To view the guide, see Solution Design Guide for Cisco Packaged Contact Center Enterprise, Release 15.0(1) .

Port Utilization Guide for Cisco Unified Contact Center Solutions

This document includes updates for the following:

Two new secure ports, TCP 8445 and TCP 443, are used for VVB Administration, VVB UCCX service, Speech Config, and the Admin
                                                API web application.

To view the guide, see Port Utilization Guide for Cisco Unified Contact Center Solutions, Release 15.0(1)

### Cisco Packaged Contact Center Enterprise Administration and Configuration Guide

Unified CCE
                              		  Administration is a set of web-based tools for configuring objects, such as
                              		  agents, teams, skill groups, and call types, that are used to operate contact
                              		  centers. This document explains the complete set of Unified CCE Administration
                              		  tools that are available in a Packaged CCE deployment to an administrator. This
                              		  document also explains how to create Script Editor routing scripts and Unified
                              		  CVP Call Studio applications for Packaged CCE.

To view the latest guide, see https://www.cisco.com/c/en/us/support/customer-collaboration/packaged-contact-center-enterprise/products-maintenance-guides-list.html .

### Cisco Packaged Contact Center Enterprise Features Guide

Packaged CCE
                              		  contains many optional features that you can enable and configure after
                              		  installation. In addition to the optional features in Packaged CCE, you can
                              		  integrate other Cisco products with Packaged CCE to extend the functionality of
                              		  your contact center. This document describes these additional features and
                              		  products. It also lists assumptions and prerequisites for proceeding with the
                              		  configuration of the optional features described in this document.

To view the latest guide, see https://www.cisco.com/c/en/us/support/customer-collaboration/packaged-contact-center-enterprise/products-maintenance-guides-list.html .
