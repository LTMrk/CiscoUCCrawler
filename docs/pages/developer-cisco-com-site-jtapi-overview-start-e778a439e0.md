Getting Started With Cisco JTAPI

- Review the JTAPI section of the Introducion to Unified CM Interface slide deck.

- Review the JTAPI Developer Guide and JavaDoc Interface Spec for the desired Cisco Unified CM release.

- Subscribe to the Cisco JTAPI blog to receive updates from the interface Product Manager.

- Cisco Unified CM software, hardware, and licenses from Cisco Marketplace or local Cisco sales representative.  150 Device License Units (DLUs) are automatically bundled free with Unified CM software. Solution Partner members should consider purchasing the Cisco Unified NFR Bundle (Ordering instructions below)

- You must have a Cisco.com account with partner level access to purchase this product. If you do not have an account, please register for one at https://id.cisco.com/signin/register . If you have an account, but have forgotten your password, you can reset it at https://pwreset.cisco.com .

- Contact the Solution Partner Program Help Desk to confirm if you have partner level access associated with your Cisco.com account. If you do not, it may take 3 – 5 days to apply this level of access to your account.

To purchase the latest Unified Communications NFR Software bundle - Navigate to Cisco Marketplace - Login using your Cisco.com UserID - Click on Unified Communications NFR Software (display box) - Select Unified Communications Not-For-Resale Products link (small link at top of page) - Select Cisco Unified Communications System Release NFR Program (drop down menu on right) - Select Technology Developer Partner - Click Add to cart

Membership and program information can be found at Solution Partner .

Program members are also eligible to purchase Cisco hardware at a discount.  Program details can be found by clicking here .(Partner Login Required).

D.

- 1. Include Cisco IP Phones and/or Softphones to validate Cisco JTAPI device monitoring and call control operations. Click here for a list of Cisco IP Communication Devices supported with Cisco CTI (JTAPI and TAPI).

- 2. Click here to access Cisco Unified CM documentation on Cisco.com. See also the UCM Technical Readiness site for additional documents, training, ordering guides and more.

- 3. After Unifed CM installation has completed, download and install the Cisco TSP and Media Driver client from the Unified CM Plug-In page. The Plug-In page is part of the Unified CM Web Administation screens (e.g. https://<UnifiedCM ip address>/ccmadmin/pluginsFindList.do).

- 4. After installation has completed, remember to activative the Cisco CTI Service on one or more CIsco Unified CM Subscribers. Service activation is accessed through Unified CM Serviceability Web Administration (https://<UnifiedCM Subscriber ip address>/ccmservice).
