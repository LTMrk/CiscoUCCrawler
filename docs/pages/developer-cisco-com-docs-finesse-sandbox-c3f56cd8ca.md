# Finesse Sandbox

RESERVATION SANDBOX

Packaged Contact Center Enterprise 12.6(1) Sandbox (with Finesse & Task Routing)

Reserve this Sandbox to make Finesse REST API requests, develop custom Finesse gadgets, try out the Finesse agent and supervisor desktops, or try out Task Routing in this Packaged Contact Center Enterprise Sandbox lab. This sandbox has been preconfigured with a SocialMiner form to send tasks, scripts to route the tasks, and a Finesse Task Management gadget for agents to accept the tasks. Reservation is required.
