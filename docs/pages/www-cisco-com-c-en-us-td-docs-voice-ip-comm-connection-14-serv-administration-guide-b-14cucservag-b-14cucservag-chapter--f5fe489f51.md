# Managing Server Status and Ports in a Cisco Unity Connection Cluster

## Managing Server
                        	 Status and Ports in a Cisco Unity Connection Cluster

The Cluster Management page in Cisco Unity Connection
                           		Serviceability lets you change the status of servers in a Unity Connection
                           		cluster, stop all ports on a server from taking new calls, and restart all
                           		ports on a server to take calls.

For the applicable procedures, see the “ Configuring Cisco Unity Connection Cluster ” chapter of the Install, Upgrade, and Maintenance Guide for Cisco Unity Connection, Release 14, available at

https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/connection/14/install_upgrade/guide/b_14cuciumg.html .

The Unity Connection cluster feature is not supported for use
                                       		  with Cisco Business Edition.
