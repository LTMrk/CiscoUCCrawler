## Overview

### Splash Access Senior Living Solution

SplashAccess IPSK (Individual Pre-Shared Key) WPN is a secure guest access solution that provides unique pre-shared keys for individual users to allow super easy connecting to a Wi-Fi network.

With WPN each user or device is assigned a unique key ensuring better security and control over network access.
