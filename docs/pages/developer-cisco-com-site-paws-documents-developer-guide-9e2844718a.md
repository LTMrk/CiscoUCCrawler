# Overview

The Platform Administrative Web Services provide Cisco clients with the ability to:

1. For a given UC application with PAWS activated:

• Upgrade

• Switch version

• Reboot

• Get node information, such as version

2. Cancel an upgrade installation that is in progress.

3. Obtain hardware specifications.

4. Retrieve installed options on active and inactive partitions.

5. Determine which products are deployed.

6. Reboot systems without switching partitions.

7. Determine if an upgrade or a COP file is valid.

Use these URLs to access Platform Administrative Web Services:

URL

Use

https://<server>/platform-services/services/listServices

List available services

https://<server>/platform-services/services/<Service Name>?wsdl

Request WSDL for client stub generation

https://<server>/platform-services/services/<Service Name>

Invoke the service
