## Features

### Export

The key advantage of VAPP Syslog Cloud Collector is that it allows you to retain your Meraki network’s syslog messages for up to one year. This feature makes it an indispensable tool not only for performing internal audits and analyzing historical data for all clients in your network, but thanks to the Export feature you can also provide raw log files to legal authorities for investigative purposes in case they request them.

### Channels

Channels allow you to create preferred channels (currently Webex and Email) through which notifications will be received by specific recipients

### Rules

Rules enable you to define how to be notified based on incoming logs by establishing three types of rules (Rate, Count, Missing Data) calculated within a specific time range. This allows you to choose the level of criticality for the logs.

### Alerts

You can group together the detected alerts and trace back to the causes that triggered them.

### Security Groups

You can update Security Groups on the fly from the settings without having to restart the collector and restore the configuration.

### User Management

Directly manage users within the application by assigning them three different levels of access (Viewer = read-only access to logs, Editor = Viewer + access to log export and alarms, User = Application Manager).

### Device’s IP Identification

Identify the IP of the device sending the logs. This allows for precise identification of the relevant device, even when the same collector is used for multiple networks, and there may be cases of sources with the same name.
