# Megaport for Cisco Catalyst SD-WAN

by Megaport

Automate secure, private branch-to-cloud connectivity from Cisco Catalyst SD-WAN Manager. Spin up on-demand links to AWS, Azure, and Google Cloud in minutes—boost performance, reduce costs, and keep traffic encrypted end to end.

## Overview

### Move at cloud speed without leaving your network behind.

Megaport for Cisco Catalyst SD-WAN lets you automate on-demand connectivity from branches to leading cloud providers like AWS, Microsoft Azure, and Google Cloud right from your SD-WAN controller. You provision bandwidth and locations in Cisco Catalyst SD-WAN Manager, and the integration automates the rest to deliver reliable performance, cost-optimized connectivity, and faster turn-up, moving provisioning from weeks to minutes.

### Key benefits

- Provision Faster with Fewer Clicks Stand up branch-to-cloud connectivity directly in Cisco Catalyst SD-WAN Manager instead of coordinating multiple providers and manual turn-ups. Select locations and bandwidth, then let the integration automate deployment end to end, cutting provisioning time from weeks to minutes and reducing human error.

- Improve Performance on a Private Backbone Move critical cloud traffic off the unpredictable public internet “middle mile.” Megaport’s cloud-neutral interconnect fabric provides a more reliable path into major cloud providers, helping you stabilize latency-sensitive applications and deliver more consistent user experience across branches and regions.

- Keep Traffic Protected, End to End Extend your SD-WAN security posture to the cloud with end-to-end encryption across the Megaport private backbone. Maintain segmentation and policy enforcement through Cisco Catalyst SD-WAN while tunneling securely between the interconnect gateway and cloud providers for branch-to-cloud traffic.

- Optimize Costs for Cloud Connectivity Get a more cost-efficient way to connect to cloud on-ramps without over-buying fixed circuits. The solution overview cites reductions in cloud data egress fees (up to 54%) and network charges (up to 75%), helping you control spend as bandwidth needs change.

## Features

### Megaport Virtual Edge (MVE) Integration with Cisco

Megaport Virtual Edge (MVE) lets you run Cisco virtual routers and SD-WAN appliances natively on Megaports global edge platform. No physical hardware needed. Create branch-to-cloud, branch-to-DC, or full-mesh SD-WAN topologies using private Layer 2 transport - with full control over traffic engineering and security policies. Integrations include: Catalyst SD-WAN, c8000v Autonomous Mode Virtual Router, Cisco Secure Firewall Threat Defense Virtual.

### On-Demand Virtual Cross Connects (VXCs)

Megaport VXCs are private Layer 2 circuits that connect your Cisco infrastructure to clouds, data centers, or SaaS services. Provision in under a minute from an intuitive UI or API, bypassing the complexity of traditional telco provisioning. VXCs give you a direct, low-latency path  without ever touching the public internet.

### Cloud On-Ramps for Every Major CSP

Access native on-ramps to AWS, Azure, Google Cloud, Oracle, IBM, and more from a single Megaport access point. Extend your Cisco environment into any cloud region with dedicated, high-performance links. Cloud-to-cloud and multicloud routing becomes simple  no additional transit providers needed.

### Elastic Bandwidth Scaling

Megaport enables you to scale bandwidth for each connection from 1 Mbps up to 100 Gbps  instantly. Increase capacity during backups, AI workloads, or peak demand windows. Scale down during off-hours to control costs. Bandwidth changes are nondisruptive and dont require ticketing or downtime.

### Self-Service Portal and Full API Access

Use Megaports self-service portal to provision, monitor, and manage services without needing to interact with a carrier. Prefer automation? Every Megaport function is available via a fully documented REST API, or deploy with Terraform to integrate into your infrastructure-as-code workflow.
