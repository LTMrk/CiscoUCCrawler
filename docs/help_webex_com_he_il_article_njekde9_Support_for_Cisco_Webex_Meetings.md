## דרישות מערכת של Webex Meetings Suite 
אם הפגישות שלך פועלות בפלטפורמת הפגישות Webex Suite[, עיין בדרישות המערכת של ](https://help.webex.com/he-il/m61d8eb/)[עבור שירותי Webex](https://help.webex.com/he-il/fz1e4b/).
### תמיכה במערכת ההפעלה ובדפדפן עבור Webex Meetings Suite
#### מערכות הפעלה נתמכות
**Windows**
  * גרסת 64 סיביות של Windows Server 2008
  * גרסת 64 סיביות של Windows Server 2008 R2
  * Windows 10
  * Windows 10 Enterprise LTSB
  * Windows 11


**הערות:**
  * קיימת תמיכה במערכת ההפעלה של Windows ב-Microsoft Surface Pro.
  * כל מהדורה חודשית של Webex Meetings נבדקת ומאושרת כנגד התצוגה המוקדמת הנוכחית של הסיכום החודשי וכל המהדורות החצי שנתיות של Windows 10.
  * Webex Meetings תומך ב-Windows Server מהדורות 2012 R2 ו-2016 עם מגבלה, כאשר בפגישות Webex , בכלי פרודוקטיביות וביישום שולחן העבודה, אם למשתמש אין הרשאות מנהל מערכת, נדרש מנהל מערכת להתקנת היישומים וכלי הפרודוקטיביות של Webex Meetings.


**Mac OS X**
  * 10.15
  * 11.0‎ (Big Sur)‎
  * ‎12.0 (Monterey)‎ 


  * אתרי Webex Meetings התואמים ל-FedRAMP מחייבים את Mac OS 10.13 ואילך.
  * החל מ-Mac OS X 10.7, ‏Apple כבר לא מציעה את Java כחלק ממערכת ההפעלה Mac. מכיוון ש-Webex Meetings הסתמך בעבר על תוסף הדפדפן של Java כדי להוריד את יישום הפגישה עבור משתמשים שמצטרפים בפעם הראשונה, משתמשים שבמחשב שלהם לא מותקן Java התקשו להצטרף לפגישה. התלות ב-Java הוסרה. במקום זאת, המשתמש מתבקש להתקין תוסף קטן אשר, לאחר התקנתו, מטפל בהמשך ההתקנה של יישום הפגישה ולאחר מכן מתחיל את הפגישה.
  * כשאתם מתחילים אירוע או מצטרפים לאירוע באמצעות Events (קלאסי) בפעם הראשונה ב-Safari 6.X וב-Safari 7, מתרחשת בעיה. לאחר שהתקנת את Webex, ‏Safari דורש ממך לתת אמון בתוסף עבור האתר שממנו אתה מנסה להצטרף לאירוע או להתחיל את האירוע. הדף יתרענן לאחר מכן, אך לא תצטרף לאירוע. כדי להצטרף, חזור לקישור שבחרת במקור ותוכל להצטרף בהצלחה.
  * השירותים הבאים של Webex זמינים:
    * Webex Meetings 
    * Webex Webinars 
מצב שידור אינטרנט עבור משתתפים אינו תומך ב-Windows Server 2008 בגרסת 64 סיביות, ב-Windows Server 2008 R2 בגרסת 64 סיביות, ב-Mac OS 10.13 וב-Mac OS 10.14.
    * Events (קלאסי) 
    * Webex Training
  * Webex Support אינו נתמך עוד ב-Mac OS מכיוון שהוא הסתמך על לקוח Java, שיצא מכלל שימוש ב-1 באפריל 2021.


**Linux‏ (Web App) (32 סיביות/64 סיביות)**
  * Ubuntu 14.x ואילך
  * OpenSuSE 13.x ואילך
  * Fedora 18 ואילך
  * Red Hat 6 ואילך
  * Debian 8.x ואילך


שירותי Webex הבאים זמינים עבור Linux ב-Web App:
  * פגישות 
  * Webex Webinars 
מצב שידור אינטרנט עבור המשתתפים אינו תומך ב-OpenSuSE 13.x ואילך, Fedora 18 ואילך, Red Hat 6 ואילך, ו-Debian 8.x ואילך.
  * Events (קלאסי) (משתתפים)
  * הדרכת Webex (משתתפים)


בעיות ומגבלות מוכרות עבור Linux ב-web app של Webex Meetings:
  * בגרסאות מסוימות של Linux, המשתמשים חייבים להתקין ולהפעיל באופן יזום את התוסף "OpenH264 Video Codec provided by Cisco Systems, Inc.‎" כדי שהתכונות 'וידאו', 'התקשר למחשב שלי', ו'שיתוף תוכן' יעבדו ב-Firefox.
  * שיתוף תוכן אינו פועל בגרסאות Linux שמשתמשות ב- Wayland כמערכת ניהול התצוגה שלהן (כגון Fedora 25 ואילך), עקב בעיה ב-API של שיתוף המסך של WebRTC.
  * לא ניתן לבצע שליחה וקבלה של וידאו ב-Fedora 28 עקב בעיה ב-H.264 Codec. 
  * לקוחות Linux אינם נתמכים עבור הצפנה מקצה לקצה.


**תמיכה במערכת ההפעלה Chrome**
תמיכה במערכת ההפעלה Google Chrome זמינה כעת ב-Web App של Webex Meetings (תמיכה בלקוח פגישות מבוסס אינטרנט) וביישום Webex Meetings ל-Android (תמיכה בלקוח פגישות ניתן להורדה). 
יישום Webex Meetings למכשירים ניידים (גרסה 11.0 ואילך) נתמך בכל מכשירי Chrome שתומכים באופן רשמי ביישומי Android, באמצעות Google Play.

###  תוכנת שולחן עבודה וירטואלי של Meetings
Meetings מספק חוויה משופרת בסביבות תשתית שולחן העבודה הווירטואלי (VDI). כאשר אתה משתתף בפגישות בסביבת VDI, התוכנה Meetings מנתבת את כל הזרמות השמע והווידאו ישירות בין הלקוח הרזה לענן Meetings מבלי לעבור דרך שולחן העבודה המתארח. תוכנת שולחן עבודה וירטואלי של Meetings תומכת כעת בסביבת שולחן העבודה הווירטואלי של Citrix והתמיכה בסביבה המתארחת של VMware נמצאת בשלבים מוקדמים של ניסוי בשטח.
#### דרישות מערכת
**תוכנת שרת במרכז הנתונים**
  * Citrix XenDesktop גרסאות 7.15, 7.16, 7.17 ו-7.18 
XenApp אינו נתמך כעת. 
  * Windows 8 או Windows 10 בשולחן עבודה וירטואלי מתארח (HVD)
  * תוסף VDI ב-Mac OS


**תוכנת לקוח**
  * Citrix Receiver או יישום Workspace שתואם ל-Citrix XenDesktop
  * Windows 10 בלקוח רזה


**חומרה**
כל הלקוחות הרזים של החומרה שמפעילים את Windows 10 עם דרישות המינימום הבאות:
  * מעבד: AMD Embedded G-Series GX-420GI Radeon R7E 2.00GHz Cores 2 
זיכרון: 4G
  * מעבד: מעבד Intel Core i5-6500TE מדור שישי
זיכרון: 4G


**נבדק על-ידי Cisco**
  * HP t630 Thin Client
  * HP t730 Thin Client 
  * Dell Optiplex 7060 
  * Lenovo ThinkCentre M710q


#### מגבלות
  * הקלטה בענן בלבד. 
הקלטה מקומית אינה נתמכת.
  * אפשרויות שיתוף: 
    * לא ניתן לשתף קובצי מולטימדיה כגון ‎*.mp4 או ‎*.avi.
    * האפשרות 'שתף את חלונות הפגישה שלי' אינה זמינה. 
    * האפשרות 'בצע מיטוב לתנועה ולווידאו' אינה זמינה.
    * קרבה לא עובדת.

## בעיות ומגבלות ידועות חוצות פלטפורמות 
סעיף זה מכיל בעיות ומגבלות מוכרות הקשורות לדפדפנים ולמערכות ההפעלה הנתמכים על-ידי Webex Meetings. לקבלת מידע על בעיות מוכרות אחרות, עיין בהערות המהדורה הבודדות עבור כל שירות.
**שיתוף קבצים מתיקיות My Webex האישיות**
המשתמשים כבר לא יכולים לשתף קבצים מתיקיות  My Webex  האישיות שלהם, על אף שכל המשתמשים יכולים להעלות ולשתף קבצים במהלך פגישה.
**תמיכה ב-Microsoft Office 2007**
  * Microsoft Office 2007 עשוי להציג התראת אבטחה שמציינת כי החתימה הדיגיטלית של Webex Meetings אינה חוקית.
  * ייתכן שהמשתמשים לא יוכלו לשתף קובצי Microsoft PowerPoint. דרך לעקיפת הבעיה הזו היא לשתף את מסך ההתקן או לשתף את היישום PowerPoint.


**תמיכה ב-Microsoft Office 2010**
  * ערכת כלים של UCF אינה נתמכת עם Microsoft Office 2010 בגרסת 64 סיביות. 
  * תכונות חדשות, שכוללות הנפשות, מעברים וגרפיקה תלת-ממדית, שהוצגו ב-Microsoft Office 2010 אינן נתמכות. 
  * יבוא פנקס כתובות של חברה לאנשי קשר של Webex Meetings לא נתמך עם Microsoft Outlook 2010 בגרסת 64 סיביות. 


**תמיכה ב-Microsoft Office 2013**
  * אם Microsoft Office 2013 מותקן, התכונות הבאות אינן נתמכות בעת שיתוף קובצי Microsoft PowerPoint 2013: 
    * הנפשות ומעברים 
    * קובצי וידאו או שמע מוטבעים 
    * ערכת כלים של UCF 
  * ייתכן שרכיבים מותאמים אישית מסוימים אינם נתמכים בלשוניות  מידע  מותאמות אישית. מומלץ שהמשתמשים יאמתו אותם כדי לוודא שהם מוצגים כראוי במהלך פגישות.
  * במקרים מסוימים, הבעיות הבאות עלולות להתרחש:
    * צבע הטקסט וצבע המילוי עשויים להיות מעט שונים מצבעי השקופית בפועל.
    * ייתכן שרכיבים גרפיים מסוימים חסרים בשקופית.
    * גופנים עשויים להיראות מטושטשים בשקופית או להיות שונים מהמקור.
    * גודל הצורות עשוי להיות שונה מהמקור. 
  * אם אובייקט במצגת Microsoft PowerPoint לא מוצג כראוי במצב עריכה, הוא מוסר באופן אוטומטי בתצוגת 'הצגת שקופיות'; עם זאת, האובייקט עשוי להמשיך להופיע כאשר הקובץ משותף בפגישה. 
  * המשתמשים לא יכולים לשתף קובצי Microsoft PowerPoint 2013 המוגנים באמצעות סיסמה באמצעות תכונת שיתוף הקבצים. השתמש במקום זאת בתכונות 'שיתוף יישומים' או 'שיתוף שולחן עבודה'. 
  * למשתמשים אין אפשרות לשתף קובצי Microsoft Excel 2013 ב-Windows 8 וב-Windows 8.1 באמצעות תכונת שיתוף הקבצים. השתמש במקום זאת בתכונות 'שיתוף יישומים' או 'שיתוף שולחן עבודה'. 
  * המשתמשים לא יכולים לשתף מסמכי Word 2013 (64 סיביות) ב-Windows 8 וב-Windows 8.1 (64 סיביות) באמצעות תכונת שיתוף הקבצים. השתמש במקום זאת בתכונות 'שיתוף יישומים' או 'שיתוף שולחן עבודה'. 


**תמיכה ב-Microsoft Office 2016**
Microsoft Office 2016 נתמך ב-Webex Meetings עבור Windows או Mac. עם זאת, שיתוף קבצים של מצגות Microsoft PowerPoint גורם לעתים לשגיאה. כמו כן, שיתוף קבצים של מצגות Microsoft PowerPoint מרובות בו-זמנית עלול לגרום ליישום להפסיק להגיב. 
**Windows 2000**
Windows 2000 אינו נתמך עוד החל מהמהדורה הזו. ייתכן שמשתמשי Windows 2000 עדיין יוכלו להצטרף לפגישות, אך הביצועים אינם מובטחים. 
**Mac OS**
  * משתמשי Mac OS X 10.6 או גרסאות מוקדמות יותר לא יוכלו עוד להתחבר לפגישות. 
  * משתמשי Mac PowerPC אינם יכולים עוד להתחבר לפגישות.
  * נגן הקלטות הרשת של Webex Meetings אינו תומך בהמרת הקלטות לתבנית MP4 ב-Mac.
  * תמיכה בצגים מרובים אינה זמינה עדיין ב-Webex Meetings עבור Mac.


**תמיכה בלינוקס של 64 סיביות**
  * Linux של 64 סיביות נתמך באמצעות [ Cisco Webex Meetings Web App ](https://help.webex.com/he-il/article/n1pxgbz), והוא נתמך במערכות Ubutuntu 14.x ואילך, OpenSuSE 13.x ואילך, Fedora 18 ואילך, Red Hat 6 ואילך, Debian 8.x ואילך


**בעיות ומגבלות מוכרות:**
  * בגרסאות מסוימות של Linux, המשתמשים חייבים להתקין ולהפעיל באופן יזום את התוסף "OpenH264 Video Codec provided by Cisco Systems, Inc.‎" כדי שהתכונות 'וידאו', 'התקשר למחשב שלי', ו'שיתוף תוכן' יעבדו ב-Firefox.
  * שיתוף תוכן אינו פועל בגרסאות Linux שמשתמשות ב-Wayland כמערכת ניהול התצוגה שלהן (כגון Fedora 25 ואילך), עקב בעיה ב-API של שיתוף המסך של WebRTC.
  * לא ניתן לבצע שליחה וקבלה של וידאו ב-Fedora 28 עקב בעיה ב-H.264 Codec.


**Mozilla Firefox 43 ואילך**
התוסף 'כלי פרודוקטיביות' של Webex Meetings עבור Mozilla Firefox אינו נתמך כעת עבור Mozilla Firefox גרסה 43 ואילך. אנחנו ממליצים למשתמשים להשתמש ב-Internet Explorer במקום זאת.
**Citrix XenDesktop ו-XenApp**
לקבלת החוויה הטובה ביותר, Cisco ממליצה על הגרסה העדכנית ביותר של מקלט Citrix עבור Windows ועבור Mac.
  * XenApp אינו נתמך עם Webex Support.
  * עקב מגבלה ארכיטקטונית של סביבת שולחן העבודה הווירטואלי, ייתכן ששליחת וידאו ב-Webex Meetings לא תפעל בצורה חלקה. בנוסף, בעת שליחת וידאו בפגישה, קצב הפריימים עשוי להיות איטי. התוצאה היא חוויית משתמש לא אופטימלית בעת שליחת וידאו.
  * לא ניתן לשתף תבניות מסוימות של קובצי וידאו (WMV‏, AVI ו-MP4) בסביבת שולחן עבודה וירטואלי ב-Webex Meetings עקב מגבלות XenApp.
  * Remote Access ו-Access Anywhere אינם נתמכים מכיוון שסוכנים אלה מוסרים באופן אוטומטי על-ידי פלטפורמת Citrix המשמשת כבסיס לאחר הפעלה מחדש של מערכת ההפעלה.
  * מעבדות מעשיות אינן נתמכות.
  * בעת שימוש ב-[Cisco Webex Meetings Web App ](https://help.webex.com/he-il/article/n1pxgbz) ב-XenApp או ב-XenDesktop, באפשרותך לקבל וידאו, אך לא לשלוח וידאו. הסיבה לכך היא שדפדפני אינטרנט אינם יכולים לזהות התקני מצלמה וירטואלית בסביבת VDI.
  * בעת שימוש ב-[Cisco Webex Meetings Web App ](https://help.webex.com/he-il/article/n1pxgbz) ב-XenApp או ב-XenDesktop, המשתמשים עלולים להיתקל בבעיות באיכות השמע בעת שימוש באפשרות התקשר באמצעות המחשב. מומלץ להשתמש באפשרויות התקשר אליי, התקשר לשיחה  או התקשר באמצעות מערכת וידאו בעת שימוש ביישום האינטרנט בסביבת VDI.

  * VMware Horizon אינו נתמך עם Webex Support.
  * עקב מגבלה ארכיטקטונית של סביבת שולחן העבודה הווירטואלי, ייתכן ששליחת וידאו ב-Webex Meetings לא תפעל בצורה חלקה. בנוסף, בעת שליחת וידאו בפגישה, קצב הפריימים עשוי להיות איטי. התוצאה היא חוויית משתמש לא אופטימלית בעת שליחת וידאו.

  * מעבדות מעשיות אינן נתמכות.
  * בעת שימוש ב-[ Cisco Webex Meetings Web App ](https://help.webex.com/he-il/article/n1pxgbz) ב-VMware Horizon 7, באפשרותך לקבל וידאו, אך לא לשלוח וידאו. הסיבה לכך היא שדפדפני אינטרנט אינם יכולים לזהות התקני מצלמה וירטואלית בסביבת Horizon.
  * בעת שימוש ב-[Cisco Webex Meetings Web App](https://help.webex.com/he-il/article/n1pxgbz) ב- VMware Horizon 7, ייתכן שתתקל בבעיות באיכות השמע בעת שימוש באפשרות התקשר באמצעות המחשב. מומלץ להשתמש באפשרויות התקשר אליי, התקשר לשיחה  או התקשר באמצעות מערכת וידאו בעת שימוש ביישום האינטרנט בסביבת Horizon .


**Mac OS X 10.8 Mountain Lion**
בעת התחלת פגישה או הצטרפות לפגישה באמצעות PAC proxy ב-Mac OS X 10.8 Mountain Lion, יישום הפגישה קורס. זהו באג במערכת ההפעלה שדווח ל-Apple (דיווח באג של Apple מס' 11844696). הבעיה נפתרה בגרסת Build ‏מס' Mac OS X 10.8.2. 
**Internet Explorer 10 ו-Internet Explorer 11**
"מצב מוגן משופר" ב-Internet Explorer 10 ו-Internet Explorer 11 בשולחן העבודה אינו נתמך. מאחר שמצב זה מציע חוויית גלישה ללא תוספים, ההרחבות של Webex Meetings מושבתות וניתן להשתמש בשיטות ההורדה של ActiveX או של Java. המשתמשים עדיין יכולים להשתמש בפתרון התיקייה הזמנית כדי להצטרף לפגישה. לחלופין, המשתמשים יכולים לבחור לבטל את 'מצב מוגן משופר' כדי להצטרף לפגישה כרגיל. 
הפעלת תצוגת תאימות ב-Internet Explorer בשולחן העבודה עלולה לגרום לעיבוד שגוי של דפי Webex Meetings מסוימים. מומלץ שמנהלי מערכת יבטלו את תצוגת התאימות עבור האתר שלהם. 
**Google Chrome**
  * חלק מהמשתמשים של Google Chrome אינם יכולים לגשת ל-Chrome Web Store. במקרה זה, קובץ ההרחבה של Webex Meetings אינו מותקן באופן אוטומטי כאשר המשתמשים מצטרפים לפגישה. המשתמשים האלה מופנים לדף עזרה עם הוראות להורדה והתקנה ידנית של קובץ ההרחבה.
  * ייתכן שההרחבה של Webex Meetings לא תותקן, ובמקום זאת תוצג הודעת שגיאה. ייתכן שהסיבה לכך היא שלא ניתן לאתחל התקנה רגילה מחלון מוקפץ ב-Google Chrome. ייתכן שיהיה צורך לשנות את השילוב כדי להשתמש בחלון ברמה העליונה במקום בחלון מוקפץ.
