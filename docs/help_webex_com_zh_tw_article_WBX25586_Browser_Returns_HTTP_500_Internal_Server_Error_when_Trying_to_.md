![list-menu](https://help.webex.com/images/feedback.svg)意見回饋？
## 瀏覽器在嘗試加入會議時返回 HTTP 500 內部伺服器錯誤。
## 伺服器遇到未預期的狀況，無法履行請求。
## 輸入會議密碼或密碼後，內部伺服器錯誤 500會議號。
## 當進入 Webex 網站時，我在網頁上收到錯誤 500。
  
**原因：**  
  
HTTP 500 內部伺服器 錯誤是 Web 瀏覽器在無法與網站正常通訊時傳遞的一般錯誤訊息。  
  
**解決方案：**
**請參閱下列建議以解決問題：**
  * 如果會議密碼已粘貼到密碼欄位中，請手動鍵入會議密碼，然後再次嘗試加入。
  * 若要清除 Web 瀏覽器中的快取和 Cookie，請參閱： 
    * [WBX38898 - 如何在 Mozilla Firefox 中清除我的快取和 Cookie？](https://help.webex.com/article/WBX38898)
    * [WBX38899 - 如何在 Google Chrome 中清除我的快取和 Cookie？](https://help.webex.com/article/WBX38899)


如果執行此文章中的步驟之後問題仍然存在，請聯絡技術支援。 有關說明，請參閱：[WBX162 - 如何联系Webex客戶服務或技術支持？](https://help.webex.com/article/WBX162)
