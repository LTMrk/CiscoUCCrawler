Overview
PB743488
Cisco announces the end-of-life dates for the Cisco Unity Connection Software Version 12.0 software.
**Software maintenance** support for Unity Connection 12.0 software release ends on August 17, 2021. No patches or maintenance releases will be provided for Cisco Unity Connection 12.0 release after that date. Customer must upgrade from 12.0 in order to continue receiving Bug fixes.
The last date to receive support for Unity Connection 12.0 as entitled by active service contracts or by warranty terms and conditions is August 31, 2023. After this date, all support services for the product are unavailable, and the product becomes obsolete.
Product migration options
Install and upgrade guides can be found here: <https://www.cisco.com/c/en/us/support/unified-communications/unity-connection/products-installation-guides-list.html>
