## مكونات Cisco المُهيأة
تقوم شركة Cisco بتكوين مكونات متعددة في تطبيقات UC المخصصة للعميل. لتسهيل التعرف على هذه المكونات، تقوم شركة Cisco بإدراج **x** في بداية اسم المكون. تنبه هذه البادئة **x** الشركاء إلى اسم تم تكوينه بواسطة Cisco والذي لا ينبغي لمسؤولي الشريك أو العميل **تعديله أو حذفه**. يتم استخدام هذا التنسيق أيضًا لعمليات شركة Cisco monitoring/readiness من تطبيقات UC المخصصة. 
لا يجوز للشريك أو العميل تعديل أو حذف أي مما يلي: 
  * إدخالات المنطقة المرتبطة بالموارد الموجودة في مركز البيانات (DC)، مثل جسور المؤتمرات، وجذوع SIP، وما إلى ذلك. 
  * إدخالات مجموعة الأجهزة المرتبطة بالأجهزة الموجودة في مركز بيانات Cisco. 
  * تكوينات الأمان حسب الحاجة: 
    * تكوين سياسة الاعتماد 
    * تكوين ملف تعريف أمان SIP 
  * جذوع SIP مهيأة من Cisco لتكامل الخدمات المختلفة، مثل RedSky، وجذوع Inter-op إلى Webex Calling Multi-tenant، وما إلى ذلك. 


تقوم شركة Cisco بتكوين وجهتين لـ CDR في Unified CM لمراقبة التطبيق وتوفير التحليلات في Control Hub للمسؤولين. 
هناك استثناءات عندما يذكر مستند مثيل مخصص صراحةً تغيير تكوين محدد للعميل في جذوع SIP.

**قاعدة سياسة الاتصال**
لتعزيز أمان منصة Dedicated Instance الأساسية، ولتعزيز ممارسات الأمان الجيدة، تم تكوين Dedicated Instance Expressway E مسبقًا باستخدام سياسة الاتصال لحظر جميع المكالمات الواردة B2B. 
![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/470001-480000/474001-475000/474733.jpg)
