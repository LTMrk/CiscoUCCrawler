1. Make a request for links to a video visit when an appointment is scheduled.
2. Distribute the links to the appropriate participants.
# Highlights
Instant Connect is a WebRTC based Webex product that provides a secure, user-friendly platform for guests to join meetings without needing an email account or the Webex Meetings app.
![](https://instant.webex.com/aa559acd6afc4f9306c2606b363b5571.png)
Invite
Configuration is simple! Make a request for meeting links and distribute them within any healthcare platform, via e-mail, or via SMS.
![](https://instant.webex.com/a30a37a8bc49b8a61640886832f7b8c8.png)
Join
Participants and Host can access their virtual visit on desktop or mobile devices directly through a browser.
![](https://instant.webex.com/7087fc40b9e695516f289fa2f237e01c.png)
Visit
One-to-one or multiparty visit are possible. We support Screen Share, Chat, Guest Invites and many more
