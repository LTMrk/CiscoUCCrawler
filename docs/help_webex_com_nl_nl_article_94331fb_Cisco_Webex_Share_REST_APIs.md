# Webex Share REST API's
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
De REST API's (Representational State Transfer Application Programming Interfaces) worden gebruikt om te bepalen hoe uw Webex Share met Control Hub communiceert via de cloud of het internet. U gebruikt deze API's en opent ze vanaf een webserver. Dit is de aanbevolen manier om deze te gebruiken. Omdat u ze rechtstreeks vanuit een webbrowser kunt invoeren, worden ze hier ook vermeld. Als u toegang wilt krijgen tot de API's vanuit uw webbrowser, schakelt u de schakelaar Instellingsvergrendeling in op de Control Hub-pagina van het apparaat.  
Tabel 1. REST API's  
|  API  |  Methode  |  Verzoek en repsons  |  Beschrijving  |  
| --- | --- | --- | --- |  
|  activatie  |  GET  |  Respons {"isActivated": "True_or_False"}   |  Retourneert of het apparaat is geactiveerd of niet.   |  
|  activatie  |  BERICHT  |  Verzoek {"activationCode": "activation_code_string" }   |  Verzendt een activeringscode naar het apparaat.   |  
|  static_ip  |  PUT  |  Verzoek { "static_ip": "static_ip_string", "gateway": "gateway_string", "subnet_mask": "subnet_mask_string", "dns_domain_name": "dns_domain_name_string", "dns_server_1": "dns_server_1_string", "dns_server_2": "dns_server_2_string", "dns_server_3": "dns_server_3_string"  Respons { "new_ip": "new_ip_string" }   |  Wijzigt het statische IP-adres.  |  
|  taal  |  GET  |  Respons { "language": "language_string" }   |  Retourneert de geconfigureerde taal.  |  
|  taal  |  PUT  |  Verzoek language_string{ "language": "" }  |  Wijzigt de geconfigureerde taal.  |  
|  upload  |  BERICHT  |  Verzoek { "file": "file_path_string" }   |  Uploadt een bestand.  |  
|  feature_toggle  |  PUT  |  Verzoek { "feature": "feature_name_string", "inschakelen": "true_or_false_string" }   |  Schakelt een functieschakelaar in.  |  
|  cloud_connectivity  |  GET  |  Respons { "connectiviteit": "connectivity_string" }   |  Retourneert de verbindingsreeks.  |
