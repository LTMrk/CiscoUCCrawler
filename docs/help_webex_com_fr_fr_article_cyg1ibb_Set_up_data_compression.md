## Activer la compression des données
Configurez la compression des données pour bénéficier de la meilleure qualité d’appel avec un appel Webex.  
| 1  |  À partir de [https://admin.webex.com](https://admin.webex.com/), allez dans Utilisateurs, puis sélectionnez l’utilisateur que vous souhaitez activer ou pour modifier le paramètre de compression des données.   |  
| --- | --- |  
| 2  |  Activez l'option de compression à partir de l'expérience d'appel de l'utilisateur.
  * Compression normale—lorsque les périphériques et les applications sélectionnés utilisent le meilleur codec négocié (le plus élevé) pour les appels entrants et sortants. Cette option s’applique aux appels vidéo et audio. Cette option est Sélectionnée par défaut. 
  * Non compressé—lorsque les périphériques et les applications sélectionnés utilisent le codec G.711 et que cette option ne prend en charge que les appels audio. Cette option est Désélectionnée par défaut.

 |  
## Activer la compression des données pour les espaces de travail
Configurez la compression des données pour optimiser la qualité des appels pour tous vos clients et périphériques.  
| 1  |  Dans [https://admin.webex.com](https://admin.webex.com/) , allez dans Espaces de travail et sélectionnez l’espace de travail que vous souhaitez activer ou modifier le paramètre de compression des données.   |  
| --- | --- |  
| 2  |  Allez dans Callin g et faites défiler jusqu'à l'option Compression de Call Experience.
  * Compression normale—lorsque les périphériques et les applications sélectionnés utilisent le meilleur codec négocié (le plus élevé) pour les appels entrants et sortants. Cette option s’applique aux appels vidéo et audio. Cette option est Sélectionnée par défaut. 
  * Non compressé—lorsque les périphériques et les applications sélectionnés utilisent le codec G.711 et que cette option ne prend en charge que les appels audio. Cette option est Désélectionnée par défaut.
