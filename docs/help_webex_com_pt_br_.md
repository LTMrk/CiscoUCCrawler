Notificações do AI Assistant sobre pausas para o bem-estar
![Ícone de produto](https://help.webex.com/images/helpdesk.svg)
Experiência do cliente
Quando o AI Assistant recomendar uma pausa para o bem-estar, aparecerá uma notificação na tela: Aceitar uma pausa: Clique em Fazer uma pausa para confirmar a pausa. O widget do Cisco AI Assistant abre automaticamente para confirmar sua escolha. Depois de encerrar a interação atual, sua pausa de bem-estar de 1 minuto começa automaticamente. Seu status muda para Pausa para o bem-estar para evitar que a próxima interação seja colocada na fila para você. Uma contagem regressiva de 5 segundos aparece na tela quando o intervalo de 1 minuto chega ao fim. Ao terminar, a janela de intervalo se fecha automaticamente e seu status muda para Disponível, preparando você para a próxima interação.
