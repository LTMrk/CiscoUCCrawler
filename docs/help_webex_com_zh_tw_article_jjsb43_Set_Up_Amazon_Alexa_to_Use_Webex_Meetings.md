# 設定 Amazon Alexa 以使用 Webex Meetings
![list-menu](https://help.webex.com/images/feedback.svg)意見回饋？
您可以透過啟用行動裝置的亞馬遜 Alexa 應用程式與 Webex Meetings 應用程式配合使用，來控制適用於 Android 和 iOS 的 Webex Meetings 應用程式。 
準備工作
若要將 Amazon Alexa 與 Webex Meetings 一起使用，請下載 Amazon Alexa 應用程式至您的行動裝置，並登入您的 Amazon 帳戶。  
| 1  |  開啟 Amazon Alexa 應用程式並點選更多。  |  
| --- | --- |  
| 2  |  點選技能與遊戲。  |  
| 3  |  點擊螢幕頂部的 搜尋 圖標，輸入 `Webex Meetings`，然後在搜尋結果中點擊 webex 會議 。  |  
| 4  |  點選 Webex Meetings，然後點選啟用以使用。  |  
| 5  |  設定權限設定，然後點選儲存權限。  |  
| 6  |  請登入您的 Webex 帳戶並點選接受以允許 Amazon Alexa 存取您的 Webex 會議資料。 當 Webex Meetings 帳戶同步處理成功時，會出現通知頁面。  |  
| 7  |  點選關閉。  |
