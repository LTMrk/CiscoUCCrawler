From what I can see, the required settings appear to be available under the Collaboration section. If your goal is to verify Teams or Webex integration, those options seem to cover the necessary functionality.
For Microsoft Teams, enabling **Display user details** allows agents to view presence information and search for users by name, department, or role when performing consults or transfers.
For Webex App, enabling **Display user details** provides similar functionality, allowing agents to locate users and view their availability during call handling.
The **State Synchronization** option is also important, as it keeps user status aligned between the Desktop application and Microsoft Teams or Webex App.
One thing to double-check is that the Microsoft Teams/Webex App integration is enabled at the tenant level[.](https://molybdenumproducts.com) Even if the desktop profile settings are configured correctly, user presence visibility and state synchronization may not function as expected unless the tenant-level setting is also turned on.
