Report Phone Issues on the Cisco IP Phone 8800 Series Multiplatform Phone
## Objective
The Problem Reporting Tool (PRT) on the Cisco 8800 Series IP Phone allows you to collect and send phone logs to your administrator. These logs are necessary for troubleshooting in case you run into phone issues.
This article aims to show you how to report phone issues by generating PRT file on the Cisco IP Phone 8800 Series Multiplatform through its web-based utility and phone GUI.
## Applicable Devices
  * 8800 Series


## Software Version
  * 11.0.1


## Report Phone Issues
### Through the Web-based Utility
Step 1. Log in to the web-based utility of the IP phone and click **Admin Login > a****dvanced**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step1.png "Related image, diagram or screenshot.")
Step 2. Click **Info > Debug Info**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step2.png "Related image, diagram or screenshot.")
Step 3. Under Problem Reports, click the **Generate PRT** button to report a problem.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step3.png "Related image, diagram or screenshot.")
Step 4. In the Report Problem pop-up window, enter the date and time when the problem occurred in their respective fields.
**Note:** In this example, the date used is August 2, 2017 and the time is 10:55:26 AM.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step4.png "Related image, diagram or screenshot.")
Step 5. Click the drop-down arrow in the Problem description area to choose the exact issue you are having with the IP Phone. The options are:
  * Phone disconnect or reboot
  * Network connection failure
  * Phone registration failure
  * Failed to place a call
  * Cannot answer a call
  * Call features do not work
  * Poor audio/video quality
  * One way audio/video
  * No audio/video
  * Slow UI response
  * UI display error
  * Other


[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step5.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step5.png "Related image, diagram or screenshot.")
**Note:** In this example, Network connection failure is chosen.
Step 6. Click **Submit**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step6.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step6.png "Related image, diagram or screenshot.")
Step 7. The Problem Report Status pop-up window appears to inform you that the PRT file is now generated. Click **OK**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step7.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step7.png "Related image, diagram or screenshot.")
Step 8. (Optional) Click on the file link in the Prt File area to view the problem report. The file will be automatically downloaded when you click the link.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step8.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step8.png "Related image, diagram or screenshot.")
**Note:** In this example, the PRT File generated is named as prt-20170801-233728-5006AB7086D6.tar.gz.
Step 9. Click on the drop-down arrow beside the filename and click **Open**. It will take you to the location where the file is downloaded.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step9.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step9.png "Related image, diagram or screenshot.")
Step 10. Click on the description to view the report.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step10.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step10.png "Related image, diagram or screenshot.")
**Note:** A .log file will open. In this example, description-20170801-233728.log is used.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step10b.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissueweb-step10b.png "Related image, diagram or screenshot.")
You now have successfully generated a problem report on your phone through its web-based utility.

Using the Navigation cluster [![](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissuewgui-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/collaboration-endpoints/cisco-ip-phone-8800-series/images/rjs-08142017-reportissuewgui-step2.png "Related image, diagram or screenshot.") button, navigate to**Status** then press the **Select** softkey.

  * One way audio/video
  * No audio/video
  * Slow UI response
  * UI display error
