### Problem Description
The Cisco Unified IP Conference Phone CP-8831 might experience one-way audio if the phone runs Firmware Release 10.3(1)SR4.
### Background
After Firmware Release 10.3(1)SR4 is downloaded and used on the CP-8831 conference phone, some customers have experienced one-way audio when both parties speak simultaneously.
### Problem Symptom
After the CP-8831 conference phone has been upgraded to Firmware Release 10.3(1)SR4, some customers have experienced one-way audio when both parties speak simultaneously.
### Workaround/Solution
As a workaround, Cisco recommends that existing customers who have experienced the one-way audio issue downgrade to Firmware Release 10.3(1)SR3 or 10.3(1)ES8 temporarily for improved acoustic performance.
