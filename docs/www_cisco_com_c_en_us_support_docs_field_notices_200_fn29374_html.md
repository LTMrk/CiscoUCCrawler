### Products Affected
  * VG248 Version 1.2(1)


### Problem Description
With VG248 version 1.2(1), conferencing and supervised transfers fail when the gateway is registered to Cisco CallManager release 4.0(1)
### Background
Changes in CallManager 4.0(1) required changes to the VG248 code.
### Problem Symptoms
VG248 will not be able to initiate an Ad-Hoc conference nor complete a supervised transfer.
### Workaround/Solution
An upgrade to engineering special build 1.2(1)ES10.2 is required. This version can be found on the [Cisco VG248 Analog Telephone Gateway](http://www.cisco.com/cgi-bin/tablebuild.pl/vg248) software page on [Cisco.com](http://www.cisco.com/).
Remember that you must first log in with your CCO Username and Password. If you do not have a CCO account go to the [Cisco.com Registration page](http://tools.cisco.com/RPF/register/register.do) and register.
