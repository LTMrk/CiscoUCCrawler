Telefonkommandon på min telefon fungerar inte
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
## Min telefons telefonkommandon fungerar inte.
## DTMF-toner känns inte längre igen.
## Webex känner inte igen mina DTMF-kommandon.
**Ändring:**  
  
Denna ändring gjordes för att ge värden den ultimata kontrollen över att stänga av och slå på ljudet för deltagare. Andra back-end förbättringar har gjorts för att binda samman denna ändring och tillhandahålla ytterligare mötesstabilitet.  
  
**Lösning:**  
  
DTMF-kommandon (Dual-Tone Multi-Frequency) stöds inte längre med möten som schemalagts för Cisco Webex Training. Detta betyder att *6 för att slå av/på ljud, ** för att spela DTMF-menyn, o.s.v. inte kommer att fungera om konferensen är associerade med en webbsession. Avsikten är att göra gränssnittet till det primära kontrollgränssnittet för alla integrerade telekonferenser. Vi känner igen detta kan orsaka problem med vissa kunder som använde DTMF-kommandon som primär kontrollmetod.  
  
Observera att funktionerna för konferenser med endast ljud inte har ändrats. Fristående konferenser som inte är kopplade till ett Webex-möte (som de flesta PCN-konton) fortsätter att använda de vanliga DTMF-kommandona.  
  
**Obs!** Webex-ljudanvändare i Webex Meetings och Events har stöd för att trycka *6  på telefonen. Om DTMF-kommandot inte fungerar måste en webbplatsadministratör aktivera det här alternativet:  

  * [Webbplatsadministration](https://help.webex.com/sv-se/article/WBX42978/Telefonkommandon-p%C3%A5-min-telefon-fungerar-inte#id_90869)
  * [Control Hub](https://help.webex.com/sv-se/article/WBX42978/Telefonkommandon-p%C3%A5-min-telefon-fungerar-inte#id_90867)


**Endast webbplatsadministratörer**
  1. Logga in på Cisco Webex Meetings webbplatsadministration. (Exempel: SITENAME.webex.com/admin.php)
  2. Klicka på Konfiguration>Allmänna webbplatsinställningar > Alternativ.
  3. I avsnittet _Webbplatsalternativ_ markerar du rutan Gör det möjligt för användare **att stänga av eller slå på ljudet i telefonen genom att trycka *6**.
  4. Bläddra ner till slutet av sidan och klicka sedan på **Uppdatera**.


**Endast control hub-administratörer**
  1. Logga in på administrationssidan för Control Hub. (https://admin.webex.com)
  2. Välj **Möte** under _Tjänster_ från navigeringsrad till vänster.
  3. Välj den webbplats som du vill ändra och välj sedan **knappen Konfigurera** webbplats i popup-menyn till höger.
  4. Under Common-inställningar väljer du **Webbplatsalternativ**.
  5. Markera rutan **Gör det möjligt för användare att slå av/på telefonljud genom att trycka *6**.
  6. Bläddra ner till slutet av sidan och klicka sedan på **Uppdatera**.
