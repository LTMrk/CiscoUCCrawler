## Introduction
This document provides an example of how to configure the Meet Me feature with User Authentication. The Meet Me feature is available in Cisco Unified Communications Manager (CUCM), and the Authentication is achieved with the help of Cisco Unity Connection (CUC).
## Prerequisites
### Requirements
Cisco recommends that you have knowledge of CUCM and CUC.
### Components Used
The information in this document is based on CUCM / CUC Release 8.x and later, but might also apply to earlier releases of CUCM / CUC.
The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, make sure that you understand the potential impact of any command.
## Design
Meet Me conferences allow users to dial-in to a conference. This requires that a directory number be allocated for exclusive use of the conference. The users call the directory number in order to join the conference. Here Authentication is not required and the users are connected to the conference call. More information can be found in the [System Guide](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/cucm/admin/8_6_1/ccmsys/accm-861-cm/a05confb.html#pgfId-1022106). 
In order to enable User Authentication, the call is transferred via CUC. The [User System Transfer](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/connection/8x/administration/guide/8xcucsagx/8xcucsag115.html) Conversation is used in order to authenticate the caller. For this purpose, a user is created on CUC. This conversation prompts callers to sign in to CUC. After callers enter the CUC ID and PIN, CUC prompts them to enter the number to which they want to be transferred.
### Call Flow
Caller dials 5000 > Computer Telephony Integration (CTI) Route Point with Extension 5000 set to **Call Forward All** to Voice Mail > Call Handler with extension 5000 > Caller provides ID and PIN > Caller dials the Meet Me Number (5002) > Call transferred to Meet Me Number on CUCM. 
## Configure
For details on Voice Mail Profile Configuration and appropriate selection of Calling Search Space (CSS), refer to the [SCCP Integration Guide](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/connection/8x/integration/guide/cucm_sccp/cucintcucmskinny/cucintcucmskinny070.html) or [SIP Integration Guide](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/connection/8x/integration/guide/cucm_sip/cucintcucmsip/cucintcucmsip060.html).
For external callers, a translation pattern is required in order to translate the called number. This document does not provide information about number translations. In order to configure translations on CUCM, refer to the [Translation Pattern Configuration](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/cucm/admin/8_5_1/ccmcfg/bccm-851-cm/b03txpat.html) document. In order to configure translations on Gateway, refer to the [Number Translation using Voice Translation Profiles](https://www.cisco.com/c/en/us/support/docs/voice/call-routing-dial-plans/64020-number-voice-translation-profiles.html) document.
Here are the steps to configure the Meet Me feature with User Authentication:
  1. Create a CTI Route Point with Extension as 5000.   
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-01.png "Related image, diagram or screenshot.")
  
  

  2. Assign appropriate CSS and Voicemail Profile to the Extension 5000 and set Forward All to VM.  
  

  3. [Optional] In order to call from an external number, configure the appropriate translation patterns on the Gateway or CUCM to convert the called number to 5000.  
  

  4. Create a user on CUC and use any extension. The caller will have to enter this extension and this extensions's PIN in order to authenticate.  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-02.png "Related image, diagram or screenshot.")
  
  

  5. Go to **Edit > Change Password** in order to change the PIN.   
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-03.png "Related image, diagram or screenshot.")
  
  

  6. Select **Voice Mail** under Choose Pin and enter the PIN.  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-04.png "Related image, diagram or screenshot.")
  
  

  7. Create a Call Handler with Extension 5000.  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-05.png "Related image, diagram or screenshot.")
  
  

  8. Go to **Edit > Greetings** and select **Standard**. Ensure that Closed Greetings is not enabled so that the call is sent to the Standard Greetings at any time of the day.  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-06.png "Related image, diagram or screenshot.")
  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-07.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-07.png "Related image, diagram or screenshot.")
  
  

  9. Configure the call Handler:  
  

     * Select **My Personal Recording** under Callers Hear Section.
     * Select the **User System Transfer** Conversation under the After Greeting section.
     * Click **Play/Record** in order to record a Greeting. The Greeting could be "Welcome to Cisco...". If you do not need a Greeting, select Nothing under the Callers Hear section.
[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-08.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-08.png "Related image, diagram or screenshot.")   
  

  10. Edit the Restriction table in order to allow the transfer to the Meet Me Number. The Default Transfer is the default restriction table in the default Class of Service (CoS) associated with the default User Template. If there is a change in the CoS associated with the User Template or User, or if there is a change in the restriction table associated with the CoS, modify the appropriate restriction table.  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-09.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-09.png "Related image, diagram or screenshot.")
  
  
In this example, 5002 is the MeetMe number.  
  

[![](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-10.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unified-communications-manager-callmanager/118722-configure-cucm-10.png "Related image, diagram or screenshot.")
  
  

  11. Modiy the CSS of the Voicemail Ports or the Rerouting CSS of the Session Initiation Protocol (SIP) trunk. This CSS should have the partition of the Meet Me Number.  
  

  12. Configure the Meet Me Number. Refer to [Meet-Me Number/Pattern Configuration](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/cucm/admin/8_6_1/ccmcfg/bccm-861-cm/b03meet.html) for more information.  
  

  13. Create a SoftKey Template to include the Meet-Me Softkey. Associate this template to the phones that will initiate the conference.
