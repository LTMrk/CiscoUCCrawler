## Предварительные условия и ограничения
### Предварительные условия
  * Версия программного обеспечения CE9.15.3 или более поздняя
  * Требуется программное обеспечение CE, поддерживающее надежное шифрование.
    * Board, стол, и серия комнаты: ключ шифрования установлен перед отправкой и не может быть добавлен после.
    * DX80: по умолчанию доступен ключ шифрования.
  * Регистрация Unified CM или Expressway
  * Unified CM версия 11.5 (1) SU3 или 12.5 (1) и более поздние версии. При наличии версии 12.0 (1) необходимо использовать метод, описанный для зарегистрированных устройств Expressway.
  * Для Expressway для инструмента Device Connector вам потребуется подключение по HTTPS на ваших устройствах.
  * [Доступ администратора узлом управления](https://help.webex.com/ru-ru/nkhozs6/)
  * [План Flex для совместной работы Cisco](https://www.cisco.com/c/en/us/products/unified-communications/collaboration-flex-plan/index.html)
  * Для встроенных устройств пакетным: [Cisco Webex Device Connector](https://help.webex.com/ru-ru/383gbd/)
  * _*.identrust.com_ необходимо разрешить для проверки сертификата.


Даже если мультимедиа не проходят через облако Webex (если не включена функция Webex), вам необходимо включить те же конфигурации брандмауэра, что и для полностью облачных зарегистрированных устройств. Дополнительные сведения о требованиях к мультимедиа и сети читайте в [статье «Сетевые требования для сервисов](https://help.webex.com/ru-ru/WBX000028782/) Webex»
### Ограничения
  * Включение гибридного календаря на устройстве, связанном с помощью Webex Edge for Devices, отключает календарь TMS на этом устройстве, так как одновременно поддерживается только один источник календаря.
  * При первом связывании устройств с Webex Edge for Devices они регистрируются как устройства общего режима. Связав устройства, можно связать устройство с пользователем. 
  * Вызов на Webex Edge for Devices связанные устройства из приложения Webex с «Вызов на Webex» не поддерживается.
  * Webex Edge for Devices связанные устройства с Microsoft Teams Rooms не поддерживаются.


## Требования к обновлению программного обеспечения
Для обеспечения связи Webex Edge for Devices Webex требуется актуальное программное обеспечение.
Начиная с марта 2021 года, Cisco Webex переходит на новый Certificate Authority, IdenTrust Коммерческий корневой CA 1. В связи с этим изменением пользователи, осуществляющие управление обновлениями программного обеспечения для устройств вручную, должны обновить свои устройства до CE 9.15.3 или более поздней, чтобы поддерживаться Webex Edge for Devices.
Неудача в обновлении приводит к потере устройств облачной связи и потере всех связанных с ними функций. Сюда входят управление узлом управления, аналитика, гибридный календарь среди прочего. На возможность подключаться и использовать инфраструктуру SIP на территории не повлияет. Кроме того, устройства в неподдерживаемых версиях теряют возможность быть связаны с облаком Webex с помощью разъема устройства Webex device Connector. 
Обычно для облачного программного обеспечения, подключенного к облачным технологиям, мы поддерживаем программное обеспечение для конкретного устройства до 6 месяцев со дня его выпуска. После обновления мы рекомендуем клиентам рассмотреть возможность настройки своих устройств для автоматического обновления облаков через Webex Control Hub. 
## Ссылка Unified CM зарегистрированных устройств
Если вы хотите добавить отдельное рабочее пространство с помощью зарегистрированного устройства Unified CM, см. раздел ["Создание рабочего пространства и добавление сервисов для устройств Board, настольных и комнатных серий"](https://help.webex.com/ru-ru/1mqb9cb/#id_137803).  
| 1  |  В окне «Пользователь» в [ https://admin.webex.com перейдите](https://admin.webex.com/) к « Устройства » и выберите « Ресурсы », чтобы найти ссылку на инструмент «Соединитель устройств». Дополнительные сведения об инструменте см. в [ статье Cisco Webex Device Connector](https://help.webex.com/ru-ru/383gbd/) .  |  
| --- | --- |  
| 2  |  После установки инструмента Device Connector выберите облачные функции для моих локальных зарегистрированных устройств и щелкните «Связать устройства, зарегистрированные с помощью Cisco Unified Communications Manager.  |  
| 3  |  Введите хост,  имя пользователя (стандартный AXL API имя пользователя) и пароль для Unified CM и нажмите Подключить . При наличии Unified CM с общедоступными подписанными сертификатами убедитесь, что они допустимы или щелкните "Продолжить без проверки сертификатов". Разъем устройства извлекает имя и описание устройств, настроенных Unified CM. Имя информации о контакте становится именем рабочей области, к которому подключено устройство. Если имя информации о контакте не задано, используется имя системного модуля или адрес MAC. Если вы хотите изменить имя устройства, это можно сделать с помощью Unified CM.  |  
| 4  |  Щелкните « Связать все », чтобы связать все устройства из списка. Чтобы связать отдельное устройство, нажмите кнопку « Ссылка » рядом с ним. Разъем устройства передает информацию об устройстве в вашу организацию Webex, а служба идентификации Webex создает коды активации для всех устройств. Unified CM применяет код активации к устройствам, а ссылку на устройства — в вашу Webex организацию. Если устройство связано с облачными сервисами Cisco Webex, можно щелкнуть имя устройства, чтобы открыть страницу устройства непосредственно в окне Control Hub. Если на устройстве отображается _ожидание_ связи, оно еще не связано. Код активации выдается из номера Unified CM. Система пытается подключиться к устройству в течение 7 дней до истечения кода активации. Если устройство доступно в это время, оно связывается.  |

## Обновление программного обеспечения с облачным управлением
При обновлении программного обеспечения с облачным управлением ваши связанные устройства с Webex Edge for Devices автоматически обновляются при появлении новой версии программного обеспечения RoomOS.
Устройства с обновлениями облачного программного обеспечения позволили получать новые стабильные сборки примерно один раз в месяц, а новые бета-версии — примерно каждые две недели. Доступные каналы совпадают с каналами для облачных зарегистрированных устройств, и релизы одновременно обновляются.
При обновлении облачного программного обеспечения вы получаете последние обновления и исправления ошибок быстрее без необходимости обновления устройства вручную. Требуется обновление облачного программного обеспечения, чтобы обеспечить возможности оптимизации Webex.
Эта функция по умолчанию отключена. После включения обновления программного обеспечения с облачным управлением можно выбрать канал программного обеспечения в меню выбора каналов рабочей области. По умолчанию для устройств используется канал Stable.
TAC поддерживает только последнюю устойчивую версию программного обеспечения RoomOS.

| --- | --- |  
| 2  |  Задайте для конфигурации ` Webex режим CloudUpgrades значение ` ` «Вкл `.».  Для настройки канала программного обеспечения перейдите в раздел  "Рабочие области ", выберите рабочее пространство и щелкните колесико в разделе "  Устройства  ". Выберите канал программного обеспечения в раскрывающемся меню. Если канал не выбран, по умолчанию имеет значение «Стабильный». Для применения изменений необходимо перезагрузить устройства под управлением CE9.14 после включения обновления программного обеспечения, управляемого облаком. Для устройств под управлением CE9.15 и более поздних эти изменения применяются при переходе устройства в режим ожидания или перезагрузки.  |

**маршрутизация вызовов**
Webex оптимизированная маршрутизация вызовов на совещаниях используется в следующих случаях. Во всех остальных случаях устройство использует SIP маршрутизации вызовов.
  * При присоединении к совещанию с помощью кнопки **«Присоединиться Webex** ». При этом всегда используется Webex, если параметр конфигурации _Webex Meetings JoinProtocol_ имеет _значение Webex_.
  * Если к совещанию в личном кабинете можно подключить с помощью Webex Assistant. При этом всегда используется Webex, аналогично кнопке **присоединения Webex** .
  * Если к совещанию присоединяется из **меню «Вызов»** с помощью Webex SIP URI. Устройство автоматически определяет Webex Meetings из SIP URI и подключается к ним автоматически.
  * Если вызов запущен с помощью xCommand _Dial_ , и параметр «Номер» соответствует сайту Webex. Если для параметра конфигурации _Webex Meetings JoinProtocol_ задано _значение_ Webex, устройство автоматически обнаруживает Webex Meetings путем изучения номеров и подключается к ним изначально. (Если _Указывается поле протокола_ , которое используется независимо от формата номера.)
  * Вызовы от подключенных приложений no Cisco Бесконтактного соединения и Webex перенаправляются в соответствии с типом начатого совещания или его присоединения. (Необходимо включить подключение на территории.)

## Переключить связанные устройства на персональный режим
Персональный режим Webex Edge for Devices позволяет назначать устройствам Webex, зарегистрированным в Unified CM (устройствам Board, настольных и комнатных серий), пользователю в управляющего концентраторе. 
Это дает пользователю множество преимуществ, таких как:
  * Личные встречи пользователя отображаются за 5 минут до начала, что позволяет пользователю нажать кнопку начала или присоединиться или запросить Webex Assistant устройства, чтобы начать совещание. 
  * Совещание Webex персональной комнате можно начать непосредственно с устройства.
  * доска и совместное с Webex пространством (только Cisco desk, Desk Pro, Desk Mini и Board серий)


Устройства, зарегистрированные в персональном режиме для Webex Edge for Devices используют линию, назначенную учетной записи конечного пользователя в Unified CM.
Развертывание персонального режима для Webex Edge for Devices по сути персонализирует устройство и назначает его конечному пользователю, уже настроенному в control Hub
Процесс или персонализация:
  * Необходимо использовать Webex API
  * Назначьте устройство конечному пользователю
  * переключение устройства из рабочего пространства в персональный режим Рабочая область, которая была предварительно настроена для привязки, автоматически скрывается и более не становится доступной.


Ограничения:
  * Открытие пробелов Webex не поддерживается на устройствах настольных серий в персональном режиме, если они связаны с Webex Edge for Devices.


Если устройство находится в персональном режиме, на нем больше не отображается рабочее пространство в окне "Control Hub". Управление программным каналом устройства осуществляется со страницы "Устройство" в Control Hub.
Перед началом настройки
  * Концентратор управления должен быть настроен, чтобы иметь возможность управлять конфигурацией зарегистрированных устройств. По умолчанию это значение — **«Выкл**. На TURN вкл:
    * выполните вход в Центр управления в качестве администратора и перейдите к разделу "Управление > Привязь > Settings.
    * Прокрутите страницу вниз, чтобы найти раздел Webex Edge for Devices и TURN на **Allow Control Hub для управления конфигурацией**.
