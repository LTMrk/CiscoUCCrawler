# Få tilgang til API for Board-, skrivebords- og romserieenheter
![list-menu](https://help.webex.com/images/feedback.svg)Tilbakemelding?
Du kan bruke enhetens API til å konfigurere enhetene dine, bygge integrasjoner og opprette utvidelser. 
For å kunne programmere mot enheten, må det være en lokal bruker på enheten. Les mer om hvordan du oppretter lokale brukere i [ artikkelen Lokal brukeradministrasjon ](https://help.webex.com/en-us/article/jkhs20/Local-User-Administration-on-Desk,-Board,-and-Room-devices) .
Det er flere måter å få tilgang til API. Uansett hvilken metode du velger, er strukturen til API den samme. Velg tilkoblingsmetoden som passer best til ditt program:
  * SSH (Sikker TCP/IP tilkobling. Aktivert som standard).
  * Telnet (bare tilgjengelig for DX80. Deaktivert som standard).
  * HTTP/HTTPS (HTTPS aktivert som standard).
  * Seriell tilkobling (Kan brukes uten IP adresse, DNS eller et nettverk. Aktivert som standard).


## API guide
Hvis du vil lese mer om hvordan du bruker API og kommandobeskrivelsene, kan du gå [ til https://roomos.cisco.com/](https://roomos.cisco.com/).
API-kommandoene for alle produkter samt syntaks og semantikk er beskrevet i denne veiledningen. 
## Kommandoer som ikke gjelder når en enhet er registrert på Webex
Noen av konfigurasjonene, kommandoene og statusene som er tilgjengelige i API, gjelder bare for lokale registrerte enheter. De gjelder ikke for Webex registrerte enheter. [ I API guidens ](https://www.cisco.com/c/dam/en/us/td/docs/telepresence/endpoint/roomos-115/api-reference-guide-roomos-115.pdf)_matrise_ over støttede kommandoer er disse elementene merket med "Kun lokalt".
Blant de ikke-gjeldende konfigurasjonene, kommandoene og statusene er alle de som er relatert til H.323, H.320, SIP, NTP, CUCM, LDAP, Proximity og Far End Camera Control.
Konfigurasjonene og statusene som ikke gjelder, vil bli fjernet fra Webex-registrerte enheter i en senere programvareversjon. Vi anbefaler at du ikke programmerer mot API-kommandoer i disse kategoriene.
