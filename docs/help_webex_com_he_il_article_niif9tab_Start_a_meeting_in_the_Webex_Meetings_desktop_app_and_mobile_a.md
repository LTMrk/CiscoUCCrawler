# התחל פגישה ביישום שולחן העבודה Webex Meetings וביישום למכשירים ניידים
![list-menu](https://help.webex.com/images/feedback.svg)משוב?
באפשרותך להתחיל פגישה ישירות מהאפליקציה 'פגישות' למחשבים שולחניים או מהאפליקציה למכשירים ניידים, מבלי שתצטרך לעבור לאתר Webex שלך. 
  * [שולחן עבודה](https://help.webex.com/he-il/article/niif9tab/%D7%94%D7%AA%D7%97%D7%9C-%D7%A4%D7%92%D7%99%D7%A9%D7%94-%D7%91%D7%99%D7%99%D7%A9%D7%95%D7%9D-%D7%A9%D7%95%D7%9C%D7%97%D7%9F-%D7%94%D7%A2%D7%91%D7%95%D7%93%D7%94-Webex-Meetings-%D7%95%D7%91%D7%99%D7%99%D7%A9%D7%95%D7%9D-%D7%9C%D7%9E%D7%9B%D7%A9%D7%99%D7%A8%D7%99%D7%9D-%D7%A0%D7%99%D7%99%D7%93%D7%99%D7%9D#id_120896)
  * [נייד](https://help.webex.com/he-il/article/niif9tab/%D7%94%D7%AA%D7%97%D7%9C-%D7%A4%D7%92%D7%99%D7%A9%D7%94-%D7%91%D7%99%D7%99%D7%A9%D7%95%D7%9D-%D7%A9%D7%95%D7%9C%D7%97%D7%9F-%D7%94%D7%A2%D7%91%D7%95%D7%93%D7%94-Webex-Meetings-%D7%95%D7%91%D7%99%D7%99%D7%A9%D7%95%D7%9D-%D7%9C%D7%9E%D7%9B%D7%A9%D7%99%D7%A8%D7%99%D7%9D-%D7%A0%D7%99%D7%99%D7%93%D7%99%D7%9D#id_120555)


יש יותר מדרך אחת להתחיל פגישה מהאפליקציה 'פגישות ' לשולחן העבודה. באפשרותך להתחיל פגישה בחדר האישי שלך, או להתחיל פגישה מתוזמנת מהרשימה פגישות קרובות.
