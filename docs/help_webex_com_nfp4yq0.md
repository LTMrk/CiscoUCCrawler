What's New for Agentic Apps
![list-menu](https://help.webex.com/images/list-menu.svg)In this article
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Webex App Hub now supports Agentic Apps, a new category of AI-native applications that enable intelligent agents to work together seamlessly across your organization. 
  * [](https://help.webex.com/en-us/article/nfp4yq0/What's-New-for-Agentic-Apps#webex_c_agentic_apps_overview)
  * [What's New](https://help.webex.com/en-us/article/nfp4yq0/What's-New-for-Agentic-Apps#webex_c_agentic_apps_whats_new)
  * [Get Started](https://help.webex.com/en-us/article/nfp4yq0/What's-New-for-Agentic-Apps#webex_c_get_started_with_agentic_apps)


Built on the Model Context Protocol (MCP) and Agent-to-Agent (A2A) communication, Agentic Apps allow AI assistants to autonomously discover capabilities, share context, and coordinate actions across Webex and your enterprise systems without traditional custom integrations.
## What's New
### Agentic Apps Category
A dedicated section in Webex App Hub for discovering and deploying AI-native applications that use Model Context Protocol and Agent-to-Agent (A2A) communication. These apps leverage MCP servers to provide standardized, secure connections between AI assistants and your business tools.
### Webex MCP Servers for External Agents
Webex now exposes its own MCP servers, allowing external AI agents built on platforms like Claude, ChatGPT, or custom solutions to access the following:
  * Meeting context - transcripts, recordings, participants, and summaries
  * Messaging history - space conversations, direct messages, and team communications
  * Contact Center data - queue states, call transcripts, agent status, and routing context*
  * Device intelligence - workspace sensors, room booking, and environmental controls


External agents can now tap into Webex capabilities through standardized protocols without building custom API integrations.
### External MCP Servers for Webex Agents
Webex AI agents can now consume external MCP servers from partners and third-party providers, giving them instant access to:
  * CRM systems - Salesforce, HubSpot, Microsoft Dynamics
  * Ticketing platforms - Jira, ServiceNow, Zendesk
  * Knowledge bases - Confluence, SharePoint, Notion
  * Business tools - Airtable, Miro, PagerDuty, Slack


Onboarding for some of the MCP servers listed above is still in progress, and they are not yet available in Webex App Hub.
This bidirectional approach means your Webex AI agents become more powerful while your existing AI investments gain Webex collaboration intelligence.
### AGNTCY Ecosystem Layer
AGNTCY serves as the orchestration and governance foundation for the agentic ecosystem:
  * Agent Registry - Discover available agents and their capabilities across your organization
  * Security Validation - Every tool invocation is scanned by MCP Scanner for threats and policy violations
  * Unified Governance - Centralized access controls, audit logging, and compliance enforcement
  * Marketplace - Browse, evaluate, and deploy certified MCP servers from Webex and partners


## Get Started
### For Administrators
  1. **Explore Agentic Apps** —Visit Webex App Hub and browse the new Agentic Apps category
  2. **Review MCP Servers** —Check available internal Webex and external partner MCP servers
  3. **Enable Users** —Approve specific MCP servers for your organization. Enable or disable supported MCP servers for your organization.


### For Developers
  1. **Access Developer Portal** —Visit [developer.webex.com](https://developer.webex.com/) and navigate to the MCP section
  2. **Review Documentation** —Read MCP server setup guides and tool schemas
  3. **Use AI Assistant** —Generate code snippets for your integration use case
  4. **Test in Sandbox** —Validate your MCP server in the developer sandbox environment
  5. **Submit for Certification** —Request review to publish in Webex App Hub marketplace


For questions or support, contact your Webex account team or visit the [Webex for Developers](https://developer.webex.com/).
