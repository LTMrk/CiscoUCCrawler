MCP server for interacting with the Supabase platform
[ Learn more ](https://developer.webex.com/mcp/docs/federated-through-external-registry-mcp-servers#supabase)
Agentic App by [supabase](https://supabase.com/)
The Supabase MCP Server turns your AI assistant into a co-developer for your backend infrastructure, allowing it to list projects, inspect database schemas, and execute SQL queries directly. By providing real-time context of your database structure and Edge Functions, it enables faster debugging, automated data analysis, and rapid prototyping, letting you ask questions like "Explain the schema of the 'users' table" or "Run a query to find the top 10 active customers." To get started, generate a Personal Access Token in your Supabase Dashboard, then add the server to your MCP-compatible AI client using npx @supabase/mcp-server and provide your token when prompted. Requirements include a Webex license and a Supabase account with at least one active project. Supabase offers a Free tier for hobby projects, with paid plans available for production workloads. For more information, please visit supabase.com/pricing.
