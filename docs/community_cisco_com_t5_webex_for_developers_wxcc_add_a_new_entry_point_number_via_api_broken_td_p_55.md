Hi Laurens,
We investigated this through your Developer Support case. Your payload was not the problem—the `404 Dialed number does not exist` response was misleading and was caused by an issue in the Dialed Number Mapping create path.
Engineering deployed the fix to EU2, and you subsequently confirmed that the API now works with a Partner Admin using the documented `cjp:config_write` scope.
I’m adding the outcome here for anyone who encounters the same issue. If the request still fails, generate a fresh token with `cjp:config_write` and retry. If it continues, please open a Developer Support case with the UTC timestamp and tracking ID from a fresh request.
