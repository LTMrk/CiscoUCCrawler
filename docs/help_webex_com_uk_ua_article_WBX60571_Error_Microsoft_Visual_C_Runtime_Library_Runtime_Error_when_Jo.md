Оформити передплату
Помилка: «Помилка виконання бібліотеки Microsoft Visual C++» під час приєднання до зустрічі
![list-menu](https://help.webex.com/images/feedback.svg)Надіслати відгук?
**ПРОБЛЕМА**  
Користувачі стикаються з помилкою «Microsoft Visual C++ Помилка середовища виконання бібліотеки під час спроби розпочати зустріч або приєднатися до неї.  
  
**РОЗДІЛЬНА ЗМІНА**  
**Оновіть візуальне оформлення C++ Бібліотека виконання**
  1. Завантажте та встановіть [останню версію Visual C++ бібліотека середовища виконання від Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170).


Якщо у вас немає прав для встановлення програмного забезпечення, зверніться за допомогою до свого ІТ-відділу.
  1. Після встановлення перезавантажте комп’ютер і спробуйте знову приєднатися до зустрічі Webex.


Якщо помилка не зникає, перейдіть до наступного рішення.  
  
**Встановіть останні оновлення для Windows** s
  1. Переконайтеся, що ваша операційна система Windows оновлена останніми оновленнями та патчами.
  2. Перезавантажте комп'ютер після застосування оновлень.
  3. Спробуйте приєднатися до зустрічі ще раз.


Щоб отримати додаткові відомості та можливі рішення, зверніться до статті бази знань Microsoft за адресою [<http://support.microsoft.com/kb/822521>]. Якщо проблема не зникає після цих кроків, може знадобитися подальше розслідування, щоб визначити причину та знайти відповідне рішення.
**ПРИЧИНА**  
Ви можете отримати помилку виконання під час початку зустрічі або приєднання до неї, якщо Microsoft Visual C++ Бібліотеки середовища виконання відсутні або пошкоджені. Помилка буде таким: «Ця програма запитала завершення середовища виконання незвичним чином».
