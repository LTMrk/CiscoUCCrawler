## Introduction
This document describes the compatible small form-factor pluggables (SFP), Broadcom has qualified for Emulex LPe31002-M6, Part Number: UCSC-PCIE-BD16GF, and Emulex LPe32002-M2, Part Number: UCSC-PCIE-BD32GF.
You might see an error in BIOS stating "Unsupported Optic Installed", if incorrect SFP is installed into Emulex.
Press **F2** During Boot to go to BIOS > **Advanced** tab > **Emulex LPe31002-M6** > **Scan for Fibre Devices** or **Find Target**
