# Autoriser les utilisateurs à se connecter à votre Site Cisco Webex Meetings avec des comptes tiers
![list-menu](https://help.webex.com/images/feedback.svg)Un commentaire ?
Les administrateurs de site peuvent autoriser leurs utilisateurs à se connecter à leur expérience de page d’affichage moderne en utilisant Google, Facebook, Microsoft Office 365 et les identifiants Apple. 
  * Nous avons mis à jour le processus de connexion sociale Microsoft pour les utilisateurs de Webex Meetings utilisant un compte Microsoft tiers pour se connecter à votre site Webex. 
Les utilisateurs doivent vérifier leur identité avec Webex avant de configurer un compte de connexion Microsoft 3ème partie dans les paramètres de leurs réunions du site Webex. Une fois que le compte de connexion Microsoft 3ème partie est configuré, l'utilisateur peut se connecter au site avec son compte Microsoft.
Si l’administrateur a configuré le tenant Microsoft 365 de l’utilisateur dans la section Intégration 3e partie des Options du site et a activé « Lier les utilisateurs automatiquement à ce site Webex si l’adresse électronique de leur compte Webex correspond à leur adresse électronique Microsoft 365 », l’utilisateur n’a pas besoin de vérifier son identité avec Webex. Ils peuvent utiliser automatiquement la connexion de Microsoft 3ème partie.
  * La connexion avec des comptes tiers est activée par défaut pour les nouveaux sites. Cette fonctionnalité n’est pas prise en charge pour l’application de bureau Cisco Webex Meetings.

  
| 1  |  Connectez-vous à Webex Administration du site puis  allez à Configuration  > Paramètres communs du site  > Options .   |  
| --- | --- |  
| 2  |  Faites défiler jusqu'à la section  Intégration d'une tierce partie , et cochez ou décochez la case  Connexion pour chaque compte tiers sur votre site.   |  
| 3  |  Faites défiler jusqu’au bas de la page et sélectionnez  Mettre à jour.   |
