# Группировка устройств с тегами в Control Hub
![list-menu](https://help.webex.com/images/feedback.svg)Отправить обратную связь?
Вы можете добавлять пользовательские теги к устройствам в Control Hub, чтобы упростить поиск устройств. 
Можно использовать теги для определения названий групп устройств на основе подразделения компании или физического местоположения. Например, если устройство отмечено тегом _третий этаж_ , то при поиске параметра _третий этаж_ будут отображены все устройства с этим тегом.
Теги также можно использовать для изменения имени устройства в приложении Webex, чтобы помочь пользователям определить правильное устройство для подключения. Для этой цели используйте формат «имя=<tag>». Первый тег, использующий этот формат, добавляется к имени устройства в скобках в меню подключений приложения Webex.  
| 1  |  В окне просмотра информации о клиенте на веб-сайте [https://admin.webex.com](https://admin.webex.com/) перейдите к меню Устройства и выберите устройство, которое необходимо отметить тегом. Если вы хотите добавить или отредактировать теги на нескольких устройствах одновременно, выберите несколько устройств и нажмите Редактировать на панели инструментов.  |  
| --- | --- |  
| 2  |  На панели, которая откроется справа, выберите Теги, добавьте тег и щелкните за пределами поля, чтобы применить тег. Тег не отображается в списке устройств, только на странице сведений об устройстве. Однако вы можете использовать теги в списке фильтров для поиска устройств.  |
