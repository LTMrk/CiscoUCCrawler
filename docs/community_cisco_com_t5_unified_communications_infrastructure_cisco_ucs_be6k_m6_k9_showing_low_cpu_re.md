Hi [@rmishra](https://community.cisco.com/t5/user/viewprofilepage/user-id/1433738) ,
The BE6K-M6-K9 has limited CPU resources, and running multiple medium-sized VMs can cause resource shortages. For your situation:
  * Shutting down existing VMs and resizing them to smaller resource allocations is possible, but may cause issues if not planned carefully.
  * Ideally, if the server supports only small VM sizes for your deployment, it’s safer to delete existing VMs and reinstall all with the small VM profile to ensure resource compatibility.
  * Make sure to verify resource allocation limits on the UCS platform and VMware ESXi before proceeding.


This approach should help avoid CPU resource conflicts during Expressway installation.
