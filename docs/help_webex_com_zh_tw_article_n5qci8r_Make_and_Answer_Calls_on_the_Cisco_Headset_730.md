# 開始使用您的 Cisco 耳機 730
![list-menu](https://help.webex.com/images/feedback.svg)意見回饋？
了解最主要的 Cisco 耳機 730 說明主題。 
![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/490001-500000/491001-492000/491186.png)
Cisco 頭戴式耳機 730 是一款無線頭戴式耳機，它使用 Bluetooth® 連接與 Cisco 軟用戶端和設備配對。 除了在繁忙的辦公環境中使用的強大噪音消除和環境音訊增強系統之外，該耳機還具有完整的通話控制和音樂播放功能。 Cisco 耳機 730 支援與 Cisco Jabber, Webex, Webex Meetings, Cisco IP 電話和 Webex Desk 裝置完全通話整合。
Cisco 耳機 730附有 USB 配接器，可用於沒有提供可靠藍牙解決方案的裝置。 耳機也可以使用隨附的 3.5mm 線和 USB-C 至 USB-A 線連接至裝置。 USB-C 線還可以用作充電電線且可連接至任何有供給電源的 USB 適配器。 
[設定您的耳機](https://help.webex.com/zh-tw/article/nxxey0cb/%E9%96%8B%E5%A7%8B%E4%BD%BF%E7%94%A8%E6%82%A8%E7%9A%84-Cisco-%E8%80%B3%E6%A9%9F-730#concept-template_98a84c16-183e-4333-adde-7ea9f2df3715)

  * [下載並安裝「Cisco 耳機」行動應用程式](https://help.webex.com/zh-tw/n29jpvz/)。
