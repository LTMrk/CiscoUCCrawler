Коли AI Assistant запропонує зробити перерву для відновлення, з’явиться спливаюче повідомлення. Прийняття перерви. Щоб прийняти пропозицію щодо перерви, клацніть «Зробити перерву». Буде автоматично відкрито віджет Cisco AI Assistant для підтвердження вибору. Після завершення поточної взаємодії автоматично почнеться 1-хвилинна перерва для відновлення. Ваш стан буде змінено на «Перерва для відновлення», щоб запобігти призначенню наступної взаємодії. Коли 1-хвилинна перерва завершуватиметься, на екрані з’явиться 5-секундний зворотний відлік. Після завершення перерви вікно буде автоматично закрито, стан змінено на «Доступний» і ви будете готові до наступної взаємодії.
