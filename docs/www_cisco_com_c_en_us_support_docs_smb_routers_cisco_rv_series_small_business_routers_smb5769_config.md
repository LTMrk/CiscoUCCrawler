Configure DHCP WAN Settings on the RV34x Router
## Introduction
A Wide Area Network (WAN) is a network that covers a broad area. A user or network of users can connect to the Internet through an Internet Service Provider (ISP) who offers various methods to set up a client with an Internet connection. These methods can be automatic Dynamic Host Configuration Protocol (DHCP), Static Internet Protocol (IP), Point-to-Point Protocol over Ethernet (PPPoE), Point-to-Point Tunneling Protocol (PPTP), Layer 2 Tunneling Protocol (L2TP), Bridge, and Stateless Address Auto-configuration (SLAAC) for IPv6.
Configuring the right WAN settings on the router is necessary in order to properly set up Internet connection based on your network requirements and setup. Some WAN settings to be used on your router such as Usernames, Passwords, IP addresses, and DNS servers should be provided to you by your ISP.
In this scenario, the setup from the ISP requires the router to use DHCP settings in order to connect to the Internet. DHCP is a network protocol that allows the server to automatically assign an IP address to every computer or device the moment it connects to the network. This connection type is ideal in setups where the administrator needs to change or assign IP addresses to a large number of systems. Instead of reconfiguring each one of the systems, IP addresses are automatically assigned to each one of them by the DHCP server.
## Objective
This article aims to show you how to configure the DHCP WAN settings on the RV34x Router.
## Applicable Devices
  * RV340
  * RV340W
  * RV345
  * RV345P


## Software Version
  * 1.0.01.17


## Configure DHCP WAN Settings
Step 1. Access the router web-based utility and click **WAN > ****WAN****Settings**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step1.png "Related image, diagram or screenshot.")
Step 2. In the WAN Table, click the **Add** button.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step2.png "Related image, diagram or screenshot.")
Step 3. In the Add/Edit WAN Sub-Interface window that appears, click on the WAN interface that you want to configure.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step3.png "Related image, diagram or screenshot.")
**Note:** In this example, WAN1 is chosen. This is the default setting.
Step 4. Enter the VLAN ID in the field provided. In this example, 1 is used.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step4.png "Related image, diagram or screenshot.")
**Note:** The Sub-Interface Name area automatically updates based on the WAN and VLAN ID entered. In this example, WAN1.1 is displayed indicating WAN 1 and VLAN 1.
Step 5. Click the tab of the connection that you are using.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step5.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step5.png "Related image, diagram or screenshot.")
**Note:** In this example, IPv4 is chosen. This is the default setting. If you are using IPv6, skip to [IPv6](https://www.cisco.com/c/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/smb5769-configure-dhcp-wan-settings-on-the-rv34x-router.html#IPv6).
### IPv4
Step 6. Click on the **DHCP** radio button to choose the Connection Type.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step6.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step6.png "Related image, diagram or screenshot.")
Step 7. Under the DHCP Settings, click the DNS Server drop-down arrow and choose the DNS server.
  * Use DHCP Provided DNS Server — Allows the router to use the DNS Server settings provided by the DHCP server.
  * Use DNS as Below — Allows you to enter specific DNS addresses provided to you by your ISP.


[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step7.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step7.png "Related image, diagram or screenshot.")
**Note:** In this example, Use DHCP Provided DNS Server is chosen. This is the default setting.
Step 8. Click **Apply**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step8.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwan-step8.png "Related image, diagram or screenshot.")
###  IPv6
Step 1. Click the **IPv6** tab.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step1.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step1.png "Related image, diagram or screenshot.")
Step 2. Click on the **DHCP** radio button to choose the Connection Type.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step2.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step2.png "Related image, diagram or screenshot.")
Step 3. Under the DHCP Settings, click the DNS Server drop-down arrow and choose the DNS server.
  * Use DHCP Provided DNS Server — Allows the router to use the DNS Server settings provided by the DHCP server.
  * Use DNS as Below — Allows you to enter specific DNS addresses provided to you by your ISP.


[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step3.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step3.png "Related image, diagram or screenshot.")
**Note:** In this example, Use DNS as Below is chosen. This is the default setting.
Step 4. In the _Static DNS 1_ field, enter the first DNS server address provided to you by your ISP.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step4.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step4.png "Related image, diagram or screenshot.")
**Note:** In this example, 2001:4860:4860::8888 is used.
Step 5. (Optional) In the _Static DNS_ _2_ field, enter the second DNS server address provided to you by your ISP.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step5.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step5.png "Related image, diagram or screenshot.")
**Note:** In this example, 2001:4860:4860::8844 is used.
Step 6. (Optional) Check the **DHCP-PD** checkbox if you are using DHCPv6 prefix delegation.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step6.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step6.png "Related image, diagram or screenshot.")
Step 7. (Optional) Enter the prefix name in the field provided.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step7.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step7.png "Related image, diagram or screenshot.")
**Note:** In this example, DHCPv6 is used.
Step 8. Click **Apply**.
[![](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step8.png)](https://www.cisco.com/c/dam/en/us/support/docs/smb/routers/cisco-rv-series-small-business-routers/images/rjs-011218-dhcpwanipv6-step8.png "Related image, diagram or screenshot.")
You now have successfully set your RV34x Router WAN settings to DHCP.
