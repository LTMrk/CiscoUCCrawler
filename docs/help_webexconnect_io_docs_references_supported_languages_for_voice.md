> Note
> To use multilingual voice , you must use SSML (Speech Synthesis Markup Language) to specify the desired language within your text.
> Even if a voice is capable of speaking multiple languages — such as JennyMultilingual — you still need to configure the correct language context explicitly using SSML.  
>  This approach ensures accurate pronunciation, tone, and linguistic nuances when synthesizing speech.
> For example, if you want to use JennyMultilingual to synthesize text in “en-IN” (Indian English):  
>  0. Select “en-US” as the language and “JennyMultilingual” as the voice from the dropdown menus.  
>  0. In your SSML text, use the  tag to specify the target language  
>    
>  Enter the text you would like to synthesize in Indian English.  
> 
> By doing this, you ensure that the multilingual voice adapts properly to the intended language variation.
