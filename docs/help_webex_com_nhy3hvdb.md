## 2026
### June 2026
#### Webex WFO: Auto Coaching in Performance Management
Webex WFO Performance Management has introduced Auto Coaching, a new feature that automates the creation of coaching sessions based on specific business rules and performance thresholds. By leveraging real-time data, Auto Coaching ensures that agents receive timely, personalized feedback while significantly reducing the administrative burden on supervisors.
**Key Benefits:**
  * Automates session creation, freeing supervisors from manual scheduling tasks.
  * Triggers coaching precisely when performance metrics indicate a need for intervention.
  * Provides agents with consistent, relevant guidance tailored to their individual performance.
  * Strengthens the feedback loop, ensuring that performance goals are tracked and addressed consistently.


For more information, see [Create rules for automatically scheduled coaching sessions in Performance Management](https://wfohelp.com/doc/Content/user-guides/performance-management/auto-coaching.htm).
Performance Management requires customers to sign in through their configured Tenant Specific URL. For more information, refer to [Tenant Specific URL for Webex WFO Users](https://help.webex.com/en-us/article/nw6wf91/Tenant-Specific-URL-for-Webex-WFO-Users).
This feature will require a minimum of Webex WFO Bundle SKU, or Full WFM, or Full QM. For more information pertaining to Webex WFO SKUs, see [Webex WFO: Feature Specific SKUs](https://help.webex.com/en-us/article/py6u9h/Webex-WFO:-Feature-Specific-SKU).
#### Webex WFO: WFM - Manage External Log-on in the Web
Webex WFO has enhanced external log-on management by adding web-based capabilities alongside existing client support. External log-ons link agent statistics from systems like Automatic Call Distribution (ACD), Customer Relationship Management (CRM), or Payroll and are automatically updated every night. Agents can have multiple external log-ons, but sharing them is not recommended to maintain accurate per-agent statistics.
For more information, see <https://wfohelp.com/doc/Content/user-guides/people/manage-basic-user-info.htm>.
This update enables administrators and users to manage external log-ons directly via the web interface, streamlining work flows while retaining client functionality. It supports improved usability and administrative efficiency in workforce management.
This feature will be available on both the web interface and the client application, maintaining full functionality across both platforms.
### April 2026
#### Webex CCE Administration Portal feature enhancements
The following portal features are enhanced for better routing control, user management, and improved speed and performance.
**Enhanced Agent Collection Management and UI refinements**
This update enhances Agent and User Collection management by showing the Login Name field to make both User and Agent Collection Management easy with the common field Login Name. Additionally, the release includes standardized column headers and stability improvements to ensure a more reliable and consistent user experience. 
**Enhanced visibility for Management User**
This feature enables Tenant administrators to view company names directly within the Management Users Grid for improved organizational oversight. The system ensures that company information is accurately reflected and updated in the grid whenever a Management User profile is created or modified.
**Enhanced Grid Customization and View Persistence for Webex CCE Portal**
Users can now resize grid columns by dragging borders and have these preferences automatically saved within their custom views for future sessions. This functionality extends to the Table Routing Control dialog, ensuring consistent column layout, visibility, and sorting preferences are applied across the Webex CCE Portal.
**Support for 4-Digit Agent Directory Numbers (DNs)**
The Webex CCE Portal now supports 4-digit Agent DNs across user creation, updating, cloning, and bulk CSV import workflows. This update includes updated validation logic and specific handling for password prefixing during user cloning to ensure shorter, valid phone numbers are processed correctly.
**Bulk Skilling Feature Enhancement**
The new Bulk Skilling feature, accessible via the Administration menu, allows authorized users to manage agent skill assignments efficiently through bulk CSV uploads and a dedicated data selection interface. This enhancement includes granular role-based access control to enable/disable the feature and comprehensive validation to ensure seamless integration within existing Bulk Request workflows.
**Unicode Support for Portal Table Controls**
This feature enables comprehensive Unicode support within Portal Table Controls, ensuring the seamless storage, retrieval, and management of international characters across databases and synchronization processes. The update includes expanded character limits, enhanced UI validation, and full compatibility for imports, exports, and audit logging to maintain data integrity and operational consistency.
**Dynamic CCAI Configuration and Management**
This feature transitions hardcoded CCAI Agent Services to a dynamic, table-driven configuration, enabling the seamless addition of new services across all user management and bulk processing workflows. Additionally, it introduces a role-based CCAI Summary page, providing administrators and supervisors with centralized visibility into AI service configurations.
**Expanding Webex Contact Center Enterprise (WXCCE) Portal Cluster Capacity**
This enhancement increases the Webex CCE Administration Portal’s cluster management limit from 12 to 15, enabling large enterprise customers to fully administer and monitor their deployments within a single interface. By removing this hard cap and improving scalability, the update ensures seamless operational management and consistent performance for high-scale customer tenants.
#### Webex WFO: WFM - Intraday Re-forecasting
Webex WFO now supports WFM Intraday Reforecasting, a powerful enhancement that enables supervisors to realign staffing throughout the day based on the latest demand. By quickly generating and implementing revised forecasts, teams can efficiently address unexpected events like call surges or agent absences with increased precision and flexibility.
This functionality enhances intraday management, supporting contact centers in boosting service levels, minimizing both overstaffing and understaffing, and ensuring well-balanced schedules. With unlimited reforecasts accessible directly from the Intraday Staffing view, supervisors can make informed, data-driven staffing decisions seamlessly, without interrupting current workflows.
For more information, refer to [View staffing levels and actual need](https://wfohelp.com/doc/Content/user-guides/intraday/view-staffing-actual-need.htm).
#### Webex WFO: New Media Player Interface
Webex WFO now supports a refreshed Media Player interface designed for a cleaner, more intuitive user experience. This transition from dense, static panels to a sleek, modular design, the new UI ensures that essential information is available exactly when needed , reducing visual clutter and improving workflow efficiency.
**Key Benefits:**
  * **Modernized Aesthetic** : Updated styling and a refined color palette provide a fresh, contemporary look.
  * **Flexible, Modular Layout** : Easily expand or collapse sections to optimize your screen space and maintain focus on the task at hand.
  * **Contextual Metadata** : Information is displayed on-demand, ensuring you have the data you need without overwhelming your view.
  * **Personalized Viewing** : Use a centralized menu to quickly show or hide key elements, such as Transcripts, Audio, Sentiment, and Phrase Hits.


For more information, see [Play contacts with the new media player](https://wfohelp.com/doc/Content/user-guides/media-player/v2/media-player-v2.htm).
#### Webex WFO: WFM - New Forecasts Viewing Page
Webex WFO now supports a new Forecasts Viewing page on the web that provides enhanced visualization of forecast charts alongside workload and skills interval data for specific skills, combining capabilities currently available in the WFM client. This new page will operate alongside the existing web forecast page, giving users flexible options for viewing forecast information and enabling a seamless transition of these features to the web platform.
In addition, editing capabilities for forecast workload and skill data will soon be available on this page, including convenient copy and paste functionality within the workload and skill grid components.
The client version of the forecast page will continue to be supported and will not be retired.
For more information, see [Forecasts Tool (web)](https://wfohelp.com/doc/Content/glossaries/wfm-tools/forecasts-web.htm).
#### Bring Your Own Virtual Agent (BYOVA) Integration
Third-party vendors can now seamlessly integrate their Virtual Agents with Unified CCE and Packaged CCE solutions. The key aspects and benefits of this feature include:
  * **Vendor/Customer onboarding** : A structured, step-by-step onboarding process has been established, with clearly defined phases, entry criteria, activities, and success checkpoints. Once a partner or customer meets the qualification criteria, completes all required functional and non-functional validations, and submits the necessary compliance documentation, their solution becomes eligible for listing on the Cisco Marketplace. This approach streamlines the process for partners and expands customer access.
  * **Visibility control** : Customers can choose whether to make their Virtual Agent bot available to other customers or restrict it so that it is accessible only within their own tenant.
  * **AI provider choice** : Customers have the flexibility to select virtual agents from any provider that best meets their business, language, or domain requirements.
  * **Diverse VA models** : The platform supports integration with virtual agents operating in either scripted or autonomous modes, allowing customers to deploy the type that best fits their needs.
  * **Seamless integration** : Once integrated, your Virtual Agents can function smoothly within the CCE solution. This enables central call flow management, session control, and AI-driven engagement without requiring changes to existing systems.


#### Increased Reliability and Scale for Contact Center AI Features
Cisco Contact Center Enterprise (CCE) introduces the Media Gateway service to improve AI capabilities for live agent interactions in on-premises deployments. This service bridges on-premises infrastructure with cloud-based AI platforms, enabling real-time AI experiences for agents and supervisors.
To enable this feature:
  * Cisco VVB provides the following modes for this feature:Cisco VVB Service Only, Media Gateway (MGW) Service Only, or Mixed Mode (Cisco VVB & Media Gateway).
For deployments using MGW Service Only or Mixed Mode, a medium profile OVA is required. Mixed Mode deployments additionally require increased vRAM (16 GB instead of the default 10 GB). For more information, see the _Cisco VVB virtualization_ page at <https://www.cisco.com/c/dam/en/us/td/docs/voice_ip_comm/uc_system/virtualization/virtualization-cisco-virtualized-voice-browser.html>.
  * For Unified CCE, configuration is done via the Unified CVP Operations Console (NOAMP).
  * For Packaged CCE, configuration is done via the Unified CCE Administration console by selecting the Media Gateway check box on the Inventory page.


### March 2026
#### Webex WFO: Manage Workflow Control Sets on the Web
Webex WFO now supports Workflow Control Set management directly on the web. This transition from the WFM client to the browser-based interface provides a more streamlined, centralized administration experience, supporting easier access and ongoing platform modernization.
For more information refer to [Manage workflow control sets and profiles in the web](https://wfohelp.com/doc/Content/user-guides/wfm-settings/manage-workflow-control-sets-web.htm).

To maintain uninterrupted service, ensure that all WFM workflow control sets are fully migrated by this date.

Webex WFO Analytics now supports seven additional languages: Turkish, Filipino, Thai, Bahasa, Greek, Hungarian, and Czech. This enhancement extends analytics coverage across both voice and digital channels, enabling broader global adoption. Customers can now leverage key capabilities, including Auto QM, Interaction Summary, Trending Topics, and Advanced Sentiment in these languages, ensuring consistent, AI-driven insights and quality analysis across more regions and customer interactions.
For more information, see [Localization and supported languages](https://wfohelp.com/doc/Content/install-guide/introduction/localization.htm).
#### Webex AI Agent
The Webex AI Agent acts as a smart assistant that handles initial customer interactions across both voice and digital channels. It works in two modes:
  * **Scripted Mode:** Uses predefined rules and natural language understanding to respond accurately to common customer intents.
  * **Autonomous Mode:** Employs advanced Large Language Models (LLMs) to engage in more natural, human-like conversations, adapting dynamically to customer needs.


This means many routine inquiries are resolved before they reach you, reducing your workload and allowing you to focus on more complex customer needs.
Here's how this impacts your workday:
  * **Reduced Wait Times for Customers:** By resolving simpler issues automatically, customers experience faster service, which improves satisfaction and reduces call volumes for you.
  * **Enhanced Customer Context:** You receive comprehensive summaries and transcripts of AI-handled interactions, giving you full visibility into customer history and preferences.
  * **Improved Efficiency and Focus:** With routine tasks managed by the AI Agent, you can dedicate more time to complex cases that require your expertise, improving your productivity and job satisfaction.
  * **Support for Hybrid and Digital Environments:** The AI Agent supports hybrid session management, allowing customers to exit and re-enter conversations smoothly, which helps maintain continuity and context.


Here's what the Webex AI Agent offers:
  * **Seamless Human Agent Handoff:** When the AI Agent escalates a conversation to you, it provides a clear summary of the interaction so far. This helps you quickly understand the customer's issue without making them repeat themselves, enabling faster and more effective support.
  * **Multi-Channel Support:** Whether customers reach out via voice calls, chat, SMS, or other digital channels, the AI Agent manages these interactions smoothly, ensuring you have consistent context regardless of the channel.
  * **Multi-Lingual Capabilities:** The AI Agent supports multiple languages, helping you assist a diverse customer base with greater ease.
  * **Built-in Reporting and Insights:** Supervisors can access detailed analytics and reports within the AI Agent Studio to monitor AI performance and customer interactions, helping optimize workflows and improve service quality.
  * **Integration with Business Systems:** The AI Agent connects seamlessly with existing business applications and automation workflows, ensuring that customer requests are handled efficiently and accurately.


#### AI Agent Transcription
The AI Agent Transcription feature automatically captures complete interaction transcripts between customers and AI Agents and makes them instantly accessible when the interactions escalate to human agents. Supporting both voice and digital channels across scripted and autonomous AI agent types, this feature provides agents with full interaction context. This eliminates the need for customers to repeat information, reducing handle times and improving the overall customer experience.
#### Webex CCE Admin Portal feature enhancements
The following portal features are enhanced for better routing control, user management, and improved speed and performance. 
##### Routing Control feature enhancements
  * **Control tags for Routing Controls:** A new Control tag field is added to all routing controls, allowing users to add up to six tags (15 characters each) per control and create new tags during editing. While creating control tags, names can contain special characters (except pipe and comma) without a space. Enhanced search features—including a dropdown, multi-select checkboxes, and 'OR/AND' conditions—make it easier to find and filter specific controls.
  * **Routing Controls in bulk request:** A new Routing Control tab on the Bulk Request page enables bulk creation or update of routing controls via downloadable templates, with an option to check for duplicate tag sets.
  * **Secret data type:** The new 'Secret' data type for table control columns makes the field required, sets a fixed length of 250 characters, and masks input for secure storage of sensitive information like passwords.
  * **XML generation for all Routing Control Types:** XML generation now applies to all control types, so whenever a control is created or updated, an XML file is generated and uploaded to the media server.


##### Attribute assignment feature enhancements
  * **Attribute schedule enhancements:** The following enhancements are made to attribute schedules for PQ attribute assignment:
    * Users can now select multiple attributes and agents for assignments, schedule attribute assignments (including recurring daily, weekly, monthly, or yearly schedules), and choose to add or remove attributes.
    * The **Replace and Restore** operation enables temporary attribute assignment for a specified duration, after which attributes revert to their previous state.
    * Pagination is added to the attribute schedule page.
    * Enhanced filtering quickly narrows down and customizes entity listings for efficient data access across the portal.
    * The new **Time Zone** field is added to address issues with UTC servers and daylight-saving time to ensure correct scheduling across time zones.
  * **Bulk Operations for attribute assignment:** Bulk operations allow you to select multiple agents for actions such as marking them for deletion or editing their attribute values simultaneously.


##### Portal general feature enhancements
  * **General Grid Enhancements:** The grid option menus now feature reorganized sub-options for columns and export, allowing users to customize, save, and persist their preferred grid views across sessions.
  * **Time Zone field:** A new Time Zone field for skill and attribute schedules ensures operations use the correct local time, resolving previous daylight-saving issues on UTC-configured servers.
  * **Attribute assignment to Agents and Supervisors:** A new Attributes tab in the 'Add New Agent' and 'Add New Supervisor' forms allows administrators to assign attributes directly during user creation.
  * **Keyboard shortcut to search users:** You can use Ctrl+F to search within fields and Esc or Tab keys to navigate between fields on the 'Users Listing' page.
  * **Webex CCE-Common Identity (CI) Integration:** Phase 1 of Common Identity (CI) integration with Portal helps provisioning agent/supervisor to enable WebexCI from Portal. This allows agents/supervisors to use Webex Common Identity Flow to login to Finesse Desktops.
  * **Access product help docs:** You can access help docs from the Portal UI by clicking the help icon (**?**). You can download the feature documentation such as Admin Guide, API Guide, Release Notes, etc. from the Webex CCE Help Center. You can also access additional resources from [_Cisco.com_](https://cisco.com/).


##### Callbacks Finesse gadget enhancements
  * **French language support:** The Portal Callbacks Finesse gadget will offer comprehensive French language support, covering all interface labels, messages, notifications, and callback flows to meet regulatory requirements for French-speaking agents.


##### Features undergoing Angular migration
  * **Change Password and Forgot User Password page changes:** The 'Change Password' and 'Forgot User Password' pages now include options for setting a new password via an external link and contacting a supervisor if email reset fails.
  * **Directory Number Routing page enhancement:** The existing Directory Number Routing page, including its grid and the ability to add new directory number routing, is migrated to Angular.
  * **Agent Desktop and Team Desktop Layout Angular migration:** The 'Agent Desktop Layout' and 'Team Desktop Layout' pages have been migrated to Angular. In addition, the XML editor is added to the Desktop layout. The team desktop layout allows editing the layout at the team level.
  * **Precision Queue Audit:** The Precision Queue Audit page is enhanced with expanding panels that display details of changes made by users.
  * **Schedule Skills Angular migration:** The following pages have been enhanced for a better user experience: 'Add New Attribute Schedule', 'Add Schedule', 'Edit Schedule', and 'Cloning of the Skill Group Schedule'.
  * **Portal callbacks wallboard:** The Portal Callbacks Wallboard page is enhanced to display live callback calls for agents to monitor call queues. This does not include historical data.
  * **Bulk migration of Agents between peripheral gateways:** The Bulk Request page now supports migrating agents from one peripheral to another platform, either individually or by team, automatically identifying agents and their skill groups. This eliminates the need to delete and recreate agents.
  * **Bulk edit of directory numbers:** You can use the bulk edit functionality to select multiple directory numbers for simultaneous changes.
  * **Enhanced Dashboard pages/widgets:** All dashboard widgets are updated with minor UI adjustments for a new look and feel. In addition, the 'Select Dashboard' option is added to help you choose a dashboard when no dashboards are configured.


### February 2026
#### Webex CCE Admin Portal Enhancements
The following portal features are enhanced for better routing control, user management, and improved speed and performance.
  * **Bulk Update for Additional Fields and Columns** - Bulk updates for new additional fields and columns, such as description and custom attributes, will now be supported, enabling users to rename or update information by Line of Business or department in bulk, rather than one at a time.
  * **Bulk Editing of Control Attributes** - Bulk load enhancements will allow editing of control attributes including Control Name, Control Description, Control Value (for number, text, switch, default, datetime, datetime range, percentage, or threshold controls), and Time Zone.
  * **Bulk Upload of Portal Controls** - Users will be able to perform bulk uploads of multiple Portal Controls and their respective value pairs using a single upload sheet, though this functionality will be further evaluated for data risk considerations.
  * **Bulk Management of Access Control Objects** - Administrators and business users will be able to efficiently manage access control objects in bulk, with the ability to add multiple objects at once, search by code names or value key pairs, and make multiple selections.
  * **Encryption Column Type in Table Controls** - Table controls are being enhanced to include an encryption column type, allowing the UI to accept entry but keeping the value hidden in view mode, with all values encrypted at rest.
  * **Enhanced Security Collections and Object Assignment** - The portal’s security collections and object assignment features are being enhanced to allow users to search values on key columns or any of ten columns within the table controls, further streamlining bulk management tasks.
  * **Portal Callbacks VXML Application API Integration** - The Portal Callbacks VXML Application will support robust and highly configurable external API calls to fetch enriched caller data, with the ability to map API responses to call variables before invoking the _createCallbackRequest_ API.
  * **Enhanced Routing Parameter Search** - Administrators and business users will have an improved UI to easily find specific routing parameters, with enhanced search options in the Routing Controls Grid that allow users to search controls by key or column values, in addition to existing filter and sort capabilities.
  * **UI Enhancements for Greater Flexibility** **-** Experience improved usability with these key UI enhancements:
    * Routing Control Code column length increased from 40 to 100 characters.
    * Routing Control Name column length increased from 40 to 100 characters.
    * Collection Name and Access Group Name column lengths increased from 50 to 100 characters.
    * Role Name column length increased 100 characters.
    * HTML tags now supported in the Table Control Key Column and up to 10 columns.
  * **Portal Callbacks to Support Secure Connections** - Portal Callback capabilities are being enhanced to support secure connections across various integration points. Previously, callback server integration used non-secure channels such as:
    * SIP communication (Voice Gateway, SIP Proxy, Call Manager)
    * RTP (Call Manager, Voice Gateway)
The update introduces secure integration for the Finesse Gadget, allowing secure Gadget API calls to the callback server.
Portal Callbacks will now support:
    * Secure PIM connections
    * Secured SIP connections to Call Manager and Voice Gateway
    * Secured RTP (SRTP) to Call Manager and Voice Gateway
Tenant Administrators can enable or disable the Secure Connection feature as needed. The portal callback will support secure PIM connections whenever TLS is enabled for the tenant.
  * **Enhanced Portal Table Control for Flexible Data Handling and Routing Configuration** - The Portal Table Control feature has been enhanced to allow users to enter and upload null values in nullable columns and empty strings in string columns, with all data saved exactly as entered-including during bulk upload or update operations.
This ensures accurate persistence for flexible routing configurations without trimming or altering the data. Users can also download and upload table data in the same format as it was originally entered, supporting consistent and reliable data management.

Cisco Contact Center Enterprise now supports separate Extended Key Usage (EKU) certificates in the Reverse Proxy. You can use one certificate for inbound HTTPS connections from desktop clients and a different certificate for outbound mutual TLS (mTLS) connections to backend services. This feature helps deployments remain compatible with public certificate authority changes that remove client authentication EKU from public TLS certificates. Existing combined-EKU certificates continue to work until they expire, which helps simplify migration to the new configuration.
## Parallel patching support
Parallel patching support will be added to the Patch Install and Rollback Orchestration CLI commands. The CLI will allow selection of all Side A or all Side B nodes by platform.
For VOS, users can select all Side A VOS-based nodes or all Side B VOS-based nodes in the inventory.
For Windows, users can select all Side A Windows-based nodes or all Side B Windows-based nodes in the inventory.
