## Introduction
This document describes how administrators with Compliance Officer role can download individual call recordings for Virtual Lines and Users with API.
## Prerequisites
### Requirements
  * Admin access in Control Hub.
  * Compliance Officer role.


### Components Used
The information in this document is based on these software and hardware versions:
  * Webex Calling.
  * Webex Calling APIs.


The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
### Background Information
In Webex Calling, you can have the option to use Webex as the recording provider for call recordings. This allows you to easily record and store your calls within the Webex platform.
Only administrators with Compliance Officer role can download and permanently delete recordings via API.
This next example explains the steps to download a call recording via API method using the developer documentation [Converged Recordings](https://developer.webex.com/docs/api/v1/converged-recordings "Converged Recordings").
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : For advanced searches or encounter any issues, contact developer support at [Developer Support for Webex](https://developer.webex.com/support "Developer Support for Webex").
## Steps to Download a Call Recording
Step 1. Log in to the [Webex Developer Portal](https://developer.webex.com/ "Webex Developer Portal") with your administrator credentials and search for **Converged Recordings**.
[![Select the Converged Recordings Option](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-00.png "Select the Converged Recordings Option")Select the Converged Recordings Option
Step 2.From the Method list, select the GET request **List Recordings for Compliance officer**.
[![List Recordings for Compliance Officer Option](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-01.png "List Recordings for Compliance Officer Option")List Recordings for Compliance Officer Option
Step 3.In the **Query Parameters** section, enter the parameters for your search and click on the **Run** button to execute the request.
[![Query Parameters and Run Button](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-02.png "Query Parameters and Run Button")Query Parameters and Run Button
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : Use the information on the right pane to get more details of each field, for example, the **locationId** can be obtained from the Webex Control Hub - Locations section.
Step 4. The response displays in the **Response** box. Each individual recording is listed within curly braces **{}** , with the **id** attribute representing the **recordingId**. Copy the results to a text file for reference.
**[![Response Box Elements](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-03.png "Response Box Elements")Response Box Elements**

Step 5. To download a specific recording, go back to the method list and select the GET request, **Get Recording Details**.
[![Get Recording Details.](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-04.png "Get Recording Details.")Get Recording Details.
Step 6. In the GET URL, replace **recordingId** with the actual **id** of the recording you want to download. Then click on the **Run** button to execute the request.
[![Click on the recordingId Button](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/webex-calling/222147-download-call-recordings-through-api-wit-05.png "Click on the recordingId Button")Click on the recordingId Button.

Step 7. The **Response** box contains the results of your search. Copy the output to a text file and identify the **audioDownloadLink** attribute.

Step 8. Copy the entire URL that is under **audioDownloadLink** and paste it into a web browser. Make sure to include all characters between the quotation marks. Press **Enter** to initiate the download. The recording downloads to your machine as an MP3 file.
