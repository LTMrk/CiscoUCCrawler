# אפליקציית Webex | מדריך לשילוב Microsoft OneDrive ו-SharePoint Online
![list-menu](https://help.webex.com/images/list-menu.svg)במאמר זה
![list-menu](https://help.webex.com/images/feedback.svg)משוב?
## סיכום
שילוב אפליקציית Webex עם Microsoft OneDrive ו-SharePoint Online מעניק למשתמשים את היכולת לשתף ולגשת לתוכן המאוחסן ב-Microsoft OneDrive וב-SharePoint Online ישירות מתוך אפליקציית Webex.
מנהל מערכת יכול לבחור לתת (להגדיר, לאפשר ולאשר) את האינטגרציה עבור הארגון שלו. ראה [אספקת ניהול תוכן](https://help.webex.com/he-il/na9del2).
לאחר ביצוע שלב הקצאת המשאבים עבור הארגון, כל משתמש חייב להעניק באופן עצמאי אישור לאפליקציית Webex לגשת ל-OneDrive. and/or SharePoint Online מטעמם. 
זה מאפשר למשתמש לעבוד עם תוכן של Microsoft OneDrive ו-SharePoint Online מתוך אפליקציית Webex. על המשתמשים לקרוא את [אפליקציית Webex | Microsoft OneDrive ו-SharePoint Online](https://help.webex.com/he-il/rkbwmu).
## אימות והרשאה
האינטגרציה בין אפליקציית Webex לבין Microsoft Azure או Office 365 ממוקדת לחלוטין באפליקציה. כל ממשקי ה-API של Microsoft Cloud (OneDrive או SharePoint Online) נקראים ישירות מאפליקציית Webex. ממשקי API אלה מוגנים על ידי OAuth2 ודורשים אסימון גישה כדי לגשת אליהם באופן מאובטח.
כדי לקבל אסימון גישה, על המשתמשים תחילה לאמת ולאחר מכן לאשר את אפליקציית Webex. אסימון הגישה שהונפק נשלח לאחר מכן בכותרת ההרשאה עבור כל שיחת API ל - Microsoft OneDrive או ל - SharePoint Online. כל שיחות ה - API מתבצעות באמצעות HTTPS. לקבלת מידע נוסף, עיין _בסעיף פניות_ שימוש במאמר זה.
קובצי Cookie של הפעלה ואסימוני רענון המונפקים כחלק מאימות והרשאה מוצפנים ומאוחסנים בצורה מאובטחת במכשיר אפליקציית Webex של המשתמש. לא ייחשף לעולם מידע אימות או הרשאה הקשור למשתמש עבור OneDrive או SharePoint Online לשירותי הענן של Webex. למידע נוסף על אחסון במטמון של אפליקציות Webex, ראה [פעולות טכנולוגיה ואבטחה - שאלות נפוצות ](https://www.cisco.com/c/dam/en/us/td/docs/voice_ip_comm/cloudCollaboration/spark/esp/Webex-Teams-Security-Frequently-Asked-Questions.pdf).
## שימוש ואחסון נתונים
כדי לשתף מסמך, להציג תמונה ממוזערת של מסמך או לצפות בתצוגה מקדימה של מסמך מ-Microsoft OneDrive או SharePoint Online, אפליקציית Webex משתמשת במזהה הכונן, במזהה הפריט, בכותרת המסמך ובכתובת URL מוחלטת או משותפת של המסמך. נתונים אלה מאוחסנים בענן Webex עבור כל מסמך המשותף באמצעות אפליקציית Webex. התוכן של קובץ Microsoft OneDrive או SharePoint Online המשותף במרחב של אפליקציית Webex, לעולם לא יאוחסן בענן Webex.
מתייחסים לנתונים שאנו מאחסנים הקשורים למסמכים כאל מידע רגיש. אפליקציית Webex תמיד מצפינה נתונים רגישים (כגון מזהה כונן, מזהה פריט, כותרת מסמך או קישורים) לפני שליחתם לענן Webex. המשמעות היא שרק נתוני מסמכים מוצפנים נשלחים או מאוחסנים בשירותי הענן של Webex.
לצורך הצפנת נתונים, אפליקציית Webex משתמשת בשירות ההצפנה של Webex Cloud. ניהול מפתחות מסופק על ידי שרת ניהול מפתחות הענן (KMS), או, אם תבחר לפרוס את אבטחת הנתונים ההיברידית, על ידי KMS משלך. לקבלת מידע נוסף, ניתן לעיין ב נייר האבטחה של אפליקציית [Webex](https://www.cisco.com/c/dam/en/us/td/docs/voice_ip_comm/cloudCollaboration/spark/esp/cisco-spark-security-white-paper.pdf).
אפליקציית Webex שומרת נתונים באופן עצמאי במטמון באופן מקומי במכשירי המשתמש. נתונים אלה מוצפנים במנוחה במכשיר. למידע נוסף על אחסון במטמון של אפליקציות Webex, ראה [פעולות טכנולוגיה ואבטחה - שאלות נפוצות ](https://www.cisco.com/c/dam/en/us/td/docs/voice_ip_comm/cloudCollaboration/spark/esp/Webex-Teams-Security-Frequently-Asked-Questions.pdf).
למרות שהדייר שלך עשוי להשתמש ביכולות מרובות גיאוגרפיות ב-Office 365 כדי לאחסן נתונים במיקום ספציפי, אפליקציית Webex מאחסנת נתונים רק במרכזי הנתונים שלה. למידע נוסף המתייחס למיקומי מרכז הנתונים של Webex ראה סעיף 3 בגיליון פרטיות השירותים של [Cisco Webex](https://www.cisco.com/c/dam/en_us/about/doing_business/trust-center/docs/cisco-webex-teams-privacy-data-sheet.pdf).
## משרד 365 תמיכה בדיירים
דייר Office 365 יחיד יכול להיות מוגדר עבור ארגון סיסקו וובקס יחיד. אנחנו תומכים רק במופע הממשלתי העולמי והמתון של משרד 365. מופעים אחרים שאנחנו לא תומכים בהם כוללים: USGovDoD, USGovGCCHigh, סין וגרמניה.

## שימוש בממשק API של Microsoft
אפליקציית Webex משתמשת בממשקי API מ-Azure Active Directory (AD) גרסה 2 ומ-Microsoft Graph. Azure AD משמש להרשאת משתמש קצה. Microsoft Graph משמש לגישה למסמכי Microsoft OneDrive ו - SharePoint. למרות שממשקי API אלה תומכים במגוון רחב של פעולות, רק קבוצת משנה של פקודות נמצאת בשימוש.
### נקודות קצה של Azure AD v2  
|  ספריית Azure Active V2  |  שימוש  |
