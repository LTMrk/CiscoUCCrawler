# Webex-App | kann Unterhaltungen mit Threads einfacher folgen
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Wenn man in einem geschäftigen Umfeld arbeitet, ist es manchmal schwierig, den Überblick über die Kommentare der Leute zu behalten. Um bestimmte Konversationen leichter verfolgen zu können, können Sie auf die Nachricht einer anderen Person antworten, indem Sie einfach einen neuen Nachrichtenthread starten oder auf einen bereits bestehenden antworten. 
  * [Desktop](https://help.webex.com/de-de/article/nvrq4ycb/Webex-App-%7C-kann-Unterhaltungen-mit-Threads-einfacher-folgen#id_108151)
  * [Mobil](https://help.webex.com/de-de/article/nvrq4ycb/Webex-App-%7C-kann-Unterhaltungen-mit-Threads-einfacher-folgen#id_111212)
  * [Internet](https://help.webex.com/de-de/article/nvrq4ycb/Webex-App-%7C-kann-Unterhaltungen-mit-Threads-einfacher-folgen#Cisco_Task.dita_8be7575b-fa98-4890-ae2c-a57b0c89ae1f)

  
|  Bewegen Sie den Mauszeiger über die Nachricht oder die Datei und klicken Sie auf Einen Thread starten ![Symbol zum Erstellen eines Threads](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/470001-480000/475001-476000/475727.jpg). Nachdem Sie den Thread erstellt haben, können Sie oder jeder andere Teilnehmer im Bereich eine Antwort auf diesen Thread hinzufügen. Klicken Sie dazu auf Antwort ![Symbol zum Erstellen eines Threads](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/470001-480000/475001-476000/475727.jpg).  Nachdem Sie oder jemand anderes auf einen Thread geantwortet hat, können Sie den Thread ausblenden. Klicken Sie dazu auf Ausblenden![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/470001-480000/475001-476000/475729.jpg). Wenn jemand auf einen Thread antwortet, sehen Sie eine Benachrichtigung im Bereich, in der Sie die neuen Antworten hervorheben können.  |  
| --- |  
|  Drücken Sie lange auf die Nachricht, und wählen Sie Thread beginnen. Ein neues Thread-Fenster wird geöffnet. Nachdem Sie den Thread erstellt haben, können Sie oder eine andere Person im Bereich diesem Thread eine Antwort hinzufügen, die Nachricht berühren und halten und dann Antwortenwählen. Sie können auf Ihrem iOS-Devce nach rechts wischen, um schnell einen Nachrichtenthread zu starten oder darauf zu antworten.  |  
| --- |  
|  Bewegen Sie den Rechten über die Nachricht oder Datei, und klicken Sie auf Thread starten. Nachdem Sie den Thread erstellt haben, können Sie oder eine andere Person im Bereich eine Antwort zu diesem Thread hinzufügen, klicken Sie auf ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/435001-436000/435413.jpg).  |
