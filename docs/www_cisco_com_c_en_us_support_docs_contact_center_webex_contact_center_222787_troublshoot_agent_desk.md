## Introduction
This document describes how to capture networking logs on agent's PC while troublshooting Agent Desktop disconnect problem.

  * WxCC 2.0

## Problem Descritpion
  
Agents complain that they see their Agent Desktop losing internet connection.
[![2025-02-26_10h14_13](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-00.png "2025-02-26_10h14_13")
## Troublshooting 
**Step 1. Collect Error report.**
You can do it while the Agent Desktop is reconnected or has lost connection.
[![2025-02-26_08h24_01](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-01.png "2025-02-26_08h24_01")
You can also collect the Error Report after the Agent Desktop reestablishes the connection.
[![2025-02-26_10h37_38](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-02.png "2025-02-26_10h37_38")
**Step 2. Understand how the keepalives are sent and received by the Agent Desktop.**
There are keepalive messages from the Agent Desktop Application to the backend every 4 seconds. In parallel, there are keepalive messages from the Notifs (backend) to the Agent Desktop.
[![2025-02-26_10h47_05](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-03.png "2025-02-26_10h47_05")
If there are no completed messages for 16 seconds either from the Agent Desktop or from the notifications, the system starts the recovery process.
Then the application tries to reestablish the connection during the time specified in the Desktop Lost Connection Recovery Timeout settings.
[![2025-02-26_10h55_30](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-04.png "2025-02-26_10h55_30")
**Step 3. Understand the indications of the problem that you can detect from the Agent Desktop logs.**
  * Agent Desktop stopped sending keepalive messages to Notifs (backend). To troubleshoot, you need to start by checking the browser, PC, and Webex Tenant configurations to ensure this is not expected behavior. Refer this article to prevent your browser or PC from stopping sending keepalive messages according to the configurations: <https://www.cisco.com/c/en/us/support/docs/contact-center/webex-contact-center/220319-configure-environment-to-prevent-agent-d.html>


If the problem is still happening after you configure your environment to prevent disconnection, it could still be a networking issue, and the IT department needs to be engaged to troubleshoot networking problems.
[![2025-02-26_11h06_50](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-05.png "2025-02-26_11h06_50")
  * Agent Desktop stopped receiving messages from the notifications, or messages from notifications are coming with delays or out of order. This points to networking issues, and as the next step, the customer's IT department needs to be engaged to help monitor networking browser logs, and collect packet captures from the agent's PC and network devices.


[![2025-02-26_11h01_30](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-06.png "2025-02-26_11h01_30")
**Step 4. Review the browser logs to find the WebSocket live messages.**
Inspect the Agent Desktop space, click on Network, filter by WS, and find the messages with the domain **api.wxcc-(dc).cisco.com** under the Response tab, you can see the keepalive message flow.
[![2025-02-26_12h19_30](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-07.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-07.png "2025-02-26_12h19_30")
**Step 5. Collect IP addresses that could be related to the WebSocket connection.**
Open up a terminal and use the **nslookup** command to find related IP addresses to**api.wxcc-(dc).cisco.com** domain. 
[![2025-02-26_12h25_23](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-08.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-08.png "2025-02-26_12h25_23")
**Step 6. Capture and review networking logs.**
Capture networking logs using Wireshark or any other networking tools that you are comfortable with.
Filter the logs by the IP addresses collected in Step 5, and filter for messages between your PC and any of those IP addresses. These messages are keepalives between the Agent Desktop and notifications, and vice versa.
### [![2025-02-26_12h32_12](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-09.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/222787-troublshoot-agent-desktop-disconnect-iss-09.png "2025-02-26_12h32_12")
**Step 7. Capture logs on netwokring devices.**
You would also need to capture the logs on your networking devices, such as routers, firewalls, or L3 switches, to troubleshoot why keepalives are not flowing properly.
