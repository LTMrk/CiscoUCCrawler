## Introduction to Webex Contact Center with Google CCAI 
The Webex Contact Center with Google CCAI is the integration that allows the use of Google Text-To-Speech, Natural Language Understanding and **Virtual Agent** technologies with Webex Contact Center.
**Dialogflow CX** is designed for building complex, multi-turn conversations that involve multiple steps and decision points. It provides tools for creating conversational flows, managing context, handling user intents and entities, and integrating with other applications. Think of conversations that have many turns and where you want to track the interaction content very deeply. These types of conversations typically happen on the phone line to a Contact Center where people ask all types of questions, and the **Virtual Agent** needs to listen in and provide the answers. It does not mean that you cannot build complex flow using Dialogflow Essentials, which is another version of Dialogflow, but you would need to use a lot of code around it to build a whole framework to achieve complicated logic. But with Dialogflow CX flow builder interface it is no longer the case as the graphical interface lets developers design and build conversational AI applications without requiring extensive coding skills.
Webex Contact Center now supports **Dialogflow CX** integration and using this article, you can configure and test the solution.
The integration requires you to do configuration in multiple portals: Google Cloud Platform and **Google Dialogflow CX** , Webex Control Hub, and Webex Contract Center.

## Configure Dialogflow CX Virtual Agent
### Objectives
This section describes how to configure the **Virtual Agent** to have a conversation with a caller and decide whether to send the call directly to the queue with human agents or collect estimate information and send the data to the **Analyzer** report.
In the next screenshot, you can see a functional diagram of the flow for this section.
[![2023-12-27_10h47_01](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-14.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-14.png "2023-12-27_10h47_01")
### Task 1. Navigate to Dialogflow CX Agent flow builder and customize the initial greeting.
Step 1. Log in to [Dialogflow CX](https://dialogflow.cloud.google.com/cx%20) portal using your user account and password. Select project **CL2024AMS**.
Step 2. Select the **Virtual Agent** that you created earlier.
[![2023-12-23_22h38_41](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-15.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-15.png "2023-12-23_22h38_41")
Step 3. In the Dialogflow CX builder click on the Start page.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : In Dialogflow CX, a page is a set of instructions that holds one or more related conversational turns. It represents a single step in a conversation flow, and it can contain various types of content, including text responses, prompts for user input, fulfillment actions, and more. Pages are connected together to create a conversation flow that guides the user through a conversation with the Dialogflow CX agent.
_[![2023-12-23_22h39_19](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-16.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-16.png "2023-12-23_22h39_19")_
Step 4. In the **Start** page click on **Default Welcome Intent Route**. On the right window, scroll down, delete all the default Agent responses, and click on the field to **Enter** agent dialog.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : A route is a mapping between an intent and a specific page or flow within a conversation. Routes define how a conversation can flow based on the user input and the intent that is matched.
[![2023-12-23_22h40_10](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-17.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-17.png "2023-12-23_22h40_10")
Step 5. Provide your customized message to let the caller know that they reached an organization that provides sales services of Webex Contact Center. You can type something like: Hello! Thank you for calling. Here you know all about Webex Contact Center. In Dialogflow CX, the changes are not saved automatically, so you need to save the page every time you make a change.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : Agent responses are the messages or actions that an agent sends back to the user or caller during a conversation. When a user or caller sends a message or makes a request to a Dialogflow CX agent, the agent analyses the input and determines the appropriate response to send back.
_[![2023-12-23_22h40_56](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-18.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-18.png "2023-12-23_22h40_56")_
Step 6. Test the agent response that you just created. Click **Test Agent** and type a greeting message such as Hello.
[![2023-12-23_22h44_11](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-19.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-19.png "2023-12-23_22h44_11")
### Task 2. Create new page to collect the caller name
Step 1. Close the **Start** page and **Test Agent** windows and click the plus icon (**+**) to create a new page. Name the page **Caller_Name** and confirm the creation.
[![2023-12-23_22h46_25](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-20.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-20.png "2023-12-23_22h46_25")
Step 2. Connect the **Start** page and **Caller_Name** page. For this, click the **Default Welcome Intent** route on the **Start** page. Scroll down on the right side and select that you would like the conversation to go to the next page.
[![2023-12-23_22h47_09](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-21.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-21.png "2023-12-23_22h47_09")
Step 3. From the drop-down list, select **Caller_Name** page. Do not forget to **Save** the change.
[![2023-12-23_22h47_44](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-22.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-22.png "2023-12-23_22h47_44")
Step 4. Configure the **Caller_Name** page to collect the name from the caller and store it in the parameter. In the **Caller_Name** page click **Entry Fulfillment** and type message in which you ask the caller name. Click **Add** and **Save** the change.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : **Entry Fulfillment** is needed to provide a message to the caller once the call is moved to a new page to let the caller know where they are in the conversation and set the right expectations.
[![2023-12-23_22h48_24](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-23.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-23.png "2023-12-23_22h48_24")
Step 5. While on the **Caller_Name** page, click on **Parameters** , type **Name** as the parameter’s name, select **`sys.any `**from the list of preconfigured Entities, and click on**Save**.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : A **Parameter** is a named entity or value that is extracted from user input during a conversation. Parameters can be used to store information that is relevant to the user request, such as their name, date of birth, or preferred language. Parameters can also be used to pass data to other parts of your application such as Contact Center.
[![2023-12-23_22h49_33](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-24.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-24.png "2023-12-23_22h49_33")
Step 6. Configure **Routes** in the **Caller_Name** page. Click **Route** , on the right window scroll down to **Condition** and set the condition **`$page.params.status ="FINAL"`**. Click**Save**. By setting this condition, you can expect the call to move to the next page once the **Name** parameter which you created in the previous step is filled with a value. For example, if the caller says Nick then the call can move forward. 
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : A **Condition** in the Dialogflow Routes configuration is a rule or set of rules that define when the route must be triggered. The **Condition** can be based on various factors such as user input, context, parameters, and session data.
[![2023-12-23_22h50_16](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-25.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-25.png "2023-12-23_22h50_16")
Step 7. Using the **Test Agent** option on the right top side, test if the flow is working as designed at this point.
[![2023-12-23_22h51_16](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-26.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-26.png "2023-12-23_22h51_16")
### Task 3. Create new page Agent_or_Estimate and connect it with the Caller_Name page.
Step 1. On the left bottom side, click to add a new page, name it **Agent_or_Estimate** , and confirm the creation.
[![2023-12-23_22h52_03](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-27.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-27.png "2023-12-23_22h52_03")
Step 2. Connect **Caller_Name** and **Agent_or_Estimate** pages. Open the **Caller_Name** page, and select the route that you created in the previous step, on the right side scroll down and select the page **Agent_or_Estimate**. Do not forget to **Save** the change.
Remember in Task 2 of this section you configured the condition that once the parameter is filled it triggers an action. By selecting the next page you specify what action it is, in this example the call moves to the page **Agent_or_Estimate**.
[![2023-12-23_22h52_45](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-28.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-28.png "2023-12-23_22h52_45")
Step 3. Configure **Entry Fulfillment** for **Agent_or_Estimate** page. Open up **Agent_or_Estimate** page, and click **Entry Fulfillment**. In the Agent response type: Hi $session.params.Name, please let me know if you would like to speak with an agent or if you would to create an estimate?
Do not forget to **Save** the change.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : If you cannot copy and paste the suggested fulfillment just start typing in the **Agent Response** field, then you can paste the text, then delete unnecessary text.
[![2023-12-23_22h54_20](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-29.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-29.png "2023-12-23_22h54_20")
Step 4. Test if the conversation flow is configured properly at this point. Click **Test Agent** and in the **Talk to Agent** field type Hello and then type your name.
[![2023-12-23_22h55_05](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-30.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-30.png "2023-12-23_22h55_05")
### Task 4. Configure Route in Agent_or_Estimate page to move the call to new page What_Kind_Of_Agent.
Step 1. Open up the **Agent_or_Estimate** page, click on **Create New Route** , and then click on **Create New Intent**.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : An intent is a mapping between what a user says or types and a specific action or response that the conversational agent can take. Intents help the agent understand the user request and determine the appropriate response or action to take.
[![2023-12-23_22h55_56](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-31.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-31.png "2023-12-23_22h55_56")
Step 2. Name the **Intent Agent_intent**. Provide 3-5 training phrases, something like agent, representative, escalate, real person. Do not forget to save the change of the page.
[![2023-12-23_22h56_39](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-32.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-32.png "2023-12-23_22h56_39")
Step 3. Create new page and name it **What_Kind_Of_Agent** .
[![2023-12-23_22h57_12](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-33.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-33.png "2023-12-23_22h57_12")
Step 4. Click on **Agent_or_Estimate** page. Add a new **Route** , select the **Intent**.
[![2023-12-23_22h57_50](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-34.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-34.png "2023-12-23_22h57_50")
Step 5. On the **Routes** settings scroll down and select action to move the call to the page **What_Kind_Of_Agent**.
[![2023-12-23_22h58_23](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-35.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-35.png "2023-12-23_22h58_23")
Step 6. For a better communication experience you need to add no-input-default **Event handlers** otherwise the system detects no input even before you have a chance to provide input. While on the **Agent_or_Estimate** page, click on **Add state handler** , select **Event handlers** , and click on **Apply**.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : An **Event handlers** is a type of intent that is triggered when a specific event occurs. For example, if the **Virtual Agent** does not receive any input or it does not recognize the input, the event handler is used to trigger no-input intent which helps to continue the conversation.

Step 7. Click on **Add New Event handlers** , select from the **No-input default** list and save the change.
[![2023-12-23_22h59_34](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-37.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-37.png "2023-12-23_22h59_34")

[![2023-12-23_23h00_31](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-38.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-38.png "2023-12-23_23h00_31")
Step 2. Name the intent as **Estimate_Intent** and provide some training phrases. As for the training phrases you can add statements like estimate, price calculation, I need to know how much it cost. Save the intent.
[![2023-12-23_23h01_08](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-39.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-39.png "2023-12-23_23h01_08")
Step 3. Create new page with the name **Estimate_Details**. Connect **Agent_or_Estimate** and **Estimate_Details** pages when **Estimate_Intent** is triggered.
[![2023-12-23_23h01_43](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-40.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-40.png "2023-12-23_23h01_43")
Step 4. Click the **Agent_or_Estimate** page. Add new **Route** , and select the **Intent Estimate_Intent**.
[![2023-12-23_23h02_22](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-41.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-41.png "2023-12-23_23h02_22")
Step 5. Scroll a bit down and add the agent response that the caller hears once the **Estimate_Intent** is triggered. You can type something like, let me collect some information for the estimate.
[![2023-12-23_23h03_07](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-42.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-42.png "2023-12-23_23h03_07")
Step 6. Scroll all the way down and select the transaction to the page **Estimate_Details** once the intent is triggered. Save the page configuration.
[![2023-12-23_23h03_39](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-43.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-43.png "2023-12-23_23h03_39")
### Task 6. Configure Estimate_Details page with Parameters and Route
Step 1. Similar to how you created the **Parameter** for the caller name, create the **Parameter** for the number of agents which the caller needs the estimate for. Click on the **Estimate_Details** page, add the **Parameter** , name it **Number_of_agents** , and select from the list the standard **Entity** type **`sys.number`**. Do not forget to save the change.
[![2023-12-23_23h04_25](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-44.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-44.png "2023-12-23_23h04_25")
Step 2. Configure the **Entry Fulfillment** for the caller to understand what information the **Virtual Agent** is looking for. You can type something like, please let me know how many agents you are planning to have in your Contact Center.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : If you cannot copy and paste the suggested fulfillment just start typing in the **Agent Responses** field, then you can paste the text, then delete unnecessary text.
[![2023-12-23_23h04_55](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-45.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-45.png "2023-12-23_23h04_55")
Step 3. Select the condition which triggers the action on the **Estimate_Details** page. While on the **Estimate_details** page, click on add new **Route** , on the right window scroll down a bit and configure the condition `**$page.params.status =“FINAL”**`.
[![2023-12-23_23h05_26](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-46.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-46.png "2023-12-23_23h05_26")
Step 4. Scroll more down and add the **Virtual Agent** response. Type: I am putting together the estimate request details for `**$session.params.Number_of_agents**`agents.
[![2023-12-23_23h06_08](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-47.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-47.png "2023-12-23_23h06_08")
Step 5. Add dialogue option and select **Custom payload** from the list.
[![2023-12-25_11h32_46](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-48.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-48.png "2023-12-25_11h32_46")
Post this next syntax to the **Custom** **payload** section and save the configurations.

```
{  
  
  "Execute_Request": {  
  
    "Data": {  
  
      "Params": {  
  
        "Estimate_Agents_Count": "$session.params.Number_of_agents"  
  
      }  
  
    }  
  
  }  
  
}
```

## Configure Flow with Virtual Agent in Webex Contact Center Management Portal
### Objectives
In this section, you can see how to build flow in Webex Contact Center Flow Builder with the **Virtual Agent** block which moves the call to queue with live agents or to estimate branch where data about the number of agents for the estimate can be extracted and used for **Analyzer** report. 
### Task 1. Create new flow.
Step 1. In the Webex Contact Center Admin portal open up the **Routing Strategy Module** and **Create New Flow** entry window.
[![2023-12-25_11h45_58](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-66.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-66.png "2023-12-25_11h45_58")
Step 2. Call the flow **`{Your Name}_Virtual_Agent_Flow`**.
[![2023-12-25_11h46_25](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-67.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-67.png "2023-12-25_11h46_25")
### Task 2. Configured Handled path to extract estimate data for the Analyzer report.
Step 1. Move the **Virtual Agent V2** to the flow and connect it with the **NewPhoneContact** block.
[![2023-12-25_11h46_58](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-68.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-68.png "2023-12-25_11h46_58")
Step 2. Click on **Virtual Agent V2** block and under the block settings select **Contact Center AI Config** which you created earlier or use the preconfigured **Virtual Agent** **`Dan_User1_Virtual_Agent`**. Also, click**Advanced Settings** and increase the **Termination Delay** time from 3 to 5 seconds.
[![note-icon](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif)](https://www.cisco.com/c/dam/en/us/td/i/templates/note.gif "note-icon")
**Note** : **Termination Delay** is the time range that must be set to allow completion of the audio prompt from the **Virtual Agent** in Dialogflow before the contacts move to the Webex Contact Center. For example, if in Dialogflow VA config there is a long response before the call goes to **Live agent handoff** , it cuts the response not finished and the call moves to the queue.
[![2023-12-25_11h47_31](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-69.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-69.png "2023-12-25_11h47_31")
Step 3. (Informational only) Understand how the call-related data is moving from Dialogflow to Webex Contact Center.
When the conversation is transferred from Dialogflow to WxCC, it creates some output variable with data in JSON format which has been generated in the Dialogflow portal while the caller was interacting with the **Virtual Agent**. One of the output variables is **VirtualAgentV2.MetaData**. You can see it by clicking anywhere on the grey area in the **Flow Builder** and scroll down on the right window. This output variable contains the data you specified in the **Custom payload**.
[![2023-12-25_11h48_04](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-70.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-70.png "2023-12-25_11h48_04")
The goal here is to extract the information about how many agents the caller requested for the estimate. In the previous section, you have created the parameter with the name **Number_of_Agents**.
[![2023-12-25_11h48_43](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-71.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-71.png "2023-12-25_11h48_43")
And you configure the **Route** with **Custom payload** where once the parameter is filled, the value of the parameter is assigned to the key **Estimate_Agents_Count** and then the call is moved to WxCC side.
[![2023-12-25_11h49_14](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-72.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-72.png "2023-12-25_11h49_14")
Step 4. Configure **Virtual Agent Handled** path to extract the estimate data and associate it with **Global Variable**. By parsing JSON data from the **VirtualAgentV2_MetaData** variable you can extract the value of the **Number_of_Agents** parameter value and assign it to the new variable on the WxCC environment. You also want the variable to be reportable, so you need to use a **Global Variable**. While in WxCC flow builder, cick anywhere on the grey area, and on the right window click on **Add Global Variable**.
[![2023-12-25_11h49_48](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-73.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-73.png "2023-12-25_11h49_48")
The **Global Variable** **Estimate_Number_of_Agents** needs to be created earlier in the WxCC Admin Portal. Then you just need to select it and click Add. This makes this **Global Variable** available for you to use in your flow. 
[![2023-12-25_11h50_19](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-74.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-74.png "2023-12-25_11h50_19")
Step 5. Add the **Parse** node. In the **Parse** node select **VirtualAgentV2.MetaData** as the **Input Variable** , select from the list the **Global Variable** you added to the flow in the previous step as the **Output Variable** , and use this next string to parse the JSON data **`$.Params.Estimate_Agents_Count`**.
[![2023-12-25_11h50_52](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-75.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-75.png "2023-12-25_11h50_52")
Step. 6. Use the **Play Message** node to validate the result and notify the caller. Add the **Play Message** node, **Enable Text-to-Speech** feature, select the TTS connector and choose **Output Voice** from the list.
[![2023-12-25_11h51_27](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-76.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/webex-contact-center/221526-configure-dialogflow-cx-virutal-agent-76.png "2023-12-25_11h51_27")
Step 7. Add **Disconnect Contact** node. Then click in the **Play Message** again, and add this Text-to-Speech Message, in the TTS field type, thank you. The estimate request for **{{Estimate_Number_of_Agents}}** agents was created, and your team can reach out to you soon with the results.
