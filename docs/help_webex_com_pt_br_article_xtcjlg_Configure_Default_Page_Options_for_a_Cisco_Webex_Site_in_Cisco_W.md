## Alterar a página padrão
Os administradores do site podem especificar a página que aparece quando os usuários se ins sign in. Os usuários podem substituir essas configurações e selecionar uma página padrão em seus perfis Meu Webex.  
| 1  |  Faça login no Control Hub [https://admin.webex.com](https://admin.webex.com/login), acesse Serviços > Reuniãoe selecione Sites.  |  
| --- | --- |  
| 2  |  Clique no site do Webex e selecione a guia Configurações.  |  
| 3  |  Na seção Reuniões, clique em Opções do Site. Existem outros links Opções padrão para configurar páginas padrão para serviços de suporte, treinamento ou eventos (clássicos) em seu site.  |  
| 4  |  Selecione a página Padrão a ser exibida da página lista suspensa:
  * Para reuniões Webex, escolha entre Participar de uma reunião não listada, Minhas reuniões agendadasou Iniciar uma reunião instantânea. Para excluir a de que a lista de reuniões apareça no site, vá para a seção Configurações comuns e selecione Segurança. Role até o serviço para alterar e desmarcar Todas as sessões devem estar não listadas.
  * Para eventos Webex, escolha entre Participar de evento não listado, Agendar um eventoou Eventos do site.
  * Para treinamento Webex, escolha entre Participar de uma sessão não listada ou Iniciar uma sessão instantânea.
  * Para suporte do Webex, a Página inicial é a página padrão do site.

 |  
| 5  |  Clique em Salvar.  |  
## Alterar a página de encerramento da sessão para reuniões Webex
Você pode alterar a página inicial que é exibida para as pessoas quando a sessão do Webex delas termina. O Webex pode exibir páginas diferentes para anfitriões e participantes.  
| 1  |  Faça login no Control Hub [https://admin.webex.com](https://admin.webex.com/login), acesse Serviços > Reuniãoe selecione Sites.  |  
| --- | --- |  
| 2  |  Clique no site do Webex e selecione a guia Configurações.  |  
| 3  |  Na seção Reuniões, clique em Opções do Site.  |  
| 4  |  Altere a opção Página de destino padrão do host para mostrar Usar página personalizada.  |  
| 5  |  No campo URL, insira o URL da página a ser exibida aos hosts quando as sessões terminarem.  |  
| 6  |  Altere a opção Página de destino padrão do participante para mostrar Usar página personalizada.  |  
| 7  |  No campo URL, insira o URL da página a ser exibida aos participantes quando as sessões terminarem.  |  
| 8  |  Clique em Salvar.  |  
## Outras opções de local para reuniões  
|  Opção   |  Descrição   |  
| --- | --- |  
|  Página de destino do organizador padrão  |  Especifica a página para exibir aos organizadores da reunião quando as reuniões terminam. Escolha entre as seguintes opções: 
  * Use a página padrão da marca Webex: para exibir a página Webex padrão. Para exibir conteúdo promocional para testes Webex gratuitos, clique em Mostrar conteúdo promocional. 
  * Use a página personalizada: Digite a URL de outra página a exibir para organizadores quando as reuniões terminam. Você não precisa do protocolo (ex: `https://`) na URL.

 |  
|  Página de destino do convidado padrão  |  Especifica a página para exibir aos convidados da reunião quando as reuniões terminam. Escolha entre as seguintes opções: 
  * Use a página padrão da marca Webex: para exibir a página Webex padrão. Para exibir conteúdo promocional para testes Webex gratuitos, clique em Mostrar conteúdo promocional. 
  * Use a página personalizada: Digite a URL de outra página a exibir para convidados quando as reuniões terminam. Você não precisa do protocolo (ex: `https://`) na URL.

 |  
|  Entrar na página  |  Para exibir conteúdo promocional para testes Webex gratuitos na página que organizadores e convidados usam para entrar em reuniões, clique em Mostrar conteúdo promocional.   |  
|  E-mail de convite  |  Para exibir conteúdo promocional para testes Webex gratuito em e-mails de convite, clique em Mostrar conteúdo promocional.   |  
|  Guia de Informações na reunião  |  Permite a exibição de uma mensagem "verde", que diz "Obrigado por trabalhar pela reunião on-line".   |  
|  Gravar automaticamente todas as sessões usando a gravação baseada em rede  |  Permite a gravação automática de todas as sessões usando a gravação baseada em rede (NBR).  Essa funcionalidade só está disponível se você tiver a função de gravação ativada no site.   |  
|  Permitir que o organizador use os controles da gravação durante a gravação automática  |  Permite que o host use controles de gravação, como Parar ou Pausar durante uma reunião com gravação automática ativada.  |  
|  Permitir que os hosts reatribuam, editem, desabilitem e excluam gravações.  |  Permite que os anfitriões gerenciem as gravações de todas as sessões.  |  
|  Enviar uma notificação por e-mail ao organizador quando o conteúdo da reunião estiver pronto  |  Especifica se deseja que o site envie um e-mail aos servidores quando as gravações estiverem prontas. Não use se a opção Gravar automaticamente todas as sessões estiver ativada.   |  
|  Habilitar Manter a teleconferência em atividade  |  Permite que a teleconferência continue após o anfitrião terminar a reunião.   |  
|  Configuração padrão  |  Habilitar ou desabilitar um valor padrão para a configuração Manter a teleconferência em vida.   |  
|  Permitir que o organizador da reunião saia da reunião sem terminá-la   |  Especifica se as reuniões terminam automaticamente quando o organizador sai.  |  
|  Exibir a tag de usuário interno na lista de participantes  |  Alterna a exibição do indicador "Interno" ao lado dos nomes dos participantes da sua organização na lista de participantes.  |
