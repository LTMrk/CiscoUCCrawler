# Optionen für Standardseiten und Webex Meetings-Seiten in Control Hub konfigurieren
![list-menu](https://help.webex.com/images/list-menu.svg)In diesem Artikel
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Mit Control Hub können Sie konfigurieren, was die Benutzer sehen, wenn sie sich bei Ihrer Webex Meetings - Website anmelden. Sie können außerdem konfigurieren, was die Benutzer am Ende der Sitzung sehen, sowie einige weitere Standardoptionen . 
  * [Standardseite ändern](https://help.webex.com/de-de/article/xtcjlg/Optionen-f%C3%BCr-Standardseiten-und-Webex-Meetings-Seiten-in-Control-Hubkonfigurieren#id_86528)
  * [Ändern der Sitzungsendseite für Webex Meetings](https://help.webex.com/de-de/article/xtcjlg/Optionen-f%C3%BCr-Standardseiten-und-Webex-Meetings-Seiten-in-Control-Hubkonfigurieren#WebEx_TK_C3F43D97_00)
  * [Weitere Optionen für Tagungsorte](https://help.webex.com/de-de/article/xtcjlg/Optionen-f%C3%BCr-Standardseiten-und-Webex-Meetings-Seiten-in-Control-Hubkonfigurieren#WebEx_RF_S931BB2B_00)


## Standardseite ändern
Site-Administratoren können die Seite festlegen, die nach der Benutzer-Anmeldung angezeigt wird. Benutzer können diese Einstellungen überschreiben und eine Standardseite in ihren Mein Webex-Profilen auswählen.  
| 1  |  Melden Sie sich bei Control Hub [https://admin.webex.com](https://admin.webex.com/login)an und gehen Sie zu Dienste. > Treffen, und wählen Sie Standorte.  |  
| --- | --- |  
| 2  |  Klicken Sie auf die Webex-Website und wählen Sie dann die Registerkarte Einstellungen aus.  |  
| 3  |  Klicken Sie im Abschnitt Meetings auf Site-Optionen. Es gibt weitere Standardoptionen -Links, um Standardseiten für Support-, Schulungs- oder Veranstaltungsdienste (Klassisch) auf Ihrer Website zu konfigurieren.  |  
| 4  |  Wählen Sie die Standardseite aus, die in der folgenden Drop-down-Liste:
  * Für Webex Meetings können Sie zwischen An einem nicht aufgeführten Meeting teilnehmen, Meine geplanten Meetings, oder Starten eines Sofort-Meetingswählen. Um auszuschließen, dass die Meeting-Liste auf der Site angezeigt wird, wechseln Sie in den Bereich Allgemeine Einstellungen und wählen Sie Sicherheit aus. Blättern Sie zum Dienst, um den Service zu ändern, und deaktivieren Sie das Kontrollkästchen Alle Sitzungen dürfen nicht aufgeführtsein.
  * Für Webex Events können Sie zwischen Nicht gelistetem Event beitreten, Event planen, oder Site Eventswählen.
  * Für Webex Training haben Sie die Wahl zwischen Einer nicht aufgeführten Sitzung beitreten oder Eine Sofortsitzung starten.
  * Für den Webex-Support ist die Startseite die Standardseite der Website.

 |  
| 5  |  Klicken Sie auf Speichern.  |  
## Ändern der Sitzungsendseite für Webex Meetings
Sie können die Startseite ändern, die den Nutzern nach Beendigung ihrer Webex-Sitzung angezeigt wird. Webex kann Gastgebern und Teilnehmern unterschiedliche Seiten anzeigen.  
| 1  |  Melden Sie sich bei Control Hub [https://admin.webex.com](https://admin.webex.com/login)an und gehen Sie zu Dienste. > Treffen, und wählen Sie Standorte.  |  
| --- | --- |  
| 2  |  Klicken Sie auf die Webex-Website und wählen Sie dann die Registerkarte Einstellungen aus.  |  
| 3  |  Klicken Sie im Abschnitt Meetings auf Site-Optionen.  |  
| 4  |  Ändern Sie den Schalter Standard-Host-Landingpage auf Benutzerdefinierte Seite verwenden.  |  
| 5  |  Geben Sie im Feld URL die URL der Seite ein, die den Hosts beim Beenden der Sitzung angezeigt werden soll.  |  
| 6  |  Ändern Sie den Schalter Standard-Teilnehmer-Landingpage auf Benutzerdefinierte Seite verwenden.  |  
| 7  |  Geben Sie im Feld URL die URL der Seite ein, die den Teilnehmern nach Sitzungsende angezeigt werden soll.  |  
| 8  |  Klicken Sie auf Speichern.  |  
## Weitere Optionen für Tagungsorte  
|  Option   |  Beschreibung   |  
| --- | --- |  
|  Standardmäßige Startseite des Gastgebers  |  Gibt die Seite an, die Gastgebern von Meetings nach dem Ende des Meetings angezeigt wird. Wählen Sie eine der folgenden Optionen aus: 
  * Standardseite mit WebEx-Branding verwenden: Zum Anzeigen der Webex-Standardseite. Um Werbung für kostenlose Webex-Testversionen anzuzeigen, wählen Sie Werbung anzeigenaus. 
  * Angepasste Seite verwenden: Geben Sie den URL einer anderen Seite an, die Gastgebern am Ende eines Meetings angezeigt werden soll. Das Protokoll (z. B. `https://`) ist in der URL nicht erforderlich.

 |  
|  Standardmäßige Startseite des Teilnehmers  |  Gibt die Seite an, die den Meeting-Teilnehmern am Ende eines Meetings angezeigt werden soll. Wählen Sie eine der folgenden Optionen aus: 
  * Standardseite mit WebEx-Branding verwenden: Zum Anzeigen der Webex-Standardseite. Um Werbung für kostenlose Webex-Testversionen anzuzeigen, wählen Sie Werbung anzeigenaus. 
  * Angepasste Seite verwenden: Geben Sie den URL einer anderen Seite an, die Teilnehmern am Ende eines Meetings angezeigt werden soll. Das Protokoll (z. B. `https://`) ist in der URL nicht erforderlich.

 |  
|  Beitrittsseite  |  Um Werbung für kostenlose Webex-Testversionen auf der Seite anzuzeigen, über die Gastgeber und Teilnehmer einem Meeting beitreten, wählen Sie Werbung anzeigen aus.   |  
|  Einladungs-E-Mail  |  Um in Einladungs-E-Mails Werbung für kostenlose Webex-Testversionen anzuzeigen, wählen Sie Werbung anzeigen aus.   |  
|  In-Meeting auf der Registerkarte „Informationen“  |  Aktiviert die Anzeige einer "grünen" Nachricht, die "Vielen Dank, dass Sie mit dem Online-Meeting zum Grün arbeiten".   |  
|  Alle Sitzungen automatisch mittels netzwerkbasierter Aufzeichnung aufzeichnen  |  Ermöglicht die automatische Aufzeichnung aller Sitzungen mit Network-Based Recording (NBR).  Diese Funktion ist nur verfügbar, wenn Sie die Aufnahmefunktion auf der Website aktiviert haben.   |  
|  Zulassen, dass Gastgeber die Aufzeichnungssteuerung während der automatischen Aufzeichnung verwendet  |  Ermöglicht es dem Gastgeber, während eines Treffens mit aktivierter automatischer Aufzeichnung Aufzeichnungssteuerungen wie Stopp oder Pause zu verwenden.  |  
|  Gastgeber dürfen Aufzeichnungen neu zuweisen, bearbeiten, deaktivieren und löschen.  |  Ermöglicht es den Gastgebern, die Aufzeichnungen aller Sitzungen zu verwalten.  |  
|  Eine E-Mail-Benachrichtigung an den Gastgeber senden, wenn der Meeting-Inhalt bereit ist  |  Legt fest, ob die Website eine E-Mail an die Hosts senden soll, wenn deren Aufnahmen fertig sind. Verwenden Sie es nicht, wenn die Option Alle Sitzungen automatisch aufzeichnen aktiviert ist.   |  
|  Aktivhalten der Telekonferenz aktivieren  |  Damit kann die Telefonkonferenz fortgesetzt werden, nachdem der Gastgeber das Meeting beendet hat.   |  
|  Standardeinstellung  |  Aktivieren oder deaktivieren Sie einen Standardwert für die Einstellung "Keep-Alive-Option für Telekonferenz".   |  
|  Meeting-Gastgeber darf ein Meeting verlassen, ohne das Meeting zu beenden   |  Gibt an, ob Meetings automatisch beendet werden, wenn der Gastgeber das Meeting verlässt.  |  
|  Internen Benutzer-Tag in Teilnehmerliste anzeigen  |  Schaltet um, ob in der Teilnehmerliste neben den Namen der Teilnehmer Ihrer Organisation der Indikator „Intern“ angezeigt wird.  |  
|  |
