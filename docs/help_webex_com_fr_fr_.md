Notifications de pause détente par AI Assistant
![Icône Produit](https://help.webex.com/images/helpdesk.svg)
Expérience client
Lorsqu’AI Assistant recommande une pause bien-être, une notification toaster s’affiche : Accepter une pause : Acceptez la pause en cliquant sur Faire une pause. Le widget Cisco AI Assistant s’ouvre automatiquement pour confirmer votre choix. Une fois votre interaction en cours terminée, votre pause bien-être d’une minute commence automatiquement. Votre statut passe à Pause bien-être, afin d’empêcher que la prochaine interaction ne vous soit attribuée. Un compte à rebours de 5 secondes s’affiche à l’écran à la fin de votre pause d’une minute. Une fois fini, la fenêtre de pause se ferme automatiquement et votre statut passe à Disponible, vous permettant ainsi d’être prêt pour la prochaine interaction.
