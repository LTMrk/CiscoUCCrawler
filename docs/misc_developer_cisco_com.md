Cisco Modeling Labs 
Cisco Modeling Labs is our premier platform for network simulation. With an easy-to-use HTML5 UI and a comprehensive API, Cisco Modeling Labs makes it fun to design, test, troubleshoot, and learn. 
  * [ Buy a license ](https://developer.cisco.com/modeling-labs/#team)
  * [ Read documentation ](https://developer.cisco.com/docs/modeling-labs/)


Welcome to the world of network simulation 
[![](https://pubhub.devnetcloud.com/media/cisco-modeling-labs-site/site/images/simulation/computer@2x.png)](https://developer.cisco.com/site/index)
Physical labs alone cannot keep pace with the changes in business and technology. That's where virtual labs come in. 
Cisco Modeling Labs provides you with an on-premise network simulation tool that runs on workstations and servers. You can quickly and easily simulate Cisco and non-Cisco networks, using real Cisco images that let you create highly reliable network simulations. 
As networks scale, your labs need to scale too 
[![](https://pubhub.devnetcloud.com/media/cisco-modeling-labs-site/site/images/labs/features.svg)](https://developer.cisco.com/site/index)
What's new in CML 2.10 
  * Integrate your preferred AI tool with CML's MCP Server, enabling you to interact with CML using natural language 
  * View packets in Wireshark while the packet capture is still running with Packet Capture Streaming 
  * Set Node Staging priorities on the nodes in your lab to control the order that CML starts them 
  * Flag labs that should be started automatically whenever CML starts up with Lab Autostart 
  * Set an Unmanaged Switch node to behave as a hub for SPAN support 
  * Configure Custom Icons for node types 
  * New Beta Features: RADIUS Authentication, Wireless Support 


[![](https://pubhub.devnetcloud.com/media/cisco-modeling-labs-site/site/images/labs/network.svg)](https://www.google.com)
