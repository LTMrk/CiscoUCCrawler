# Webex 앱 | 그룹에 참여
![list-menu](https://help.webex.com/images/feedback.svg)피드백이 있습니까?
Webex 앱에서 팀에 참여하는 유일한 방법은 관리자가 당신을 팀에 추가하는 것입니다. 가끔 프로젝트 또는 부서의 일원이기 때문에 그룹으로 추가되는 경우도 있습니다. 또는 함께 작업하는 사용자가 이미 멤버이기 때문에 그룹에 대해서 알고 있는 경우, 추가하도록 요청할 수 있습니다.   
|  다른 동료에게 연락하여 해당 사용자가 이미 사용하고 있는 그룹에 귀하를 추가하도록 요청하십시오. 또는 새로운 그룹을 시작하여 모든 사용자가 함께 작업하게 할 수도 있습니다.  참여하기 위해 사용 가능한 그룹을 검색할 수는 없습니다. 검색 결과는 이미 참여한 그룹만 표시합니다.  |
