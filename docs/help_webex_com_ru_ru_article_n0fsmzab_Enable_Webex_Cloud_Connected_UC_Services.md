# Включить или отключить службы Webex Cloud-Connected UC в Control Hub
![list-menu](https://help.webex.com/images/feedback.svg)Отправить обратную связь?
Включить службы облако Webex UC с подключением, такие как аналитика, управление сертификатами, эксплуатационные метрики, CTI и аналитические сведения о развертывании без границ, чтобы собрать информацию о локальном развертывании, а также просмотреть данные аналитики. Эти службы можно включить или отключить в зависимости от ваших требований.  
| 1  |  В представлении клиента в [Control Hub](https://admin.webex.com/) перейдите в раздел Службы > Connected UC. В карточке Управление UC щелкните Инвентарный список. Будет отображен список групп кластеров с описанием, состоянием, кластерами и узлами.  |  
| --- | --- |  
| 2  |  Щелкните Сведения рядом с группой кластеров, которой принадлежит узел. Будет отображена страница инвентарного списка с перечнем кластеров, принадлежащих выбранной группе кластеров.  |  
| 3  |  Щелкните Сведения рядом с кластером, которому принадлежит узел.  Будет отображено имя узла с указанием версии, продукта и состояния.  |  
| 4  |  Щелкните пиктограмму многоточия ... рядом с полем История событий и выберите Управление службами. Появится страница управления службами со списком таких служб, как аналитика, управление сертификатами, эксплуатационные показатели, CTI без границ и аналитические сведения о развертывании.  |  
| 5  |  Для включения необходимой службы воспользуйтесь кнопкой переключателя, а затем следуйте инструкциям на экране для ее включения.  |
