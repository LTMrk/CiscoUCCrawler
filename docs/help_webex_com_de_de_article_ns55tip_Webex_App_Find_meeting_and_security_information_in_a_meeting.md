# Webex-App | Meeting- und Sicherheitsinformationen in einem Meeting finden
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Wenn Sie sich in einem Raum angesetztes Meeting, einem Meeting in einem persönlichen Raum oder einem Meeting, das in einem Bereich gestartet wurde, haben Sie Zugriff auf Meeting-Informationen. Sie können diese Informationen mit anderen Personen teilen, die die Einladung verpasst haben oder Schwierigkeiten haben, dem Meeting bei beitreten. 
![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/460001-470000/460001-461000/460453.jpg)
  * [Desktop](https://help.webex.com/de-de/article/ns55tip/Webex-App-%7C-Meeting--und-Sicherheitsinformationen-in-einem-Meeting-finden#Cisco_Task_in_List_GUI.dita_059f4c3e-090c-44f6-b0b2-46f31608501b)
  * [Mobil](https://help.webex.com/de-de/article/ns55tip/Webex-App-%7C-Meeting--und-Sicherheitsinformationen-in-einem-Meeting-finden#Cisco_Task_in_List_GUI.dita_e311eb7d-b9f6-4526-ad87-bacef0bb0ecb)

  
| 1  |  Klicken Sie in angesetztes Meeting auf Meeting-Info.  |  
| --- | --- |  
| 2  |  Auf der Registerkarte Meeting-Informationen werden folgende Informationen angezeigt:
  * Meeting-Informationen kopieren
  * Registerkarte Allgemein 
  * Registerkarte Sicherheit

 |  
| 3  |  Auf der Registerkarte Allgemein können Sie die Meeting-Informationen wie folgt teilen:
  * Klicken Sie auf Den Meeting-Link kopieren, um nur den Meeting-Link zu kopieren.
  * Klicken Sie mit der rechten Maustaste auf den URL und anschließend auf Kopieren.

 |  
| 4  |  Die Registerkarte Sicherheit zeigt die Sicherheitsinformationen an und ob Ihr Meeting ein verschlüsseltes Meeting ist.  |  
| 5  |  Sie können die Sicherheitsinformationen wie folgt teilen:
  * Klicken Sie zum Kopieren auf den Sicherheitscode.
  * Kommunizieren Sie diesen Code an alle Teilnehmer, entweder mündlich oder in einer Nachricht außerhalb der App.

 |  
| 1  |  Tippen angesetztes Meeting Meeting-Namen oben im Bildschirm auf den Dropdown-Pfeil neben dem Meeting-Namen.   |  
| --- | --- |  
| 2  |  Auf der Registerkarte Allgemein können Sie die Meeting-Informationen auf eine der folgenden Arten mit anderen teilen:
  * Tippen ![Freigeben](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/443001-444000/443664.jpg) Sie auf und wählen Sie aus, wie Sie die Informationen freigeben möchten.
  * Tippen Sie auf das ![Link kopieren](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/458001-459000/458960.jpg) neben dem Meeting-Link und fügen Sie den Link in eine Webex-App-Nachricht oder eine E-Mail ein. 

 |  
| 3  |  Die Registerkarte Sicherheit zeigt Sicherheitsinformationen an und ob Ihr Meeting ein verschlüsseltes Meeting ist.  |  
| 4  |  Sie können den Sicherheitscode für andere freigeben, wenn Sie sicherstellen möchten, dass Ihr Meeting sicher ist. 
  * Drücken Sie lange auf den Sicherheitscode, um ihn zu kopieren und dann in eine Nachricht oder E-Mail ein.
  * Kommunizieren Sie diesen Code an alle Teilnehmer, entweder mündlich oder in einer Nachricht außerhalb der App.

Fragen Sie alle Meeting-Mitglieder, ob sie denselben Sicherheitscode sehen. Teilnehmer, die denselben Code nicht sehen, müssen dem Meeting möglicherweise erneut besuchen.   |
