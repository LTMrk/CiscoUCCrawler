## Twoja słuchawka
Seria Cisco IP DECT 6800 składa się z wielokomórkowej stacji bazowej Cisco IP DECT 210 i telefonu IP Cisco DECT 6825. System ten jest przeznaczony dla małych i średnich firm, a także dla dużych organizacji.
Seria Cisco IP DECT 6800 składa się z wielokomórkowej stacji bazowej Cisco IP DECT 210, słuchawki Cisco IP DECT 6825 i wzmocnionej słuchawki Cisco IP DECT 6825. System ten jest przeznaczony dla małych i średnich firm, a także dla dużych organizacji.
Seria telefonów IP Cisco DECT 6800 składa się z:
  * Wielokomórkowa stacja bazowa Cisco IP DECT 210
  * Jednokomórkowa stacja bazowa Cisco IP DECT 110
  * Wzmacniacz Cisco IP DECT 110
  * Słuchawka telefonu IP Cisco DECT 6822 — nie używaj
  * Słuchawka telefonu IP Cisco DECT 6825
  * Słuchawka wzmocniona do telefonu IP Cisco DECT 6825

Słuchawki komunikują się ze stacją bazową przy użyciu protokołu DECT (Digital Enhanced Cordless Telecommunications) w celu zapewnienia wszystkich funkcji związanych z połączeniami. Słuchawka musi być w zasięgu stacji bazowej, aby działała poprawnie. 
Słuchawki komunikują się ze stacją bazową przy użyciu protokołu DECT (Digital Enhanced Cordless Telecommunications) w celu zapewnienia wszystkich funkcji związanych z połączeniami. Słuchawka musi być w zasięgu stacji bazowej, aby działała poprawnie. Gdy słuchawka znajduje się poza zasięgiem stacji bazowej, zostanie wyświetlony alert i będzie konieczny powrót do zasięgu, aby móc wykonywać połączenia. 
Jeśli konieczne jest użycie słuchawki w środowisku niebezpiecznym, pełnym kurzu lub wilgoci, można użyć wzmocnionej słuchawki telefonu IP Cisco DECT 6825. Ta słuchawka jest oznaczona jako IP65, co oznacza, że jest uszczelniona i chroniona przed kurzem i wodą. 
W tym dokumencie termin _telefon_ oznacza słuchawkę, a termin _system_ oznacza słuchawkę, wzmacniacz i stację bazową.
Słuchawka może nie obsługiwać wszystkich funkcji. Aby uzyskać informacje na temat obsługiwanych funkcji, skontaktuj się z dostawcą usług.
