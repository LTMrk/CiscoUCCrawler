## Introduction
This document describes the configuration of Specific License Reservation (SLR) features which are introduced in CVP and UCCE version 12.6.2.
## Prerequisites
### Requirements
Cisco recommends that you have knowledge of these topics:
  * Unified Contact Center Enterprise (UCCE)
  * Customer Voice Portal (CVP)


### Components Used
The information in this document is based on these software versions:
  * CVP Noamp
  * UCCE - Single Pane of Glass (SPOG)
  * CSSM (Cisco Smart Software Manager)


The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Configure
SLR 
  * Allows you to reserve the licenses from the virtual account, tie them to the UDI of the device, and then use the device with the reserve licenses in the disconnected mode.
  * SLR Feature is for highly secure networks and other devices that cannot or do not connect to Cisco.
  * Devices that are registered with smart license share device information at regular intervals with Cisco Smart Software Manager (CSSM).
  * Cisco offers license reservation as on-request configuration for these devices.

## Procedure
### Specific License Reservation (SLR)
Step 1: To configure Specific License Reservation (SLR) on CVP 12.6.2, Log in to **CVP Noamp** , navigate to **License Management****>** **License Settings**.
Step 2: Click **Enable Reservation** check box and then click **Save** button.
[![Specific License Reservation](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-03.png "Specific License Reservation")
Step 3: Registration Status is **Unregistered – Reservation Enabled**.
[![License Management](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-04.png "License Management")
Step 4: Click **Register** , and under Reserve Licenses window, click **Request Reservation Code**. It generates a Request Code. Copy this Request code and Log in to **Cisco Smart Software Manager** **(CSSM)** , and paste this Request code on CSSM portal to generate the Authorization Code for SLR.
[![Reserve Licenses](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-05.png "Reserve Licenses")
Step 5: Navigate to**CSSM** **portal**. Click **License Reservation** tab.
[![Smart Software Licensing](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-06.png "Smart Software Licensing")
Step 6: Paste the Request code in **Reservation Request code** window and click **Next**. 
[![Smart License Reservation Step 1](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-07.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-07.png "Smart License Reservation Step 1")
Step 7: Select **Reserve a Specific Licenses** and enter the number of licenses you want to Reserve.
[![Smart License Reservation Step 2](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-08.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-08.png "Smart License Reservation Step 2")
Step 8: Review and Confirm the license reservation on CSSM and click **Generate Authorization code**.
[![Smart License Reservation Step 3](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-09.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-09.png "Smart License Reservation Step 3")
Step 9: **Copy** and also make sure to **Download** the Authorization Code. It is advised to download the authorization code so that if you want to update **License Reservation** or **Return Reservation** in future, you can use this Authorization Code.
[![Smart License Reservation Step 4](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-10.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-10.png "Smart License Reservation Step 4")
Step 10: Navigate to **Reserve Licenses** window on **CVP** and paste the Authorization Code, and click **Reserve** to complete the reservation.
[![Reserve Licenses Auth Code](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-11.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-11.png "Reserve Licenses Auth Code")
**Note** : To **Update** or **Return** the license reservation, click the **Action** button and select **Update Reservation** or **Return Reservation** (as shown in this screencapture) respectively.
[![License Management Update/Return Reservation](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-12.png)](https://www.cisco.com/c/dam/en/us/support/docs/contact-center/unified-contact-center-enterprise-1262/221117-configure-smart-license-specific-license-12.png "License Management Update/Return Reservation")
