# Een test toevoegen wanneer u een trainingssessie plant
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Wanneer u een trainingssessie plant, kunt u een test toevoegen om de kennis van de deelnemers te evalueren. 
Tijdens het plannen van een trainingssessie kunt u alleen tests toevoegen die u al hebt gemaakt en hebt opgeslagen in de Testbibliotheek.   
| 1  |  Selecteer  Tests > test toe te voegen.   |  
| --- | --- |  
| 2  |  Selecteer een test waarop u uw nieuwe test wilt baseren en selecteer  Volgende .   |  
| 3  |  Typ een naam voor uw nieuwe test, selecteer de opties voor het afleveren van de test en klik vervolgens op Opslaan.  Zie Opties voor het afnemen van tests voor een geplande trainingssessie voor meer informatie.  |  
| 4  |  Herhaal deze stappen als u meerdere tests wilt toevoegen aan uw trainingssessie.   |  
| 5  |  Selecteer  Plannen  of Bijwerken.   |
