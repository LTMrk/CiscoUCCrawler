[ Learn more ](https://developer.webex.com/mcp/docs/federated-through-external-registry-mcp-servers#orgx)
Agentic App by [useorgx](https://www.useorgx.com/)
OrgX provides coordination infrastructure for AI-native teams, acting as a persistent organizational layer for your LLMs. It allows AI agents to maintain "organizational memory," ensuring context like initiatives, milestones, and decisions persists across different AI tools and sessions. With 61 integrated tools, OrgX enables your assistant to scaffold initiatives by decomposing goals into workstreams, manage human-in-the-loop decision workflows with audit trails, and delegate tasks to specialist agents across Engineering, Marketing, and Sales. To get started, visit useorgx.com to set up your workspace, then connect the hosted MCP server using the URL <https://mcp.useorgx.com/> or the command npx mcp-remote <https://mcp.useorgx.com/>. Usage requires a Webex license, an OrgX account, and an MCP-compatible AI client. OrgX offers various tiers for solo founders and enterprise teams; visit useorgx.com/#pricing for details.
