## Introduction
This document describes the procedure for the integration of Microsoft Office 365 with Cisco Unity Connection (CUC). 
## Prerequisites
### Requirements
Cisco recommends that you have knowledge of Cisco Unity Connection (CUC), Release 8.x and later.
### Components Used
The information in this document is based on CUC Release 8.x and later.
The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Background Information
The implementation of this feature is documented in the [Unified Messaging Guide for Cisco Unity Connection Release 12.x.](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/connection/12x/unified_messaging/b_12xcucumgx/b_12xcucumgx_chapter_01.html)
## Configure
This section provides the procedure to integrate Unity Connection with Office 365. This document provides only the minimum required steps.
## Office 365
The steps required on Office 365 are:
  1. Log in to the [Office 365 portal](https://www.office.com/) with an Admin account. 
  2. From the **Admin** drop-down list, choose **Office 365**. 
[![Select Office 365 from Drop-down](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-00.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-00.png "Select Office 365 from Drop-down")
  3. On the Dashboard, click **Add new users**. 
[![Add New Users](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-01.png "Add New Users")
  4. Create a new **User** **account**. This is the Unified Messaging Service account used by CUC in order to access the User mailbox. 
[![Create New User Account](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-02.png "Create New User Account")
  5. Choose **Users > Active Users** in order to locate the User account. 
[![Select Active Users](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-03.png "Select Active Users")
  6. From the **Admin** drop-down list, choose **Exchange** in order to set the Application Impersonation rights. 
[![Select Exchange](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-04.png "Select Exchange")
  7. In the Exchange Admin Center, choose **permissions**. Click **admin roles** and then click the **+** symbol in order to add a new admin role group membership. 
[![Assign Permissions](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-05.png "Assign Permissions")
  8. Create the new Role Group. 
    1. In the Name field, enter a **name**. Call it ApplicationImpersonationRG for ease of identification.
    2. In the Description field, enter a **description**. This is an optional field
    3. In the Roles section, click the **+** symbol and choose **ApplicationImpersonation**.
    4. In the Members section, click the **+** symbol and choose **um**. This is the user created earlier for the Unified Messaging Service Account.
[![Choose ApplicationImpersonation and Add Members](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-06.png "Choose ApplicationImpersonation and Add Members")


## Unity Connection
The steps required on CUC are listed here. The same procedure is documented in the [Unified Messaging Guide for Cisco Unity Connection Release 12.x and Later](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/connection/12x/unified_messaging/b_12xcucumgx/b_12xcucumgx_chapter_01.html).
  1. Create a Unified Messaging (UM) Service. 
    1. Choose **Unified Messaging > Unified Messaging Services**. Click **Add New**.
    2. In the Type field, enter **Office 365**.
    3. In the Display Name field, enter a **Display Name** in order to identify this UM Service.
    4. In the Proxy Server (Address:Port) field, enter a **Proxy Server address** if the Unity Connection server cannot access the Office 365 servers in the cloud.
    5. In the Hosted Exchange Servers section, choose **Search for Hosted Exchange Servers**. This is mandatory. Specify the Hosted Exchange Server is not supported since the IP Address or the Hostname of the server in the cloud is not known.
    6. In the Active Directory DNS Domain Name field, enter the **domain name** provided by Office 365. See the [Select the Active Directory DNS Domain Name](https://www.cisco.com/c/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00.html#anc7) section for more information.
    7. In the Account Used to Access Exchange section, enter the **Unified Messaging Service Account information** created previously.
    8. Leave the selections under Service Capabilities section as is and **Save**. 
[![Edit Unified Message Service](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-07.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-07.png "Edit Unified Message Service")
**Note** : You can configure up to 1800 users with a single Office 365 Unified Messaging Service. To allow more than 1800 users to use Office 365, create additional Unified Messaging services.
  2. Associate the User with the Unified Messaging Service. 
    1. Choose **Users > Users**. Choose the **User**.
    2. Choose **Edit > Unified Messaging Account**. Click **Add New**.
    3. In the Unified Messaging Service field, select the **newly created service** from the drop-down list.
    4. In the User This Email Address field, enter the **email address** of the Office 365 mailbox. This email address can be either user@<OrganizationDomainName>.onmicrosoft.com or user@<OrganizationDomainName>.com based on the deployment model.
    5. Click **Save**. 
[![Unity Connection](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-08.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-08.png "Unity Connection")
    6. Validate the configuration with the test option. 
[![Validate with Test Option](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-09.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-09.png "Validate with Test Option")
    7. Repeat the same procedure for all users. You can also use the Bulk Administration Tool in order to update all users in bulk. Read the [Unity Connection FAQ: How do I Bulk Assign Unified Messaging in Cisco Unity Connection](https://www.cisco.com/c/en/us/support/docs/voice-unified-communications/unity-connection/116049-qanda-unity-connect-bat-00.html) document for more information.
  3. Enable UM. 
    1. Choose **Class Of Service > Class of Service**.
    2. In the Display Name drop-down list, choose **Voice Mail User COS**. This is the default Class of Service (CoS) associated with all users. If users are associated with a different CoS, choose the appropriate selection.
    3. Check the **Allow Users to Access Voicemail Using and IMAP Client and/or Single Inbox** checkbox.
    4. **Save**. 
[![Edit the Class of Service](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-10.png)](https://www.cisco.com/c/dam/en/us/support/docs/unified-communications/unity-connection/118828-config-cuc-00-10.png "Edit the Class of Service")


### Select the Active Directory DNS Domain Name
The Domain name is the one that is provided by Office 365. It can be in the form of <name>.onmicrosoft.com. In this example, the mailboxes are in the calobgl.onmicrosoft.com domain.
In the Unified Messaging Services configuration, use either calobgl.onmicrosoft.com or outlook.office365.com as the domain name. Either one can work fine. The only difference is in the Autodiscover URL that Unity Connection uses in order to discover the mailbox.
