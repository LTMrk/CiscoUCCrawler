## Introduction
This document describes the step-by-step process to configure and troubleshoot MeetingApp for File sharing on Cisco Meeting Server (CMS).
Contributed by Vikas Kumar, Sateesh Katukam, Aviral Pal, Cisco TAC Engineers.
## Prerequisites
### Requirements
Cisco recommends that you have knowledge of these topics:
  * Understanding of CMS API for meetingapps configuration
  * Cisco Meeting Server version 3.5 and later


### Components Used
The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Background Information
  * MeetingApp service has been introduced to support file sharing from version 3.5 Web App ,meeting participants can share files in the meeting.
  * MeetingApps service must be configured in stand alone Meeting Server node and no other services must be running on this node,MeetingApps can be configured on DMZ network for external users and internal also depending upon the requirement.
  * MeetingApps service must be deployed in the DMZ network for external users to share files and must be assigned public IP and firewall ports must be opened on DMZ for public access. The MeetingApps service can be configured on a Meeting Server 1000 or Meeting Server on VM deployments.
  * Only a signed-in web app user with appropriate permissions can share files in a meeting.
  * File sharing supports a maximum of 5 files with a size limit of 10MB each at a time.
  * The shared file is available for download only during the meeting. Participants joining after a meeting has started can only view or download the files that are shared after they joined the meeting.
  * exe files cannot be shared.
  * MeetingApps services cannot be configured on a Meeting Server 2000.
  * File share feature does not work if your cluster has a Meeting Server 2000 deployment.

Web Bridges in your environment must be configured to talk to MeetingApps in order to upload or download the files shared in the meeting.
## Configure
Follow these steps to configure:
1. SSH into the MMP and log in.
  
2. Configure the interface and port used by MeetingApps to communicate using the command
**meetingapps https listen <interface> <port>**
[![vikasku8_1-1659425858413](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-01.png "vikasku8_1-1659425858413")
3. Configure the certificate key pair for the MeetingApps using the command 
**meetingapps https certs <key-file> <crt-fullchain-file>**
[![vikasku8_2-1659426139144](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-02.png "vikasku8_2-1659426139144")
4. Generate the secret key using the command:  
**meetingapps gensecret**
  
Copy the generated key to later configure the Web Bridge (at Step 7). Everytime the command is executed, a new secret key is generated and Web Bridge must be configured with the new key.
[![vikasku8_3-1659426212491](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-03.png "vikasku8_3-1659426212491")
5. Enable the MeetingApps service using the command  
**meetingapps enable**
[![vikasku8_11-1659433252291](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-04.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-04.png "vikasku8_11-1659433252291")
6. Before configuring the Web Bridge to connect to MeetingApps, all the Web Bridges must be disabled using the command 
**webbridge3 disable**
[![vikasku8_5-1659426255129](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-05.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-05.png "vikasku8_5-1659426255129")
7. All the Web Bridges in your setup need to communicate with the MeetingApps to upload or download files shared in the meeting. Configure the Web Bridge to connect to the MeetingApps using the command
**webbridge3 meetingapps add <hostname> <port> <secretkey>**
[![vikasku8_1-1659442065258](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-06.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-06.png "vikasku8_1-1659442065258")
8. Enable all the Web Bridges using the command  
**webbridge3 enable**
9. Sharing files in a meeting : API parameter**fileReceiveAllowed** ( true|false ) has been introduced to enable or disable the file share at the callProfile level or Call level.
Set **fileReceivedAllowed** to **true** in callProfile and assign to cospace or system level.
[![sakatuka_0-1659541940651](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-07.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-07.png "sakatuka_0-1659541940651")
10. File Upload Allowed : API parameter**fileUploadAllowed** ( true|false ) has been introduced to enable user to allow share file or not in thecallLegProfile
Set **fileUploadAllowed** to**true** in callLegProfile and assign to cospace or system level.
[![sakatuka_1-1659542144327](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-08.png)](https://www.cisco.com/c/dam/en/us/support/docs/conferencing/meeting-server-1000/218117-configure-and-troubleshoot-meetingapps-f-08.png "sakatuka_1-1659542144327")
