## 기본 시간대 지정
Webex 서비스 사이트의 기본 시간대를 설정합니다. 미팅의 시작 및 종료 시간을 포함하여 모든 시간은 선택된 시간대로 나타납니다. 사용자는 계정을 요청할 때 또는 내 Webex의 내 프로필 페이지에서 자신의 시간대를 선택하여 이 설정을 덮어쓸 수 있습니다.   
| 1  |  Webex 사이트 관리에 로그인하고 구성 > 공통 사이트 설정 > 옵션으로 이동합니다.   |  
| --- | --- |  
| 2  |  사이트 옵션 섹션의 시간대 드롭다운 목록에서 시간대를 선택합니다.   |  
| 3  |  이메일 및 웹 페이지에 시간대에 대한 GMT 오프셋을 표시하려면 이메일 및 웹 페이지에 시간대의 GMT 오프셋 표시 체크 상자를 체크합니다.   |  
| 4  |  업데이트를 선택합니다.   |  
## 목록에서 항목 수를 지정  
| 1  |  Webex 사이트 관리에 로그인하고 구성 > 공통 사이트 설정 > 옵션으로 이동합니다.   |  
| --- | --- |  
| 2  |  사이트 옵션 섹션의 페이지당 나열 항목 수 상자에 표시할 항목 수를 입력합니다.   |  
| 3  |  업데이트를 선택합니다.   |  
## 상단 네비게이션 바 변경
이 절차는 기업판 사이트 전용입니다. 
Webex 기업판 사이트의 상단에 나타나는 내비게이션 바의 버튼 순서를 변경할 수 있습니다.   
| 1  |  Webex 사이트 관리에 로그인하고 구성 > 공통 사이트 설정 > 옵션으로 이동합니다.   |  
| --- | --- |  
| 2  |  상단 네비게이션 바 구성 섹션까지 스크롤 다운합니다.  사이트에서 사용할 수 없는 서비스는 괄호 ()로 나타납니다.   |  
| 3  |  사이트에 대해 활성화되지 않은 서비스를 목록에 포함하려면 이 사이트에 허용되지 않은 모든 서비스 표시 박스를 체크합니다.  사이트 관리는 사이트 관리 권한를 가진 호스트에게만 보입니다.   |  
| 4  |  네비게이션 바에 나타나는 버튼의 순서를 변경하려면 서비스를 선택한 후 위로 이동 또는 아래로 이동 버튼을 선택합니다.   |  
| 5  |  업데이트를 선택합니다.   |  
## 내 Webex의 왼쪽 네비게이션 링크 사용자 정의  
| 1  |  Webex 사이트 관리에 로그인하고 구성 > 공통 사이트 설정 > 옵션으로 이동합니다.   |  
| --- | --- |  
| 2  |  내 Webex에 대한 왼쪽 네비게이션 바 사용자 정의 섹션까지 스크롤 다운합니다.   |  
| 3  |  추가할 링크 유형(사용자 정의, 파트너 또는 지원 및 교육)과 관련된 섹션을 선택합니다.  |  
| 4  |  메뉴 항목 이름 필드에서 링크의 이름을 입력합니다.   |  
| 5  |  사용자가 링크를 클릭할 때 표시할 URL을 입력합니다.  URL에 "http://"를 포함하지 않아도 됩니다.   |  
| 6  |  대상 창 목록에서 웹 페이지 또는 문서가 열리는 방법을 선택합니다.
  * **새 창** : 새로운 브라우저 창에서 페이지를 열려는 경우. 
  * **기본** : 프레임을 사용하는 웹 페이지의 기본 프레임에서 페이지를 열려는 경우. 
  * **상위** : 프레임을 사용하는 웹 페이지의 상위 프레임에서 페이지를 열려는 경우. 
  * **상단** : 프레임을 사용하는 웹 페이지의 최상위 프레임에서 페이지를 열려는 경우. 

 |  
| 7  |  (선택 사항) 사용자 정의 또는 파트너 링크에 대해 링크의 위치에 클릭할 수 있는 이미지를 표시하려면 찾아보기를 선택하고 컴퓨터에서 이미지 파일을 선택합니다. 이미지 파일은 최대 25 X 25 픽셀일 수 있습니다.  |  
| 8  |  업데이트를 선택합니다.   |

## Webex 홍보 콘텐츠 숨기기
이 절차는 Webex Meetings, Webex Events, Webex Training 및 Webex Support에만 적용됩니다.
표준 Webex 세션 종료(랜딩) 페이지, 참여 페이지, 초대 이메일 메시지 등의 특정 페이지에는 Webex 기능을 소개하는 메시지가 포함됩니다. 이 절차를 사용하여 해당 페이지에서 이 홍보 콘텐츠를 제거할 수 있습니다.  
| 1  |  Webex 사이트 관리에 로그인하고 다음 중 하나로 이동합니다.
  * 구성 > Webex Meetings
  * 구성 > Webex Events > 옵션
  * 구성 > Webex Training

 |  
| --- | --- |  
| 2  |  사이트 옵션 섹션에서 홍보 콘텐츠를 표시하지 않을 각 항목에 대해 홍보 콘텐츠 보이기를 체크 해제합니다.   |  
| 3  |  (Webex Events 전용) Webex Events 홍보 페이지를 변경하려면 프로모션 섹션까지 스크롤 다운하고 프로모션 페이지 URL에 새 페이지 URL을 입력합니다.   |  
| 4  |  업데이트를 선택합니다.   |
