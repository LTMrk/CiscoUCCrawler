# Für Regierung bei Webex anmelden
![list-menu](https://help.webex.com/images/feedback.svg)Feedback?
Sie können sich über die von Ihrem Administrator bereitgestellte Version bei der Webex-App anmelden. Sie können auch die kommerzielle Webex-App umleiten, um Webex for Government zu starten. 
![Webex für Desktop- und Mobil-Anmeldebildschirme der Regierung](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/460001-470000/468001-469000/468924.jpg)**_Anmeldebildschirme von Webex for Government_**
  * [Für Regierung bei Webex anmelden](https://help.webex.com/de-de/article/b7urh8/F%C3%BCr-Regierung-bei-Webex-anmelden#Cisco_Task.dita_d0324c16-0bb5-4191-afc9-ea8b5c379056)
  * [Wechseln von der kommerziellen Webex-App](https://help.webex.com/de-de/article/b7urh8/F%C3%BCr-Regierung-bei-Webex-anmelden#Cisco_Task.dita_f8b28eb6-fe00-420f-87f4-406adb003ce9)


Ihr Administrator stellt möglicherweise eine benutzerdefinierte Installation der Webex-App zur Verfügung, die für die Regierung von Webex vorkonfiguriert ist.  
| 1  |  Starten Sie die Webex-App.  Der Anmeldebildschirm zeigt das FedRamp-Logo und Webex for Government als vorab ausgewählt an.  |  
| --- | --- |  
| 2  |  Klicken Sie auf Anmelden, und geben Sie Ihre Anmeldeinformationen ein.  |  
Sie können innerhalb der Webex-App von der kommerziellen Webex-App zu Webex for Government wechseln.  
| 1  |  Starten Sie die Webex-App.  Auf dem Anmeldebildschirm werden das Webex-Logo und Webex ausgewählt angezeigt.  |  
| --- | --- |  
| 2  |  Klicken Sie auf den Abwärtspfeil neben Webex, und wählen Sie in der Liste Webex für die Regierung aus. Die Webex-App wird neu gestartet, damit Sie zur FedRAMP-Anmeldeseite gehen.   |  
| 3  |  Geben Sie Ihre E-Mail-Adresse ein und aktivieren Sie Ich stimme den Geschäftsbedingungen zuund klicken Sie dann auf Weiter, um sich zu anmelden. Wenn Sie sich zum ersten Mal anmelden, müssen Sie ein Passwort einrichten.  |
