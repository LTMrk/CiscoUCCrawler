# Webex-appen | Konfigurera ditt personliga rum
![list-menu](https://help.webex.com/images/feedback.svg)Har du feedback?
Om du har ett Webex-konto kan du använda ditt personliga rum för dina möten. Om det inte redan är konfigurerat för dig kan du göra det själv. Om du har flera personliga rum kan du välja vilket du vill använda. 
  * [Desktop](https://help.webex.com/sv-se/article/e7l52d/Webex-appen-%7C-Konfigurera-ditt-personliga-rum#id_81518)
  * [Mobil](https://help.webex.com/sv-se/article/e7l52d/Webex-appen-%7C-Konfigurera-ditt-personliga-rum#task_58E9BC717CEB9E3B828F9DC4BA4B570B)


Ditt personliga rum kan redan vara konfigurerat i Webex-appen. För att kontrollera, gå till Möten så bör du se länken till ditt personliga rum högst upp på skärmen. Om det är så är allt klart och du behöver inte göra något.
Om du istället ser Konfigurera Mitt personliga rum, följ dessa steg för att konfigurera den.  
| 1  |  Gå till Möten och klicka på Konfigurera Mitt personliga rum .  |  
| --- | --- |  
| 2  |  Ange länken till det personliga rummet i formatet `https://` eller `company` och ange sedan din värd-PIN-kod. När du tillhör flera Webex-webbplatser och därmed har flera personliga rum kan du lägga till det rum du föredrar att associera med Webex-appen.  Du kan se din länk till ditt personliga rum och din värd-PIN på din Webex-webbplats. Logga in på din Webex-webbplats, gå till Inställningar > Mitt personliga rum. Om en länk till ett personligt rum och värd-PIN-koden inte visas där har ett personligt rum inte aktiverats på din webbplats. Kontakta din systemadministratör.  |  
| 3  |  Klicka på Spara.  |  
Ditt personliga rum kan redan vara konfigurerat i appen. För att kontrollera detta, gå till Möten ![Mötesknapp](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/420001-421000/420217.jpg)och tryck på Mitt personliga rum. Om länken till ditt personliga rum redan visas under INFORMATION OM PERSONLIGT RUM är allt klart och du behöver inte göra någonting.
Om du inte ser länken till ditt personliga rum följer du instruktionerna för att konfigurera din Windows- eller Mac-app.
