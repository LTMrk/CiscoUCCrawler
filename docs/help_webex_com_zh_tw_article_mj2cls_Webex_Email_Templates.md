## Webex Meetings電子郵件範本格式 
從 WBS39.5 更新開始，對 Webex Meetings 邀請範本進行了以下更新。
如果您變更了自訂 Webex Meetings 電子郵件範本中的變數，則可能會看不到以下某些更新。每個電子郵件範本包含各自的變數集。不支援在電子郵件主旨和內文之間複製和貼上變數或將變數從一個範本複製和貼到另一個範本。變數在多個範本中不是共用的。
  * 已移除新增到行事曆功能。使用者可以按兩下 ICS 附件以將邀請加入其行事曆中，或者在其電子郵件應用程式中接受會議邀請。
  * 對於透過 Webex 網站上的會議安排程式安排的會議，電子郵件範本現在預設採用 iCalendar 格式；如果您不想使用 iCalendar 格式，可以將其關閉。
  * 如果您使用 啟用視訊平台版本 2 的短 URL，則 _使用 Microsoft Lync 或 Microsoft Skype for Business 加入_ 部分將與 _從視訊系統或應用程式加入_ 部分合併，因為視訊系統和 Lync 或 Skype for Business 使用相同的視訊位址。
![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/437001-438000/437579.jpg)
  * 加入會議的鏈結已替換為按鈕。您可以變更電子郵件範本中的 HTML，並使用加入鏈結替換加入按鈕代碼。
  * Meeting Center Invitation PCM(Productivity Tools) Cisco WebEx 電子郵件範本已棄用，因為它僅適用於 Mac。我們合併了 Windows 和 Mac 電子郵件範本 MC MeetingInfo For Attendee_PCM（生產力工具）。如果 Mac 和 Windows 使用者使用不同的電子郵件範本，則 Windows 電子郵件範本會覆寫 Mac 電子郵件範本。 
  * 如果網站管理員不想利用新的使用者體驗，則可以關閉網站的這個功能。


## Webex Events 電子郵件範本格式
從 WBS39.7.4 更新開始，以下更新已套用至大多數 Webex Events 電子郵件邀請範本，其中包括自訂電子郵件範本。所有其他自訂設定保持不變。
視覺按鈕和對所有 Webex Meetings 範本的 iCalendar 變更也適用於大多數 Webex 範本，行為如下所示：
  * 尚未修改自訂範本的現有客戶不受影響。
  * 希望繼續自訂其範本的使用者，應該先還原為預設電子郵件範本，然後再更新其範本。
  * 使用者無法再以 WBS39.7 及其之前版本中存在的方式，透過直接上傳將頁首或頁尾影像新增至邀請。從 WBS39.7.4 開始，使用者可以在自訂模板時直接透過變更 HTML 程式碼來新增頁首和頁尾圖片。

![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/439001-440000/439379.png)
鎖定使用者和非鎖定使用者均會收到此變更。
