## Introduction
  
This article describes the scenario where unable to change the HDD’s state from Unconfigured good to JBOD as the pass through controller UCSC-SAS12GHBA supports only JBOD mode 
## Prerequisites
### Requirements
There are no specific requirements for this document.
### Components Used
  * UCSC-C220-M4L
  * CIMC: 3.0.3a
  * 2xUCS-HD12TB10KHY-E
  * RAID controller : Pass through UCSC-SAS12GHBA


The information in this document was created from the devices in a specific lab environment. All of the devices used in this document started with a cleared (default) configuration. If your network is live, ensure that you understand the potential impact of any command.
## Background Information
Refer the UCSC-240C-M4L specification [here](https://www.cisco.com/c/dam/en/us/products/collateral/servers-unified-computing/ucs-c-series-rack-servers/c220m4-lff-spec-sheet.pdf)

## **Troubleshooting steps**
1. UCS-HD12TB10KHY-E is supported with controller UCSC-SAS12GHBA as per the spec sheet of UCSC-C220-M4L.  
<https://www.cisco.com/c/dam/en/us/products/collateral/servers-unified-computing/ucs-c-series-rack-servers/c220m4-lff-spec-sheet.pdf>
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/216118-unable-to-change-hdd-status-from-unconfi-01.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/216118-unable-to-change-hdd-status-from-unconfi-01.png "Related image, diagram or screenshot.")
2. There is no Option in the CIMC>Inventory>Storage>Controller/VD properties to set/change the HDD status to JBOD.
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/216118-unable-to-change-hdd-status-from-unconfi-02.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/216118-unable-to-change-hdd-status-from-unconfi-02.png "Related image, diagram or screenshot.")
3. Check the status of the controller settings from the CLI and the controller shows JBOD is Enabled:
[![](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/216118-unable-to-change-hdd-status-from-unconfi-03.png)](https://www.cisco.com/c/dam/en/us/support/docs/servers-unified-computing/ucs-c-series-rack-servers/216118-unable-to-change-hdd-status-from-unconfi-03.png "Related image, diagram or screenshot.")
4. No option is avaialble from CIMC CLI to change/set the HDD status to JBOD.
5. When the server reboots, it prompts to select CTRL+C to get into to web bios utility of UCSC-SAS12GHBA.  
But there is no option from webbios as well to change the physical drive status.
## **Resolution**
The HDD's will remain in 'Unconfigured Good' state when managed by Pass through controller UCSC-SAS12GHBA.
After an install of Windows 2012 R2 on the Unconfogured good drive - HDD#1 and the installation completed.
Post the Installation the drive - HDD#1 continued to remain in Unconfigured Good state.
