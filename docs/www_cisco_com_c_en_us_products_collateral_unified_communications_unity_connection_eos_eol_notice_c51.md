Cisco announces the **end-of-life** for Cisco Unity Connection 11.0 software.
**Software maintenance** will not be available for the stated software version beyond **August 1, 2018**.
SW Maintenance releases will be made available via **Version 11.5**.
Software maintenance and application software support requires an active service contract.
Product Migration Options
Customers are encouraged to migrate to Cisco Unity Connection 11.5 software. The software can be downloaded from CCO.
